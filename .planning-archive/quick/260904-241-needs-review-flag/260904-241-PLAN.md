# 레슨별 "더 공부하기" 표시 기능

## 무엇을 만드나

레슨마다 "이 레슨은 더 공부해야 함"을 표시(토글)할 수 있게 한다. 표시하면:

1. 완료 영역에 그 상태가 남는다(다른 기기에서도 유지 — 서버 저장).
2. "클로드에 물어보기" 버튼이 시각적으로 강조된다.
3. 복사되는 프롬프트에 "이 레슨은 내가 더 공부해야 하는 부분"임을 명시하는
   블록이 추가되어, 선생님(클로드)이 더 꼼꼼히 가르치도록 지시한다.

## 설계 결정

TIL 기능(quick 260902-0rz)을 **그대로 미러링**한다. TIL과 같은 경로:
`lesson_note` 테이블의 컬럼 → note-store 함수 → 새 actions 파일 → `/api/progress`
`lesson` 객체 → progress-provider 타입 → 슬롯 → 클라이언트 아일랜드.

- 저장 위치: `lesson_note.needs_review boolean not null default false`.
  완료 여부와 무관하게(완료 안 한 레슨도 표시 가능) 한 slug당 한 행을 공유하는
  `lesson_note`가 자연스럽다. `progress` 테이블은 "행 존재 = 완료"라 재사용 불가.
- 게이트 주의:
  - G4는 `actions.ts`의 식별자 위치를 고정 → 새 액션은 **별도 파일**
    `needs-review-actions.ts`로 만든다(til-actions.ts와 동일 이유).
  - G14/G21: `/api/progress/route.ts`는 hasUnlockCookie가 readCompletedLessonIds
    보다 먼저, no-store 유지 → 필드만 추가하고 순서·헤더 불변.
  - G9: 레슨 page.tsx에 쿠키/진도 식별자 추가 금지 → 슬롯 컴포넌트만 추가.
  - G23: progress-provider.tsx에 loading 상태 리터럴 추가 금지 → 타입 필드만 추가.

## 작업(원자적 커밋 단위)

### Task 1 — 데이터 계층 (needs_review 컬럼 + store 읽기/쓰기)
- `supabase/migrations/2026090416xxxx_add_needs_review_to_lesson_note.sql`:
  `alter table public.lesson_note add column if not exists needs_review boolean not null default false;`
  (til 마이그레이션과 같은 "검토용 사본 + 멱등" 주석)
- 라이브 Supabase 테이블에도 같은 컬럼을 실제 적용(관리 API).
- `src/lib/note-store.ts`:
  - `NoteRead` 성공 타입에 `needsReview: boolean` 추가.
  - `readLessonNote`가 `needs_review`도 select, `data?.needs_review ?? false` 반환.
  - `saveLessonNeedsReview(slug, next)` 추가 — `needs_review`만 upsert(body/til 보존,
    saveLessonTil와 동형, WR-01).
- **files:** supabase/migrations/…, src/lib/note-store.ts
- **verify:** `npm run build`(타입) 통과, 게이트 스크립트 통과
- **done:** readLessonNote가 needsReview를 돌려주고, saveLessonNeedsReview가 존재

### Task 2 — 서버 액션 + API + provider 타입
- `src/app/lesson/[lessonId]/needs-review-actions.ts` (신규, 'use server'):
  `setLessonNeedsReviewAction(lessonId, next: boolean)` —
  hasUnlockCookie → getLessonBySlug → saveLessonNeedsReview (til-actions.ts와 동형).
- `src/app/api/progress/route.ts`: `ProgressLesson`에 `needsReview: boolean` 추가,
  `noteRead.ok ? noteRead.needsReview : false`로 채움.
- `src/components/progress-provider.tsx`: `ProgressLesson`에 `needsReview: boolean` 추가.
- **files:** needs-review-actions.ts, route.ts, progress-provider.tsx
- **verify:** 빌드/게이트 통과 (G4·G14·G21·G23 불변 확인)
- **done:** API가 lesson.needsReview를 노출, 액션이 저장

### Task 3 — 토글 UI + 슬롯 + 프롬프트 반영
- `src/components/lesson-needs-review.tsx` (신규 'use client'):
  토글 버튼. 낙관적 업데이트 후 `setLessonNeedsReviewAction` 호출, 실패 시 되돌림
  (bookmark-button 낙관적 패턴). 표시 문구: off "더 공부할 레슨으로 표시" /
  on "더 공부할 레슨 ✓ (표시 해제)". 표시 시 이 레슨에서 클로드 프롬프트가
  강조됨을 한 줄로 안내.
- `src/components/progress-slots.tsx`: `LessonNeedsReviewSlot` 추가 —
  `status==='ready' && data.lesson && data.lesson.note.ok`에서만 렌더(TIL 슬롯과
  동일 가드). `initialNeedsReview={data.lesson.needsReview}` 전달.
- `src/app/lesson/[lessonId]/page.tsx`: `<LessonNeedsReviewSlot>`를
  progress-controls 영역(CompleteButtonSlot·LessonTilSlot 근처)에 추가.
- `src/components/lesson-copy-prompt.tsx`:
  - `buildPrompt`에 `needsReview` 인자 추가. true면 레슨 본문 뒤(메모 블록 앞)에
    "# 이 레슨은 내가 더 공부해야 하는 부분이야" 블록 삽입 — 막히는 지점 먼저
    찾기, 더 작게 쪼개기, 내 말로 재설명 확인 등 선생님 지시.
  - `handleCopy`에서 `data.lesson?.needsReview`를 읽어 넘김.
  - needsReview true일 때 버튼 강조(class 변형) + 안내 문구 노출.
- **files:** lesson-needs-review.tsx, progress-slots.tsx, page.tsx, lesson-copy-prompt.tsx
- **verify:** 빌드/게이트 통과, 내장 브라우저(iPad 크기)로 토글→복사 프롬프트 확인
- **done:** 표시 토글 동작, 표시 시 프롬프트에 블록 포함 + 버튼 강조

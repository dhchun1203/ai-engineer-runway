# Quick Task 260904-a1o — 스탭별 "책으로 읽기(book reader)"

## 목표

스텝 화면에 **"📖 책으로 읽기"** 버튼을 넣고, 누르면 그 스텝의 레슨들을 **한 권의
책처럼 연속으로(이동하며 술술) 읽는** 전용 화면(`/book/[step]`)으로 이동한다. 레슨
모음이 아니라 하나의 스토리라인으로 읽혀야 한다. Step 1을 파일럿으로 품질 검증한다.

## 핵심 설계 (탐색으로 확정)

- **책 본문 = 기존 레슨의 이야기 뼈대만 남긴 것.** 레슨 헤딩은 게이트 L1이 전
  레슨 동일 구조로 강제한다(`## 1.학습목표 / 2.왜 배우나 / 3.개념 설명 /
  4.실무 예제 / 5.실무 팁 / 6.핵심 정리·스스로 점검`, 끝에 `<NextTeaser>`).
  → **`## 2` 본문 + `## 3` 본문(비유·SVG 다이어그램·TwistBox 포함) + 끝의
  `<NextTeaser>`**(다음 챕터로 넘어가는 다리)만 남기고, `## 2`/`## 3` 라벨 헤딩과
  1·4·5·6 및 RunPython/RunSQL/PredictPrompt 학습 장치는 걷어낸다.
- **컴파일:** velite `s.mdx()`가 `@mdx-js/mdx`(function-body) 로 컴파일하는 것과
  동일하게, lessons 스키마 `.transform()`에서 잘라낸 마크다운을 직접
  `@mdx-js/mdx` `compile({outputFormat:'function-body'})`로 컴파일해 `bookCode`
  필드로 넣는다(remarkGfm + rehypePrettyCode, 앵커 중복 피하려 rehypeSlug 제외).
  렌더는 기존 `MDXContent code={bookCode}` 그대로(new Function 런타임 호환).
- **선례:** `src/app/print/[scope]/page.tsx` 서버 컴포넌트가 여러 레슨을 한 문서로
  정적 렌더하는 패턴을 화면 읽기용으로 변형. 진도·쿠키 안 읽음 → 완전 정적 프리렌더.

## 작업 (atomic)

### Task 1 — 책 본문 컴파일 파이프라인
- `velite.config.ts`: lessons 스키마에 `bookCode` 추가.
  - `sliceBookContent(raw)`: `## 2.` ~ `## 4.` 사이(라벨 헤딩 2줄 제거) +
    `<NextTeaser>…</NextTeaser>` 블록(있으면) 이어 붙이기.
  - `compileBook(md)`: `@mdx-js/mdx` compile, function-body, remarkGfm +
    rehypePrettyCode. hasContent=false 는 빈 문자열.
- `verify`: `npm run build`(또는 velite build)로 `.velite`에 bookCode 생성 확인,
  Step 1 레슨 하나 콘솔로 컴파일 결과가 `default` 반환하는지 스모크 확인.
- `done`: 전 레슨 빌드 통과, bookCode 비어있지 않음(hasContent 레슨).

### Task 2 — `/book/[step]` 라우트 + "책으로 읽기" 버튼
- `src/content/book-scopes.ts`: `getBookSteps()` / `getBookStep(stepId)` —
  step 메타 + hasContent 레슨(전역 순서) + 스텝 여는 글(짧게, 스텝별) + 총
  예상 읽기 시간.
- `src/app/book/[step]/page.tsx`: `generateStaticParams` [1,2,3]. 표지(책 제목=
  Step 제목, 부제, 챕터 수·읽기 시간) → 여는 글 → 챕터들(챕터 번호+레슨 제목 h2,
  모듈 kicker, `MDXContent bookCode`, 챕터 구분선). 아이패드 우선 읽기 컬럼
  (prose, 넉넉한 행간/여백), 상단 스크롤 진행 바(client, 작게), 맨 위로 버튼.
- `src/app/step/[stepId]/page.tsx` 헤더에 `/book/${stepId}` 링크 버튼
  ("📖 책으로 읽기") 추가 — tap-feedback·min-h-11.
- `verify`: 내장 브라우저 아이패드(768×1024)에서 `/book/1` 열어 흐름 확인.
- `done`: 버튼→책 이동, Step 1이 표지→여는 글→챕터 연속으로 렌더.

### Task 3 — Step 1 스토리 파일럿 검증 + 마감
- Step 1 여는 글이 "왜 이 여정을 떠나는지"를 한 문단으로 세팅, 챕터들이 왜배우나→
  개념→다음 예고로 자연스럽게 이어지는지 아이패드에서 통독 점검. 필요한 최소
  연결/여는 문단만 손본다(레슨 원문 대량 재작성 금지).
- 게이트: `node scripts/check-*.mjs` 통과, `npm run build` 통과, lint 통과.
- push까지 해서 사용자가 배포본으로 아이패드 검증 가능하게.

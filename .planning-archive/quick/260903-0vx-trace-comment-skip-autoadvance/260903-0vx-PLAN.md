<objective>
따라 치기(고스트 오버레이)를 줄 단위 안내 흐름으로 개선한다: (1) 주석은 타이핑
대상에서 제외 — 주석·빈 줄은 미리 채워진(given) 줄로 두고 학습자는 코드 줄만 채운다.
(2) 한 코드 줄을 정확히 다 치면 다음 코드 줄로 커서가 자동 이동(주석·빈 줄 건너뜀).
</objective>

<design>
- 미리 채우기(template): buildTraceTemplate(guide, prefixes)가 진입 시 코드 줄만
  ''로 비우고 주석·빈 줄은 원본대로 준다. 줄 개수를 원본과 같게 유지 → 고스트와
  줄 인덱스 1:1, 정렬 불변. 부모(RunPython='#', RunSQL='--')가 prefixes를 준다
  (모듈 상수로 identity 고정).
- 주석 판정: 전체 줄 주석만 제외(트림 후 접두사로 시작). 인라인 주석은 코드 줄.
- 자동 이동: value 변경 후 현재 커서 줄이 정확히 일치하면 다음 코드 줄로 setSelectionRange.
  커서만 옮기고 값은 안 바꿔 루프·IME 무간섭. 한글 조합 중(composingRef)에는 미루고
  조합 끝(onCompositionEnd)에 재시도. Enter는 새 줄 대신 다음 코드 줄 이동(단
  isComposing 시 조합 확정에 양보). 진입 시 커서를 첫 코드 줄로.
- 카운트: 'N/M줄 일치'의 M = 코드(타이핑 대상) 줄 수. 빨간 오답 표시·블록 설명·
  스크롤 동기는 그대로.
</design>

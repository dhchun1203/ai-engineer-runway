# Summary — 따라 치기: 주석 제외 + 줄 완성 시 자동 다음 줄 이동

따라 치기를 줄 단위 안내 흐름으로 바꿨다. 아이패드 크기 내장 브라우저 실측 검증.

## 변경
- **주석 제외(미리 채움)**: `buildTraceTemplate(guide, prefixes)`가 진입 시 코드 줄만
  빈칸으로 비우고 주석·빈 줄은 원본대로 채워 준다. 줄 개수를 원본과 같게 유지해
  고스트와 줄 정렬 불변. `RunPython`은 `['#']`, `RunSQL`은 `['--']`를 모듈 상수로
  넘긴다. 전체 줄 주석만 제외(인라인 주석은 코드 줄).
- **자동 다음 줄 이동**: 현재 커서 줄을 정확히 다 치면 다음 코드 줄로 커서 자동
  이동(주석·빈 줄 건너뜀). 커서만 옮기고 값은 그대로라 IME 무간섭. 한글 조합
  중에는 미루고(composingRef) 조합 끝에 재시도. Enter는 새 줄 대신 다음 코드 줄
  이동(조합 중 Enter는 확정에 양보). 진입 시 커서를 첫 코드 줄로.
- **카운트**: 'N/M줄 일치'의 M = 코드 줄 수(주석·빈 줄 제외). 빨간 오답 표시·
  블록 설명·스크롤 동기는 유지.

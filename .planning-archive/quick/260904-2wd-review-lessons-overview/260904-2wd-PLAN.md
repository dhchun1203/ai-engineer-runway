# 커리큘럼 목록에서 더 공부할 레슨 한눈에

사용자 선택: **목록에 표시 + 개수 배지**(전용 페이지 아님).

## 만드는 것

needs_review(quick 260904-241)로 표시한 레슨을 커리큘럼 목록에서 바로 보이게 한다.
- **Step 페이지(/step/[stepId]) 모듈 아코디언**: 표시한 레슨 줄에 🚩 마크(완료 ✓와 공존),
  모듈 헤더에 "🚩 N" 개수 배지.
- **커리큘럼 페이지(/curriculum) StepCard**: Step 단위 "🚩 N" 개수 배지("Step 1 · 🚩 3").

## 데이터 경로

전체 표시 슬러그 목록을 진도 API로 내려, 각 UI가 자기가 아는 레슨과 교집합해 센다
(completedSlugs와 동형).

- `src/lib/note-store.ts`: `readNeedsReviewLessonIds()` → `{ok:true; ids:Set<string>} | {ok:false; error}`
  (readCompletedLessonIds와 동형, lesson_note에서 needs_review=true인 lesson_id).
- `src/app/api/progress/route.ts`: 응답에 `needsReviewSlugs: string[] | null` 추가.
  게이트(hasUnlockCookie) 통과 후 읽고, 조회 실패 시 null로 부드럽게 강등(진도 응답은
  유지 — needsReview는 부가 정보). G14/G21 순서·no-store 불변.
- `src/components/progress-provider.tsx`: `ProgressData`에 `needsReviewSlugs: string[] | null`.

## UI

- `src/components/needs-review-indicator.tsx` (신규 'use client' 아님 — 순수 표현):
  `NeedsReviewCount({ count })` — "🚩 N" 배지(count>0일 때만). 공통 스타일.
- `src/components/module-accordion.tsx`: useProgress에서 needsReviewSlugs 읽어 Set 구성.
  - 레슨 줄: flagged면 Flag 아이콘(✓와 별개로 표시). 완료+표시 동시 가능.
  - 모듈 헤더: lessons ∩ set 개수를 NeedsReviewCount로.
- `src/app/curriculum/page.tsx`: 각 StepCard에 그 Step의 레슨 슬러그 배열을 prop으로 전달
  (서버에서 getModulesByStep→getLessonsByModule로 계산; G9 금지 식별자 아님).
- `src/components/step-card.tsx`: `stepLessonSlugs` prop 받아 needsReviewSlugs와 교집합,
  NeedsReviewCount 렌더(Step 헤더 줄 또는 배지 옆).

## 게이트 주의

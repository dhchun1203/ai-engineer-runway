# Quick Task 260902-j7t — 모바일 메뉴 닫힘(접힘) 애니메이션

## 문제

260902-j1i가 펼침(unfold)은 넣었지만, 패널이 `{open && …}` 조건부 렌더라 닫으면
즉시 언마운트돼 접히는 과정이 보이지 않는다. 닫힐 때도 대칭으로 접히게 한다.

## 접근

- 논리 토글 `open`과 실제 DOM 마운트 `panelMounted`를 분리.
  - open=true → 즉시 마운트(reveal 발화).
  - open=false → 언마운트 보류. `data-state="closed"`로 conceal 애니메이션을 걸고,
    끝나면 패널의 `onAnimationEnd`에서 panelMounted를 내려 언마운트.
- CSS: `nav-panel-conceal` 키프레임(1fr→0fr, opacity 1→0) 신설. `data-state`로
  reveal/conceal 분기. conceal은 `forwards`로 마지막 상태를 붙들어 언마운트 직전
  한 프레임 재확장 깜빡임 차단.
- reduced-motion: 양쪽 `animation: none` → onAnimationEnd가 안 뜬다. 그 경우
  effect가 즉시 panelMounted=false로 내려 패널이 클릭을 가로채지 않게 함.

## 변경

1. `src/app/globals.css` — `nav-panel-conceal` 추가, `.nav-panel-reveal`를
   `[data-state=open|closed]`로 분기, reduced-motion 블록 갱신.
2. `src/components/site-nav.tsx` — `panelMounted` 상태 + 마운트 게이트 effect,
   패널 렌더 조건을 `panelMounted`로, `data-state`·`onAnimationEnd` 부여.

## 검증

내장 브라우저 375px: 열기 시작 1px(reveal), 닫기 476→316→언마운트(~180ms),
닫힘 후 패널 DOM 부재 확인.

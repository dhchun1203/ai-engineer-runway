`src/lib/schedule.ts`를 만든다. 역시 import 0. `SCHEDULE_START = '2026-08-25'`, `COURSE_START_DATE = '2026-09-30'`, `scheduleTotalDays(lessonCount) = lessonCount + 1`(+1은 9/29 복습·버퍼일, D-34). `buildSchedule(orderedSlugs: readonly string[], startDateISO: string, totalDays: number): ScheduleRow[]`는 RESEARCH.md Pattern 2 코드를 그대로 옮긴다 — 날짜 산술 전 구간을 `Date.UTC(y, m-1, d+i)` + `.toISOString().slice(0,10)`로만 하고, 로컬 타임존 getter는 한 번도 쓰지 않는다(Pitfall 1). `i < orderedSlugs.length`면 그 slug, 아니면 `null` + `isBuffer: true`. 입력 배열을 변형하지 않는다. 35개 날짜→레슨 매핑을 상수로 적는 방식은 쓰지 않는다 — 배정은 항상 `orderedSlugs` 순서에서 파생된다(D-32/D-33).

# Round 4-P: 기술 다이어그램 문화 (2026-09-01)

1. **질문 유형→도식 유형 매핑** — Dan Roam 6×6: 구조=해부도 / 변화·순서=타임라인 /
   상태 전이=상태도 / 비교=대비 그리드 / 과정=흐름도. 우리 115점이 상자·화살표로 통일된
   게 강점이자 위험 — 상태 전이 개념(Promise, Git staging)이 흐름도로 그려졌다면 교체
   우선. 반나절(최악 불일치 5~10점만).
2. **번호 매긴 읽기 경로** — ByteByteGo 시그니처. 다이어그램에는 읽기 순서가 없다 —
   ①②③ 원형 배지가 서사를 강제하고, 본문 문단이 같은 번호를 부르면 왕복 비용 소멸
   (공간 근접성·분할 주의). 흐름형 그림 ~30점 + 본문 동기화 1일.
3. **텍스트 밀도 규칙** — Datawrapper(Muth): 직접 레이블(범례 제거), 위계 2단계만,
   대화체 먼저. SVG 규칙 성문화: 제목 1 + 요소 레이블 + "핵심 한 줄" 주석 최대 1 —
   그 외 금지. 반나절(+과밀 그림 10점 수리).
4. **손그림풍 — 하지 마라 판정** — Wood 2012: 참여↑ 정밀 판독↓. Bateman 2010(Useful
   Junk?): 장식이 이해 손실 없이 장기 회상 유리. 알맹이만: 훅 그림(2장) 1점만 장식적
   구체물 허용, 비교·수치 그림은 현행 유지.
5. **은유 앵커 제작 절차** — Maggie Appleton: 원천-대상-성질 매핑 → 그 위에 그림.
   4층: 은유 > 드로잉 > 구도 > 색. Step 3 추상 개념 5~7편(RAG=오픈북 시험, 임베딩=좌표
   지도) + 은유가 깨지는 지점 한 줄 명시. 1~2일.
6. **색·모양 전역 의미 계약** — C4 model 체크리스트. 4색 토큰에 사이트 전역 의미 고정
   (예: 강조=주의·외부, soft=면…) + 실선=데이터/점선=참조. 신규 그림부터 준수, 위반은
   grep 반자동 검출. R2-F "색 일치"(본문-그림)의 상위 버전(그림-그림 간). 반나절.

중복: "N개 1장" 대비 그리드→스몰 멀티플(R2-F), Grokking 구조→이미 함.

# Round 2-F: 설명의 장인들 — explorable explanations의 정적 이식분 (2026-09-01)

조사: ncase.me(Stanford 강연 전문), redblobgames.com(making-of), ciechanow.ski(Mechanical
Watch 구조 분석 — 본인 방법론 글은 미확인), distill.pub, 3Blue1Brown SoME 기준, Bret Victor
원전, unsung.aresluna.org(제3자 정밀 분석).

### 발견 (전부 충돌 없음)

1. **북엔드 구조** — 완성품 전체를 먼저 → 분해 → 끝에 같은 그림 재등장 + "이제 모든
   화살표를 설명할 수 있는지"(ciechanow.ski). 선행 조직자 + 자기효능감 + 회상.
   기존 115점 중 전체도가 있는 레슨은 배치만 바꾸면 됨. 반나절(파일럿).
2. **실패하는 소박한 버전 먼저** — "태엽에 바늘을 직접 달면 헛돈다"를 먼저 보여주고
   실제 메커니즘 공개. 그림 2컷 구성(①순진한 방법+✗ ②실제 방법). 후보: RAG(전부
   프롬프트에), 인덱스 없는 풀스캔, useState 없이 변수, 콜백 지옥. 1일(4~5편).
3. **복잡도 사다리 + 러닝 예제 하나** — Red Blob: BFS→Dijkstra→A*를 같은 지도에서.
   레슨 안 예제 시나리오 하나로 고정 + 그림 시리즈 같은 레이아웃, 달라진 부분만 색.
   R1 프레임 분할과 상호보완(그건 한 그림을 쪼갬, 이건 그림들 사이 연속성). 반나절(규칙).
4. **그림-본문 색 일치 (semantic color alignment)** — 다이어그램 색 = 본문 해당 용어
   하이라이트. signaling 원리. 색 상한 3개. 인라인 span 컴포넌트 1개 + 그림 주변
   1~2문단만. 반나절.
5. **슬라이더 대신 스몰 멀티플** — Red Blob 본인이 "인터랙션이 항상 필요한 건 아니다,
   모든 변형을 나란히"라고 명시. **이 군집의 위젯을 우리 정적 제약 안으로 옮기는 정공법.**
   temperature 0/0.7/1.5, 청크 소/중/대, learning rate 과소/적정/과대 — "값 하나만
   다르고 레이아웃 동일" 3분할 SVG. 1일(3~4편).
6. **"왜 배우나"를 구체 장면으로** — ncase: "Show WHAT made you care, not tell WHY".
   3B1B SoME 기준 1번(첫 30초). 2장 첫 문단을 구체적 실패 장면·퍼즐로 시작, 효용 나열은
   한 문장으로 축소. 반나절(규칙+파일럿).
7. **Therefore/But 인과 사슬** — "끊긴 리스트가 아니라 연결된 이야기". 소제목 전환이
   "그런데 문제가 생긴다 → 그래서 X 등장" 형태인지 저작 체크 항목. 반나절.
8. **그림-본문 호흡** — 2~4문단당 그림 1개, 그림 없이 5문단 연속 금지. 논증은 글이
   진다(Bret Victor: "핵심 논증에 인터랙션이 필요해선 안 된다" — 우리 정적 제약의
   정당화). 문단/SVG 비율 스캔 스크립트로 리워크 우선순위 도출. 반나절.

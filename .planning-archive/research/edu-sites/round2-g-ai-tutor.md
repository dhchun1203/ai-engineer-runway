# Round 2-G: AI 튜터의 학습 사이트 통합 (2026-09-01)

기준점: 현행 `lesson-copy-prompt.tsx`의 TEACHER_BRIEF를 정독 대조 — **이미 Khanmigo·
ChatGPT study mode의 핵심 원칙(정답 금지·회상 우선·오답 무채점·인용 요구)과 거의 일치.**
아래는 추가분만.

### 1. 모드 메뉴 — 명령어를 학습자에게 보이는 세트로 (반나절)
- Quizlet Q-Chat(Teach Me/Quiz Me/Apply), ChatGPT study mode(허용 활동 열거).
- buildPrompt 마무리를 명령어 메뉴로: "레슨 해줘"(구간 과외) / "퀴즈 내줘" / "내가
  설명해볼게" / "실무에 연결해줘". 자유 질문은 평소 규칙.
- study mode의 퀴즈 규칙 "정답 공개 전 2회 시도, 한 번에 한 문제"를 퀴즈 모드에 이식.

### 2. Feynman 모드 — "내가 설명해볼게" 전용 규칙 (반나절, 1과 동일 커밋)
- 역할 교대: 학습자가 선생, AI가 호기심 많은 학생. 채점표 대신 "그건 왜 그렇게 돼?"
  한 번에 하나. 얼버무리는 지점이 빈 구멍 — 거기를 파고, "어때?"라고 물으면 그때 평가
  (맞은 것/빠뜨린 것/어긋난 것 — 어긋남은 레슨 인용). 빠뜨림은 답 대신 "레슨 ○○ 다시
  보고 와서 설명해봐"로 돌려보냄.
- 근거: self-explanation effect (Khan 7단계 문서 명시), Feynman Bot 연구.

### 3. 완료 레슨 목록 동봉 (반나절~1일)
- 현행 지침의 "앞선 레슨과 연결해줘"는 **클로드가 진도를 모르므로 실행 불가능한 지시.**
- CopyLessonPrompt는 이미 useProgress() 사용 — 완료 레슨 제목 목록을 프롬프트에 동봉
  + "아직 안 배운 레슨 내용으로는 설명하지 마"(역류 방지).

### 4. [레슨 밖] 표찰 — NotebookLM식 범위 구분 (반나절)
- 현행 지침은 레슨 근거 인용만 요구, **레슨 밖으로 나갈 때 표시하는 반대 방향 규칙이 없음.**
- 추가: 레슨에 없는 내용은 문장 앞 [레슨 밖] + 뒤 레슨에서 다룰 주제면 "나중에 ○○쯤에서
  배울 거야"로 멈추고 깊이 안 들어감.

### 5. 점검 문제 옆 "이 문제 클로드랑 풀기" (1일)
- Duolingo Max "Explain My Answer"(틀린 그 순간의 버튼) + Vercel/Mintlify 상황별 복사 진입점.
- 미니 지침 + 문제 + (채점용, 먼저 안 보여줄) 정답 복사. "네 답이 뭐였고 왜 그렇게
  생각했어?" → 갈라진 지점 하나만 되물음 → 두 번 막히면 정답.
- 충돌 판단: 채점은 사이트가 아니라 클로드가 함 — 시스템 구축 아님. 경계에 있음을 표시.

### 6. 코드 빈칸 #TODO 패턴 (반나절)
- Claude 학습 모드 — 배운 부분 한 줄을 `# 여기는 네가 채워봐: (힌트)`로 비움. 말이나
  글로 답하면 완성본. 생성 효과. 실행 아님 — 단 "아이패드에서 실습 안 함"을 코드 쓰기
  전체로 넓게 해석하면 충돌 — 판단은 사용자 몫.

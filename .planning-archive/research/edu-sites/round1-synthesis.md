# Round 1 종합 — 5개 군집 광역 조사 (2026-09-01)

조사원 5명(인터랙티브 플랫폼 / 개념 시각화 / 한국 교육 / 문서형 학습 / 유지·복습 메커니즘)이
독립적으로 조사했고, 원문은 `round1-*.md` 5편에 있다. 여기서는 군집을 가로지르는 수렴
패턴과 군집 고유 발견을 추린다.

## 수렴 패턴 (2개 군집 이상에서 독립적으로 등장 — Round 2 심화 대상)

### S1. 완료 레슨의 간격 재등장 (4개 군집)
- Execute Program(완료 후 1→3→7→…일 사다리 + 졸업 규칙), Khan Academy(시간차 재확인으로
  숙련도 승급), Duolingo Practice Hub, Boot.dev, Readwise가 전부 같은 뼈대.
- 핵심 통찰 (A·E 일치): **복습 문제를 새로 만들 필요가 없다** — 레슨마다 이미 있는
  "스스로 점검 문제"를 재소환만 하면 된다. 자동 채점 불필요(자기 판정이 이 계열의 주류).
- 우리 적용 합의안: 홈 "오늘의 복습" 카드(만기 레슨의 점검 문제 앵커) + 고정 간격
  사다리(1·3·7·21일, 3회 졸업) + Supabase 완료 시각으로 클라이언트 계산.

### S2. 힌트 사다리 — 정답 일괄 공개 대신 단계 공개 (3개 군집)
- Codecademy(힌트→정답), DataCamp(정답 열람에 비용), Khan(한 단계씩), RegexOne(방향만).
- 우리 적용: 점검 문제 접기를 2단으로 — `▶ 힌트(방향만)` → `▶ 정답`. 힌트는 "어느
  개념/그림을 떠올려야 하는지" 한 줄.

### S3. 예측 먼저, 공개는 나중 (pretesting / pause-and-predict) (3개 군집)
- 생활코딩("질문입니다 — 맞혀 보세요"), Josh Comeau(예상 답을 대신 말한 뒤 뒤집기),
  react.dev·PostgreSQLTutorial(출력 예측 후 확인).
- 우리 적용: (a) 개념 도입부 예측 질문 1개, (b) 핵심 예제 1~2곳의 실행 결과를 접기로
  숨기고 "출력을 예측해 보세요", (c) 코드 앞 "30초 머릿속 설계" 문장.

### S4. 스트릭 + 용서 장치 (3개 군집)
- Brilliant(Streak Charge — 완료로 버는 보호권), solved.ac(프리즈), Duolingo, Boot.dev(embers).
- 공통 세부: 보호권을 "벌금"이 아니라 "성실함으로 미리 버는 저축"으로 설계.
- E의 1인용 변형 제안이 유력: 새 레슨 스트릭은 기존 페이스 판정과 중복 → **"복습 만기
  0건" 배지**가 행동을 더 정확히 유도.

### S5. 집계 페이지 — 모듈 복습 페이지 / 용어집 (3개 군집)
- freeCodeCamp Review Pages(62개, 레슨과 동급 구성요소), Codecademy Cheatsheets,
  MDN Glossary, E의 /review 세션 페이지.
- 우리 적용: 레슨 6장 용어 표를 구조화 데이터로 올려 빌드타임에 `/glossary`(ㄱㄴㄷ 정렬
  + 출처 역링크)와 모듈별 복습 페이지 자동 생성. **선행 조건: 용어 표의 데이터화.**

### S6. 선수 지식·후속 연결 메타데이터 (3개 군집)
- Exercism(개념 의존성), MDN(Prerequisites + Learning outcomes), 생활코딩/seomal(지식지도),
  Real Python("몰라도 괜찮아요" 안심 문구).
- 우리 적용: frontmatter `prerequisites`/`unlocks` → 레슨 상단 "먼저 보면 좋아요" 칩
  (+ 안심 문구), 하단 "이 레슨이 열어주는 것" 한 줄. 전체 그래프 UI는 만들지 않는다.

## 군집 고유 발견 (단독이지만 강함)

- **D: 실행 결과 블록 표준화** — 실행 환경이 없는 우리에게 특히 중요. 모든 예제 코드에
  "실행 결과"를 표준 하위 블록으로(Python `>>>`·SQL 결과 표), 동일 샘플 데이터 유지.
- **D: 콜아웃 3종** (react.dev) — 함정(Pitfall)/참고(Note)/더 깊이(접기 Deep Dive).
  "더 깊이" 접기가 eli5 본문을 짧게 유지하는 안전판.
- **D: 다음 레슨 예고** — 다음 레슨을 "방금 배운 것의 빈틈"으로 제시. 하루 1레슨 페이스와
  정확히 맞물림.
- **B: 혼란 패턴 13개 체크리스트** (Julia Evans) — 저작·감수 기준으로 즉시 사용 가능.
- **B: 비유 3원칙** — 비유 1개=오개념 1개, 두 문단 이상 금지, 한계 명시.
- **B: 그림 프레임 분할** — 종합 그림 1장 대신 같은 레이아웃 3~4프레임 세로 나열(분할 원리).
- **B: 목표 그림 먼저** — 레슨 서두에 최종 그림 축소 배치 → 핵심 정리에서 재등장(수미상관).
- **C: TIL 한 줄** — 완료 체크 순간 "오늘 배운 것 한 줄?" 입력(기존 메모장 재활용).
- **C: 여정 내러티브** — 모듈 경계 ~10곳에 "산 하나를 넘었다" 서사.
- **C: 용어 병기 규칙 명문화** — 첫 등장 1회만 병기, 이후 한글 단독, 전량은 용어 표가 담당.
- **A: 완료 후에만 열리는 "더 깊이"** (Exercism Dig Deeper 솔로 변형) — 콘텐츠 작성 비용
  때문에 우선순위 중하.
- **D: 3상태 진도** (roadmap.sh Learning/Done) — "읽다 만 레슨" 구분. 우선순위 중하.
- **D: Odin Project Knowledge check** — 답 못 하면 해당 본문 섹션으로 돌아가는 링크.

## 실측 사실 (설계 전제)

- F1: `progress.completed_at timestamptz`가 **이미 있다** — 다만 아무도 안 읽는다
  (`readCompletedLessonIds()`는 lesson_id만 select).
- F2: 재완료 upsert가 completed_at을 **덮어쓰고**, 완료 취소는 행을 **삭제** —
  progress에 복습 상태를 얹으면 이력 소실 경로가 둘.
- F5: rehype-slug 없음 — h2에 id가 없어 `#앵커` 링크가 현재 불가능.
- F6: 35편 전부 `## 6. 핵심 정리 및 스스로 점검` + `**스스로 점검**` 마커 + 정답 접기
  구조를 check-lesson-structure.mjs(L1~L7)가 **기계 강제** — 추출 파서가 기댈 계약.
- F7: 점검 문항 **총 70개**(레슨당 정확히 2). `정답 보기` 접기는 4장 해보기에도 있으므로
  추출은 반드시 `**스스로 점검**` 마커 이후로 한정.
- F8: 9/29 복습일은 buffer 행으로 존재하나 **CTA 없음**(홈 카드·일정표 모두 문구뿐).
- F9: Velite 0.4에 `s.raw()` 존재 — 빌드타임 본문 파싱 가능.

## 확정 설계

**간격 사다리**: `[1, 3, 7, 21]`일, 직전 사건(완료 or 마지막 복습) 기준, 3회 졸업
(21 칸은 개강 후 확장용 상수 보존). 벌점 없음 — "복습 완료" 자기 신고 1버튼.
Round 1 문서 간 불일치(E: 1·3·7·21 / A: 3·7·21 3회 졸업)를 이렇게 해소.

**새 테이블 `lesson_review`** (round1-e "새 테이블 불필요"는 F2로 **기각**):
`lesson_id text pk, review_count int default 0, last_reviewed_at timestamptz,
missed_q int[] default '{}'`. RLS default-deny + supabaseAdmin 패턴 복제.
완료 취소돼도 복습 이력은 남기고, 만기 계산은 progress 현재 행과 join.

**앵커**: rehype-slug 추가(A안 권장). 35편 공통 헤딩이라 앵커가 상수 1개
(`#6-핵심-정리-및-스스로-점검`). 구간 테이프는 id 무관 동작이라 충돌 없음 —
단 section-tape.tsx의 "플러그인 안 쓴다" 주석은 사유가 다르므로 갱신.

**/review 세션**: velite transform에서 `selfCheck[]` 추출(마커 이후 한정, 0개면 throw)
→ force-dynamic 페이지. 약한 것(missed_q) 우선 → 만기 → 나머지, 날짜 시드 결정적 셔플
+ 레슨 라운드로빈(교차 연습), 12문항 컷. 정답은 마크다운이라 초소형 렌더러 필요
(Round 1이 놓친 +반나절). [기억남/다시 봐야 함] 2버튼 → missed_q 기록.
9/29 버퍼 CTA 2곳(홈 카드·일정표) → `/review` 연결.

**스트릭 불채택** — 페이스 판정과 중복. "복습 만기 0건 ✓ / 다음 복습 M/D" 배지로 대체.

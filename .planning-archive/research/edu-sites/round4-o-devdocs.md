# Round 4-O: 가르치는 개발자 문서 (2026-09-01)

사전 대조: 우리 레슨 원문을 열어 "이미 하는 것"(현실 도메인 예제+가르치는 주석, 예측 후
실행 프롬프트, 왜-형 점검 문제) 제외. 아래는 델타만.

1. **verbatim 실행 결과 블록** — Twilio "코드→실행→이렇게 보인다" 3박자, Stripe "Try it
   out". 실행 안 하는 학습자에게 출력 블록이 유일한 결과 관찰 수단(대리 검증). 산문
   요약("~가 출력됩니다")보다 실제 출력 텍스트가 부담 적음. **R2-I·R1-D와 3번째 수렴 —
   확정적.** 1일(콘텐츠).
2. **정답 전 "커밋" 장치** — 실험판 Rust Book(rust-book.cs.brown.edu): 제출해야 정답
   열림, 들여다보기에 비용. **OOPSLA 2024 논문(114만 응답): 퀴즈 데이터 기반 본문 개입
   12건이 해당 문항 +20%.** 최소 버전: "먼저 머릿속으로 답한 뒤 여세요" + 탭 2번.
   확장(로컬 즉시 정오답 표시)은 자동 채점 제외 결정과 **충돌 소지** — 보고만.
3. **개념형("왜") 문항 기준** — 같은 논문: "왜 컴파일 안 되나"형이 "되나 안 되나"형보다
   판별력 높음(문항반응이론). 우리 문항 70개를 이 기준으로 감사, 예/아니오형만 수정.
   반나절.
4. **인라인 렌더 데모** — Tailwind "개념→만져보는 실물→코드". 우리 CSS/JS/React 레슨에
   렌더된 데모 0개(실측). 코드의 렌더 결과를 실제 HTML로 삽입 — 완전 정적. 코드 실행이
   아니라 완성물 만지기 — Pyodide 결정과 다른 물건이나 "실습 안 함"의 정신과 겹쳐 보일
   여지 표시. 파일럿 반나절~1일.
5. **"나는 ~할 수 있다" 체크리스트로 닫기** — Astro 튜토리얼. 완료 버튼 위에 학습 목표를
   1인칭 능력 진술로 재제시(수미상관 + 메타인지). 코드 한 곳 수정으로 35편 일괄. 반나절~1일.
6. **고비 지점 표적 투자** — OOPSLA: 이탈은 특정 지점에 몰림, 균등 투자보다 표적 개입.
   콘텐츠 투자를 예상 고비(TS 타입, React 상태, RAG)에 우선 배정하는 **배분 지침**.
   1인용 신호: 밀린 레슨 + 메모량.
7. 선수지식 칩 — **S6·R3와 4번째 수렴** (조건부 표시 아이디어 추가: Twilio식).

한 줄 평: 실험판 Rust Book(최대 수확 — 유일한 대규모 통제 실험) / Stripe(명성의 실체는
코드 자체 — 우리가 이미 같은 문체) / Twilio(3박자 리듬 원조) / Tailwind(정적으로 흉내
가능한 유일한 인터랙티브) / Astro(수미상관 교과서) / Laravel(Bootcamp 폐지 확인 —
laravel.com/learn으로 리다이렉트).

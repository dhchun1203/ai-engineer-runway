`uv run python`으로 REPL을 열어요.

### dataclass: 칸이 정해진 기록 만들기

```python
>>> from dataclasses import dataclass, asdict
>>> @dataclass
... class Point:
...     x: int
...     y: int
... 
>>> p = Point(1, 2)
>>> p
Point(x=1, y=2)
>>> p.x
1
>>> asdict(p)
{'x': 1, 'y': 2}
>>> Point(**{"x": 3, "y": 4})
Point(x=3, y=4)
```

`@dataclass`를 붙이고 칸 이름과 자료형을 적으면, 값을 담는 틀이 생겨요. 이 틀이 **클래스**이고, `Point(1, 2)`로 찍어 낸 것이 **객체**예요.

값은 `p.x`처럼 점으로 꺼내요. 딕셔너리와 달리 **오타를 내면 바로 에러**가 나고, VS Code가 칸 이름을 자동 완성해 줘요.

`asdict(p)`는 딕셔너리로, `Point(**딕셔너리)`는 그 반대로 바꿔요. JSON 저장과 불러오기에 이 둘을 써요. `**`는 딕셔너리를 이름 붙은 값들로 풀어 넣는 표시예요.

### class: 자료와 기능을 함께 묶기

```python
>>> class Counter:
...     def __init__(self, start):
...         self.value = start
...     def up(self):
...         self.value += 1
... 
>>> c = Counter(10)
>>> c.up()
>>> c.up()
>>> c.value
12
```

클래스 안에 쓴 함수를 **메서드**라고 해요. `c.up()`처럼 점으로 불러요.

`__init__`은 객체를 찍어 낼 때 자동으로 불리는 준비 함수예요. `self`는 "지금 이 객체 자신"이에요. 메서드의 첫 번째 칸에 항상 쓰고, 부를 때는 파이썬이 알아서 넣어 줘요.

`self.value`처럼 `self`에 달아 둔 값은 객체가 살아 있는 동안 남아요.

### 리스트 컴프리헨션: 한 줄로 걸러 만들기

```python
>>> rows = ["2026-09-28", "2026-10-02", "2026-10-03"]
>>> [row for row in rows if row.startswith("2026-10")]
['2026-10-02', '2026-10-03']
>>> sum(n for n in [1, 2, 3] if n > 1)
5
```

`[꺼낸값 for 꺼낸값 in 리스트 if 조건]`은 빈 리스트에 for로 append하는 코드의 한 줄 버전이에요. 대괄호 없이 `sum()` 안에 바로 쓸 수도 있어요.

`.startswith("2026-10")`은 그 글자로 시작하는지 물어요. 어제 날짜를 문자열로 저장해 둔 덕분에 이걸로 월을 고를 수 있어요.

```python
def signed_amount(entry):
    if entry["kind"] == "수입":
        return entry["amount"]
    return -entry["amount"]


def balance(entries):
    total = 0
    for entry in entries:
        total += signed_amount(entry)
    return total


def biggest_expense(entries):
    biggest = None
    for entry in entries:
        if entry["kind"] == "지출":
            if biggest is None or entry["amount"] > biggest["amount"]:
                biggest = entry
    return biggest


def category_totals(entries):
    totals = {}
    for entry in entries:
        if entry["kind"] == "지출":
            category = entry["category"]
            totals[category] = totals.get(category, 0) + entry["amount"]
    return totals
```

## 4. 고쳐 치기

`ledger.py`의 함수들을 `Ledger` 클래스로 묶어요. 지금은 모든 함수에 `entries`를 넘기고 있는데, 가계부가 자기 기록을 들고 있게 하는 거예요.

```python
book = Ledger(storage.load_entries())
book.balance()
```

- `__init__`에서 `entries`를 받아 `self.entries`에 둬요.
- `add`, `balance`, `biggest_expense`, `category_totals` 메서드를 만들어요.
- `ui.py`의 함수들은 `entries` 대신 이 객체를 받아요.
- `main.py`는 `book`을 만들어 넘겨요. 동작은 그대로예요.

<Hints>
<Hint>

클래스 안에 있는 함수는 첫 번째 칸이 `self`예요. `def balance(self):`처럼 쓰고, 안에서는 `entries` 대신 `self.entries`를 써요.

</Hint>
<Hint>

`ui.py`에서 `import ledger`는 이제 필요 없어요. 함수의 매개변수 이름을 `ledger`로 받아서 `ledger.balance()`로 부르면 돼요.

</Hint>
<Hint>

`main.py` 맨 위는 `from ledger import Ledger`예요. 저장할 때는 `storage.save_entries(book.entries)`처럼 안의 리스트를 넘겨요.

</Hint>

```python
class Ledger:
    def __init__(self, entries):
        self.entries = entries

    def add(self, entry):
        self.entries.append(entry)

    def balance(self):
        total = 0
        for entry in self.entries:
            total += entry.signed_amount()
        return total

    def biggest_expense(self):
        biggest = None
        for entry in self.entries:
            if entry.kind == "지출":
                if biggest is None or entry.amount > biggest.amount:
                    biggest = entry
        return biggest

    def category_totals(self):
        totals = {}
        for entry in self.entries:
            if entry.kind == "지출":
                totals[entry.category] = totals.get(entry.category, 0) + entry.amount
        return totals
```

## 5. 혼자 치기

마지막 기능이에요. 메뉴에 `5. 월별 리포트`를 넣고, 끝내기를 6번으로 밀어요.

- `월(YYYY-MM): `로 물어요.
- 그 달의 수입, 지출, 잔액을 찍고, 이어서 분류별 지출(큰 순서, 비율)을 찍어요.
- 그 달 기록이 없으면 `2026-08에는 기록이 없어요.`처럼 찍어요.

`Ledger`에 `in_month(month)`, `income()`, `expense()` 메서드를 더해 봐요. `in_month`가 **그 달 기록만 담은 새 Ledger**를 돌려주면, 이미 만든 `balance()`와 `show_totals()`를 그대로 다시 쓸 수 있어요.

시험 자료는 이렇게 넣어요. `ledger.json`을 지우고 시작하면 숫자가 아래 표와 같아져요.

| 날짜 | 종류 | 분류 | 항목 | 금액 |
| --- | --- | --- | --- | --- |
| 2026-09-28 | 지출 | 식비 | 점심 | 9000 |
| 2026-09-25 | 수입 | 월급 | 9월 월급 | 3000000 |
| 2026-10-02 | 지출 | 식비 | 저녁 | 15000 |
| 2026-10-03 | 지출 | 교통 | 버스 | 1500 |

```python
class Ledger:
    def __init__(self, entries):
        self.entries = entries

    def add(self, entry):
        self.entries.append(entry)

    def balance(self):
        total = 0
        for entry in self.entries:
            total += entry.signed_amount()
        return total

    def biggest_expense(self):
        biggest = None
        for entry in self.entries:
            if entry.kind == "지출":
                if biggest is None or entry.amount > biggest.amount:
                    biggest = entry
        return biggest

    def category_totals(self):
        totals = {}
        for entry in self.entries:
            if entry.kind == "지출":
                totals[entry.category] = totals.get(entry.category, 0) + entry.amount
        return totals

    def in_month(self, month):
        picked = [entry for entry in self.entries if entry.date.startswith(month)]
        return Ledger(picked)

    def income(self):
        return sum(entry.amount for entry in self.entries if entry.kind == "수입")

    def expense(self):
        return sum(entry.amount for entry in self.entries if entry.kind == "지출")
```

from datetime import date

from models import Entry


def ask_date():
    while True:
        text = input("날짜(YYYY-MM-DD, 비우면 오늘): ")
        if text == "":
            return date.today().isoformat()
        try:
            date.fromisoformat(text)
            return text
        except ValueError:
            print("2026-10-31 같은 모양으로 입력해 주세요.")


def ask_kind():
    kind = input("종류(수입/지출): ")
    while kind != "수입" and kind != "지출":
        print("수입 또는 지출로 입력해 주세요.")
        kind = input("종류(수입/지출): ")
    return kind


def ask_amount():
    amount_text = input("금액: ")
    while not amount_text.isdigit():
        print("숫자만 입력해 주세요.")
        amount_text = input("금액: ")
    return int(amount_text)


def add_entry(ledger):
    day = ask_date()
    kind = ask_kind()
    category = input("분류: ")
    item = input("항목: ")
    amount = ask_amount()
    ledger.add(Entry(day, kind, category, item, amount))
    print("기록했어요.")


def show_list(ledger):
    print(f"모두 {len(ledger.entries)}건")
    for entry in sorted(ledger.entries, key=lambda e: e.date):
        print(f"{entry.date} {entry.signed_amount():>+12,}원  [{entry.category}] {entry.item}")
    print(f"잔액: {ledger.balance():,}원")


def show_biggest(ledger):
    biggest = ledger.biggest_expense()
    if biggest is None:
        print("지출 기록이 없어요.")
    else:
        print(f"가장 큰 지출: [{biggest.category}] {biggest.item} -{biggest.amount:,}원")


def show_totals(ledger):
    totals = ledger.category_totals()
    if len(totals) == 0:
        print("지출 기록이 없어요.")
    else:
        whole = sum(totals.values())
        ranked = sorted(totals.items(), key=lambda pair: pair[1], reverse=True)
        for category, total in ranked:
            print(f"{category}: {total:,}원 ({total / whole * 100:.1f}%)")


def show_month_report(ledger):
    month = input("월(YYYY-MM): ")
    report = ledger.in_month(month)
    if len(report.entries) == 0:
        print(f"{month}에는 기록이 없어요.")
        return
    print(f"--- {month} 리포트 ---")
    print(f"수입: {report.income():,}원")
    print(f"지출: {report.expense():,}원")
    print(f"잔액: {report.balance():,}원")
    show_totals(report)

## 2. 필요한 개념만

`uv run python`으로 REPL을 열어요.

### def와 return: 코드에 이름 붙이기

```python
>>> def add(a, b):
...     return a + b
... 
>>> add(9000, 1500)
10500
>>> result = add(1, 2)
>>> result
3
```

`def 이름(받을 것):`로 함수를 만들어요. 만들 때는 실행되지 않고, `add(9000, 1500)`처럼 **부를 때** 실행돼요.

괄호 안 `a`, `b`가 매개변수예요. 부를 때 넣은 값이 여기에 담겨요. `return`은 결과를 부른 곳으로 돌려주고 함수를 끝내요.

### print와 return은 달라요

`print`는 화면에 보여 줄 뿐이고, `return`은 값을 돌려줘서 변수에 담거나 계산을 이어 가게 해 줘요. 계산 함수는 `return`, 화면 함수는 `print`로 나누면 코드가 깔끔해져요.

오늘 파일을 나누는 기준도 이거예요. `ledger.py`에는 `print`가 하나도 없어요.

### 함수 안에서 리스트를 바꾸면

```python
>>> def add_one(entries):
...     entries.append("새 기록")
... 
>>> box = []
>>> add_one(box)
>>> box
['새 기록']
```

함수에 리스트를 넘기면 복사본이 아니라 **같은 리스트**가 가요. 그래서 안에서 `.append()`하면 바깥 리스트에도 들어가 있어요. `add_entry(entries)`가 `return` 없이도 되는 이유예요.

### import: 다른 파일의 함수 쓰기

```python
import ledger

ledger.balance(entries)
```

같은 폴더의 `ledger.py`를 `import ledger`로 불러와요. 확장자 `.py`는 쓰지 않아요. 안의 함수는 `파일이름.함수이름`으로 불러요. 이렇게 불러 쓰는 파이썬 파일을 **모듈**이라고 해요.

### if __name__ == "__main__"

```python
if __name__ == "__main__":
    main()
```

"이 파일을 직접 실행했을 때만 `main()`을 불러라"는 뜻이에요. `import`로 불려 왔을 때는 실행하지 않아요. 파이썬 파일 끝에서 정말 자주 보는 관용구라, 외운다고 생각하고 쳐요.

### 금액 줄 맞추기

```python
>>> f"{-9000:>+12,}원"
'      -9,000원'
>>> f"{3000000:>+12,}원"
'  +3,000,000원'
>>> f"{9000:>12,}원"
'       9,000원'
```

콜론 뒤 `>`는 오른쪽 정렬, `+`는 양수에도 부호 붙이기, `12`는 전체 12칸, `,`는 천 단위 쉼표예요.

def biggest_expense(entries):
    biggest = None
    for entry in entries:
        if entry["kind"] == "지출":
            if biggest is None or entry["amount"] > biggest["amount"]:
                biggest = entry
    return biggest


def category_totals(entries):
    totals = {}
    for entry in entries:
        if entry["kind"] == "지출":
            category = entry["category"]
            totals[category] = totals.get(category, 0) + entry["amount"]
    return totals

## 6. 자주 나는 에러

### 모듈 이름이 틀렸어요: ModuleNotFoundError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 1, in <module>
    import ledgr
ModuleNotFoundError: No module named 'ledgr'
```

`ledgr`이라는 파일이 없다는 뜻이에요. 오타이거나, 파일이 다른 폴더에 있거나, 터미널이 다른 폴더에서 실행하고 있는 경우예요. 프로젝트 폴더에서 실행하는지 먼저 봐요.

### 모듈 안에 그런 함수가 없어요: AttributeError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 3, in <module>
    print(ledger.balanc([]))
          ^^^^^^^^^^^^^
AttributeError: module 'ledger' has no attribute 'balanc'. Did you mean: 'balance'?
```

파일은 찾았는데 그 안에 `balanc`가 없다는 뜻이에요. 친절하게 맞는 이름까지 알려 줘요. 함수를 옮기고 나서 호출 쪽을 안 고쳤을 때도 나요.

`from ledger import balanc`처럼 쓰는 방식에서는 ImportError로 나요.

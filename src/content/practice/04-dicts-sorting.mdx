## 2. 필요한 개념만

`uv run python`으로 REPL을 열어요.

### 딕셔너리: 이름으로 꺼내는 상자

```python
>>> entry = {"kind": "지출", "item": "점심", "amount": 9000}
>>> entry["item"]
'점심'
>>> entry["amount"]
9000
>>> entry["memo"] = "회사 앞"
>>> entry
{'kind': '지출', 'item': '점심', 'amount': 9000, 'memo': '회사 앞'}
```

리스트가 자리 번호로 꺼낸다면, 딕셔너리는 **이름**(key)으로 꺼내요. 중괄호 안에 `이름: 값`을 쉼표로 이어요.

없는 이름에 값을 넣으면 새로 생기고, 있는 이름이면 덮어써요.

### get: 없으면 이 값으로

```python
>>> totals = {"식비": 9000}
>>> totals.get("식비", 0)
9000
>>> totals.get("교통", 0)
0
>>> totals["식비"] = totals.get("식비", 0) + 15000
>>> totals
{'식비': 24000}
```

`totals["교통"]`은 없으면 에러지만, `.get("교통", 0)`은 없으면 0을 줘요. 그래서 "지금까지 합에 더하기"를 한 줄로 쓸 수 있어요. 처음 나온 분류든 아니든 똑같이 돌아가요.

### items, values: 전부 꺼내기

```python
>>> totals = {"식비": 24000, "교통": 1500}
>>> list(totals.items())
[('식비', 24000), ('교통', 1500)]
>>> totals.values()
dict_values([24000, 1500])
>>> sum(totals.values())
25500
>>> for category, total in totals.items():
...     print(category, total)
... 
식비 24000
교통 1500
```

`.items()`는 이름과 값을 쌍으로 줘요. `for category, total in ...`처럼 변수 두 개로 받으면 쌍이 알아서 나뉘어 담겨요.

`.values()`는 값만 줘서 `sum`에 바로 넣을 수 있어요.

### sorted와 lambda: 무엇을 기준으로 줄 세울까

```python
>>> pairs = [("교통", 1500), ("식비", 24000)]
>>> sorted(pairs, key=lambda pair: pair[1])
[('교통', 1500), ('식비', 24000)]
>>> sorted(pairs, key=lambda pair: pair[1], reverse=True)
[('식비', 24000), ('교통', 1500)]
>>> pair = ("식비", 24000)
>>> pair[0]
'식비'
>>> pair[1]
24000
>>> 24000 / 25500 * 100
94.11764705882352
>>> f"{24000 / 25500 * 100:.1f}%"
'94.1%'
```

`("식비", 24000)`처럼 소괄호로 묶은 건 **튜플**이에요. 리스트처럼 번호로 꺼내지만 내용을 바꿀 수는 없어요.

`sorted`는 줄 세운 새 리스트를 돌려줘요. `key`에는 "각 값에서 무엇을 기준으로 삼을지"를 주는데, `lambda`는 그 자리에 쓰는 이름 없는 한 줄 함수예요.

`lambda pair: pair[1]`은 "쌍을 받아서 두 번째 값을 돌려줘"라는 뜻이에요. `reverse=True`를 붙이면 큰 순서가 돼요.

끝의 `{값:.1f}`는 소수 첫째 자리까지 보이라는 f-string 표시예요.

### None: 아직 아무것도 없음

```python
biggest = None
```

`None`은 "값이 없다"를 나타내는 값이에요. 찾기 전 상태를 표시할 때 써요. 맞는지 물을 때는 `==` 대신 `is None`으로 써요.

## 3. 따라 치기

어제 코드를 고쳐요. `lines`와 `amounts`를 없애고 `entries` 하나로 합쳐요. 기능은 어제와 똑같고 **속만** 바뀌어요. 이런 변경을 리팩터링이라고 해요.

<details>
<summary>어제 끝난 코드(시작 코드) 보기</summary>

```python
print("=== 나의 가계부 ===")

lines = []
amounts = []

while True:
    print()
    print("1. 기록 추가")
    print("2. 목록 보기")
    print("3. 가장 큰 지출")
    print("4. 끝내기")
    choice = input("선택: ")

    if choice == "1":
        kind = input("종류(수입/지출): ")
        while kind != "수입" and kind != "지출":
            print("수입 또는 지출로 입력해 주세요.")
            kind = input("종류(수입/지출): ")

        category = input("분류: ")
        item = input("항목: ")

        amount_text = input("금액: ")
        while not amount_text.isdigit():
            print("숫자만 입력해 주세요.")
            amount_text = input("금액: ")
        amount = int(amount_text)

        if kind == "수입":
            lines.append(f"[{category}] {item} +{amount:,}원")
            amounts.append(amount)
        else:
            lines.append(f"[{category}] {item} -{amount:,}원")
            amounts.append(-amount)
        print("기록했어요.")
    elif choice == "2":
        print(f"모두 {len(lines)}건")
        for line in lines:
            print(line)
        print(f"잔액: {sum(amounts):,}원")
    elif choice == "3":
        if len(amounts) == 0 or min(amounts) >= 0:
            print("지출 기록이 없어요.")
        else:
            smallest = min(amounts)
            position = amounts.index(smallest)
            print(f"가장 큰 지출: {lines[position]}")
    elif choice == "4":
        print("다음에 또 만나요.")
        break
    else:
        print("메뉴 번호로 골라 주세요.")
```

## 5. 혼자 치기

4번 메뉴를 다듬어요.

- 금액이 큰 분류부터 찍어요.
- 금액 뒤에 전체 지출에서 차지하는 비율을 소수 첫째 자리까지 붙여요. `식비: 24,000원 (94.1%)` 모양이에요.
- 지출이 없으면 `지출 기록이 없어요.`를 찍어요.

| 넣은 기록 | 4번을 고르면 |
| --- | --- |
| 아무것도 안 넣음 | `지출 기록이 없어요.` |
| 지출 식비 점심 9000, 지출 교통 버스 1500, 수입 월급 3000000, 지출 식비 저녁 15000 | `식비: 24,000원 (94.1%)`<br />`교통: 1,500원 (5.9%)` |

entries = []

while True:

## 6. 자주 나는 에러

### 없는 이름을 꺼냈어요: KeyError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 2, in <module>
    print(entry["amout"])
          ~~~~~^^^^^^^^^
KeyError: 'amout'
```

맨 아래 `KeyError: 'amout'`이 틀린 이름을 그대로 보여 줘요. 오타를 고치거나, 없을 수도 있는 이름이면 `.get()`을 써요.

### 점으로 꺼냈어요: AttributeError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 2, in <module>
    print(entry.amount)
          ^^^^^^^^^^^^
AttributeError: 'dict' object has no attribute 'amount'
```

딕셔너리 값은 `entry["amount"]`처럼 대괄호로 꺼내요. 점으로 꺼내는 건 7단원에서 배우는 클래스 쪽이에요.

### 리스트에 이름을 썼어요: TypeError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 2, in <module>
    print(entries["amount"])
          ~~~~~~~^^^^^^^^^^
TypeError: list indices must be integers or slices, not str
```

`entries`는 리스트라서 번호만 받아요. 기록 하나를 먼저 꺼낸 다음(`entries[0]["amount"]`, 또는 for로) 이름을 써요.

리스트 안에 딕셔너리가 있으니, 지금 손에 든 게 어느 쪽인지 늘 생각해요.

### items로 sum을 했어요: TypeError

```text
Traceback (most recent call last):
  File "C:\...\python-ledger\main.py", line 2, in <module>
    print(sum(totals.items()))
          ^^^^^^^^^^^^^^^^^^^
TypeError: unsupported operand type(s) for +: 'int' and 'tuple'
```

`.items()`는 쌍을 주니까 숫자와 더할 수 없어요. 합을 구할 때는 `.values()`예요.

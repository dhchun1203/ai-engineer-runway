## 2. 필요한 개념만

`uv run python`으로 REPL을 열어요.

### JSON: 파이썬 자료를 글자로 적는 약속

```python
>>> import json
>>> rows = [{"item": "점심", "amount": 9000}]
>>> json.dumps(rows)
'[{"item": "\\uc810\\uc2ec", "amount": 9000}]'
>>> json.dumps(rows, ensure_ascii=False)
'[{"item": "점심", "amount": 9000}]'
>>> json.loads('[{"item": "점심"}]')
[{'item': '점심'}]
```

JSON은 프로그램끼리 자료를 주고받을 때 가장 많이 쓰는 글자 형식이에요. 리스트와 딕셔너리 모양이 거의 그대로라서 읽기도 쉬워요.

`ensure_ascii=False`를 빼면 한글이 `점`처럼 저장돼요. 한글을 쓸 때는 꼭 붙여요.

### with open: 파일 열고 알아서 닫기

```python
with open("ledger.json", "w", encoding="utf-8") as file:
    json.dump(entries, file, ensure_ascii=False, indent=2)
```

`open`은 파일을 열어요. `"w"`는 쓰기(있으면 덮어쓰기)이고, 안 쓰면 읽기예요. `with`를 쓰면 안쪽이 끝날 때 파일을 알아서 닫아 줘요.

`encoding="utf-8"`도 항상 붙여요. 윈도우는 기본값이 달라서, 빼면 한글에서 에러가 날 수 있어요. `indent=2`는 사람이 읽기 좋게 줄을 나눠 주는 옵션이에요.

| 함수 | 하는 일 |
| --- | --- |
| `json.dump(자료, 파일)` | 자료를 파일에 써요 |
| `json.load(파일)` | 파일을 읽어 자료로 돌려줘요 |
| `json.dumps(자료)` | 자료를 문자열로 돌려줘요 |
| `json.loads(문자열)` | 문자열을 자료로 돌려줘요 |

끝에 `s`가 붙은 쪽이 문자열(string)용이에요.

### try / except: 터질 곳을 미리 받기

```python
try:
    with open("ledger.json", encoding="utf-8") as file:
        return json.load(file)
except FileNotFoundError:
    return []
```

`try` 안에서 에러가 나면 프로그램이 죽는 대신 `except`로 넘어와요. `except` 뒤에는 받을 에러 이름을 써요. 맨 아래 줄에서 봐 온 그 이름이에요.

처음 실행할 때는 파일이 없는 게 당연하니까, 그때는 빈 리스트로 시작해요.

### date: 날짜 다루기

```python
>>> from datetime import date
>>> date.today().isoformat()
'2026-10-31'
>>> date.fromisoformat("2026-10-30")
datetime.date(2026, 10, 30)
>>> "2026-09-28" < "2026-10-02"
True
>>> "2026-10-30".startswith("2026-10")
True
```

`YYYY-MM-DD` 모양 문자열은 **글자 순서가 곧 날짜 순서**예요. 그래서 문자열 그대로 비교하고 정렬해도 돼요. `date.today()`의 값은 실행한 날짜로 나와요.

`date.fromisoformat()`은 문자열을 날짜로 바꾸는데, 날짜가 아니면 ValueError를 내요. 오늘 검사에 이걸 써요.

```python
def signed_amount(entry):
    if entry["kind"] == "수입":
        return entry["amount"]
    return -entry["amount"]


def balance(entries):
    total = 0
    for entry in entries:
        total += signed_amount(entry)
    return total


def biggest_expense(entries):
    biggest = None
    for entry in entries:
        if entry["kind"] == "지출":
            if biggest is None or entry["amount"] > biggest["amount"]:
                biggest = entry
    return biggest


def category_totals(entries):
    totals = {}
    for entry in entries:
        if entry["kind"] == "지출":
            category = entry["category"]
            totals[category] = totals.get(category, 0) + entry["amount"]
    return totals
```

```python
import ledger


def ask_kind():
    kind = input("종류(수입/지출): ")
    while kind != "수입" and kind != "지출":
        print("수입 또는 지출로 입력해 주세요.")
        kind = input("종류(수입/지출): ")
    return kind


def ask_amount():
    amount_text = input("금액: ")
    while not amount_text.isdigit():
        print("숫자만 입력해 주세요.")
        amount_text = input("금액: ")
    return int(amount_text)


def add_entry(entries):
    kind = ask_kind()
    category = input("분류: ")
    item = input("항목: ")
    amount = ask_amount()
    entries.append({"kind": kind, "category": category, "item": item, "amount": amount})
    print("기록했어요.")


def show_list(entries):
    print(f"모두 {len(entries)}건")
    for entry in entries:
        print(f"{ledger.signed_amount(entry):>+12,}원  [{entry['category']}] {entry['item']}")
    print(f"잔액: {ledger.balance(entries):,}원")


def show_biggest(entries):
    biggest = ledger.biggest_expense(entries)
    if biggest is None:
        print("지출 기록이 없어요.")
    else:
        print(f"가장 큰 지출: [{biggest['category']}] {biggest['item']} -{biggest['amount']:,}원")


def show_totals(entries):
    totals = ledger.category_totals(entries)
    if len(totals) == 0:
        print("지출 기록이 없어요.")
    else:
        whole = sum(totals.values())
        ranked = sorted(totals.items(), key=lambda pair: pair[1], reverse=True)
        for category, total in ranked:
            print(f"{category}: {total:,}원 ({total / whole * 100:.1f}%)")
```

## 5. 혼자 치기

프로그램을 튼튼하게 만들어요. 고칠 파일은 `ui.py`와 `storage.py`예요.

- 날짜가 잘못되면 `2026-10-31 같은 모양으로 입력해 주세요.`를 찍고 다시 물어요. `date.fromisoformat()`과 `try / except`를 써요.
- 목록은 날짜순으로 찍어요. 원본 순서는 건드리지 말고 `sorted`로요.
- `ledger.json`이 망가져 있으면 죽지 말고, 파일을 `ledger.json.bak`로 옮긴 뒤 안내를 찍고 빈 가계부로 시작해요.

파일 옮기기는 `import os` 후 `os.replace("원래이름", "새이름")`이에요. 받을 에러 이름은 `json.JSONDecodeError`예요. 옮겨 둔 파일도 내 기록이니, `.gitignore`에 `ledger.json.bak` 한 줄을 더 넣어요.

망가진 파일은 직접 만들어요. `ledger.json`을 열어 내용 중간부터 지우고 저장한 다음 실행해요.

| 해 볼 것 | 나와야 하는 것 |
| --- | --- |
| 날짜에 `2026-13-01`, `10월 30일` | 둘 다 다시 묻기 |
| 25일 기록을 30일 기록 다음에 넣고 2번 | 25일이 위로 |
| `ledger.json` 망가뜨리고 실행 | `저장 파일이 망가져서 ledger.json.bak로 옮겨 뒀어요. 새로 시작해요.`<br />`저장된 기록 0건을 불러왔어요.` |

<details>
<summary>정답 코드 보기: storage.py</summary>

```python
import json
import os

FILE_NAME = "ledger.json"
BACKUP_NAME = "ledger.json.bak"


def load_entries():
    try:
        with open(FILE_NAME, encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        return []
    except json.JSONDecodeError:
        os.replace(FILE_NAME, BACKUP_NAME)
        print(f"저장 파일이 망가져서 {BACKUP_NAME}로 옮겨 뒀어요. 새로 시작해요.")
        return []


def save_entries(entries):
    with open(FILE_NAME, "w", encoding="utf-8") as file:
        json.dump(entries, file, ensure_ascii=False, indent=2)
```

```python
    amount = ask_amount()
    entries.append({"date": day, "kind": kind, "category": category, "item": item, "amount": amount})
    print("기록했어요.")


def show_list(entries):
    print(f"모두 {len(entries)}건")
    for entry in sorted(entries, key=lambda e: e["date"]):
        print(f"{entry['date']} {ledger.signed_amount(entry):>+12,}원  [{entry['category']}] {entry['item']}")
    print(f"잔액: {ledger.balance(entries):,}원")


def show_biggest(entries):
    biggest = ledger.biggest_expense(entries)
    if biggest is None:
        print("지출 기록이 없어요.")
    else:
        print(f"가장 큰 지출: [{biggest['category']}] {biggest['item']} -{biggest['amount']:,}원")


def show_totals(entries):
    totals = ledger.category_totals(entries)
    if len(totals) == 0:
        print("지출 기록이 없어요.")
    else:
        whole = sum(totals.values())
        ranked = sorted(totals.items(), key=lambda pair: pair[1], reverse=True)
        for category, total in ranked:
            print(f"{category}: {total:,}원 ({total / whole * 100:.1f}%)")
```

</details>

날짜를 받는 쪽은 `while True`로 돌면서, 맞으면 `return`으로 빠져나와요. `return`은 반복 안에서도 함수를 바로 끝내요.

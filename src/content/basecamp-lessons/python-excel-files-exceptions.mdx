앞 레슨에서는 데이터를 코드 안에 직접 적었어요. 하지만 실무에서는 데이터가 늘 파일 안에 있죠. 매주 지점에서 올라오는 엑셀 파일처럼요.

오늘은 그 파일을 파이썬으로 여는 법, 결과를 새 엑셀 파일로 저장하는 법을 배워요. 그리고 파일 하나가 깨져 있어도 멈추지 않는 코드를 만드는 법까지요.

> 이 레슨은 공식 STEP 4의 "4-2 엑셀 파일 읽고 쓰기, 멈추지 않는 코드 만들기"에 대응해요. 공식 자료는 카페 지점 파일로 연습하고, 우리는 서점 지점 파일로 같은 내용을 익혀요.

| 파이썬 | 엑셀로 치면 | 오늘 하는 일 |
| --- | --- | --- |
| 파일 읽고 쓰기 | 파일 열기, 저장 | 지점 파일을 읽고, 결과 엑셀 만들기 |
| 예외처리 | 오류 난 칸은 표시하고 넘어가기 | 깨진 파일은 건너뛰고 기록하기 |

이번에도 Colab에서 예제를 직접 실행하며 따라와 주세요. 단, 이번에는 진짜 파일이 있어야 해서 준비부터 하고 시작해요.

## 0. 시작 전 준비: 실습 파일을 Colab에 두기

### 공식 과제의 준비 칸 이해하기

공식 과제는 실습 파일 묶음(zip)을 내려받아 Colab에 올리고 시작해요. 그때 쓰는 준비 칸은 대략 이렇게 생겼어요. 한 줄씩 무슨 일을 하는지 먼저 알아 둘게요.

```python
%cd /content
from google.colab import files

uploaded = files.upload()                  # ① 파일 선택 버튼이 나타나요
zip_name = list(uploaded.keys())[0]        # ② 올린 zip 파일 이름

!unzip -o -q "{zip_name}"                  # ③ 압축 풀기
%cd /content/step4                         # ④ 실습 폴더로 이동
!ls data                                   # ⑤ 파일 목록 확인
```

| 코드 | 하는 일 |
| --- | --- |
| `%cd /content` | Colab의 기본 폴더로 이동 |
| `files.upload()` | 내 컴퓨터의 파일을 Colab에 올리는 [파일 선택] 버튼 만들기 |
| `list(uploaded.keys())[0]` | 올린 파일들의 이름 중 첫 번째 꺼내기 |
| `!unzip -o -q "{zip_name}"` | 올린 zip 파일의 압축 풀기 |
| `%cd /content/step4` | 압축을 푼 폴더로 이동. 이제부터 `"data/파일이름"`으로 파일을 찾을 수 있어요 |
| `!ls data` | data 폴더 안의 파일 목록 보기 |

> `!`나 `%`로 시작하는 줄은 파이썬 코드가 아니라 Colab에게 내리는 명령어예요. 파일을 올리고 폴더를 옮기는 준비 작업에만 쓰니까, 지금은 "준비 칸은 이렇게 생겼구나" 정도로 넘어가도 괜찮아요.

`uploaded`는 사실 딕셔너리예요. 키가 파일 이름이고, 값이 파일 내용이죠. 그래서 `.keys()`로 이름만 꺼낸 뒤 리스트로 바꿔 `[0]`번을 집는 거예요. 앞 레슨에서 배운 것들이 이렇게 조합돼 있어요.

### 우리 레슨의 준비 칸: 재료를 코드로 직접 만들기

우리 레슨에서는 파일을 내려받는 대신, 서점 지점 파일을 코드로 직접 만들어서 써요. 새 Colab 노트를 열고 첫 칸에 아래를 붙여 넣어 실행하세요.

지금 이 코드를 다 이해할 필요는 없어요. 절반쯤은 오늘 배울 "엑셀 쓰기" 코드라서, 레슨을 끝내고 다시 보면 읽힐 거예요.

```python
# 준비 칸: 노트를 열 때마다 맨 처음 한 번 실행하세요
import csv
from pathlib import Path
from openpyxl import Workbook

Path("data").mkdir(exist_ok=True)          # data 폴더 만들기
Path("추가파일").mkdir(exist_ok=True)       # 추가파일 폴더 만들기
header = ["날짜", "지점", "분야", "권수", "가격"]

def make_xlsx(path, rows):
    wb = Workbook()
    sheet = wb.active
    sheet.append(header)
    for row in rows:
        sheet.append(row)
    wb.save(path)

# 종로점: 깔끔한 엑셀 파일
make_xlsx("data/종로점.xlsx", [
    ["2026-10-05", "종로점", "소설", 12, 15000],
    ["2026-10-05", "종로점", "에세이", 8, 13000],
    ["2026-10-05", "종로점", "IT", 5, 32000],
])
# 신촌점: 숫자가 "15,000" 같은 글자로, 분야 앞뒤에 공백이 있는 파일
make_xlsx("data/신촌점.xlsx", [
    ["2026-10-05", "신촌점", " 소설 ", "20", "15,000"],
    ["2026-10-05", "신촌점", " 에세이", "6", "13,000"],
    ["2026-10-05", "신촌점", "IT ", "9", "32,000"],
])
# 해운대점: 엑셀이 아닌 CSV 파일
with open("data/해운대점.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(header)
    writer.writerow(["2026-10-05", "해운대점", "소설", 15, 15000])
    writer.writerow(["2026-10-05", "해운대점", "에세이", 10, 13000])
    writer.writerow(["2026-10-05", "해운대점", "IT", 3, 32000])
# 광주점: 이름만 .xlsx 이고 속은 깨진 파일 (예외처리 연습용)
Path("data/광주점.xlsx").write_text("이 파일은 일부러 깨뜨린 파일이에요")
# 대구점: 다음 주에 새로 도착할 파일 (과제 보강 레슨에서 사용)
make_xlsx("추가파일/대구점.xlsx", [
    ["2026-10-05", "대구점", "소설", 7, 15000],
    ["2026-10-05", "대구점", "에세이", 11, 13000],
    ["2026-10-05", "대구점", "IT", 4, 32000],
])
print(sorted(p.name for p in Path("data").iterdir()))
```

마지막에 이 줄이 보이면 준비 완료예요.

```text
['광주점.xlsx', '신촌점.xlsx', '종로점.xlsx', '해운대점.csv']
```

만들어진 파일은 이런 모양이에요. 공식 과제의 파일 묶음과 똑같은 구성이에요. 깔끔한 파일, 지저분한 파일, CSV 파일, 깨진 파일, 그리고 나중에 추가될 파일.

| 폴더 | 파일 | 어떤 파일인가요 |
| --- | --- | --- |
| data | 종로점.xlsx | 깔끔한 엑셀 파일 |
| data | 신촌점.xlsx | 숫자가 "15,000" 같은 글자로, 분야 앞뒤에 공백이 있는 파일 |
| data | 해운대점.csv | 엑셀이 아닌 CSV 파일 |
| data | 광주점.xlsx | 일부러 깨뜨린 파일 (예외처리 연습용) |
| 추가파일 | 대구점.xlsx | 다음 주에 새로 도착할 파일 (과제 보강 레슨에서 사용) |

두 폴더 모두 Colab의 기본 위치(`/content`) 안에 생겨요.

### 올라간 파일 눈으로 확인하기

Colab 왼쪽 세로 메뉴에서 폴더 모양(파일) 아이콘을 누르면 지금 Colab 안에 있는 파일이 보여요. 목록이 바로 안 보이면 패널 위쪽의 새로고침 버튼을 눌러 보세요.

`sample_data` 폴더는 Colab이 기본으로 넣어 둔 것이라 신경 쓰지 않아도 돼요.

### 꼭 알아 둘 두 가지

첫째, 노트를 새로 열 때마다 준비 칸부터 실행하세요. Colab 연결이 끊기면 파일도 함께 사라져요.

다시 열었을 때 FileNotFoundError가 나면 준비 칸을 다시 실행하면 돼요. 작성한 코드는 노트에 그대로 저장돼 있어요.

둘째, 코드로 저장한 파일은 내 컴퓨터가 아니라 Colab 안에 생겨요. 내 컴퓨터로 가져오는 법은 조금 뒤 "엑셀 쓰기"에서 알려 드릴게요.

## 1. 먼저 알아 둘 것: 파일 경로

파이썬이 파일을 찾으려면 파일이 어디 있는지(경로) 알려 줘야 해요.

`"data/종로점.xlsx"`는 "지금 위치에서 data 폴더 안의 종로점.xlsx"라는 뜻이에요. 우리 준비 칸은 Colab의 기본 위치(`/content`)에 data 폴더를 만들었어요. 공식 과제는 `%cd /content/step4`로 실습 폴더에 들어가 있고요.

파일을 못 찾으면 FileNotFoundError가 나요. 대부분 준비 칸을 실행하지 않았거나 파일 이름에 오타가 있는 경우예요.

## 2. 엑셀 파일의 구조

파이썬으로 엑셀을 다룰 때는 openpyxl이라는 도구를 써요. Colab에는 보통 이미 설치돼 있어요.

혹시 `No module named 'openpyxl'` 에러가 나면, 새 칸에서 `!pip install openpyxl`을 실행하세요.

openpyxl은 엑셀 파일을 이렇게 세 겹으로 봐요.

| 이름 | 뜻 | 코드에서 |
| --- | --- | --- |
| Workbook | 엑셀 파일 하나 | `load_workbook(...)`, `Workbook()` |
| Worksheet | 그 안의 시트 한 장 | 보통 첫 번째 시트인 `wb.active` |
| Cell | 시트의 칸 하나 | `sheet["A1"]`, `sheet["B2"]` |

책으로 치면 Workbook은 책 한 권, Worksheet는 그 안의 한 장, Cell은 그 장의 한 칸이에요.

> openpyxl은 엑셀 프로그램 없이 파이썬이 파일을 직접 읽고 써요. 유료 엑셀이 없어도 실습할 수 있어요.

## 3. 엑셀 읽기

```python
from openpyxl import load_workbook

wb = load_workbook("data/종로점.xlsx")    # ① 파일 열기 (Workbook)
sheet = wb.active                        # ② 첫 번째 시트 선택 (Worksheet)

print(sheet.max_row)                     # 4   ← 몇 줄인지 (제목 1줄 + 데이터 3줄)
print(sheet["D2"].value)                 # 12  ← 칸 하나 읽기 (엑셀처럼 주소로)
```

`sheet["D2"]`는 D열 2행 칸이에요. 칸 자체가 아니라 안에 든 값이 필요하니까 `.value`를 붙여요.

### 모든 줄을 한 번에 읽기

```python
for row in sheet.iter_rows(values_only=True):   # 한 줄씩 읽기
    print(row)
# ('날짜', '지점', '분야', '권수', '가격')
# ('2026-10-05', '종로점', '소설', 12, 15000)
# ('2026-10-05', '종로점', '에세이', 8, 13000)
# ('2026-10-05', '종로점', 'IT', 5, 32000)
```

- `iter_rows()`: 시트를 위에서부터 한 줄씩 꺼내 줘요.
- `values_only=True`: 칸의 값만 꺼내요.
- 한 줄은 `( )` 괄호로 묶여 나와요. 이건 튜플이에요. 리스트와 비슷하지만 고칠 수 없는 묶음이에요. 우리는 읽기만 할 거라 괜찮아요.

### 제목 줄과 데이터 줄 나누기

```python
rows = list(sheet.iter_rows(values_only=True))   # 모든 줄을 리스트로
header = rows[0]     # 첫 줄 = 열 이름
body = rows[1:]      # 두 번째 줄부터 끝까지 = 데이터

print(header)        # ('날짜', '지점', '분야', '권수', '가격')
print(body[0])       # ('2026-10-05', '종로점', '소설', 12, 15000)
print(len(body))     # 3
```

`rows[1:]`은 "1번부터 끝까지"라는 뜻이에요(슬라이싱). 제목 줄만 빼고 가져올 때 자주 써요.

### 한 줄을 딕셔너리로 바꾸기

지금 `body[0]`은 값만 있어서, 몇 번째 값이 권수인지 번호로 기억해야 해요. 열 이름과 짝지어 딕셔너리로 만들면 훨씬 편해요.

```python
print(dict(zip(header, body[0])))
# {'날짜': '2026-10-05', '지점': '종로점', '분야': '소설', '권수': 12, '가격': 15000}
```

`zip`은 두 묶음을 지퍼처럼 하나씩 짝지어 줘요. 같은 자리에 있는 것끼리 한 쌍이 돼요.

| 자리 | `header`에서 | `body[0]`에서 | 딕셔너리에서 |
| --- | --- | --- | --- |
| 1번째 | `'날짜'` | `'2026-10-05'` | `'날짜': '2026-10-05'` |
| 2번째 | `'지점'` | `'종로점'` | `'지점': '종로점'` |
| 3번째 | `'분야'` | `'소설'` | `'분야': '소설'` |
| 4번째 | `'권수'` | `12` | `'권수': 12` |
| 5번째 | `'가격'` | `15000` | `'가격': 15000` |

> `dict(zip(...))`은 처음엔 낯설어요. 지금은 "열 이름과 값을 짝지어 딕셔너리로 만드는 공식"이라고만 기억해도 충분해요. 이렇게 만들면 앞 레슨에서 배운 "한 행 = 딕셔너리" 모양이 돼요.

### 모든 줄을 한꺼번에 딕셔너리로

한 줄씩 하던 걸 모든 줄에 하려면 for문으로 모으면 돼요.

```python
table = []
for row in body:
    table.append(dict(zip(header, row)))

print(len(table))        # 3
print(table[2]["분야"])   # IT
```

이 네 줄을 한 줄로 줄여 쓰는 문법도 있어요. 리스트 컴프리헨션이라고 불러요.

```python
table = [dict(zip(header, row)) for row in body]
print(len(table))        # 3
```

`[만들 것 for 하나 in 묶음]` 모양이에요. "body에서 한 줄씩 꺼내, 딕셔너리로 만들어서, 리스트에 담아"라고 읽으면 돼요. 공식 과제 코드에 이 모양이 나오니 눈에 익혀 두세요.

## 4. CSV 읽기

CSV는 엑셀에서 "다른 이름으로 저장, CSV"로 만드는 파일이에요. 메모장으로 열어 보면 이렇게 생겼어요.

```text
날짜,지점,분야,권수,가격
2026-10-05,해운대점,소설,15,15000
2026-10-05,해운대점,에세이,10,13000
```

값 사이를 쉼표(`,`)로 구분한 단순한 글자 파일이라, 어떤 프로그램에서도 열 수 있어요. 그래서 회사 시스템에서 데이터를 내려받으면 CSV인 경우가 많아요.

Colab 파일 패널에서 data 폴더의 해운대점.csv를 더블클릭하면 내용을 직접 볼 수도 있어요.

CSV는 파이썬에 기본으로 들어 있는 csv 도구로 읽어요.

```python
import csv

with open("data/해운대점.csv", encoding="utf-8-sig") as f:   # ① 파일 열기
    rows = list(csv.DictReader(f))                            # ② 한 줄 = 딕셔너리로 읽기

print(len(rows))    # 3
print(rows[0])
# {'날짜': '2026-10-05', '지점': '해운대점', '분야': '소설', '권수': '15', '가격': '15000'}
```

| 코드 | 뜻 |
| --- | --- |
| `with open(...) as f:` | 파일을 열고, 들여쓴 부분이 끝나면 자동으로 닫아 줘요 |
| `encoding="utf-8-sig"` | 한글이 깨지지 않게 읽는 방식. 엑셀에서 저장한 CSV는 이걸 쓰세요 |
| `csv.DictReader(f)` | 첫 줄을 열 이름으로 써서, 각 줄을 딕셔너리로 바로 만들어 줘요 |

엑셀처럼 `dict(zip(...))`을 하지 않아도 `DictReader`가 알아서 딕셔너리로 만들어 줘요.

### 눈여겨볼 점: CSV는 모든 값을 글자로 읽어요

위 결과에서 권수가 `15`가 아니라 `'15'`예요. 따옴표가 붙었다는 건 글자라는 뜻이죠.

```python
print(rows[0]["권수"] + rows[1]["권수"])             # 1510  ← 15 + 10이 아니라 이어 붙이기!
print(int(rows[0]["권수"]) + int(rows[1]["권수"]))   # 25    ← 숫자로 바꿔야 제대로 계산
```

그래서 계산 전에 반드시 `int()`나, 앞 레슨에서 만든 `to_number()`로 숫자로 바꿔야 해요.

> `encoding="utf-8-sig"` 대신 `"utf-8"`로 읽으면 첫 열 이름 앞에 눈에 안 보이는 글자가 붙어요. 그러면 `row["날짜"]`로 꺼낼 수 없게 돼요(KeyError). 한글 CSV가 이상하면 인코딩부터 의심하세요.

## 5. 엑셀 쓰기

읽기의 반대예요. 새 파일을 만들고, 줄을 쌓고, 저장해요.

```python
from openpyxl import Workbook

wb = Workbook()                          # ① 새 엑셀 파일 만들기
sheet = wb.active                        # ② 기본 시트 선택
sheet.title = "요약"                      # ③ 시트 이름 바꾸기

sheet.append(["지점", "총매출"])           # ④ 한 줄 추가 (제목 줄)
sheet.append(["종로점", 444000])           #    한 줄 추가
sheet.append(["해운대점", 451000])         #    한 줄 추가

memo = wb.create_sheet("메모")            # ⑤ 시트 하나 더 만들기
memo["A1"] = "이번 주 특이사항 없음"        #    칸에 직접 쓰기

wb.save("연습.xlsx")                      # ⑥ 저장!
print(wb.sheetnames)                     # ['요약', '메모']
```

`연습.xlsx` 파일에 요약, 메모 두 시트가 생겼어요. `wb.sheetnames`는 시트 이름 목록을 리스트로 보여 줘요. 결과를 확인할 때 쓸모 있으니 기억해 두세요.

| 코드 | 하는 일 |
| --- | --- |
| `sheet.append([...])` | 리스트를 맨 아래 새 줄에 추가 |
| `sheet["A1"] = 값` | 특정 칸에 값 쓰기 |
| `wb.create_sheet("이름")` | 새 시트 추가 |
| `wb.save("파일명.xlsx")` | 파일로 저장 (이걸 안 하면 아무것도 안 남아요!) |
| `wb.sheetnames` | 시트 이름 목록 |

### 만든 파일 내 컴퓨터로 가져오기

1. 왼쪽 파일 패널에서 `연습.xlsx`를 찾아요. (안 보이면 새로고침)
2. 파일 이름 옆 점 세 개(⋮) 메뉴에서 다운로드를 눌러요.
3. 받은 파일을 Excel 웹(office.com)이나 구글 시트에 올려서 열어 봐요. 요약, 메모 시트 두 개가 보이면 성공이에요.

### 저장할 때 주의할 점

- 같은 이름의 파일이 있으면 묻지 않고 덮어써요.
- 나중에 내 컴퓨터(VS Code 등)에서 실행할 때, 저장하려는 파일이 엑셀에서 열려 있으면 PermissionError가 나요. 엑셀을 닫고 다시 실행하세요.

## 6. 예외처리: 에러가 나도 멈추지 않기

### 에러가 나면 무슨 일이 생길까요?

파이썬은 에러를 만나면 그 자리에서 멈춰요. 그 아래 코드는 하나도 실행되지 않아요.

지점 파일 10개를 처리하는데 3번째 파일이 깨져 있다면요? 나머지 7개도 처리되지 않고 멈춰 버려요. 매주 돌려야 하는 자동화 툴이라면 곤란하죠.

### 에러 메시지 읽는 법

에러가 나면 겁먹지 말고 맨 아래 줄부터 읽으세요. Colab에서 아래를 실행해 보면

```python
int("확인필요")
```

이런 메시지가 나와요.

```text
ValueError                                Traceback (most recent call last)
/tmp/ipython-input-...
----> 1 int("확인필요")                         ← ② 에러가 난 줄 (화살표로 표시)

ValueError: invalid literal for int() with base 10: '확인필요'
↑ ① 에러 종류           ↑ ③ 무엇이 문제인지
```

- 에러 종류(ValueError): 어떤 성격의 문제인지
- 에러가 난 줄(`---->` 화살표): 어디서 났는지
- 설명: `'확인필요'`는 정수로 바꿀 수 없다는 뜻

메시지 모양은 Colab 버전에 따라 조금씩 달라요. 맨 아래 줄(종류와 설명)과 `---->` 화살표(위치), 이 두 가지만 찾으면 돼요.

### 실무에서 자주 만나는 에러

| 에러 | 언제 나나요? | 예시 |
| --- | --- | --- |
| ValueError | 값의 모양이 잘못됨 | `int("확인필요")` |
| KeyError | 딕셔너리에 없는 키 | `row["권수"]`인데 열 이름이 판매권수 |
| IndexError | 리스트에 없는 번호 | `genres[10]` |
| FileNotFoundError | 파일이 없음 | 경로 오타, 준비 칸을 실행하지 않음 |
| PermissionError | 파일을 쓸 권한 없음 | (내 컴퓨터에서) 결과 엑셀이 열려 있음 |
| BadZipFile | 엑셀 파일이 깨짐 | 이름만 .xlsx인 파일 (우리의 광주점!) |
| NameError | 없는 변수나 함수 이름 | 오타, 앞 칸을 실행하지 않음 |

BadZipFile이 낯설죠? 사실 .xlsx 파일은 속이 zip 압축 파일이에요. 그래서 속이 깨진 엑셀을 열면 "zip 파일이 아니에요"라는 에러가 나요.

### try / except: 에러가 나도 계속 가기

```python
try:
    print(int("확인필요"))                          # 에러가 날 수 있는 코드
except Exception as e:
    print("숫자로 못 바꿨어요:", type(e).__name__)   # 에러가 나면 대신 실행
print("계속 진행!")
# 숫자로 못 바꿨어요: ValueError
# 계속 진행!
```

동작 순서는 이래요.

1. `try:` 안의 코드를 실행해요.
2. 에러가 없으면 `except` 부분은 건너뛰어요.
3. 에러가 나면 그 자리에서 `try`를 멈추고 `except` 부분을 실행해요.
4. 어느 쪽이든 그다음 코드(`print("계속 진행!")`)는 계속 실행돼요.

| 부분 | 뜻 |
| --- | --- |
| `try:` | "일단 시도해 봐" |
| `except Exception as e:` | "에러가 나면 이쪽을 실행해. 에러 정보는 e에 담아 둬" |
| `Exception` | "모든 종류의 에러" |
| `type(e).__name__` | 에러 종류의 이름 (예: `'ValueError'`) |

### 특정 에러만 잡기

`Exception` 대신 에러 이름을 쓰면 그 에러만 잡아요. 무슨 문제가 생길지 알 때는 이렇게 쓰는 게 더 정확해요.

```python
for v in ["12", "확인필요", "8"]:
    try:
        print(int(v))
    except ValueError:
        print("숫자가 아님:", v)
# 12
# 숫자가 아님: 확인필요
# 8
```

"확인필요" 하나 때문에 멈추지 않고, 문제만 표시한 뒤 다음 값으로 넘어갔어요. 엑셀에서 오류 칸만 노란색으로 칠해 두고 나머지 작업을 계속하는 것과 같아요.

### 과제 미리 보기: 파일 여러 개 처리하기

과제에서는 이 패턴을 파일 단위로 써요. 광주점.xlsx가 바로 일부러 깨뜨린 파일이에요.

```python
from openpyxl import load_workbook

errors = []                                       # 문제 있던 파일 기록장

for name in ["종로점.xlsx", "광주점.xlsx", "신촌점.xlsx"]:
    try:
        sheet = load_workbook("data/" + name).active
        print("[성공]", name)
    except Exception as e:
        errors.append(name)                       # 기록!
        print("[건너뜀]", name, type(e).__name__)

print("확인 필요한 파일:", errors)
# [성공] 종로점.xlsx
# [건너뜀] 광주점.xlsx BadZipFile
# [성공] 신촌점.xlsx
# 확인 필요한 파일: ['광주점.xlsx']
```

광주점이 깨져 있어도 신촌점까지 끝까지 처리했어요. 그리고 무엇을 건너뛰었는지 `errors`에 남겼죠.

### 좋은 예외처리의 3원칙

1. 멈추지 않는다: 문제 있는 것만 건너뛰고 나머지는 처리한다.
2. 숨기지 않는다: 건너뛴 건 반드시 기록한다.
3. 알아볼 수 있게 남긴다: 나중에 "광주점 파일 다시 보내 주세요"라고 말할 수 있을 만큼.

반대로 이런 코드는 가장 위험해요.

```python
try:
    ...
except:
    pass        # 에러를 조용히 삼켜 버림
```

에러가 나도 아무 표시 없이 넘어가서, 데이터가 빠진 걸 아무도 모르게 돼요. 결과는 틀렸는데 틀린 줄도 모르는 상황이에요.

## 한 장 요약

| 하고 싶은 것 | 핵심 코드 | 기억할 것 |
| --- | --- | --- |
| 엑셀 열기 | `load_workbook(경로).active` | 파일, 시트, 칸의 세 겹 |
| 모든 줄 읽기 | `iter_rows(values_only=True)` | 한 줄은 튜플, 첫 줄은 열 이름 |
| 한 줄을 딕셔너리로 | `dict(zip(header, row))` | 열 이름과 값을 짝짓는 공식 |
| CSV 읽기 | `csv.DictReader(f)`, `utf-8-sig` | 모든 값이 글자라 숫자로 바꾸기 |
| 엑셀 쓰기 | `Workbook()`, `append`, `create_sheet`, `save` | save를 안 하면 아무것도 안 남아요 |
| 멈추지 않기 | `try: ... except Exception as e:` | 건너뛴 건 반드시 기록 |

이제 재료가 다 모였어요. 과제 보강 레슨에서 이 조각들을 조립해, 서점 지점 파일을 한 번에 정리하는 자동화 툴을 함께 만들어 봐요.

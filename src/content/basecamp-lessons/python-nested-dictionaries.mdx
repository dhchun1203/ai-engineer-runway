딕셔너리는 이름표로 값을 찾는 자료형이었어요. "아메리카노"라고 물으면 4500원이라고 답해 주는 작은 안내 데스크 같은 거죠.

그런데 세상일은 그렇게 한 겹으로 끝나지 않아요. 카페 한 곳의 메뉴판이 아니라, 여러 카페의 메뉴판을 한꺼번에 들고 있어야 할 때가 생겨요.

이럴 때 필요한 게 바로 중첩 딕셔너리예요. 딕셔너리 안에 또 딕셔너리를 넣는 거죠. 큰 서랍장을 하나 두고, 그 안에 작은 서랍을 여러 개 넣는 모습을 떠올리면 딱이에요.

이번 레슨도 읽기만 하지 말고, 나오는 코드를 Colab에 직접 쳐 보면서 따라와 주세요. 눈으로 본 것보다 손으로 친 것이 훨씬 오래 남아요.

> 이 레슨은 심화 과제 1번(중첩 딕셔너리 다루기)을 스스로 풀 수 있게 준비시켜요. 안쪽 값들의 평균을 항목마다 구하는 법, 그중 가장 큰 값을 찾는 법, 그리고 이 모든 걸 한 줄로 줄이는 딕셔너리 컴프리헨션까지 익히면, 과제는 예제만 바꿔 끼우면 되는 수준이 돼요.

## 1. 중첩 딕셔너리가 뭘까요

중첩 딕셔너리는 값(value) 자리에 또 다른 딕셔너리가 들어간 딕셔너리예요.

카페 이름을 바깥 열쇠(key)로 두고, 그 값으로 각 카페의 메뉴판 딕셔너리를 넣어 볼게요.

```python
# 카페마다 메뉴 가격표를 딕셔너리로 담아요
cafes = {
    "이음": {"아메리카노": 4500, "라떼": 5000, "콜드브루": 4800},
    "볕": {"아메리카노": 4000, "라떼": 4700, "콜드브루": 5200},
}

# 바깥 열쇠 "이음"으로 들어가면, 안에 또 딕셔너리가 나와요
print(cafes["이음"])
# 출력: {'아메리카노': 4500, '라떼': 5000, '콜드브루': 4800}

# 대괄호를 한 번 더 붙이면 안쪽 값까지 꺼낼 수 있어요
print(cafes["이음"]["라떼"])
# 출력: 5000
```

대괄호를 두 번 쓰는 게 핵심이에요. 첫 번째 대괄호로 어느 카페인지 고르고, 두 번째 대괄호로 그 카페의 어느 메뉴인지 고르는 거죠.

서랍장에서 "이음" 서랍을 열고, 그 안에서 다시 "라떼" 칸을 여는 것과 똑같아요.

## 2. 두 겹을 순회하기 (중첩 for 문)

값 하나만 꺼낼 게 아니라 전부 훑어보고 싶을 때가 많아요. 이럴 때 `.items()`를 씁니다.

`.items()`는 딕셔너리를 돌 때 열쇠와 값을 짝으로 같이 꺼내 줘요.

```python
# 바깥을 먼저 돌고, 그 안에서 다시 안쪽을 돌아요
for cafe_name, menu in cafes.items():
    print(f"[{cafe_name}]")
    for item_name, price in menu.items():
        print(f"  {item_name}: {price}원")

# 출력:
# [이음]
#   아메리카노: 4500원
#   라떼: 5000원
#   콜드브루: 4800원
# [볕]
#   아메리카노: 4000원
#   라떼: 4700원
#   콜드브루: 5200원
```

바깥 for 문이 카페를 하나 고르면, 안쪽 for 문이 그 카페의 메뉴를 전부 훑어요. 카페가 바뀌면 안쪽 순회가 처음부터 다시 시작되고요.

값만 필요할 때는 `.values()`를 쓰면 열쇠는 빼고 값만 꺼내 줘요.

```python
# "이음"의 가격들만 모아서 보고 싶을 때
for price in cafes["이음"].values():
    print(price)
# 출력:
# 4500
# 5000
# 4800
```

## 3. 항목마다 평균 구하기

이제 각 카페의 평균 메뉴 가격을 구해 볼게요. 평균은 합계를 개수로 나누면 되죠.

값들을 다 더하는 건 `sum(menu.values())`, 개수를 세는 건 `len(menu)`예요.

```python
# 한 카페의 평균 가격을 먼저 구해 봐요
menu = cafes["이음"]
average = sum(menu.values()) / len(menu)
print(average)
# 출력: 4766.666666666667
```

소수점이 너무 길게 나오죠. `round(값, 2)`를 쓰면 소수점 아래 둘째 자리까지만 남겨요.

```python
average = round(sum(menu.values()) / len(menu), 2)
print(average)
# 출력: 4766.67
```

이제 이걸 모든 카페에 적용해서, 카페 이름을 평균 가격에 연결한 새 딕셔너리를 만들어 볼게요.

```python
# 카페 이름 -> 평균 가격 을 담을 빈 딕셔너리부터 준비해요
cafe_avg = {}

for cafe_name, menu in cafes.items():
    cafe_avg[cafe_name] = round(sum(menu.values()) / len(menu), 2)

print(cafe_avg)
# 출력: {'이음': 4766.67, '볕': 4633.33}
```

빈 딕셔너리를 하나 만들어 두고, for 문을 돌면서 한 칸씩 채워 넣는 흐름이에요. 이 패턴은 정말 자주 쓰니 손에 익혀 두면 좋아요.

이제 심화 과제에서는 카페와 메뉴 대신, 여러분에게 주어진 데이터로 똑같은 흐름을 직접 만들어 보세요.

## 4. 안쪽에서 가장 큰 값 찾기

한 카페에서 가장 비싼 메뉴가 무엇인지 찾고 싶어요. 값이 아니라 그 값을 가진 열쇠(메뉴 이름)를 알고 싶은 거죠.

이럴 때 `max()`에 `key=` 옵션을 함께 씁니다.

```python
menu = cafes["볕"]

# key=menu.get 은 "각 메뉴 이름을 비교할 때 가격을 기준으로 삼아라" 라는 뜻이에요
most_expensive = max(menu, key=menu.get)
print(most_expensive)
# 출력: 콜드브루
```

`key=menu.get`이 조금 낯설 텐데, 풀어서 설명해 볼게요.

`max(menu)`만 쓰면 파이썬은 메뉴 이름끼리 비교해 버려요. 우리가 원하는 건 이름이 아니라 가격 비교죠.

그래서 `key=menu.get`으로 "각 이름을 비교할 때는 `menu.get(이름)`, 즉 그 이름의 가격을 꺼내서 비교해라"라고 알려 주는 거예요. 무엇을 기준으로 크기를 잴지 정해 주는 안내판이라고 보면 돼요.

가격까지 같이 보고 싶으면 이렇게 하면 돼요.

```python
name = max(menu, key=menu.get)
print(f"가장 비싼 메뉴는 {name}, {menu[name]}원이에요")
# 출력: 가장 비싼 메뉴는 콜드브루, 5200원이에요
```

가장 싼 메뉴가 궁금하면 `max` 대신 `min`을 쓰면 되고, `key=menu.get`은 그대로 두면 돼요.

## 5. 딕셔너리 컴프리헨션으로 한 줄 만들기

3번에서 for 문 여러 줄로 만들었던 평균 딕셔너리를, 딕셔너리 컴프리헨션이라는 방법으로 한 줄로 줄일 수 있어요.

기본 모양은 이래요.

```python
# {키: 식 for 키, 값 in 딕셔너리.items()}
```

왼쪽 중괄호 안에서 "새 열쇠: 새 값"의 모양을 정하고, 오른쪽에서 "무엇을 하나씩 돌 것인가"를 정해요. for 문을 안팎이 뒤집힌 형태로 한 줄에 담았다고 생각하면 편해요.

3번의 코드를 그대로 옮겨 볼게요.

```python
# for 문 버전 (3번에서 만든 것)
cafe_avg = {}
for cafe_name, menu in cafes.items():
    cafe_avg[cafe_name] = round(sum(menu.values()) / len(menu), 2)

# 컴프리헨션 버전 (같은 결과, 한 줄)
cafe_avg = {
    cafe_name: round(sum(menu.values()) / len(menu), 2)
    for cafe_name, menu in cafes.items()
}

print(cafe_avg)
# 출력: {'이음': 4766.67, '볕': 4633.33}
```

두 코드의 결과는 완전히 똑같아요. 컴프리헨션은 "빈 딕셔너리 만들기 + for 문 + 한 칸씩 채우기"를 한 문장으로 압축한 것뿐이에요.

처음에는 for 문으로 먼저 짠 다음, 익숙해지면 컴프리헨션으로 줄이는 순서를 추천해요. 그러면 무슨 일이 벌어지는지 놓치지 않아요.

이제 심화 과제에서는 이 한 줄 패턴으로 여러분의 데이터를 요약해 보세요.

## 한 줄 정리

중첩 딕셔너리는 대괄호 두 번으로 안쪽 값을 꺼내고, `.items()`로 두 겹을 순회하며, `sum/len`으로 평균을, `max(딕셔너리, key=딕셔너리.get)`으로 최고값을 찾고, 이 모든 걸 딕셔너리 컴프리헨션 한 줄로 줄일 수 있어요.

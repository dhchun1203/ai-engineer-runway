## 1. NumPy: 숫자 계산을 빠르게

NumPy는 숫자로 이루어진 묶음(배열)을 빠르고 간편하게 계산하게 해 주는 도구예요.

평균, 표준편차, 최댓값처럼 자주 쓰는 통계를 함수 한 줄로 끝낼 수 있어요.

```python
import numpy as np

측정값들 = np.array([23.5, 24.1, 22.9, 25.3, 24.0, 26.8])

print("평균:", np.mean(측정값들))
print("표준편차:", np.std(측정값들))
print("중앙값:", np.median(측정값들))
print("최댓값:", np.max(측정값들))
print("최솟값:", np.min(측정값들))
```

첫 줄 `import numpy as np`는 NumPy 도구를 불러오면서 앞으로는 `np`라는 짧은 이름으로 부르겠다는 뜻이에요. 파이썬 세계에서는 관례적으로 NumPy를 `np`로 줄여 써요.

### 리스트로도 되는데, 왜 굳이 NumPy 배열을 쓸까요?

파이썬 기본 리스트(`[23.5, 24.1, ...]`)에도 값을 담을 수는 있어요.

하지만 리스트는 그냥 "값들의 묶음"일 뿐, 계산 기능이 없어요. 평균 하나를 구하려 해도 `합계 = 0`으로 시작해서 반복문으로 하나씩 더한 뒤 개수로 나누는 과정을 직접 짜야 했죠.

반면 NumPy 배열(`np.array()`)은 "계산 기능이 내장된 리스트"라고 생각하면 편해요. `np.mean()`, `np.std()`처럼 함수 하나만 부르면 배열 전체의 통계가 바로 나와요.

겉모습은 리스트와 비슷하지만 속은 달라요. 리스트는 값 하나하나를 파이썬이 일일이 처리하는 반면, NumPy 배열은 값들을 한 덩어리로 묶어 한 번에 계산하도록 설계돼 있어요. 이걸 벡터화 연산이라고 불러요.

그래서 데이터가 수만, 수백만 개로 많아질수록 NumPy가 리스트보다 훨씬 빠르게 계산해요.

정리하면 이래요.

- 리스트: 값을 담는 상자. 계산하려면 반복문을 직접 써야 함
- NumPy 배열: 값을 담으면서 통계와 연산 기능까지 갖춘 상자. 함수 한 줄로 계산 가능

## 2. Pandas: 표 형태 데이터 다루기

실제 데이터는 측정값 하나만 달랑 있는 경우가 드물어요. "이름, 번호, 날짜, 측정값, 담당자"처럼 여러 정보가 표(엑셀) 형태로 있는 경우가 대부분이죠.

이런 표 데이터를 다루는 도구가 Pandas예요. 관례적으로 `pd`라는 이름으로 줄여 써요.

Pandas의 핵심은 DataFrame이에요. 엑셀 시트 한 장을 파이썬 코드 안으로 그대로 가져왔다고 생각하면 쉬워요. 행과 열로 된 표 구조를 그대로 가지면서, 동시에 파이썬 코드로 자유롭게 계산하고 가공할 수 있어요.

```python
import pandas as pd

데이터 = {
    "로트번호": ["L001", "L002", "L003", "L004", "L005"],
    "측정값": [23.5, 26.1, 22.9, 27.0, 24.5]
}

df = pd.DataFrame(데이터)
print(df)
print(df["측정값"].mean())
print(df.describe())
```

딕셔너리(`{"컬럼명": [값들], ...}`)를 `pd.DataFrame()`에 넣으면, 각 키가 컬럼(열) 이름이 되고 값 리스트가 그 컬럼의 데이터가 되는 표가 만들어져요. `df["측정값"]`처럼 대괄호 안에 컬럼명을 넣으면 그 컬럼만 따로 꺼내 쓸 수 있어요.

> 참고: `describe()`는 개수(count), 평균(mean), 표준편차(std), 최솟값(min), 최댓값(max) 같은 걸 한 번에 보여줘요. 데이터를 처음 받았을 때 전체 분포를 빠르게 훑어보는 용도로 자주 써요.

### `df`를 출력하면 왼쪽에 뜨는 숫자(0, 1, 2...)는 뭔가요?

`print(df)`를 실행하면 맨 왼쪽에 0, 1, 2... 번호가 자동으로 붙어요. 이걸 인덱스(index)라고 해요. 각 행에 자동으로 매겨지는 "행 번호표"예요.

우리가 따로 만든 게 아니라 Pandas가 알아서 붙여 줘요. 나중에 특정 행을 찾거나(`df.loc[0]`처럼) 데이터를 정렬하고 병합할 때 이 번호가 기준으로 쓰여요.

### 더 알아보기: `df["측정값"] > 25.0`이 어떻게 한 번에 계산되나요?

Pandas가 이 비교를 컬럼 안의 각 값에 대해 자동으로 하나씩 반복해 줘요. 우리가 반복문을 직접 쓰지 않아도, Pandas 안에서는 반복문과 똑같은 일이 일어나는 거예요.

그 결과로 `True`/`False`가 값 개수만큼 나오고, 그걸 새 컬럼에 그대로 담을 수 있어요. 이렇게 반복문 없이 컬럼 전체를 한 번에 계산하는 방식은 NumPy에서도 Pandas에서도 똑같이 쓰이는 핵심 아이디어예요.

이걸 미리 보는 이유는, 숫자로 계산해야 할 컬럼이 실수로 문자열로 저장돼 있으면 평균이나 표준편차 계산이 아예 안 되기 때문이에요.

```python
print(df.shape)       # (행 수, 열 수)
```

### 더 알아보기: `dtypes`에 나오는 `float64`, `object`는 뭔가요?

`df.dtypes`를 실행하면 컬럼마다 이런 자료형이 나와요.

- `int64`: 소수점이 없는 정수 (예: 5)
- `object`: 대부분 문자열(텍스트). "로트번호", "검사자"처럼 글자로 된 컬럼이 여기에 해당해요.


### 더 알아보기: 결측치(NaN)가 정확히 뭔가요?

결측치는 "값이 0이다"나 "빈 문자열이다"와는 달라요.

아예 아무 값도 기록되지 않은 상태를 말해요. 실무에서는 센서 오류, 측정 누락, 담당자 미기입 같은 이유로 생겨요.

Pandas는 이 상태를 `NaN`(Not a Number)이라는 특별한 값으로 표시해요.

`NaN`이 섞인 컬럼은 평균을 낼 때 자동으로 빠지기도 하고, 때로는 에러를 일으키기도 해서 미리 확인해 두는 게 중요해요.

## 6. 예외 처리 가볍게 알아보기

데이터는 늘 깨끗하지 않아요. 숫자가 들어 있어야 할 칸에 오타나 빈칸, 이상한 문자가 섞여 있는 경우도 있겠지요?

이럴 때 아무 안전장치 없이 코드를 돌리면, 데이터 하나 때문에 프로그램 전체가 멈춰 버려요.

`try`/`except`는 "이 부분에서 오류가 나도 멈추지 말고, 대신 이렇게 처리해라"는 안전장치예요.

```python
값 = "23.5"

try:
    숫자값 = float(값)
    print("변환 성공:", 숫자값)
except:
    print("숫자로 변환할 수 없는 값입니다")
```

### 더 알아보기: `try`/`except`는 정확히 어떻게 동작하나요?

`try` 블록 안의 코드를 먼저 실행해 봐요. 오류 없이 끝나면 `except`는 아예 무시돼요.

오류가 나면 그 순간 즉시 `except` 블록으로 넘어가서 그 안의 코드를 실행해요. 프로그램은 멈추지 않고 계속 진행돼요.

### 연습문제 3

아래 리스트에는 정상적인 숫자와, 숫자로 바꿀 수 없는 값이 섞여 있어요.

`try`/`except`를 반복문과 함께 써서, 변환 가능한 값만 숫자로 바꿔 출력하고, 변환에 실패한 값은 "건너뜀"이라고 출력해 보세요.

```python
측정값_원본 = ["23.5", "24.1", "측정불가", "25.3", ""]
```

<details>
<summary>정답 확인 (충분히 고민해 보셨나요?)</summary>

## 한 줄 정리

NumPy는 숫자 배열의 통계를 함수 한 줄로 뽑아 주고, Pandas는 표 데이터를 DataFrame으로 다뤄 컬럼 단위로 계산하며, 실제 CSV는 `read_csv`로 불러와 `shape`, `dtypes`, `isnull().sum()`으로 구조와 결측치를 먼저 확인하고, 지저분한 값은 `try`/`except`로 걸러 낸다.

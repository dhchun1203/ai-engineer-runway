지금까지 배운 코드는 위에서 아래로 한 줄씩 그냥 흘러갔어요. 그런데 진짜 프로그램은 "상황을 보고 다르게 행동"하고, "같은 일을 여러 번 되풀이"해요.

"비가 오면 우산을 챙긴다"가 조건문이고, "100명에게 똑같이 문자를 보낸다"가 반복문이에요. 이 두 가지가 붙는 순간 코드가 갑자기 살아 움직여요.

개념은 어렵지 않은데 실수가 가장 많이 나오는 부분이에요. 그러니 눈으로만 읽지 말고 Colab에 직접 쳐 보면서 따라와 주세요.

## 1. 조건문: 상황에 따라 갈라지기

조건문은 "이 조건이 참이면 이걸 하라"고 코드에 길을 갈라 주는 문법이에요. 기본은 `if` 예요.

```python
temperature = 30

if temperature >= 28:
    print("에어컨을 켜세요")
```

`if 조건:` 다음 줄에, 안으로 들여쓴 코드가 "조건이 참일 때 할 일"이에요.

### 들여쓰기가 곧 문법이에요

파이썬에서 가장 자주 걸려 넘어지는 지점이에요. 다른 언어는 괄호로 묶지만, 파이썬은 **들여쓰기(보통 공백 4칸)** 로 "이 줄들이 if에 속한다"를 표시해요.

```python
if temperature >= 28:
    print("덥네요")      # 들여쓰기 O -> if에 속함
    print("에어컨 켜요")  # 들여쓰기 O -> if에 속함
print("끝")              # 들여쓰기 X -> if와 상관없이 항상 실행
```

들여쓰기가 어긋나면 오류가 나거나, 의도와 다르게 동작해요. 한 블록 안에서는 들여쓰기 칸 수를 똑같이 맞춰 주세요.

### 조건에 쓰는 연산자

조건은 보통 "값을 비교"해서 참/거짓을 만들어요.

- 비교: `==`(같다), `!=`(다르다), `>`, `>=`, `<`, `<=`
- 논리: `and`(둘 다 참), `or`(하나라도 참), `not`(반대로)

```python
age = 20

if age >= 19 and age < 65:
    print("성인 요금")
```

여기서 `=`(값 대입)과 `==`(같은지 비교)를 헷갈리지 않도록 조심하세요. 비교할 때는 항상 `==` 예요.

### if, elif, else

갈림길이 여러 개면 `elif`(else if)로 잇고, 어디에도 안 걸리면 `else` 로 받아요.

```python
score = 82

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
# 출력: B
```

위에서부터 검사해서 **처음 참이 되는 하나만** 실행하고 나머지는 건너뛰어요.

### 짧게 쓰는 표현

값 하나를 조건에 따라 정할 때는 한 줄로 줄일 수 있어요.

```python
age = 20
ticket = "성인" if age >= 19 else "청소년"
print(ticket)   # 성인
```

## 2. 반복문: 같은 일을 되풀이하기

같은 코드를 100번 복사할 수는 없죠. 반복문은 "이 일을 여러 번 하라"고 시키는 문법이에요.

### for문: 정해진 만큼 반복

`for` 는 리스트 같은 묶음의 원소를 하나씩 꺼내며 돌아요.

```python
fruits = ["사과", "귤", "포도"]

for fruit in fruits:
    print(fruit, "맛있어요")

# 사과 맛있어요
# 귤 맛있어요
# 포도 맛있어요
```

몇 번 반복인지 숫자로 정하고 싶으면 `range()` 를 써요.

```python
for i in range(3):     # 0, 1, 2
    print(i, "번째")
```

### 조건문과 함께 쓰기

반복 안에서 조건으로 걸러내는 조합이 실무에서 정말 많이 나와요.

```python
scores = [88, 42, 95, 60, 77]

for s in scores:
    if s >= 60:
        print(s, "합격")
    else:
        print(s, "불합격")
```

### 반복 안에 반복 (이중 for문)

표(가로 x 세로)처럼 두 겹으로 도는 것도 돼요. 바깥이 한 번 돌 때 안쪽이 통째로 다 돌아요.

```python
for dan in range(2, 4):        # 2단, 3단
    for i in range(1, 4):      # 1, 2, 3
        print(dan, "x", i, "=", dan * i)
```

### while문: 조건이 참인 동안 반복

몇 번인지 미리 모르고 "어떤 조건이 될 때까지" 돌 때는 `while` 을 써요.

```python
count = 3
while count > 0:
    print(count)
    count = count - 1     # 이 줄이 없으면 영원히 멈추지 않아요
print("발사!")
```

`while` 은 조건을 언젠가 거짓으로 만들어 주지 않으면 무한 반복에 빠져요. 반복 안에서 조건에 쓰인 값을 꼭 바꿔 주세요.

## 3. 실전 예시: 데이터를 보고 판단하기

조건문과 반복문을 합치면 "데이터를 하나씩 보며 규칙에 따라 처리"하는, 분석의 가장 기본 동작이 돼요.

```python
students = [
    {"이름": "김민수", "점수": 88},
    {"이름": "이서연", "점수": 52},
    {"이름": "박지훈", "점수": 74},
]

pass_count = 0
for s in students:
    if s["점수"] >= 60:
        print(s["이름"], "합격")
        pass_count = pass_count + 1
    else:
        print(s["이름"], "재시험")

print("합격 인원:", pass_count, "명")
```

딕셔너리(각 학생), 리스트(명부), 반복문(한 명씩), 조건문(합격 여부)이 한자리에 모였어요. 앞에서 배운 것들이 이렇게 맞물려요.

## 한 줄 정리

조건문(`if` / `elif` / `else`)은 상황에 따라 코드를 갈라 주고, 반복문(`for` / `while`)은 같은 일을 되풀이해요. 파이썬은 들여쓰기로 블록을 구분하니 그 칸을 꼭 맞추고, `while` 은 무한 반복에 빠지지 않게 조건 값을 바꿔 주세요.

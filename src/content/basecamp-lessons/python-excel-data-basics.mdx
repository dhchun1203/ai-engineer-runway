## 엑셀 자동화가 뭔가요?

손으로 반복하던 엑셀 작업을 파이썬이 대신 처리하게 만드는 거예요. 코드를 한 번만 만들어 두면, 다음 주에도 그다음 주에도 파일만 넣고 실행하면 같은 작업이 금방 끝나요.

예를 들면 이런 일들이에요.

| 업무 | 카페 프랜차이즈라면 |
| --- | --- |
| 여러 파일 하나로 합치기 | 매주 들어오는 지점별 매출 파일을 통합 파일 하나로 |
| 데이터 정리하기 | 중복 지우기, 빈칸 처리, `"4,500"` 같은 글자 숫자 바꾸기, 날짜와 전화번호 형식 맞추기 |
| 조건에 따라 분류하기 | 매출 100만 원 이상이면 "우수 고객" 표시 붙이기 |
| 반복 계산하기 | 지점별, 상품별 합계와 평균, 지난주 대비 증감률 |
| 특정 데이터만 뽑기 | 특정 지역 고객, 특정 기간 주문만 골라 따로 저장하기 |
| 보고서 파일 만들기 | 원본 정리부터 계산, 표 작성, 결과 엑셀 저장까지 한 번에 |

### 엑셀 수식으로 하면 안 되나요?

한 번만 하는 합계나 평균이라면 엑셀 수식이 더 빠르고 편해요. 굳이 파이썬을 쓸 필요가 없어요.

파이썬이 빛나는 건 같은 작업을 매주 반복하거나, 파일 여러 개를 다뤄야 할 때예요.

| 상황 | 엑셀 수식 | 파이썬 |
| --- | --- | --- |
| 합계, 평균 계산 | 편리 | 가능하지만 과함 |
| 간단한 조건 분류 | 편리 | 가능 |
| 수천에서 수만 행 처리 | 느려지거나 복잡해짐 | 유리 |
| 여러 엑셀 파일 합치기 | 복사, 붙여 넣기의 반복 | 자동화하기 좋음 |
| 매주 반복되는 정리 | 매번 다시 손봐야 함 | 한 번 만들고 반복 실행 |
| 형식이 제각각인 파일 | 수식이 복잡해짐 | 유리 |
| 다른 시스템이나 AI와 연결 | 제한적 | 가능 |

엑셀 수식은 "엑셀 안에서 계산하는 도구"이고, 파이썬은 "엑셀을 포함한 반복 업무 자체를 자동화하는 도구"예요.

그리고 파이썬으로 만든 자동화 코드는 나중에 AI 에이전트가 직접 실행하는 도구가 돼요. 이번 주가 AI 에이전트를 향한 첫걸음인 이유예요.

| 예외처리 | 오류 난 칸은 표시하고 넘어가기 | (다음 레슨) 깨진 파일은 건너뛰고 기록하기 |

## 1. 함수: 반복 작업에 이름 붙이기

### 왜 함수가 필요할까요?

엑셀에서 매출을 구할 때 `=D2*E2`를 쓰고 아래로 쭉 끌어내리죠. 파이썬에서도 같은 계산을 여러 번 해야 할 때가 많아요.

그때마다 같은 코드를 복사해 붙여 넣으면 곤란한 일이 생겨요.

- 코드가 길어지고 읽기 어려워져요.
- 계산 방식이 바뀌면(예를 들어 할인이 생기면) 붙여 넣은 곳을 전부 찾아 고쳐야 해요.
- 한 곳이라도 빠뜨리면 결과가 틀려요.

함수는 작업을 한 번만 만들어 두고, 이름으로 불러 쓰는 방법이에요. 고칠 일이 생기면 함수 한 곳만 고치면 돼요.

### 함수의 생김새

몇 잔을 얼마에 팔았는지 받아서 매출을 돌려주는 함수를 만들어 볼게요.

```python
def calc_sales(quantity, price):     # ① def 함수이름(받을 값들):
    result = quantity * price        # ② 할 일 (들여쓰기 필수!)
    return result                    # ③ return 돌려줄 값
```

| 부분 | 뜻 | 엑셀로 치면 |
| --- | --- | --- |
| `def` | "지금부터 함수를 만든다"는 표시 | 없음 |
| `calc_sales` | 함수 이름 | SUM, VLOOKUP 같은 함수 이름 |
| `(quantity, price)` | 함수가 받을 값 (매개변수) | `SUM(A1:A10)`의 괄호 안 |
| `return` | 계산 결과를 돌려줌 | 셀에 표시되는 결과값 |

### 함수 불러 쓰기 (호출)

만든 함수는 이름 뒤에 괄호를 붙이고 값을 넣어서 써요. 이걸 호출이라고 해요.

```python
print(calc_sales(30, 4500))    # 135000
print(calc_sales(12, 5000))    # 60000

gangnam = calc_sales(30, 4500)      # 결과를 변수에 담을 수도 있어요
hongdae = calc_sales(25, 4500)
print(gangnam + hongdae)            # 247500
```

`calc_sales(30, 4500)`을 실행하면 이런 순서로 움직여요.

```text
calc_sales(30, 4500)
    │
    ▼  quantity = 30, price = 4500 이 들어감
    result = 30 * 4500 = 135000
    │
    ▼  return 135000
calc_sales(30, 4500) 자리가 135000 으로 바뀜
```

마지막 줄이 핵심이에요. 함수를 부른 자리가 돌려받은 값으로 싹 바뀐다고 생각하면 돼요.

### 헷갈리기 쉬운 것: print와 return은 달라요

둘 다 "결과를 내놓는" 것처럼 보여서 자주 헷갈려요. 직접 비교해 볼게요.

```python
def show(q, p):
    print(q * p)        # 화면에 보여 주기만 함

def give(q, p):
    return q * p        # 결과를 돌려줌

a = show(3, 1000)       # 화면에 3000 이 찍힘
b = give(3, 1000)       # 화면에는 아무것도 안 찍힘

print("a =", a)         # a = None   ← 돌려받은 게 없어요!
print("b =", b)         # b = 3000
```

- `print`는 눈으로 보여 주기만 해요. 그 값을 다른 계산에 쓸 수 없어요.
- `return`은 결과를 돌려줘서, 변수에 담거나 다른 계산에 쓸 수 있어요.
- 함수가 계산한 값을 나중에 써야 한다면 반드시 `return`을 쓰세요.

`None`은 파이썬의 "아무것도 없음"이에요. `return`이 없는 함수는 조용히 `None`을 돌려줘요.

### 기본값 정해 두기

자주 쓰는 값은 미리 정해 둘 수 있어요. 아메리카노 한 잔 값이 대부분 4500원이라면 이렇게요.

```python
def calc_sales(quantity, price=4500):    # price를 안 주면 4500으로
    return quantity * price

print(calc_sales(10))          # 45000   ← price 생략, 4500 사용
print(calc_sales(10, 5000))    # 50000   ← price를 주면 그 값 사용
```

### 자주 하는 실수

| 실수 | 증상 | 고치는 법 |
| --- | --- | --- |
| `def` 줄 끝에 `:` 빠뜨림 | SyntaxError | `def 이름():` 콜론 확인 |
| 함수 안쪽을 들여쓰지 않음 | IndentationError | 함수 안 코드는 스페이스 4칸 들여쓰기 |
| `return` 빠뜨림 | 결과가 `None` | 돌려줄 값이 있으면 `return` |
| 함수를 만들기 전에 호출 | NameError | `def`가 호출보다 위에 있어야 해요 |

### 연습문제 1

가격 `price`를 받아서 부가세 10%를 더한 값을 돌려주는 함수 `add_tax(price)`를 만들어 보세요. `add_tax(10000)`의 결과는 `11000`이 나와야 해요.

<details>
<summary>정답 확인 (충분히 고민해 보셨나요?)</summary>

```python
def add_tax(price):
    return round(price * 1.1)

print(add_tax(10000))    # 11000
```

`round()` 없이 `return price * 1.1`만 쓰면 결과가 `11000`이 아니라 `11000.0`으로 나와요. 1.1처럼 소수를 곱하면 결과도 소수(실수)가 되기 때문이에요.

`round()`로 반올림하면 깔끔한 정수가 돼요. `price + price // 10`처럼 정수 나눗셈(`//`)으로 계산해도 돼요.

## 2. 글자 정리하기: 실무 파일은 늘 지저분해요

지점에서 올라온 엑셀 파일을 열어 보면 이런 값이 흔해요.

- `" 카페라떼 "`: 앞뒤에 공백이 붙어 있어요. 컴퓨터는 이걸 `"카페라떼"`와 다른 값으로 봐요.
- `"1,200"`: 숫자처럼 보이지만 글자로 저장돼 있어요. 계산이 안 돼요.

파이썬에는 글자(문자열)를 정리하는 기능이 들어 있어요.

| 기능 | 하는 일 | 예시 | 결과 |
| --- | --- | --- | --- |
| `.strip()` | 앞뒤 공백 지우기 | `" 카페라떼 ".strip()` | `'카페라떼'` |
| `.replace(A, B)` | A를 B로 바꾸기 | `"1,200".replace(",", "")` | `'1200'` |
| `int()` | 글자를 정수로 | `int("1200")` | `1200` |
| `str()` | 숫자를 글자로 | `str(4500)` | `'4500'` |

### 왜 꼭 숫자로 바꿔야 할까요?

```python
print("1,200" + "1")                         # 1,2001  ← 글자끼리는 이어 붙이기가 돼요!
print(int("1,200".replace(",", "")) + 1)     # 1201    ← 숫자로 바꿔야 계산이 돼요
```

글자 상태로 더하면 계산이 아니라 이어 붙이기가 돼요. 무서운 건 에러도 안 난다는 점이에요. 틀린 줄 모르고 넘어가기 쉬워요.

### 기능 이어서 쓰기

점(`.`)을 이어 붙이면 여러 정리를 한 줄에 할 수 있어요. 왼쪽부터 차례로 실행돼요.

```python
value = " 4,500 "
print(int(value.replace(",", "").strip()))    # 4500
#        " 4,500 " → " 4500 " → "4500" → 4500
```

### 함수로 만들어 두기

이 정리 작업을 함수로 만들어 두면, 어떤 값이 와도 한 줄로 숫자로 바꿀 수 있어요.

```python
def to_number(value):
    """ '1,200' 같은 글자를 1200 숫자로 바꾼다 """
    return int(str(value).replace(",", "").strip())

print(to_number("4,500"))    # 4500   ← 쉼표 있는 글자
print(to_number(4500))       # 4500   ← 이미 숫자
print(to_number(" 30 "))     # 30     ← 공백 있는 글자
```

맨 앞에 `str(value)`를 쓴 이유가 있어요. 값이 이미 숫자 `4500`일 수도 있거든요.

숫자에는 `.replace()`를 쓸 수 없어서, 일단 글자로 바꾼 다음 정리해요. 이렇게 하면 숫자든 글자든 똑같이 처리돼요.

함수 첫 줄의 `""" 설명 """`은 독스트링이라고 불러요. 함수가 무슨 일을 하는지 적는 메모예요. 실행에는 영향이 없지만, 나중에 코드를 보는 사람(미래의 나 포함)에게 큰 도움이 돼요.

공백만 지우는 함수도 하나 만들어 둘게요. 품목 이름이나 지점 이름을 다듬을 때 써요.

```python
def clean_text(value):
    """ ' 아메리카노 ' 처럼 앞뒤에 붙은 공백을 지운다 """
    return str(value).strip()

print(clean_text(" 카페라떼 ") + "!")    # 카페라떼!
```

print(" 바닐라라떼 ".strip() == "바닐라라떼")
print(" 바닐라라떼 " == "바닐라라떼")

셋째 줄은 `" 1,250 "`이 쉼표와 공백이 빠진 숫자 `1250`이 된 다음 2를 곱해서 `2500`이에요.

## 3. 리스트: 여러 값을 순서대로

엑셀 파일을 파이썬으로 가져오면 데이터를 어딘가에 담아야 해요. 그 그릇이 리스트와 딕셔너리예요. 먼저 리스트부터 볼게요.

리스트는 엑셀의 한 열에 값을 쭉 적어 둔 것과 같아요.

```python
menu = ["아메리카노", "카페라떼", "바닐라라떼"]
```

### 꺼내기: 번호(인덱스)로

```python
print(menu[0])        # 아메리카노   ← 첫 번째는 0번!
print(menu[2])        # 바닐라라떼
print(menu[-1])       # 바닐라라떼   ← -1은 맨 마지막
print(len(menu))      # 3           ← 몇 개인지
```

> 파이썬은 번호를 0부터 세요. 첫 번째가 `[0]`, 두 번째가 `[1]`이에요. 없는 번호(`menu[10]`)를 꺼내려고 하면 IndexError가 나요.

### 추가하기: append

```python
menu.append("콜드브루")   # 맨 뒤에 추가
print(menu)              # ['아메리카노', '카페라떼', '바닐라라떼', '콜드브루']
```

과제에서는 파일을 읽을 때마다 판매 기록을 `append`로 계속 쌓아요. 엑셀로 치면 맨 아래 빈 줄에 한 줄씩 붙여 넣는 거예요.

### 하나씩 꺼내 보기: for

```python
for item in menu:
    print("-", item)
# - 아메리카노
# - 카페라떼
# - 바닐라라떼
# - 콜드브루
```

### 숫자 리스트는 바로 계산

```python
qty = [30, 12, 25]
print(sum(qty))       # 67   ← 엑셀의 SUM
print(max(qty))       # 30   ← 엑셀의 MAX
print(min(qty))       # 12   ← 엑셀의 MIN
```

## 4. 딕셔너리: 이름표가 붙은 값 (엑셀의 한 행)

엑셀의 한 행을 떠올려 보세요. 칸마다 열 이름(날짜, 지점, 수량...)이 있고, 그 아래에 값이 있죠. 딕셔너리는 이 "이름: 값" 짝을 모아 둔 거예요.

엑셀에 이런 한 행이 있다고 해 볼게요.

| 지점 | 품목 | 수량 | 단가 |
| --- | --- | --- | --- |
| 강남점 | 아메리카노 | 30 | 4500 |

이 한 행을 딕셔너리로 옮기면 이렇게 돼요. 열 이름이 키가 되고, 그 아래 칸의 값이 값이 돼요.

```python
row = {"지점": "강남점", "품목": "아메리카노", "수량": 30, "단가": 4500}
#       키(이름)  값
```

### 꺼내기: 이름(키)으로

```python
print(row["지점"])                  # 강남점
print(row["수량"] * row["단가"])     # 135000
```

엑셀에서는 D2, E2처럼 위치로 찾죠. 딕셔너리는 `"수량"`, `"단가"`처럼 이름으로 찾아요.

그래서 파일마다 열 순서가 달라도 코드가 깨지지 않아요. 실무 파일은 지점마다 열 순서가 제멋대로인 경우가 많아서, 이 점이 정말 든든해요.

### 추가하기, 바꾸기

```python
row["매출"] = row["수량"] * row["단가"]    # 없던 키 → 새로 추가
print(row)
# {'지점': '강남점', '품목': '아메리카노', '수량': 30, '단가': 4500, '매출': 135000}

row["수량"] = 31                           # 있던 키 → 값이 바뀜
```

엑셀에서 옆에 새 열(매출)을 하나 만드는 것과 같아요.

### 없는 키를 꺼낼 때: .get()

```python
print(row.get("할인", 0))     # 0                 ← 없으면 0을 대신 돌려줌
print(row["할인"])            # KeyError: '할인'  ← 없는 키라서 에러!
```

두 번째 줄은 일부러 에러가 나게 둔 거예요. 실행하면 KeyError가 나는 걸 확인해 보세요.

`.get(키, 기본값)`은 "있으면 꺼내고, 없으면 기본값을 줘"라는 뜻이에요. 조금 뒤 지점별 합계에서 핵심으로 쓰여요.

### 모든 항목 하나씩 보기: .items(), .values()

```python
for key, value in row.items():
    print(key, ":", value)
# 지점 : 강남점
# 품목 : 아메리카노
# 수량 : 31
# 단가 : 4500
# 매출 : 135000

print(list(row.values()))    # ['강남점', '아메리카노', 31, 4500, 135000]
```

`.items()`는 이름과 값을 짝으로, `.values()`는 값만 꺼내 줘요. `list(row.values())`는 한 행의 값들을 넣은 순서대로 리스트로 만들어요. 이 모양은 나중에 결과 엑셀에 한 줄씩 적을 때 그대로 쓰여요.

## 5. 둘을 합치면 엑셀 표 전체

한 행은 딕셔너리, 여러 행은 그 딕셔너리들을 담은 리스트예요. 엑셀에 이런 표가 있다면

| 지점 | 매출 |
| --- | --- |
| 강남점 | 135000 |
| 홍대점 | 90000 |
| 강남점 | 70000 |

파이썬에서는 이렇게 담아요. 한 행이 딕셔너리 하나, 표 전체가 그걸 모은 리스트예요.

```python
sales = [
    {"지점": "강남점", "매출": 135000},   # ← sales[0]
    {"지점": "홍대점", "매출": 90000},    # ← sales[1]
    {"지점": "강남점", "매출": 70000},    # ← sales[2]
]
```

| 하고 싶은 것 | 코드 | 결과 |
| --- | --- | --- |
| 전체 행 수 | `len(sales)` | `3` |
| 두 번째 행 | `sales[1]` | `{'지점': '홍대점', '매출': 90000}` |
| 두 번째 행의 지점 | `sales[1]["지점"]` | `'홍대점'` |

표는 리스트, 한 행은 딕셔너리. 과제의 데이터는 전부 이 모양이에요.

### 연습문제 3

위 `sales`에서 `len(sales)`는 얼마일까요? `sales[1]["지점"]`은요?

<details>
<summary>정답 확인 (충분히 고민해 보셨나요?)</summary>

- `len(sales)` → `3`
- `sales[1]["지점"]` → `'홍대점'`

`len()`은 리스트에 든 항목의 개수를 세요. `sales`에는 딕셔너리(한 행)가 3개 들어 있으니 3이에요.

`sales[1]`은 두 번째 행이에요. 파이썬은 번호를 0부터 세서, `sales[0]`이 첫 번째 줄, `sales[1]`이 두 번째 줄이에요. 두 번째 줄 `{"지점": "홍대점", "매출": 90000}`에서 `"지점"` 값을 꺼내면 `'홍대점'`이에요.

`sales[1]["지점"]`은 왼쪽부터 차례로 읽으면 쉬워요. `sales[1]`로 두 번째 줄을 꺼내고, 거기서 `["지점"]`으로 지점 칸을 꺼내요.

</details>

## 6. 지점별 합계 구하기 (엑셀의 SUMIF)

엑셀에서 `=SUMIF(A:A, "강남점", B:B)`로 하던 일을 파이썬으로 해 볼게요.

```python
sales = [
    {"지점": "강남점", "매출": 135000},
    {"지점": "홍대점", "매출": 90000},
    {"지점": "강남점", "매출": 70000},
]

total = {}                                               # ① 빈 합계표
for row in sales:                                        # ② 한 줄씩 보면서
    branch = row["지점"]                                  # ③ 이 줄의 지점 이름
    total[branch] = total.get(branch, 0) + row["매출"]    # ④ 원래 합계(없으면 0) + 이번 매출

print(total)    # {'강남점': 205000, '홍대점': 90000}
```

for문이 한 바퀴 돌 때마다 `total`이 어떻게 바뀌는지 따라가 볼게요.

| 순서 | 읽은 줄 | `total.get(branch, 0)` | 계산 | 돌고 난 뒤 `total` |
| --- | --- | --- | --- | --- |
| 시작 | 없음 | 없음 | 없음 | `{}` |
| 1바퀴 | 강남점, 135000 | 처음 보는 지점이라 0 | 0 + 135000 | `{'강남점': 135000}` |
| 2바퀴 | 홍대점, 90000 | 처음 보는 지점이라 0 | 0 + 90000 | `{'강남점': 135000, '홍대점': 90000}` |
| 3바퀴 | 강남점, 70000 | 이미 있어서 135000 | 135000 + 70000 | `{'강남점': 205000, '홍대점': 90000}` |

`total.get(branch, 0)`은 "이 지점의 합계가 있으면 가져오고, 처음 보는 지점이면 0부터 시작해 줘"라는 뜻이에요.

> 이 패턴 하나로 지점별, 품목별, 날짜별 합계를 모두 만들 수 있어요. `"지점"`만 `"품목"`으로 바꾸면 품목별 합계가 돼요. 엑셀 피벗 테이블이 하는 일이 바로 이거예요.

### 연습문제 4

위 `sales`의 전체 매출 합계를 for문으로 구해 보세요. 정답은 `295000`이에요.

<details>
<summary>정답 확인 (충분히 고민해 보셨나요?)</summary>

```python
total_sales = 0                                  # ① 합계를 담을 변수, 0에서 시작
for row in sales:                                # ② 한 줄씩 꺼내서
    total_sales = total_sales + row["매출"]       # ③ 지금까지 합계에 이번 줄 매출 더하기
print(total_sales)                               # 295000
```

한 바퀴 돌 때마다 `total_sales`는 이렇게 바뀌어요.

| 순서 | 읽은 줄 | 계산 | `total_sales` |
| --- | --- | --- | --- |
| 시작 | 없음 | 없음 | 0 |
| 1바퀴 | 강남점, 135000 | 0 + 135000 | 135000 |
| 2바퀴 | 홍대점, 90000 | 135000 + 90000 | 225000 |
| 3바퀴 | 강남점, 70000 | 225000 + 70000 | 295000 |

지점별 합계 `total`이 이미 있다면 `sum(total.values())`로도 같은 값을 얻어요. 지점별 합계를 다 더한 값과 전체 합계가 같아야 한다는 사실은, 나중에 과제에서 결과를 검증할 때 아주 쓸모 있어요.

</details>

### 연습문제 5

아래 데이터로 품목별 수량 합계를 구해 보세요. 결과는 `{'아메리카노': 55, '카페라떼': 19}`가 나와야 해요.

```python
orders = [
    {"품목": "아메리카노", "수량": 30},
    {"품목": "카페라떼", "수량": 19},
    {"품목": "아메리카노", "수량": 25},
]
```

<details>
<summary>정답 확인 (충분히 고민해 보셨나요?)</summary>

```python
by_item = {}
for row in orders:
    item = row["품목"]
    by_item[item] = by_item.get(item, 0) + row["수량"]

print(by_item)    # {'아메리카노': 55, '카페라떼': 19}
```

지점별 합계와 모양이 똑같죠. 무엇을 기준으로 묶을지(`"품목"`)와 무엇을 더할지(`"수량"`) 두 군데만 바뀌었어요. 최종 과제에서 AI에게 요청하는 "품목별 합계"도 바로 이 모양이에요.

</details>

## 한 장 요약

| 개념 | 핵심 코드 | 기억할 것 |
| --- | --- | --- |
| 함수 | `def 이름(값): return 결과` | 결과가 필요하면 print가 아니라 return |
| 글자 정리 | `.strip()`, `.replace(",", "")`, `int()` | 글자로 된 숫자는 계산 전에 꼭 숫자로 |
| 리스트 | `[ ]`, `[0]`, `.append()`, `len()` | 번호는 0부터 |
| 딕셔너리 | `{"키": 값}`, `["키"]`, `.get(키, 0)` | 표의 한 행. 위치 대신 이름으로 |
| 표 전체 | 딕셔너리들의 리스트 | 합계는 `total.get(key, 0) + 값` 패턴 |

다음 레슨에서는 이 데이터를 코드에 직접 적는 대신, 공식 실습 파일의 진짜 엑셀과 CSV에서 읽어 와요. 그리고 파일 하나가 깨져도 멈추지 않는 코드를 만들어요.

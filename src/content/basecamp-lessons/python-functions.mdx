코드를 짜다 보면 같은 일을 여기저기서 반복하게 돼요. 그때마다 같은 코드를 복사해 붙이면, 나중에 한 군데를 고칠 때 모든 복사본을 다 찾아 고쳐야 해요.

**함수(function)** 는 이 반복을 이름 하나로 묶는 도구예요. 자판기를 떠올려 보세요. 안에서 어떻게 동작하는지 몰라도, 버튼(이름)을 누르고 돈(입력)을 넣으면 음료(결과)가 나와요. 함수도 똑같아요. 한 번 만들어 두면 이름만 부르면 돼요.

이번 레슨은 내용이 조금 많아요. 한 번에 다 외우려 하지 말고, "이런 게 있구나" 흐름을 잡는 걸 목표로 천천히 따라와 주세요.

## 1. 함수란 무엇일까

함수는 "이름 붙인 코드 묶음"이에요. `def` 로 만들고, 이름을 부르면(호출하면) 그 안의 코드가 실행돼요.

```python
def say_hello():
    print("안녕하세요")
    print("반갑습니다")

say_hello()   # 이 한 줄로 위 두 줄이 실행된다
say_hello()   # 몇 번이든 다시 부를 수 있다
```

`def 함수이름():` 아래에 들여쓴 코드가 함수의 몸통이에요. 만들기만 해서는 아무 일도 안 일어나고, `say_hello()` 처럼 **불러야(호출해야)** 실행돼요.

## 2. 입력을 받고 결과를 돌려주기

자판기가 돈을 받고 음료를 내주듯, 함수도 값을 받아서(입력) 결과를 돌려줄(출력) 수 있어요.

- 받는 값을 넣는 자리를 **매개변수(parameter)** 라고 해요.
- 결과를 돌려줄 때는 `return` 을 써요.

```python
def add(a, b):
    return a + b

result = add(3, 5)    # 3과 5를 넣으면
print(result)         # 8을 돌려받는다
```

`return` 이 있으면 함수는 그 값을 "돌려주고" 끝나요. 그래서 `add(3, 5)` 자리를 마치 값 `8` 처럼 쓸 수 있어요. `return` 이 없으면 함수는 일만 하고 아무 값도 돌려주지 않아요(`None`).

여기서 용어 하나. 함수를 **정의할 때** 자리(a, b)는 매개변수(parameter), 함수를 **부를 때** 실제로 넣는 값(3, 5)은 **인수(argument)** 라고 불러요. 같은 것을 만드는 쪽과 쓰는 쪽에서 다르게 부르는 것뿐이에요.

## 3. 인수를 넣는 여러 방법

### 위치 인수와 키워드 인수

기본은 **순서대로** 넣어요(위치 인수).

```python
def introduce(name, age):
    print(name, "님은", age, "살")

introduce("김민수", 20)      # 순서대로: name="김민수", age=20
```

순서가 헷갈릴 것 같으면 **이름을 붙여서** 넣을 수 있어요(키워드 인수). 그러면 순서가 바뀌어도 정확해요.

```python
introduce(age=20, name="김민수")   # 이름을 붙이면 순서 상관없음
```

### 기본값

매개변수에 미리 값을 정해 두면, 부를 때 안 넘겨도 그 값이 쓰여요.

```python
def greet(name, greeting="안녕하세요"):
    print(greeting, name)

greet("김민수")                  # 안녕하세요 김민수
greet("이서연", "반가워요")       # 반가워요 이서연 (기본값을 덮어씀)
```

자주 쓰는 값을 기본값으로 두면 부를 때 편해져요.

### 가변 인수 (조금 어려우면 흐름만)

몇 개가 올지 모를 때는 `*` 를 붙여 여러 값을 한 번에 받아요. 지금은 "이런 것도 있다" 정도만 알아 두면 충분해요.

```python
def total(*numbers):        # 넘어온 값들이 numbers에 묶여 들어온다
    return sum(numbers)

print(total(1, 2, 3))       # 6
print(total(10, 20, 30, 40))# 100
```

## 4. 지역변수와 전역변수 (흐름만 잡기)

함수 안에서 만든 변수는 그 함수 안에서만 살아요. 이걸 **지역변수(local)** 라고 해요. 함수 밖에서 만든 변수는 **전역변수(global)** 라 어디서나 보이고요.

```python
def calc():
    x = 10        # 지역변수: calc 안에서만 존재
    print(x)

calc()            # 10
# print(x)        # 오류! 밖에서는 x를 모른다
```

이 구분 덕분에 함수마다 자기 변수를 안심하고 쓸 수 있어요. 지금 100% 이해 안 돼도 괜찮아요. 나중에 다시 만나면 조금씩 선명해져요.

## 5. 실전 예시: 반복 계산을 함수로 묶기

같은 계산을 여러 데이터에 반복할 때, 함수로 묶으면 코드가 짧고 고치기 쉬워져요.

```python
def grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "D"

students = [
    {"이름": "김민수", "점수": 88},
    {"이름": "이서연", "점수": 95},
    {"이름": "박지훈", "점수": 72},
]

for s in students:
    print(s["이름"], grade(s["점수"]))

# 김민수 B
# 이서연 A
# 박지훈 C
```

등급 기준이 바뀌면 `grade` 함수 한 곳만 고치면 돼요. 반복문 안에서 함수를 부르는 이 패턴이 데이터 분석 코드의 뼈대예요.

## 한 줄 정리

함수는 **같은 코드를 이름 하나로 재사용하는** 도구예요. `def` 로 만들고, 매개변수로 값을 받고, `return` 으로 결과를 돌려줘요. 위치/키워드 인수와 기본값으로 부르는 방법을 유연하게 바꿀 수 있고, 반복문과 함께 쓰면 데이터 처리 코드가 훨씬 깔끔해져요.

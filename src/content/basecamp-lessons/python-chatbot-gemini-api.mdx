드디어 마지막 조각이에요. 2편에서 우리는 검색어를 받아 맞는 영화를 찾아 주는 기능까지 만들었어요.

그런데 지금 챗봇의 답은 이래요. "코코 (2017, 애니메이션, 평점 8.4)". 데이터를 그대로 늘어놓은 거죠.

진짜 챗봇이라면 이렇게 답할 거예요. "코코는 2017년에 나온 애니메이션 영화예요. 평점이 8.4로 꽤 높은 편이고요."

같은 정보인데 말투가 다르죠. 이 "말로 풀어 주는" 일을 사람 대신 해 주는 게 언어 AI예요. 오늘은 구글의 Gemini를 불러와 우리 챗봇의 입을 달아 줍니다.

> 이번 편은 인터넷에 연결된 AI를 실제로 부릅니다. Google Colab에서 따라 하고, 앞 편에서 만든 검색 함수(`search_as_text`)를 이어서 써요.

## API가 뭐예요?

Gemini 같은 똑똑한 AI를 우리가 직접 만들 수는 없어요. 대신 구글이 만들어 둔 걸 인터넷 너머로 빌려 쓸 수 있어요. 그 빌려 쓰는 창구가 API예요.

전화로 음식을 주문하는 걸 떠올려 보세요. 우리는 주방이 없어도, 전화로 "이거 만들어 주세요" 하고 재료와 요청을 보내면, 주방이 요리해서 돌려주죠.

API도 똑같아요. 우리가 질문과 데이터를 구글의 AI에 보내면, AI가 답을 만들어 돌려줘요. 우리는 주방을 가질 필요 없이 결과만 받으면 돼요.

## API 키 받기

전화 주문에도 내 번호가 필요하듯, API도 "이 요청은 나야"라고 알려 줄 출입증이 필요해요. 그게 API 키예요.

Google AI Studio에 접속해 로그인한 뒤, API 키 발급 메뉴에서 키를 하나 만들어요. 긴 암호 같은 글자가 나오는데, 이게 여러분 전용 출입증이에요.

> 이 키는 비밀번호와 같아요. 코드에 그대로 적어서 남에게 공유하거나 공개된 곳에 올리면 안 돼요. 누군가 가져가면 여러분 이름으로 API를 써 버릴 수 있어요.

그래서 키를 코드에 직접 쓰지 않고, Colab의 보안 비밀 기능에 넣어 둘 거예요. Colab 왼쪽의 열쇠 모양 아이콘을 누르고, 이름은 `GEMINI_API_KEY`로, 값에는 발급받은 키를 넣은 뒤, 노트북 접근을 켜 주세요.

이제 코드에서는 키 값을 직접 쓰지 않고 이렇게 꺼내 써요.

```python
from google.colab import userdata

# 보안 비밀에 저장해 둔 키를 이름으로 꺼내요 (키 값이 코드에 남지 않아요)
api_key = userdata.get("GEMINI_API_KEY")
```

## 설치하고 첫 인사 건네기

이제 Gemini를 부르는 도구를 설치하고, 잘 연결되는지 짧게 확인해 볼게요.

```python
!pip install google-genai
```

```python
from google import genai

# 출입증(키)을 들고 창구를 하나 열어요
client = genai.Client(api_key=api_key)

# model: 어떤 AI를 쓸지, contents: 보낼 말
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="안녕? 한 문장으로 자기소개 해 줘.",
)

print(response.text)
```

`response.text`에 AI가 돌려준 답이 들어 있어요. 실행해서 답이 나오면 연결에 성공한 거예요.

> 모델 이름은 새 버전이 계속 나와요. `gemini-2.5-flash`가 동작하지 않으면 Google AI Studio에서 지금 쓸 수 있는 모델 이름을 확인해 그 이름으로 바꿔 주세요.

## 핵심: 프롬프트에 데이터를 담기

여기가 오늘의 진짜 핵심이에요. 그냥 "코코 어때?"라고만 물으면, Gemini는 자기가 원래 알고 있던 지식으로 답해요. 우리 데이터를 근거로 답하는 게 아니죠. 때로는 없는 내용을 그럴듯하게 지어내기도 해요.

그래서 우리는 질문만 보내지 않고, 검색으로 찾은 데이터도 함께 보내요. 그리고 "이 데이터를 근거로만 답해"라고 부탁해요. AI 리터러시 편에서 배운 좋은 프롬프트의 힘이 여기서 발휘돼요.

말로 보내는 이 부탁 전체를 프롬프트라고 불러요. 재료(데이터)와 요청(질문)을 한 장의 주문서에 같이 적는 셈이에요.

## 검색과 AI 답변 합치기

2편에서 만든 `search_as_text`가 검색어로 데이터를 찾아 문장으로 돌려줬죠. 그 결과를 프롬프트에 담아 Gemini에게 보내는 함수를 만들어요.

먼저 2편의 준비물(영화 표와 검색 함수)을 다시 올려 둘게요.

```python
import pandas as pd

movies = pd.DataFrame({
    "제목": ["인터스텔라", "기생충", "라라랜드", "매드맥스", "코코"],
    "연도": [2014, 2019, 2016, 2015, 2017],
    "장르": ["SF", "드라마", "뮤지컬", "액션", "애니메이션"],
    "평점": [8.6, 8.5, 8.0, 8.1, 8.4],
})

def search_as_text(keyword):
    result = movies[movies["제목"].str.contains(keyword, na=False)]
    if len(result) == 0:
        return "찾는 영화가 없어요."
    lines = []
    for _, row in result.iterrows():
        lines.append(f'{row["제목"]} ({row["연도"]}, {row["장르"]}, 평점 {row["평점"]})')
    return "\n".join(lines)
```

이제 검색 결과를 Gemini에게 건네는 함수예요.

```python
def answer(user_input):
    # 1) 먼저 데이터에서 관련 있는 부분만 찾아요 (2편의 검색)
    found = search_as_text(user_input)

    # 2) 찾은 데이터와 질문을 한 장의 프롬프트에 담아요
    prompt = f"""너는 영화 안내 도우미야. 아래 데이터만 근거로 사용자에게 친절하게 답해 줘.
데이터에 없는 내용은 지어내지 말고 "그 정보는 데이터에 없어요"라고 답해.

[데이터]
{found}

[질문]
{user_input}"""

    # 3) 프롬프트를 Gemini에게 보내고 답을 받아요
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
    )
    return response.text

print(answer("코코"))
# 예시 답변: 코코는 2017년에 나온 애니메이션 영화예요. 평점이 8.4로 꽤 높은 편이에요.
```

세 단계로 흐르는 게 보이죠.

- 먼저 `search_as_text`로 데이터에서 관련 부분을 찾고,
- 그 결과와 질문을 프롬프트에 나란히 담고,
- Gemini에게 보내 자연스러운 답을 받아요.

`f"""..."""`는 여러 줄 글에 값을 끼워 넣는 방법이에요. `{found}` 자리에 검색 결과가, `{user_input}` 자리에 사용자 질문이 들어가요.

여기서는 사용자가 넣은 말을 통째로 검색어로 넘겨 단순하게 만들었어요. 그래서 제목에 든 단어로 물어보면 잘 찾아요. 질문을 더 똑똑하게 해석하는 건 다음 단계의 이야기이고, 지금은 데이터를 근거로 답하는 흐름을 완성하는 게 목표예요.

## Gradio로 챗봇 완성하기

2편에서 화면 붙이는 법은 익혔죠. 부를 함수만 `answer`로 바꾸면 끝이에요.

```python
import gradio as gr

demo = gr.Interface(
    fn=answer,          # 이제 검색 + AI 답변을 하는 함수를 연결해요
    inputs="text",
    outputs="text",
)

demo.launch()
```

이제 입력창에 "코코"나 "기생충"을 넣으면, 데이터에서 찾아 자연스러운 문장으로 답하는 챗봇이 움직여요. 세 조각이 하나로 이어진 순간이에요. 데이터 불러오기, 검색, AI 답변까지요.

## 한 줄 정리

API는 남이 만든 AI를 인터넷 너머로 빌려 쓰는 창구이고, 키로 신원을 밝힌 뒤, 검색한 데이터를 프롬프트에 함께 담아 `client.models.generate_content`로 보내면, 데이터를 근거로 자연스럽게 답하는 챗봇이 완성돼요.

세 편으로 데이터 불러오기, 검색, AI 답변을 모두 만들었어요. 이제 예시 영화 데이터 대신, 여러분이 Kaggle에서 고른 데이터로 바꿔 끼우면 나만의 Q&A 챗봇이 돼요. 그걸 과제로 제출하면 됩니다. 여기까지 왔다면 충분히 해낼 수 있어요.

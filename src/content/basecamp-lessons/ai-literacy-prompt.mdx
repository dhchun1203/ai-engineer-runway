요즘 AI를 한 번도 안 써 본 사람은 거의 없어요.

그런데 AI를 **쓰는 것**과 **잘 쓰는 것**은 다른 이야기예요. 같은 질문을 해도 어떤 사람은 원하는 답을 한 번에 얻고, 어떤 사람은 열 번을 물어도 아쉬운 답만 받아요. 이 차이를 만드는 가장 큰 이유 하나가 바로 **프롬프트(Prompt)** 입니다.

이 레슨은 설명을 읽고 끝내는 게 아니라, 직접 질문을 만들어 보고 결과를 비교해 보도록 짜여 있어요. 그 과정이 훨씬 오래 기억에 남아요.

## 시작 전에, 명심할 5가지 관점

한 데이터 컨퍼런스에서 전략, 데이터, AI 분야 실무자 세 명이 공통으로 강조한 말이 있어요.

> "AI는 옳아 보이는 답을 얼마든지 만들 수 있지만, 그중 하나를 골라 행동하는 건 결국 사람이다."

AI 도구를 다루는 손재주는 시간이 지나면 누구나 비슷해져요. 진짜 차이는 **무엇을 풀지, 무엇을 믿고 무엇을 검증할지, 결과를 어떻게 행동으로 이을지**를 정하는 힘에서 나요.

1. **도구보다 먼저, 누구의 어떤 결정이나 행동을 바꿀지 정한다.** "무슨 도구를 쓸까"가 아니라 "무엇을 바꿀까"가 먼저예요.
2. **판단 기준(지표)을 정확히 정의한다.** 분모, 단위, 범위, 예외 조건까지. "좋아졌다"가 아니라 "무엇이 얼마나"로 말해요.
3. **AI가 만든 결과를 그대로 믿지 않고 다시 검증한다.** 그럴듯함과 맞음은 다르니까요.
4. **결과를 산출물에서 끝내지 않고 타깃, 액션, 지표 변화로 잇는다.** "표를 만들었다"에서 멈추지 않고 "그래서 무엇을 바꿨나"까지 가요.
5. **포트폴리오는 완성도보다 흐름을 보여준다.** 문제에서 기준, 검증, 결정, 행동으로 이어지는 생각의 길이 핵심이에요.

## 잠깐, 나는 AI를 어떻게 써 왔나

본격적으로 배우기 전에 스스로 돌아볼까요. 아래에서 나에게 해당하는 게 많을수록, 이 레슨이 크게 도움이 될 거예요.

- GPT에게 주로 "~가 뭐야?" 형태로만 묻는다.
- 내 상황이나 배경을 설명하고 물어본 적이 거의 없다.
- 역할("~처럼 답해줘")을 준 적이 없다.
- 주로 네이버나 구글 검색 대용으로만 쓴다.
- "표로 정리해줘", "3가지로 나눠줘" 같은 출력 형식을 지정한 적이 없다.
- 보고서, 코드, 분석 결과물, 디자인 시안 같은 걸 만들어 본 적이 없다.

체크가 많이 됐다면 정상이에요. 지금부터 하나씩 바꿔 봐요.

## 1. AI란 무엇일까

AI(Artificial Intelligence)는 데이터를 바탕으로 학습해서, 사람처럼 추론하고 판단하고 예측하도록 만든 컴퓨터 시스템이에요.

예전에는 사람이 모든 규칙을 직접 정해 줘야 했어요. 요즘 AI는 데이터에서 스스로 패턴을 배워서, 처음 보는 입력에도 그럴듯한 답을 내놓아요. 우리가 매일 만나는 예로는 메일 자동 분류, 사진 속 사물 인식, 번역과 요약, 추천, 그리고 질문에 답을 만들어 주는 ChatGPT 같은 것이 있어요.

AI는 동작 방식에 따라 크게 두 가지로 나눠요.

**규칙 기반 AI (Rule-based AI)** 는 사람이 "이런 경우엔 이렇게" 하는 규칙을 하나하나 손으로 적어 둔 AI예요. 적어 둔 상황에서는 정확하지만, 미리 적지 못한 상황을 만나면 꼼짝을 못 해요. 매뉴얼에 있는 것만 답하는 신입 사원을 떠올리면 돼요.

**학습 기반 AI (Learning-based AI)** 는 수많은 예시(데이터)를 보고 패턴을 스스로 익힌 AI예요. 그래서 새로운 상황에도 유연하게 대응해요. 요즘 우리가 쓰는 AI는 대부분 이쪽이에요. 사례를 잔뜩 겪으며 감을 잡은 베테랑에 가까워요.

## 2. AI는 어떤 일을 할 수 있을까

하는 일로 보면 AI는 크게 두 갈래예요.

**분류 AI** 는 입력을 정해진 갈래로 나누거나 값을 예측해요. "이 메일은 스팸일까 아닐까", "이 사진은 고양이일까 강아지일까" 같은 판단이 여기에 속해요.

**생성 AI** 는 새로운 것을 만들어 내요. 글, 코드, 이미지처럼요. ChatGPT가 대표적이에요.

우리가 프롬프트로 다루는 건 주로 이 **생성 AI**, 그중에서도 글을 다루는 LLM(Large Language Model)이에요.

## 3. 프롬프트, AI에게 잘 질문하는 법

### 프롬프트란

프롬프트는 LLM에게 원하는 작업을 시키는 **입력 지시문**이에요. 단순한 질문을 넘어서, 다음을 담아요.

- 수행할 작업 (Task)
- 필요한 정보 (Context)
- 원하는 결과 형식 (Output Format)
- 답변의 기준과 조건 (Constraint)

즉 프롬프트는 "무엇을 원하는지"를 AI에게 전달하는, 사람과 AI 사이의 **인터페이스**예요.

비유하면 이래요. 후배에게 "자소서 써줘"라고만 하면 목적도 대상도 몰라 헤매요. 하지만 목적, 대상, 조건, 형식을 알려 주면 원하는 결과가 나와요. AI도 똑같아요.

### 같은 요청, 다른 결과

**막연한 프롬프트**

```text
자기소개서 작성해줘.
```

AI는 작성 목적, 대상, 강조할 내용, 문체를 알 수 없어서 그저 일반적인 글을 뱉어요.

**구조화된 프롬프트**

```text
목표:
신입 백엔드 개발자 지원용 자기소개서 작성

지원자 정보:
- 컴퓨터공학 비전공자
- Spring Boot 프로젝트 경험 보유
- 협업 경험 강조 필요

조건:
- 500자 이내
- 성장 과정 → 기술 경험 → 지원 동기 순서
- 채용 담당자가 읽기 쉬운 문체

출력 형식:
자기소개서 형태로 작성
```

같은 요청이라도 맥락을 구체적으로 줄수록 결과가 원하는 것에 가까워져요.

### 좋은 프롬프트의 6가지 구성 요소

| 구성 요소 | 설명 | 예시 |
| --- | --- | --- |
| Instruction | AI가 수행할 작업 | "마케팅 전략을 분석해줘" |
| Input | 분석에 쓸 데이터 | 고객 리뷰, 기획서 |
| Context | 문제 상황과 배경 | 신규 서비스 출시 상황 |
| Role | AI에게 줄 역할 | "당신은 PM 전문가입니다" |
| Output Format | 결과물 형태 | 표, Markdown, JSON |
| Constraint | 결과물의 제한 | 500자 이내, 3가지 제안 |

### 나쁜 예 vs 좋은 예

**아쉬운 프롬프트**

```text
학습 계획을 작성해줘.
```

정보가 부족해서 AI가 대상, 목적, 말투를 혼자 추측해야 해요.

**좋은 프롬프트**

```text
Role:
당신은 AI Engineer 교육과정 수강생입니다.

Goal:
AI 엔지니어 직무 지원을 위한 학습 계획을 작성해주세요.

Context:
저는 비전공자로 AI 분야 취업을 준비하고 있습니다.
이 교육과정에서 Python, LLM, RAG, AI Agent 등을 학습할 예정입니다.
9개월 후 AI 엔지니어 취업을 목표로 하고 있습니다.

Constraint:
- 초보자도 따라갈 수 있는 단계별 계획으로 작성
- 각 단계별 필요한 학습 내용 포함
- 주차별 목표 형태로 정리
- 실습 프로젝트 아이디어 3개 추가

Output:
Markdown 표 형식으로 작성
```

역할(Role), 목표(Goal), 맥락(Context), 조건(Constraint), 출력(Output)을 갖추자 AI가 훨씬 쓸 만한 계획을 내놓아요.

## 4. 직접 해보기

이제 배운 걸 써 볼 차례예요. 읽기만 하면 안 남아요. 직접 만들어 보고 비교하는 순간 내 것이 돼요.

**해보기 1. 단순 vs 구조화 비교**
내가 실제로 필요한 것 하나를 고르세요(예: 이번 주 공부 계획, 이메일 초안). 그것을 (1) 막연한 한 줄 프롬프트와 (2) 위 6요소를 갖춘 구조화 프롬프트로 각각 써서 같은 AI에 넣어 보세요. 두 답을 나란히 놓고 무엇이 달라졌는지 적어 보세요.

**해보기 2. 재검증 관점 적용**
위에서 받은 답에서 사실처럼 보이는 문장 하나를 골라, 그게 정말 맞는지 직접 확인해 보세요. 그럴듯함과 맞음이 어떻게 다른지 몸으로 느껴 볼 수 있어요.

공식 베이스캠프의 ZEP 프로젝트 활동지에 나만의 프롬프트를 작성해 제출하면, 이 레슨이 실제 활동으로 이어져요.

## 한 줄 정리

AI를 잘 쓰는 힘은 도구 숙련이 아니라, **무엇을 풀지 정하고(문제), 기준을 세우고(지표), 결과를 검증해(신뢰) 행동으로 잇는 판단력**이에요. 프롬프트는 그 판단을 AI에게 정확히 전달하는 언어고요.

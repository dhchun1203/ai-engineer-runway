손으로 하면 30분 걸리는 일이에요. 파일을 하나씩 열고, 복사하고, 붙여 넣고, 숫자를 고치고, 합계를 내고요. 이걸 코드가 1초 만에 해 주면 어떨까요?

> 이 두 편은 공식 STEP 4 최종 과제(나만의 엑셀 자동 정리 툴 만들기)를 직접 만들어 보며 익히는 보강 레슨이에요. 공식 과제는 카페 프랜차이즈 판매 실적을 다루고, 우리는 서점 체인 판매 기록으로 같은 흐름을 처음부터 끝까지 완성해 봐요. 흐름을 다 익히고 나면 공식 과제의 빈칸 7개는 스스로 채울 수 있을 거예요.

## 이번 상황

여러분은 동네 서점 체인 본사의 운영팀이에요. 매주 월요일, 지점에서 판매 파일이 도착하면 하나로 모아 지점별 매출 합계를 보고해야 해요.

그런데 파일 상태가 제각각이에요.

- 신촌점: 가격이 `"15,000"`처럼 글자로 들어 있고, 분야 이름 앞뒤에 공백이 있어요.
- 해운대점: 엑셀이 아니라 CSV로 보내왔어요.
- 광주점: 파일이 열리지 않아요.

실무에서 정말 흔한 상황이에요. 이 지저분함을 코드가 알아서 처리하게 만드는 게 오늘의 목표예요.

## 준비하기

### 재료 파일 만들기

공식 과제는 실습 zip 파일(카페 지점 파일)을 올리고 시작하죠. 이 보강 레슨에서는 그 파일을 쓰지 않고, 같은 구성의 서점 지점 파일을 코드로 직접 만들어 써요. 공식 과제와 다른 데이터로 한 번 끝까지 만들어 봐야, 공식 과제의 빈칸은 스스로 채울 수 있거든요.

새 Colab 노트를 만들고 첫 칸에 아래를 붙여 넣어 실행하세요. 지금 이 코드를 다 이해할 필요는 없어요. 절반쯤은 [엑셀 파일 읽고 쓰기 레슨](/basecamp/python-excel-files-exceptions)에서 배운 "엑셀 쓰기" 코드예요.

```python
# 준비 칸: 노트를 열 때마다 맨 처음 한 번 실행하세요
import csv
from pathlib import Path
from openpyxl import Workbook

Path("data").mkdir(exist_ok=True)          # data 폴더 만들기
Path("추가파일").mkdir(exist_ok=True)       # 추가파일 폴더 만들기
header = ["날짜", "지점", "분야", "권수", "가격"]

def make_xlsx(path, rows):
    wb = Workbook()
    sheet = wb.active
    sheet.append(header)
    for row in rows:
        sheet.append(row)
    wb.save(path)

# 종로점: 깔끔한 엑셀 파일
make_xlsx("data/종로점.xlsx", [
    ["2026-10-05", "종로점", "소설", 12, 15000],
    ["2026-10-05", "종로점", "에세이", 8, 13000],
    ["2026-10-05", "종로점", "IT", 5, 32000],
])
# 신촌점: 숫자가 "15,000" 같은 글자로, 분야 앞뒤에 공백이 있는 파일
make_xlsx("data/신촌점.xlsx", [
    ["2026-10-05", "신촌점", " 소설 ", "20", "15,000"],
    ["2026-10-05", "신촌점", " 에세이", "6", "13,000"],
    ["2026-10-05", "신촌점", "IT ", "9", "32,000"],
])
# 해운대점: 엑셀이 아닌 CSV 파일
with open("data/해운대점.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(header)
    writer.writerow(["2026-10-05", "해운대점", "소설", 15, 15000])
    writer.writerow(["2026-10-05", "해운대점", "에세이", 10, 13000])
    writer.writerow(["2026-10-05", "해운대점", "IT", 3, 32000])
# 광주점: 이름만 .xlsx 이고 속은 깨진 파일 (예외처리 연습용)
Path("data/광주점.xlsx").write_text("이 파일은 일부러 깨뜨린 파일이에요")
# 대구점: 다음 주에 새로 도착할 파일 (과제 보강 레슨에서 사용)
make_xlsx("추가파일/대구점.xlsx", [
    ["2026-10-05", "대구점", "소설", 7, 15000],
    ["2026-10-05", "대구점", "에세이", 11, 13000],
    ["2026-10-05", "대구점", "IT", 4, 32000],
])
print(sorted(p.name for p in Path("data").iterdir()))
```

마지막에 이 줄이 보이면 준비 완료예요.

```text
['광주점.xlsx', '신촌점.xlsx', '종로점.xlsx', '해운대점.csv']
```

만들어진 파일은 공식 실습 파일과 구성이 똑같아요.

| 폴더 | 서점 파일 | 어떤 파일인가요 | 공식 실습 파일에서는 |
| --- | --- | --- | --- |
| data | 종로점.xlsx | 깔끔한 엑셀 파일 | 강남점.xlsx |
| data | 신촌점.xlsx | 숫자가 "15,000" 같은 글자로, 분야 앞뒤에 공백 | 홍대점.xlsx |
| data | 해운대점.csv | 엑셀이 아닌 CSV 파일 | 부산점.csv |
| data | 광주점.xlsx | 일부러 깨뜨린 파일 | 대전점.xlsx |
| 추가파일 | 대구점.xlsx | 다음 주에 새로 도착할 파일 | 판교점.xlsx |

공식 과제의 준비 칸(zip 올리기)은 [엑셀 파일 읽고 쓰기 레슨](/basecamp/python-excel-files-exceptions)에서 한 줄씩 풀어 뒀어요. 그 칸을 실행하면 `/content/step4`로 이동하지만, 이 준비 칸은 Colab 기본 위치(`/content`)에 바로 폴더를 만들어요. 그래서 이 레슨의 코드도 `data` 폴더를 그대로 찾을 수 있어요.

### 도구 불러오기

새 칸에 붙여 넣어 실행하세요. 이번 툴에서 쓸 도구를 한꺼번에 불러오고, 자주 쓸 경로에 이름을 붙여 둬요.

```python
import csv
from pathlib import Path
from openpyxl import Workbook, load_workbook

DATA_FOLDER = Path("data")                # 지점 파일이 있는 폴더
RESULT_FILE = Path("주간판매_정리.xlsx")    # 만들 결과 파일 이름
```

`DATA_FOLDER`처럼 이름을 전부 대문자로 쓴 건 "프로그램 내내 바뀌지 않는 설정값"이라는 표시예요. 파이썬이 강제하는 건 아니고, 사람끼리의 약속이에요.

### 새 도구: Path로 파일 다루기

`Path`는 파일 경로를 다루는 도구예요. 글자로 된 경로(`"data/종로점.xlsx"`)보다 할 줄 아는 게 많아요. 과제에서 쓰는 기능만 짚어 볼게요.

```python
p = DATA_FOLDER / "종로점.xlsx"    # / 로 폴더와 파일 이름을 이어 붙여요
print(p)                          # data/종로점.xlsx
print(p.name)                     # 종로점.xlsx   ← 파일 이름만
print(p.suffix)                   # .xlsx         ← 확장자만

for path in sorted(DATA_FOLDER.iterdir()):    # 폴더 안의 파일을 이름순으로 하나씩
    print(path.name, path.suffix)
# 광주점.xlsx .xlsx
# 신촌점.xlsx .xlsx
# 종로점.xlsx .xlsx
# 해운대점.csv .csv
```

| 코드 | 하는 일 |
| --- | --- |
| `폴더 / "파일이름"` | 경로 이어 붙이기. 여기서 `/`는 나눗셈이 아니에요 |
| `.name` | 파일 이름 (예: `종로점.xlsx`) |
| `.suffix` | 확장자 (예: `.csv`). 엑셀인지 CSV인지 가를 때 써요 |
| `.iterdir()` | 폴더 안의 파일을 하나씩 꺼내 줘요 |
| `sorted(...)` | 이름순으로 정렬. 매번 같은 순서로 처리하려고 써요 |

폴더 안에 무슨 파일이 있는지 코드에 적어 두지 않는다는 점이 중요해요. `iterdir()`가 그때그때 폴더를 들여다보니까, 파일이 늘어나도 코드를 고칠 필요가 없어요. 이게 2편의 "새 파일이 오면 다시 실행만 하기"로 이어져요.

## 1단계. 업무 쪼개기

코드를 쓰기 전에, 손으로 하던 일을 먼저 단계별로 적어 봐요. 자동화는 코드보다 이 단계에서 성패가 갈려요.

기준은 하나예요. "매주 똑같은 방법으로 반복하는 일인가?" 그렇다면 규칙대로 하는 일이고, 코드로 바꿀 수 있어요. 그때그때 상황을 보고 정해야 한다면 사람의 판단이 필요한 일이에요.

우리 서점의 업무를 예로 해 볼게요.

| 순서 | 손으로 하는 일 | 구분 |
| --- | --- | --- |
| 1 | 가격 `"15,000"`을 숫자로 바꾸고, 분야 이름 공백 지우기 | 규칙 |
| 2 | 지점 파일(엑셀, CSV)을 하나씩 열기 | 규칙 |
| 3 | 모든 지점 데이터를 한 시트에 모으기 | 규칙 |
| 4 | 열리지 않는 파일은 따로 적어 두기 | 규칙 |
| 5 | 매출(권수 × 가격)을 계산하고 지점별로 더하기 | 규칙 |
| 6 | 결과를 보고용 엑셀 파일로 저장하기 | 규칙 |
| 7 | 판매가 부진한 지점에 어떤 신간을 더 보낼지 정하기 | 판단 |

7번은 매주 사정이 달라요. 지역 행사, 날씨, 요즘 뜨는 책을 보고 사람이 정해야 하죠. 코드는 판단에 필요한 숫자를 빠르게 모아 주고, 결정은 사람이 해요.

공식 과제 1-1은 이 구분을 Colab 코드 칸에 주석(`#`)으로 적는 문제예요. 형식은 이런 식이에요.

```python
# 1단계. 업무 쪼개기
# 1번: 규칙 - 매주 같은 방식으로 쉼표와 공백을 지우면 되니까
# 2번: ...
# 7번: ...
```

공식 과제의 7가지 업무는 우리와 조금 달라요. 같은 기준으로 하나씩 따져 보세요. 사람에게 연락하거나 상황을 봐서 결정하는 일이 섞여 있는지 눈여겨보면 돼요.

아래부터는 규칙에 해당하는 1~6번을 차례로 코드로 바꿔요.

## 2단계. 정리 함수 만들기 (1번 일)

지저분한 값을 정리하는 함수 두 개예요. [첫 번째 레슨](/basecamp/python-excel-data-basics)에서 만든 것과 같아요.

```python
def to_number(value):
    """ '15,000' 같은 글자를 15000 숫자로 바꾼다 """
    return int(str(value).replace(",", "").strip())

def clean_text(value):
    """ ' 소설 ' 처럼 앞뒤에 붙은 공백을 지운다 """
    return str(value).strip()
```

만들었으면 바로 확인해요. 함수는 만들자마자 작은 값으로 시험해 보는 습관이 중요해요. 나중에 큰 코드 속에서 틀린 걸 찾기는 훨씬 어렵거든요.

```python
print(to_number("15,000") + 1)
print(to_number(15000) + 1)
print(clean_text(" 에세이 ") + "!")
# 15001
# 15001
# 에세이!
```

`+ 1`과 `+ "!"`를 붙인 데는 이유가 있어요. 정말 숫자가 됐다면 `15001`이 나오고, 여전히 글자라면 에러가 나요. 공백이 남았다면 `" 에세이 !"`처럼 보일 거고요. 결과를 눈으로 구별하기 쉽게 만든 시험이에요.

## 3단계. 파일 읽고 합치기 (2~4번 일)

### 엑셀이든 CSV든 읽는 함수

지점마다 파일 형식이 달라요. 그래서 경로를 받으면 확장자를 보고 알맞은 방법으로 읽는 함수를 만들어요. 어느 쪽이든 결과는 "한 줄 = 딕셔너리"인 리스트로 똑같이 맞춰서 돌려줘요.

```python
def read_file(path):
    """ 엑셀이든 CSV든 [ {한 줄}, {한 줄}, ... ] 모양으로 읽어 온다 """
    if path.suffix == ".csv":                          # 확장자가 .csv 이면
        with open(path, encoding="utf-8-sig") as f:
            return list(csv.DictReader(f))

    sheet = load_workbook(path).active                 # 엑셀이면 첫 번째 시트
    rows = list(sheet.iter_rows(values_only=True))
    header = rows[0]                                   # 첫 줄 = 열 이름
    return [dict(zip(header, row)) for row in rows[1:]]
```

한 줄씩 짚어 볼게요.

- `if path.suffix == ".csv":` CSV면 `DictReader`로 바로 딕셔너리 리스트를 만들어 `return`해요. `return`을 만나면 함수가 그 자리에서 끝나서, 아래 엑셀 코드는 실행되지 않아요.
- CSV가 아니면 엑셀이라고 보고 아래로 내려가요. `else:`를 쓰지 않아도 되는 이유가 바로 앞의 `return` 덕분이에요.
- 마지막 줄은 [앞 레슨](/basecamp/python-excel-files-exceptions)에서 본 리스트 컴프리헨션이에요. 제목 줄을 뺀 모든 줄을 열 이름과 짝지어 딕셔너리로 만들어요.

확인해 볼게요. 가장 지저분한 신촌점 파일을 읽어요.

```python
sinchon = read_file(DATA_FOLDER / "신촌점.xlsx")
print(len(sinchon), "줄 /", sinchon[0])
# 3 줄 / {'날짜': '2026-10-05', '지점': '신촌점', '분야': ' 소설 ', '권수': '20', '가격': '15,000'}
```

잘 읽혔지만 아직 지저분하죠. 분야는 `' 소설 '`, 권수는 `'20'`, 가격은 `'15,000'`이에요. 이걸 바로 다음 칸에서 2단계의 함수로 정리해요.

### 폴더 전체 읽어서 합치기

이제 오늘의 핵심이에요. data 폴더의 파일을 하나씩 읽어 정리한 뒤 `all_rows` 리스트에 모두 모으고, 열지 못한 파일은 `errors`에 기록해요.

```python
all_rows = []      # 정리된 모든 판매 기록
errors = []        # 열지 못한 파일 목록

for path in sorted(DATA_FOLDER.iterdir()):          # data 폴더의 파일을 하나씩
    try:
        for row in read_file(path):                  # 파일의 한 줄씩
            count = to_number(row["권수"])
            price = to_number(row["가격"])
            all_rows.append({                        # 정리한 한 줄을 맨 뒤에 추가
                "날짜": row["날짜"],
                "지점": clean_text(row["지점"]),
                "분야": clean_text(row["분야"]),
                "권수": count,
                "가격": price,
                "매출": count * price,
            })
        print("[읽기 성공]", path.name)
    except Exception as e:                           # 어떤 에러든 잡아서
        errors.append(path.name)                     # 기록하고 다음 파일로
        print("[건너뜀]", path.name, "/", type(e).__name__)
# [건너뜀] 광주점.xlsx / BadZipFile
# [읽기 성공] 신촌점.xlsx
# [읽기 성공] 종로점.xlsx
# [읽기 성공] 해운대점.csv
```

반복문이 두 겹이에요. 바깥은 파일을 하나씩, 안쪽은 그 파일의 줄을 하나씩 돌아요. 엑셀로 치면 "파일을 하나 열어서, 위에서부터 한 줄씩 복사해 통합 시트 맨 아래에 붙여 넣기"를 파일마다 반복하는 거예요.

`try`가 감싸는 범위를 잘 보세요. 파일 하나를 통째로 감싸고 있어요. 그래서 광주점에서 에러가 나면 광주점만 건너뛰고, 바깥 반복문은 다음 파일인 신촌점으로 넘어가요.

정리한 한 줄을 만들 때 `"매출"` 열도 새로 계산해 넣었어요. 엑셀에서 옆에 새 열을 추가하는 것과 같아요. 여기서 정한 열 순서(날짜, 지점, 분야, 권수, 가격, 매출)는 2편에서 결과 파일에 적을 때 그대로 쓰여요.

### 결과 확인하기

```python
print("모은 줄 수:", len(all_rows))
print("신촌점 첫 줄:", all_rows[0])
print("열지 못한 파일:", errors)
# 모은 줄 수: 9
# 신촌점 첫 줄: {'날짜': '2026-10-05', '지점': '신촌점', '분야': '소설', '권수': 20, '가격': 15000, '매출': 300000}
# 열지 못한 파일: ['광주점.xlsx']
```

세 지점에서 3줄씩, 모두 9줄이 모였어요. 광주점이 깨져 있어도 멈추지 않고 나머지를 처리했죠.

신촌점 데이터도 `'소설'`, `20`, `15000`으로 깔끔하게 정리됐어요. 따옴표가 사라진 숫자를 보면 이제 계산할 수 있는 값이 됐다는 걸 알 수 있어요.

신촌점 첫 줄이 `all_rows[0]`인 이유는, 광주점이 이름순으로 맨 앞이지만 건너뛰어졌기 때문이에요. 몇 번째 줄에 누가 있는지는 파일 순서와 줄 수로 따져 볼 수 있어요. 공식 과제의 확인 코드도 이런 식으로 특정 번호의 줄을 꺼내 봐요.

A1. CSV일 때는 `return`을 만나 함수가 그 자리에서 끝나기 때문이에요. 아래 줄까지 내려왔다는 건 CSV가 아니었다는 뜻이라, 따로 `else:`를 쓰지 않아도 돼요.

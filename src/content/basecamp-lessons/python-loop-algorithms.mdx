파이썬에는 이미 `sort`가 있는데 왜 정렬을 직접 짜 볼까요?

도구가 안에서 어떻게 도는지 알고 나면, 비슷한 다른 문제도 스스로 풀 힘이 생겨요. "이미 만들어진 걸 쓰는 사람"에서 "필요하면 직접 만들 수 있는 사람"으로 한 걸음 올라서는 거예요.

알고리즘은 어렵고 특별한 게 아니라, 사람이 손으로 하던 일을 컴퓨터가 하도록 순서대로 적어 둔 것뿐이에요. 카드를 작은 것부터 정리하거나, 두꺼운 사전에서 단어를 찾는 것처럼요.

이 레슨은 심화 과제 3번(반복문 알고리즘)을 스스로 풀 수 있게 준비시켜요. 선택 정렬, 이진 탐색, 소수 판별 세 가지를 하나씩 제 예시 데이터로 같이 짜 볼게요. 원리를 이해한 다음, 과제의 실제 입력에는 여러분이 직접 적용하면 돼요.

## 1. 선택 정렬 (Selection Sort)

선택 정렬의 아이디어를 먼저 말로 풀어 볼게요.

남은 구간에서 가장 작은 값을 찾아 맨 앞으로 보내요. 그다음 그 자리는 확정된 걸로 치고, 나머지 구간에서 또 가장 작은 값을 찾아 그다음 자리로 보내요. 이걸 반복하면 리스트가 작은 것부터 차례로 정렬돼요.

책상 위에 흩어진 카드를 정리할 때, 제일 작은 카드를 골라 맨 왼쪽에 놓고, 그다음 작은 카드를 그 옆에 놓는 방식과 똑같아요.

제 예시 리스트로 오름차순 정렬을 짜 볼게요.

```python
nums = [64, 25, 12, 22, 11]

# 맨 앞 자리부터 하나씩 "여기에 올 가장 작은 값"을 채워 나가요
for i in range(len(nums)):
    # 아직 정렬 안 된 구간(i부터 끝까지)에서 가장 작은 값의 위치를 찾아요
    min_index = i
    for j in range(i + 1, len(nums)):
        if nums[j] < nums[min_index]:
            min_index = j

    # 찾은 가장 작은 값을 지금 자리(i)와 서로 맞바꿔요 (swap)
    nums[i], nums[min_index] = nums[min_index], nums[i]

print(nums)
# 출력: [11, 12, 22, 25, 64]
```

첫 번째 통과(i가 0일 때)를 말로 따라가 볼게요.

`min_index`는 처음에 0(값 64)으로 시작해요. 안쪽 반복문이 25, 12, 22, 11을 차례로 보면서 "지금까지 본 것 중 가장 작은 값"을 갱신해요. 마지막에는 11이 가장 작으니 `min_index`가 11의 위치를 가리켜요.

그리고 맨 앞의 64와 11을 맞바꿔요. 이제 리스트는 `[11, 25, 12, 22, 64]`가 되고, 맨 앞자리는 확정돼요. 다음 통과에서는 1번 자리부터 같은 일을 반복해요.

내림차순으로 바꾸려면 '가장 작은' 대신 '가장 큰'을 찾으면 돼요. 즉 `if nums[j] < nums[min_index]`의 부등호 방향을 `>`로 바꾸고, 변수 이름도 `max_index`처럼 두면 자연스러워요.

심화 과제에서는 (이름, 평균) 튜플을 평균 기준 내림차순으로 정렬해야 하니 이 원리를 직접 적용해 보세요. 튜플에서 비교할 값은 평균, 즉 `tup[1]`이 된다는 점만 기억하면 돼요. 이제 과제의 (이름, 평균) 데이터에 직접 적용해 보세요.

## 2. 이진 탐색 (Binary Search)

이번엔 "찾기"예요. 이진 탐색의 아이디어는 이래요.

정렬된 리스트에서 한가운데 값을 먼저 봐요. 찾는 값이 그보다 크면 왼쪽 절반은 통째로 버리고 오른쪽만 봐요. 반대로 작으면 오른쪽을 버리고 왼쪽만 봐요. 이렇게 볼 범위를 매번 절반으로 줄여 나가요.

두꺼운 사전에서 단어를 찾을 때, 처음부터 한 장씩 넘기지 않고 가운데를 펼쳐 앞뒤를 가늠하는 것과 똑같아요.

제 예시 리스트로 짜 볼게요. 과제와는 다른 데이터를 쓸게요.

```python
def binary_search(sorted_list, target):
    low = 0                      # 살펴볼 범위의 왼쪽 끝
    high = len(sorted_list) - 1  # 살펴볼 범위의 오른쪽 끝

    while low <= high:
        mid = (low + high) // 2  # 가운데 위치 (정수 나눗셈)

        if sorted_list[mid] == target:
            return mid           # 찾았으면 그 위치를 돌려줘요
        elif sorted_list[mid] < target:
            low = mid + 1        # 찾는 값이 더 크니 오른쪽 절반만 남겨요
        else:
            high = mid - 1       # 찾는 값이 더 작으니 왼쪽 절반만 남겨요

    return -1                    # 끝까지 못 찾으면 -1

data = [1, 4, 9, 16, 25, 36, 49]

print(binary_search(data, 25))   # 출력: 4  (data[4]가 25)
print(binary_search(data, 100))  # 출력: -1 (리스트에 없음)
```

25를 찾는 과정을 따라가 볼게요.

처음엔 `low=0`, `high=6`이라 `mid=3`이고 `data[3]`은 16이에요. 25가 16보다 크니 왼쪽 절반을 버리고 `low`를 4로 옮겨요. 이제 `mid=5`, `data[5]`는 36이라 25보다 크니 오른쪽을 버리고 `high`를 4로 옮겨요. 마지막에 `mid=4`, `data[4]`가 25라 위치 4를 돌려줘요.

일곱 개짜리 리스트를 단 세 번만에 찾았어요. 만약 처음부터 하나씩 비교했다면 다섯 번을 봤어야 해요.

이 차이는 데이터가 커질수록 어마어마해져요. 항목이 1,000개면 하나씩 보는 방법은 최대 1,000번이지만, 이진 탐색은 약 10번이면 끝나요. 볼 범위를 매번 절반으로 접기 때문이에요. 단, 이진 탐색은 리스트가 미리 정렬돼 있어야만 쓸 수 있다는 점을 꼭 기억하세요.

이제 과제의 리스트와 찾을 값에 직접 적용해 보세요.

## 3. 소수 판별 (Prime Check)

마지막은 소수예요. 소수는 1과 자기 자신으로만 나누어떨어지는, 2 이상의 수예요.

예를 들어 7은 1과 7 말고는 나누어떨어지는 수가 없으니 소수예요. 반대로 9는 3으로 나누어떨어지니 소수가 아니에요.

그럼 어떤 수 `n`이 소수인지 어떻게 확인할까요? 2부터 `n - 1`까지 하나씩 나눠 보면서, 딱 떨어지는 수가 하나라도 있으면 소수가 아니에요. 끝까지 하나도 없으면 소수예요.

작은 헬퍼 함수로 만들어 볼게요.

```python
def is_prime(n):
    if n < 2:          # 2보다 작은 수는 소수가 아니에요
        return False
    for i in range(2, n):   # 2부터 n-1까지 확인
        if n % i == 0:      # 딱 나누어떨어지는 수를 만나면
            return False    # 소수가 아니에요
    return True             # 끝까지 없었으면 소수예요

# 작은 범위(2부터 20까지)에서 소수만 출력해 볼게요
for num in range(2, 21):
    if is_prime(num):
        print(num, end=" ")
# 출력: 2 3 5 7 11 13 17 19
```

`range(2, 21)`은 2부터 20까지를 뜻해요. 각 수를 `is_prime`에 넣어 소수일 때만 출력했어요.

여기서 한 가지 더요. 사실 2부터 `n - 1`까지 다 볼 필요 없이, `n`의 제곱근까지만 확인해도 충분해요. 어떤 수가 두 수의 곱으로 쪼개진다면, 둘 중 하나는 반드시 제곱근보다 작거나 같기 때문이에요. 그래서 제곱근까지 나누어떨어지는 게 없다면 그 위쪽도 없어요.

이렇게 하면 큰 수를 판별할 때 확인 횟수가 확 줄어들어 훨씬 빨라요. 제곱근까지만 도는 방법은 이렇게 쓸 수 있어요.

```python
def is_prime_fast(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n:   # i의 제곱이 n을 넘지 않는 동안만 확인
        if n % i == 0:
            return False
        i += 1
    return True

print(is_prime_fast(13))  # 출력: True
print(is_prime_fast(15))  # 출력: False (3으로 나누어떨어짐)
```

`i * i <= n`은 "`i`가 `n`의 제곱근 이하인 동안"과 같은 뜻이에요. 제곱근을 직접 계산하지 않고 곱셈으로 비교해서 더 간단하고 정확해요.

심화 과제에서는 1부터 50까지의 소수를 출력해야 해요. 방금 배운 방법을 그 범위에 직접 적용해 보세요. `range`의 끝 숫자와, 1은 소수가 아니라는 점만 조심하면 돼요.

## 한 줄 정리

선택 정렬은 남은 구간에서 최솟값(또는 최댓값)을 찾아 맨 앞으로 보내는 걸 반복하고, 이진 탐색은 정렬된 리스트를 절반씩 접어 가며 빠르게 찾고, 소수 판별은 나누어떨어지는 수가 있는지 확인하는 것이에요. 원리를 손에 익혔으니, 이제 과제의 실제 데이터에 직접 적용해 보세요.

리스트는 데이터를 순서대로 줄 세우는 자료형이었어요. 그런데 살다 보면 순서보다 "이름표"로 찾고 싶을 때가 훨씬 많아요.

전화번호부에서 12번째 사람을 찾는 일은 거의 없죠. 우리는 "김민수의 번호"를 찾아요. 이렇게 이름표(키)로 값을 꺼내는 자료형이 바로 **딕셔너리(dictionary)** 예요.

이번 레슨은 읽기만 하지 말고, 나오는 코드를 Colab에 직접 쳐 보면서 따라와 주세요. 눈으로 본 것보다 손으로 친 것이 훨씬 오래 남아요.

## 1. 딕셔너리란 무엇일까

딕셔너리는 이름 그대로 **사전**이에요. 사전에서 단어를 찾으면 그 뜻이 나오죠. 딕셔너리에서는 **키(key)** 를 찾으면 그에 짝지어진 **값(value)** 이 나와요.

리스트와 비교하면 차이가 분명해요.

- 리스트는 **순서(위치 번호)** 로 값을 꺼내요. `scores[0]`, `scores[1]` 처럼요.
- 딕셔너리는 **이름표(키)** 로 값을 꺼내요. `student["이름"]` 처럼요.

그래서 "학생의 이름, 나이, 점수"처럼 서로 다른 성격의 값을 한 덩어리로 묶을 때는 딕셔너리가 훨씬 잘 맞아요.

```python
# 리스트: 순서로 기억한다 (0번은 이름, 1번은 나이 ... 라고 내가 외워야 한다)
student_list = ["김민수", 20, 88]

# 딕셔너리: 이름표로 기억한다 (외울 필요 없이 이름표가 알려준다)
student = {"이름": "김민수", "나이": 20, "점수": 88}
```

`{}` 중괄호 안에 `키: 값` 을 쉼표로 나열해요. 위에서 `"이름"`, `"나이"`, `"점수"` 가 키이고, `"김민수"`, `20`, `88` 이 각각의 값이에요.

## 2. 딕셔너리 기본기: 만들고, 찾고, 바꾸기

### 값 꺼내기

키를 대괄호 `[]` 안에 넣으면 그 값이 나와요.

```python
student = {"이름": "김민수", "나이": 20, "점수": 88}

print(student["이름"])   # 김민수
print(student["점수"])   # 88
```

여기서 리스트와 헷갈리기 쉬운 점 하나. 리스트는 `[0]` 처럼 숫자 위치를 넣지만, 딕셔너리는 `["이름"]` 처럼 **키**를 넣어요.

### 값 추가하고 바꾸기

없는 키에 값을 넣으면 **새로 추가**되고, 있는 키에 넣으면 **덮어써요**.

```python
student = {"이름": "김민수", "나이": 20}

student["점수"] = 88      # "점수" 키가 없었으니 새로 추가
student["나이"] = 21      # "나이" 키가 이미 있으니 값을 바꿈

print(student)
# {'이름': '김민수', '나이': 21, '점수': 88}
```

### 값 지우기

`del` 로 키를 통째로 지울 수 있어요.

```python
del student["점수"]
print(student)   # {'이름': '김민수', '나이': 21}
```

## 3. 없는 키를 찾으면? get을 기억하세요

딕셔너리에서 가장 자주 만나는 실수가 **없는 키를 대괄호로 찾는 것**이에요. 이러면 프로그램이 오류(KeyError)를 내며 멈춰요.

```python
student = {"이름": "김민수", "나이": 20}

print(student["점수"])   # KeyError! "점수" 키가 없어서 멈춘다
```

그래서 "있을 수도, 없을 수도 있는" 키는 `get()` 으로 찾는 게 안전해요. 없으면 오류 대신 `None`(값 없음)을 돌려주거든요.

```python
print(student.get("점수"))        # None (오류 없이 넘어감)
print(student.get("점수", 0))     # 0 (없을 때 대신 쓸 기본값을 정해 줄 수 있다)
```

키가 있는지 먼저 확인하고 싶으면 `in` 을 쓰면 돼요.

```python
if "점수" in student:
    print("점수가 있어요")
else:
    print("아직 점수가 없어요")
```

## 4. 자주 쓰는 메서드: keys, values, items

딕셔너리 전체를 훑고 싶을 때 쓰는 세 가지예요.

```python
student = {"이름": "김민수", "나이": 20, "점수": 88}

print(student.keys())     # 키만 모아서: dict_keys(['이름', '나이', '점수'])
print(student.values())   # 값만 모아서: dict_values(['김민수', 20, 88])
print(student.items())    # 키와 값을 짝으로: dict_items([('이름', '김민수'), ...])
```

특히 `items()` 는 반복문과 함께 쓸 때 아주 편해요. 키와 값을 한 번에 꺼내 주거든요.

```python
for key, value in student.items():
    print(key, ":", value)

# 이름 : 김민수
# 나이 : 20
# 점수 : 88
```

반복문은 다음 레슨에서 자세히 다루니, 지금은 "딕셔너리는 이렇게 통째로 훑을 수 있구나" 정도만 느끼면 충분해요.

## 5. 실전 예시: 데이터를 사전처럼 저장하기

딕셔너리의 진짜 힘은 **여러 개를 리스트로 묶을 때** 나와요. STEP 1 마지막 과제에서 만든 "학생 명부"를 떠올려 보세요. 학생 한 명이 딕셔너리 하나이고, 그 학생들을 리스트에 담으면 명부가 돼요.

```python
students = [
    {"이름": "김민수", "점수": 88},
    {"이름": "이서연", "점수": 95},
    {"이름": "박지훈", "점수": 72},
]

# 두 번째 학생의 이름
print(students[1]["이름"])   # 이서연

# 모든 학생의 이름과 점수를 출력
for s in students:
    print(s["이름"], s["점수"])
```

이 "리스트 안에 딕셔너리" 구조는 실무에서 정말 자주 나와요. 서버에서 받아 오는 데이터, 엑셀을 코드로 읽은 결과, AI에게 보내는 요청까지 대부분 이 모양이에요. 지금 익숙해지면 앞으로가 훨씬 수월해요.

## 한 줄 정리

딕셔너리는 **이름표(키)로 값을 저장하고 꺼내는** 자료형이에요. 대괄호로 찾고 바꾸되, 없을 수 있는 키는 `get()` 으로 안전하게 다루고, `items()` 로 전체를 훑는다. 이 세 가지만 손에 익으면 딕셔너리는 다 쓴 거예요.

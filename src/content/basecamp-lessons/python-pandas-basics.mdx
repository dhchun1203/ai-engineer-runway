## 1. Pandas, 다시 만나요

### Pandas가 뭐였죠?

STEP 3에서 데이터를 불러올 때 잠깐 만났던 도구예요. 한마디로 "파이썬 안의 엑셀"이에요.

STEP 4 방식을 떠올려 보세요. 매출을 구하려면 for문이 표의 첫 줄부터 마지막 줄까지 한 줄씩 내려가며 곱셈을 했어요. 원리를 이해하기엔 최고의 방법이에요. 그런데 줄이 수만 개가 되면 코드도 길어지고 느려져요.

Pandas는 줄 단위가 아니라 열 단위로 일해요. "수량 열 전체 곱하기 단가 열 전체"를 한 번에 해 줘요.

```python
# 비교용 (실행하지 않아도 돼요)
# STEP 4 방식: 한 줄씩
for row in sales:
    row["매출"] = row["수량"] * row["단가"]

# Pandas 방식: 열 전체를 한 번에
df["매출"] = df["수량"] * df["단가"]
```

비유하자면 STEP 4는 계산기를 들고 영수증을 한 장씩 계산하는 거고, Pandas는 영수증 묶음을 기계에 통째로 넣는 거예요.

STEP 4에서 배운 건 버리는 게 아니에요. Pandas도 속에서는 같은 일을 해요. 원리를 알고 쓰니까, 결과가 이상할 때 왜 그런지 짐작할 수 있어요.

### Pandas 불러오기

Colab에는 Pandas가 이미 설치돼 있어요. 새 코드 칸에서 실행하세요.

```python
import pandas as pd
```

`as pd`는 "앞으로 pandas를 pd라는 짧은 이름으로 부를게"라는 뜻이에요. 전 세계 코드 대부분이 `pd`라고 써서, 검색할 때도 편해요.

## 2. DataFrame: 딕셔너리 리스트를 표로

### STEP 4의 표를 그대로 DataFrame으로

STEP 4에서 "표 = 리스트, 한 행 = 딕셔너리"로 담았던 것 기억나죠? 그 모양을 `pd.DataFrame()`에 넣기만 하면 표가 돼요.

```python
sales = [
    {"지점": "강남점", "품목": "아메리카노", "수량": 30, "단가": 4500},
    {"지점": "강남점", "품목": "카페라떼", "수량": 19, "단가": 5000},
    {"지점": "홍대점", "품목": "아메리카노", "수량": 36, "단가": 4500},
    {"지점": "홍대점", "품목": "바닐라라떼", "수량": 25, "단가": 5500},
    {"지점": "부산점", "품목": "아메리카노", "수량": 47, "단가": 4500},
    {"지점": "부산점", "품목": "카페라떼", "수량": 35, "단가": 5000},
]

df = pd.DataFrame(sales)
print(df)
```

```text
    지점     품목  수량    단가
0  강남점  아메리카노  30  4500
1  강남점   카페라떼  19  5000
2  홍대점  아메리카노  36  4500
3  홍대점  바닐라라떼  25  5500
4  부산점  아메리카노  47  4500
5  부산점   카페라떼  35  5000
```

딕셔너리 리스트가 어떻게 표로 바뀌었는지 짝지어 보면 이래요.

| 딕셔너리 리스트에서 | DataFrame에서 | 엑셀로 치면 |
| --- | --- | --- |
| 딕셔너리의 키(`"지점"`, `"품목"`...) | 열 이름 (맨 윗줄) | 머리글 (1행) |
| 딕셔너리 하나 | 한 행 | 데이터 한 줄 |
| 리스트 안의 순서 | 맨 왼쪽 0, 1, 2... (인덱스) | 행 번호 (단, 0부터!) |
| 리스트 전체 | `df` 표 전체 | 시트 하나 |

`df`는 DataFrame의 줄임말이에요. 표 변수 이름으로 아주 많이 써요.

> Colab에서는 `print(df)` 대신 칸 맨 아래 줄에 `df`만 적어도 표가 예쁜 모양으로 나와요. 둘 다 괜찮아요.

### 표 훑어보기

데이터를 처음 받으면 "몇 줄인지, 어떤 열이 있는지"부터 확인하는 게 좋은 습관이에요.

```python
print(df.shape)              # (6, 4)  ← (행 개수, 열 개수)
print(len(df))               # 6       ← 행 개수만
print(df.columns.tolist())   # ['지점', '품목', '수량', '단가']
print(df.head(2))            # 위에서 2줄만 (괄호를 비우면 5줄)
```

```text
    지점     품목  수량    단가
0  강남점  아메리카노  30  4500
1  강남점   카페라떼  19  5000
```

| 코드 | 하는 일 | STEP 4에서는 |
| --- | --- | --- |
| `df.shape` | (행, 열) 개수 | `len(sales)` (행만) |
| `df.columns.tolist()` | 열 이름 목록 | `header` 변수 |
| `df.head()` | 위 몇 줄 미리보기 | `print(rows[0])` |

`shape`와 `columns`에는 괄호를 붙이지 않고, `head()`에는 붙여요. 헷갈리면 이렇게 기억하세요. 이미 있는 정보를 보는 건 괄호 없이, 일을 시키는 건 괄호와 함께.

## 3. 열 다루기: 꺼내고, 계산하고, 추가하기

### 열 꺼내기

열 이름을 대괄호에 넣으면 그 열이 나와요.

```python
print(df["지점"])
```

```text
0    강남점
1    강남점
2    홍대점
3    홍대점
4    부산점
5    부산점
Name: 지점, dtype: object
```

열 여러 개를 꺼낼 때는 대괄호가 두 겹이에요.

```python
print(df[["지점", "수량"]])
```

```text
    지점  수량
0  강남점  30
1  강남점  19
2  홍대점  36
3  홍대점  25
4  부산점  47
5  부산점  35
```

왜 두 겹일까요? 안쪽 `["지점", "수량"]`은 STEP 4에서 배운 리스트예요. 바깥 대괄호는 "꺼내 줘"라는 뜻이고요. 그래서 "이 목록에 있는 열들을 꺼내 줘"가 돼요. `df["지점", "수량"]`처럼 한 겹으로 쓰면 그런 이름의 열이 없다고 KeyError가 나요.

> 마지막 줄의 `dtype: object`는 이 열의 자료형이 "주로 글자"라는 뜻이에요. Colab의 Pandas 버전에 따라 `str`로 보일 수도 있어요. 둘 다 글자라는 뜻이에요.

### 열 전체 계산하기

열 하나를 꺼내면 STEP 4의 숫자 리스트처럼 바로 계산할 수 있어요.

```python
print(df["수량"].sum())     # 192   ← 엑셀의 SUM
print(df["수량"].max())     # 47    ← 엑셀의 MAX
print(df["수량"].mean())    # 32.0  ← 엑셀의 AVERAGE
```

### 새 열 추가하기: 매출 = 수량 × 단가

STEP 4에서는 for문으로 한 줄씩 매출을 넣었죠. Pandas에서는 열끼리 곱하면 모든 줄이 한 번에 계산돼요.

```python
df["매출"] = df["수량"] * df["단가"]
print(df)
```

```text
    지점     품목  수량    단가      매출
0  강남점  아메리카노  30  4500  135000
1  강남점   카페라떼  19  5000   95000
2  홍대점  아메리카노  36  4500  162000
3  홍대점  바닐라라떼  25  5500  137500
4  부산점  아메리카노  47  4500  211500
5  부산점   카페라떼  35  5000  175000
```

같은 줄에 있는 값끼리 짝지어 곱해요. 0번 줄은 30 × 4500 = 135000, 1번 줄은 19 × 5000 = 95000, 이렇게요.

엑셀로 치면 E2 칸에 `=C2*D2`를 쓰고 아래로 쭉 끌어내리는 것과 같아요. Pandas는 끌어내리기까지 알아서 해 줘요.

`df["매출"] = ...`처럼 없는 열 이름에 값을 넣으면 새 열이 생겨요. STEP 4에서 `row["매출"] = ...`로 딕셔너리에 새 키를 넣던 것과 같은 모양이에요.

## 4. 조건으로 거르기: 엑셀의 필터

매출이 15만 원 이상인 줄만 보고 싶다면 이렇게 써요.

```python
print(df[df["매출"] >= 150000])
```

```text
    지점     품목  수량    단가      매출
2  홍대점  아메리카노  36  4500  162000
4  부산점  아메리카노  47  4500  211500
5  부산점   카페라떼  35  5000  175000
```

`df[ 조건 ]`은 "df에서 조건에 맞는 줄만 보여 줘"라는 뜻이에요. 속에서는 이런 일이 일어나요.

1. `df["매출"] >= 150000`이 줄마다 True 또는 False를 매겨요.
2. `df[ ... ]`가 True인 줄만 남겨요.

0번 줄(135000)은 False라 빠지고, 2번 줄(162000)은 True라 남는 식이에요. 남은 줄의 인덱스(2, 4, 5)가 원래 번호 그대로라는 점도 눈여겨보세요.

같은 방법으로 강남점만 골라 볼게요.

```python
print(df[df["지점"] == "강남점"])
```

```text
    지점     품목  수량    단가      매출
0  강남점  아메리카노  30  4500  135000
1  강남점   카페라떼  19  5000   95000
```

### 조건이 두 개 이상이면

홍대점이면서 수량이 30 이상인 줄을 찾아요.

```python
print(df[(df["지점"] == "홍대점") & (df["수량"] >= 30)])
```

```text
    지점     품목  수량    단가      매출
2  홍대점  아메리카노  36  4500  162000
```

| 하고 싶은 것 | STEP 4 (if문) | Pandas |
| --- | --- | --- |
| 그리고 | `and` | `&` |
| 또는 | `or` | `\|` |

두 가지를 꼭 지켜야 해요.

- `and`, `or` 대신 `&`, `|`를 써요. `and`를 쓰면 ValueError가 나요.
- 조건마다 괄호 `( )`로 감싸요. 괄호를 빠뜨리면 계산 순서가 꼬여서 에러가 나요.

## 5. 지점별 합계: groupby (엑셀의 SUMIF, 피벗 테이블)

### STEP 4에서는 이렇게 했어요

```python
# STEP 4 방식 (실행해 봐도 돼요)
total = {}
for row in sales:
    branch = row["지점"]
    total[branch] = total.get(branch, 0) + row["수량"] * row["단가"]
print(total)    # {'강남점': 230000, '홍대점': 299500, '부산점': 386500}
```

빈 합계표를 만들고, 한 줄씩 보면서, 지점마다 매출을 더해 나갔죠.

### Pandas에서는 한 줄이에요

```python
print(df.groupby("지점")["매출"].sum())
```

```text
지점
강남점    230000
부산점    386500
홍대점    299500
Name: 매출, dtype: int64
```

왼쪽부터 차례로 읽으면 돼요.

1. `df.groupby("지점")`: 지점이 같은 줄끼리 묶어요.
2. `["매출"]`: 그 묶음들에서 매출 열을 골라요.
3. `.sum()`: 묶음마다 더해요.

강남점 묶음에는 135000과 95000이 들어가서 230000이 돼요. STEP 4의 `total.get(branch, 0) + 매출`이 하던 일을 groupby가 속에서 똑같이 해 준 거예요. 숫자도 STEP 4 결과와 같죠?

결과는 지점 이름의 가나다순(강남, 부산, 홍대)으로 정렬돼서 나와요. STEP 4 딕셔너리는 처음 본 순서였던 것과 다르니, 순서가 달라 보여도 놀라지 마세요.

### 기준만 바꾸면 다른 합계

`"지점"`을 `"품목"`으로 바꾸면 품목별 합계가 돼요.

```python
print(df.groupby("품목")["매출"].sum())
```

```text
품목
바닐라라떼    137500
아메리카노    508500
카페라떼     270000
Name: 매출, dtype: int64
```

엑셀 피벗 테이블에서 "행" 칸에 넣는 열만 바꾸는 것과 같아요.

### 큰 순서대로 정렬하기

```python
print(df.groupby("지점")["매출"].sum().sort_values(ascending=False))
```

```text
지점
부산점    386500
홍대점    299500
강남점    230000
Name: 매출, dtype: int64
```

`ascending=False`는 "큰 것부터(내림차순)"라는 뜻이에요. 빼면 작은 것부터 정렬돼요.

이렇게 점(`.`)을 이어 붙여 쓰는 건 STEP 4의 `" 4,500 ".replace(",", "").strip()`과 같은 원리예요. 왼쪽부터 차례로 실행되고, 앞의 결과에 다음 일을 시켜요.

## 6. 문자 정리: .str로 열 전체 정리하기

### STEP 4의 지저분한 데이터, 기억나죠?

홍대점 파일은 품목 앞뒤에 공백이 있고, 단가가 `"4,500"`처럼 글자로 들어 있었어요. 비슷한 표를 만들어 볼게요.

```python
messy = pd.DataFrame({
    "품목": [" 아메리카노 ", "카페라떼 ", " 바닐라라떼"],
    "단가": ["4,500", "5,000", "5,500"],
})
print(messy["단가"] + "1")
```

```text
0    4,5001
1    5,0001
2    5,5001
Name: 단가, dtype: object
```

이번에는 딕셔너리 리스트가 아니라 `{열 이름: [값 목록]}` 모양의 딕셔너리로 표를 만들었어요. 열 단위로 값을 적을 때 편한 방법이에요.

그리고 STEP 4에서 본 것처럼, 글자끼리 더하면 이어 붙이기가 돼요. `"4,500" + "1"`이 `"4,5001"`이 됐죠. 계산하려면 정리가 먼저예요.

### .str + STEP 4에서 쓴 그 기능들

STEP 4에서는 `clean_text()`, `to_number()` 함수로 값을 하나씩 정리했어요. Pandas에서는 열 이름 뒤에 `.str`을 붙이면 같은 기능을 열 전체에 한 번에 쓸 수 있어요.

```python
messy["품목"] = messy["품목"].str.strip()                          # 앞뒤 공백 지우기
messy["단가"] = messy["단가"].str.replace(",", "").astype(int)     # 쉼표 지우고 숫자로

print(messy)
print(messy["단가"] + 1)
```

```text
      품목    단가
0  아메리카노  4500
1   카페라떼  5000
2  바닐라라떼  5500
0    4501
1    5001
2    5501
Name: 단가, dtype: int64
```

이번엔 `+ 1`이 진짜 덧셈이 됐어요. 숫자로 바뀌었다는 증거예요.

| 하는 일 | STEP 4 (값 하나) | Pandas (열 전체) |
| --- | --- | --- |
| 앞뒤 공백 지우기 | `value.strip()` | `df["열"].str.strip()` |
| 쉼표 지우기 | `value.replace(",", "")` | `df["열"].str.replace(",", "")` |
| 글자를 정수로 | `int(value)` | `df["열"].astype(int)` |

- `.str`은 "이 열에 든 글자 하나하나에 대해"라는 뜻이에요. `.str` 없이 `df["품목"].strip()`이라고 쓰면, 열이라는 덩어리 자체에 strip을 하려는 거라 에러가 나요.
- `astype(int)`는 "이 열의 자료형(type)을 int로 바꿔 줘"라는 뜻이에요. STEP 4의 `int()`를 열 전체에 쓰는 버전이에요.
- 정리한 결과를 `messy["품목"] = ...`처럼 다시 담는 것도 잊지 마세요. 담지 않으면 정리한 결과가 화면에만 나오고 표는 그대로예요.

### 정리됐는지 확인하는 법

표로 보면 공백이 잘 안 보여요. 리스트로 바꿔 보면 따옴표 안까지 보여서 확인하기 좋아요.

```python
print(messy["품목"].tolist())    # ['아메리카노', '카페라떼', '바닐라라떼']
```

`.tolist()`는 열을 STEP 4의 리스트로 바꿔 줘요. 정리 전에 찍었다면 `[' 아메리카노 ', '카페라떼 ', ' 바닐라라떼']`처럼 공백이 보였을 거예요.

## 자주 하는 실수

| 실수 | 증상 | 고치는 법 |
| --- | --- | --- |
| `df["지점", "수량"]` (대괄호 한 겹) | KeyError | 열 여러 개는 `df[["지점", "수량"]]` |
| 조건에 `and`, `or` 사용 | ValueError | `&`, `\|`로 바꾸고 조건마다 괄호 |
| `.str` 빼먹기 `df["품목"].strip()` | AttributeError | `df["품목"].str.strip()` |
| 쉼표가 남은 채로 `astype(int)` | ValueError | 먼저 `.str.replace(",", "")` |
| 열 이름 오타나 공백 `df["단가 "]` | KeyError | `df.columns.tolist()`로 정확한 이름 확인 |
| 정리하고 다시 담지 않기 | 정리가 반영 안 됨 | `df["품목"] = df["품목"].str.strip()`처럼 다시 담기 |

에러 이름만 봐도 어디를 볼지 감이 와요. KeyError는 "그런 이름의 열이 없어요", AttributeError는 "그 대상은 그런 기능이 없어요", ValueError는 "값이 기대한 모양이 아니에요"예요.

## 스스로 확인하기

Q1. `df.groupby("지점")["매출"].sum()`의 결과가 STEP 4 딕셔너리 결과와 순서가 다른 이유는 무엇일까요?

Q2. `messy["단가"].astype(int)`를 `.str.replace(",", "")` 없이 바로 실행하면 어떻게 될까요?

Q3. `df[df["매출"] >= 150000]`의 결과에서 인덱스가 0, 1, 2가 아니라 2, 4, 5로 나오는 이유는 무엇일까요?

<details>
<summary>정답 확인</summary>

A1. groupby는 결과를 묶는 기준(지점 이름)의 가나다순으로 정렬해서 돌려주기 때문이에요. STEP 4 딕셔너리는 처음 만난 순서대로 키가 쌓였고요. 순서만 다르고 숫자는 같아요.

## 한 장 요약

| 개념 | 핵심 코드 | STEP 4에서는 |

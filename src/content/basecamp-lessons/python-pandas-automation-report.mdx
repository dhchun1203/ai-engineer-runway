## 7단계. [D] 지점별 매출 합계

STEP 4에서는 빈 딕셔너리, for문, `.get()`으로 4줄이 필요했어요.

```python
# STEP 4 [D] (참고용)
branch_total = {}
for row in all_rows:
    branch = row["지점"]
    branch_total[branch] = branch_total.get(branch, 0) + row["매출"]
```

Pandas에서는 한 줄이에요.

```python
branch_total = all_df.groupby("지점")["매출"].sum()
print(branch_total)
```

```text
지점
신촌점     666000
종로점     444000
해운대점    451000
Name: 매출, dtype: int64
```

STEP 4 결과 `{'신촌점': 666000, '종로점': 444000, '해운대점': 451000}`과 숫자가 완전히 같아요.

변수 이름 `branch_total`이 STEP 4와 같아도 담긴 것의 모양은 달라요. STEP 4는 딕셔너리였고, 이번엔 지점 이름이 인덱스(왼쪽 이름표)에 붙은 Pandas 결과예요. 이 차이가 바로 다음 단계에서 중요해져요.

## 8단계. [E] 결과 파일 저장하기

STEP 4와 같은 시트 세 개짜리 파일을 만들어요.

- 전체데이터: `all_df` 전체
- 지점별합계: 지점, 총매출 두 열
- 확인필요: 열지 못한 파일 목록

STEP 4 [E]는 Workbook을 만들고 시트마다 제목 줄과 for문으로 한 줄씩 `append`해서 15줄이었어요. Pandas 버전은 이래요.

```python
with pd.ExcelWriter(RESULT_FILE) as writer:
    all_df.to_excel(writer, sheet_name="전체데이터", index=False)
    branch_total.reset_index(name="총매출").to_excel(writer, sheet_name="지점별합계", index=False)
    pd.DataFrame({"열지 못한 파일": errors}).to_excel(writer, sheet_name="확인필요", index=False)

print(f"완료! 총 {len(all_df)}줄 → {RESULT_FILE}")
```

```text
완료! 총 9줄 → 주간판매_정리_pandas.xlsx
```

15줄이 4줄이 됐어요. 시트마다 한 줄씩 짚어 볼게요.

### 전체데이터: index=False

`all_df`를 그대로 저장해요. `index=False`가 없으면 맨 앞에 0, 1, 2... 번호 열이 같이 저장돼서, 다시 읽었을 때 `Unnamed: 0`이라는 쓸모없는 열이 생겨요. 세 시트 모두에 넣었어요.

### 지점별합계: reset_index(name="총매출")

여기가 이번 과제에서 제일 실수하기 쉬운 곳이에요. 두 가지를 한 번에 해요.

1. `reset_index()`: 인덱스 자리에 있던 지점 이름을 보통 열로 꺼내요. 이걸 빼면 `index=False` 때문에 지점 이름이 통째로 사라져요.
2. `name="총매출"`: 꺼내면서 매출 숫자 열의 이름을 정해요. STEP 4 결과 파일의 제목 줄이 `["지점", "총매출"]`이었으니 똑같이 맞춰야 해요.

`name=`을 빼면 열 이름이 원래 이름인 "매출"로 나와요. 숫자는 맞아도 제목 줄이 STEP 4 파일과 달라지는 거죠. 다음 단계의 비교가 바로 이런 차이를 잡아내요.

```python
print(branch_total.reset_index(name="총매출"))
```

```text
     지점     총매출
0   신촌점  666000
1   종로점  444000
2  해운대점  451000
```

> 공식 과제의 카페 정답 코드는 지점별합계 시트의 제목을 `["지점", "매출"]`로 적어요. 그래서 공식 과제에서는 `name=` 없이 `reset_index()`만 해도 제목이 맞아요. 번역할 때는 늘 원래 코드의 제목 줄을 먼저 확인하세요.

### 확인필요: 리스트를 표로

`errors`는 그냥 리스트라서 `to_excel()`을 쓸 수 없어요. 표 기능은 DataFrame에만 있거든요. 그래서 먼저 표로 만들어요.

[Pandas 다시 만나기](/basecamp/python-pandas-basics)에서 `{열 이름: [값 목록]}` 모양의 딕셔너리로 표를 만들었죠. 같은 방법이에요. 열 이름은 STEP 4 파일과 똑같이 "열지 못한 파일"로 정해요.

```python
print(pd.DataFrame({"열지 못한 파일": errors}))
```

```text
   열지 못한 파일
0  광주점.xlsx
```

## 9단계. 두 버전 비교하기

이제 진짜 확인이에요. STEP 4 코드로 만든 `주간판매_정리.xlsx`와 Pandas로 만든 `주간판매_정리_pandas.xlsx`가 같은 내용인지 코드로 비교해요.

```python
step4 = pd.read_excel("주간판매_정리.xlsx", sheet_name=None)
step5 = pd.read_excel("주간판매_정리_pandas.xlsx", sheet_name=None)

for name in step4:
    same = step4[name].astype(str).equals(step5[name].astype(str))
    print(name, "→", "같아요" if same else "달라요")
```

```text
전체데이터 → 같아요
지점별합계 → 같아요
확인필요 → 같아요
```

세 시트가 모두 같아요. 코드는 절반 넘게 줄었는데 결과는 한 글자도 다르지 않아요.

비교 코드도 한 줄씩 짚어 볼게요.

| 코드 | 하는 일 |
| --- | --- |
| `sheet_name=None` | 모든 시트를 `{시트 이름: 표}` 딕셔너리로 읽어요 |
| `for name in step4:` | 딕셔너리를 돌면 키(시트 이름)가 하나씩 나와요 |
| `.astype(str)` | 모든 칸을 글자로 바꿔요. 숫자가 15000인지 15000.0인지 같은 자료형 차이는 무시하고 보이는 값만 비교하려는 거예요 |
| `.equals(...)` | 두 표의 모양, 열 이름, 모든 칸이 같으면 True |

> 공식 과제에는 결과 옆에 체크 표시 그림 문자가 붙어 있어요. 여기서는 "같아요", "달라요" 글자로만 적었어요.

### 일부러 틀려 보기

비교 코드가 정말 차이를 잡아내는지 확인해 봐야 믿을 수 있어요. 8단계의 실수 두 가지를 일부러 넣은 파일을 만들어 비교해 볼게요.

```python
with pd.ExcelWriter("틀린버전.xlsx") as writer:
    all_df.to_excel(writer, sheet_name="전체데이터")              # index=False를 빼먹음
    branch_total.reset_index().to_excel(writer, sheet_name="지점별합계", index=False)   # name= 을 빼먹음
    pd.DataFrame({"열지 못한 파일": errors}).to_excel(writer, sheet_name="확인필요", index=False)

wrong = pd.read_excel("틀린버전.xlsx", sheet_name=None)
for name in step4:
    same = step4[name].astype(str).equals(wrong[name].astype(str))
    print(name, "→", "같아요" if same else "달라요")
print(wrong["전체데이터"].columns.tolist())
print(wrong["지점별합계"].columns.tolist())
```

```text
전체데이터 → 달라요
지점별합계 → 달라요
확인필요 → 같아요
['Unnamed: 0', '날짜', '지점', '분야', '권수', '가격', '매출']
['지점', '매출']
```

"달라요"가 나오면 이렇게 해당 시트의 열 이름부터 찍어 보세요. 전체데이터에는 `Unnamed: 0` 열이 끼어 있고, 지점별합계는 제목이 "총매출"이 아니라 "매출"이에요. 공식 과제에서 "달라요"가 나올 때도 대부분 이 둘 중 하나예요.

## 한 줄 정리

[D]는 `groupby` 한 줄로, [E]는 `ExcelWriter`와 시트마다 `to_excel(..., index=False)` 한 줄씩으로 옮기되 지점 이름이 사라지지 않게 `reset_index()`를 하고, 마지막에 두 결과 파일을 시트별로 비교해 "같아요"를 확인하면, 짧아진 코드가 같은 일을 한다는 걸 증명할 수 있어요.

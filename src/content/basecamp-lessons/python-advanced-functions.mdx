함수는 이미 배웠죠. 어떤 일을 한 덩어리로 묶어 두고, 이름만 부르면 그 일을 대신 해 주는 작은 일꾼이었어요.

## 1. 재귀: 함수가 자기 자신을 부르는 재주

재귀(recursion)는 함수가 자기 자신을 다시 부르는 거예요.

말로만 들으면 이상하죠. 일꾼이 일을 하다가 똑같은 일꾼을 또 부른다니, 끝이 안 날 것 같잖아요.

그래서 재귀에는 반드시 멈추는 조건이 필요해요. 이걸 base case(기저 조건)라고 불러요. 더 이상 자기 자신을 부르지 않고, 그냥 값을 돌려주는 지점이에요.

base case가 없으면 함수가 자기를 부르고 또 부르다가 무한히 반복돼요. 이걸 무한 재귀라고 하고, 프로그램이 멈추거나 에러가 나요.

1부터 n까지 모두 더하는 함수를 재귀로 만들어 볼게요.

```python
# 1부터 n까지 더하는 함수 (재귀 버전)
def sum_to(n):
    if n == 1:          # base case: 더 이상 자기를 안 부르고 값을 돌려줘요
        return 1
    return n + sum_to(n - 1)   # 자기 자신을 부르는 부분 (n보다 하나 작은 값으로)

print(sum_to(5))   # 기대 출력: 15  (1+2+3+4+5)
```

어떻게 15가 나오는지 차근차근 따라가 볼게요.

`sum_to(5)`는 아직 답을 모르니까 `5 + sum_to(4)`를 계산하려고 잠깐 멈춰요. 그럼 `sum_to(4)`는 다시 `4 + sum_to(3)`, `sum_to(3)`은 `3 + sum_to(2)`, `sum_to(2)`는 `2 + sum_to(1)`로 계속 안쪽으로 들어가요.

이렇게 호출이 차곡차곡 쌓이는 걸 "쌓인다(stack)"고 해요.

드디어 `sum_to(1)`에 도착하면 base case를 만나 1을 딱 돌려줘요. 그때부터 거꾸로 풀려요. `sum_to(2)`는 `2 + 1 = 3`, `sum_to(3)`은 `3 + 3 = 6`, `sum_to(4)`는 `4 + 6 = 10`, `sum_to(5)`는 `5 + 10 = 15`.

쌓였다가(내려가고) 풀리는(올라오는) 이 두 방향을 머릿속에 그리면 재귀가 훨씬 쉬워져요.

> 심화 과제의 팩토리얼과 피보나치도 똑같이 base case + 자기 호출로 만들어요. 팩토리얼은 n이 1 이하일 때, 피보나치는 n이 0 또는 1일 때가 base case예요. 이 힌트만 손에 쥐고, 위 sum_to의 구조를 흉내 내서 직접 만들어 보세요.

## 2. base case를 먼저 정하는 습관

재귀를 쓸 때 가장 흔한 실수가 base case를 빼먹는 거예요.

그래서 순서를 바꿔서 생각하면 좋아요. "자기를 언제까지 부를까?"가 아니라 "언제 멈출까?"를 먼저 정하는 거죠.

카운트다운으로 연습해 볼게요. 큰 수부터 1까지 세고, 다 세면 "발사"를 외치는 함수예요.

```python
# n부터 1까지 세고 마지막에 발사를 외쳐요
def countdown(n):
    if n == 0:              # base case: 다 셌으면 멈춰요
        print("발사!")
        return
    print(n)               # 지금 숫자를 보여주고
    countdown(n - 1)       # 하나 작은 수로 자기 자신을 다시 불러요

countdown(3)
# 기대 출력:
# 3
# 2
# 1
# 발사!
```

여기서도 `n == 0`이라는 멈추는 지점을 먼저 정해 두었기 때문에 안전해요.

만약 이 줄을 빼면 n이 음수로 계속 내려가면서 영원히 멈추지 않아요. base case를 먼저 쓰는 습관이 무한 재귀를 막아 줘요.

## 3. 입력 검증: 이상한 값을 걸러내는 재주

함수를 만들 때, 들어오는 값이 항상 올바르다고 믿으면 위험해요.

예를 들어 나이를 받는 함수인데 누가 실수로 -5나 300을 넣으면 어떻게 될까요? 그대로 쓰면 이상한 결과가 나와요.

그래서 함수 앞부분에서 값이 정상 범위인지 먼저 확인하고, 벗어나면 안내 메시지를 돌려주는 게 좋아요. 이걸 입력 검증(validation)이라고 해요.

```python
# 나이가 0~120 범위인지 확인하는 함수
def validate_age(age):
    if age < 0 or age > 120:      # 정상 범위를 벗어나면
        return "잘못된 나이입니다"
    return age                    # 정상이면 그대로 돌려줘요

print(validate_age(25))    # 기대 출력: 25
print(validate_age(-3))    # 기대 출력: 잘못된 나이입니다
print(validate_age(200))   # 기대 출력: 잘못된 나이입니다
```

핵심은 두 가지예요. 잘못된 경우를 `if`로 먼저 잡아내고, 그 경우에는 값 대신 메시지를 돌려주는 거죠.

`or`는 "둘 중 하나라도 참이면 참"이에요. 그래서 너무 작거나(0 미만) 너무 크거나(120 초과) 둘 중 하나만 걸려도 잘못된 값으로 처리돼요.

이 패턴만 익히면, 검사할 범위와 메시지만 바꿔서 어떤 값이든 검증할 수 있어요. 이제 과제에 직접 적용해 보세요.

## 4. `**kwargs`: 인수를 유연하게 받는 재주

지금까지 함수는 받을 인수의 개수가 정해져 있었어요. `validate_age(age)`처럼 하나면 하나, 둘이면 둘이었죠.

그런데 몇 개가 들어올지 미리 알 수 없을 때가 있어요. 이럴 때 `**kwargs`를 써요.

`**kwargs`는 이름을 붙여서 전달한 키워드 인수들(예: `name="철수"`)을 전부 하나의 딕셔너리로 모아 줘요. 이름은 꼭 kwargs가 아니어도 되지만, 관례로 많이 써요.

먼저 받은 것들을 그대로 보여 주는 함수예요.

```python
# 이름을 붙여 넘긴 값들을 딕셔너리로 모아서 보여줘요
def make_profile(**info):
    print(info)              # info는 평범한 딕셔너리예요

make_profile(name="철수", city="서울", job="개발자")
# 기대 출력: {'name': '철수', 'city': '서울', 'job': '개발자'}
```

보다시피 `info`는 특별한 무언가가 아니라 그냥 딕셔너리예요. 그래서 우리가 이미 배운 딕셔너리 기능을 그대로 쓸 수 있어요.

이번엔 개수가 몇 개든 상관없이, 넘긴 숫자들을 전부 더하는 함수예요.

```python
# 키워드로 넘긴 숫자들을 모두 더해요
def total(**nums):
    return sum(nums.values())   # 딕셔너리의 값들만 모아서 더해요

print(total(a=10, b=20, c=30))   # 기대 출력: 60
print(total(x=5, y=5))           # 기대 출력: 10
```

`nums`도 딕셔너리이기 때문에 `nums.values()`로 값들만 꺼낼 수 있어요. 거기에 `sum()`을 쓰면 전부 더해지죠.

인수를 2개 넣든 3개 넣든 함수는 그대로 동작해요. 개수를 미리 못 박지 않아도 되는 게 `**kwargs`의 장점이에요.

> 심화 과제에서는 과목명을 키워드로 받아 평균을 내는 함수를 직접 만들어 보세요 (합을 개수로 나누면 평균이에요). 값들의 합은 `sum(nums.values())`, 개수는 `len(nums)`로 구할 수 있다는 것만 힌트로 드릴게요. 이제 과제에 직접 적용해 보세요.

## 한 줄 정리

재귀는 자기 자신을 부르되 멈추는 조건(base case)을 반드시 두고, 입력 검증은 이상한 값을 `if`로 먼저 걸러 메시지를 돌려주며, `**kwargs`는 개수가 정해지지 않은 키워드 인수를 딕셔너리로 모아 준다.

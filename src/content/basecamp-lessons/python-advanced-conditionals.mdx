조건문은 상황에 따라 다른 길로 가게 해 줘요. 그런데 조건이 여러 개 겹치기 시작하면 if를 계속 쌓게 되죠.

오늘은 그 여러 조건을 깔끔하게 한 번에 다루는 법을 배워요. 그리고 if/elif를 길게 늘어놓는 대신 "표"를 만들어 판별하는 방법도 함께 익혀요.

이 방법을 알아두면 조건이 아무리 많아져도 코드가 지저분해지지 않아요. 하나씩 천천히 따라와 보세요.

이 레슨은 심화 과제 2번(조건문 심화)을 스스로 풀 수 있게 준비시켜요. 여러 조건을 묶는 법, all()로 한꺼번에 검사하는 법, 긴 if/elif를 표로 바꾸는 법을 여기서 충분히 연습해 두면 과제는 스스로 풀 수 있어요.

## 1. and와 or로 조건 묶기

조건 하나로는 부족할 때가 많아요. 예를 들어 놀이기구는 키도 충분하고 나이도 충분해야 탈 수 있어요.

이럴 때 `and`를 써요. `and`는 "둘 다 참이어야" 참이 돼요.

```python
키 = 145
나이 = 12

if 키 >= 140 and 나이 >= 10:
    print("탑승 가능")
else:
    print("탑승 불가")
# 출력: 탑승 가능
```

반대로 "둘 중 하나라도 참이면" 통과시키고 싶을 때는 `or`를 써요.

```python
회원 = False
초대권 = True

if 회원 or 초대권:
    print("입장 가능")
# 출력: 입장 가능
```

조건이 세 개 이상 섞이면 괄호로 묶어 주세요. 파이썬은 괄호가 없어도 계산하지만, 사람이 읽기에는 괄호가 있는 편이 훨씬 명확해요.

```python
키 = 145
나이 = 12
보호자동반 = True

# 괄호로 "키와 나이 조건"을 한 덩어리로 묶어 읽기 쉽게
if (키 >= 140 and 나이 >= 10) or 보호자동반:
    print("탑승 가능")
# 출력: 탑승 가능
```

## 2. all()과 any()로 여러 개를 한꺼번에 검사하기

검사할 대상이 여러 개일 때, `and`를 계속 이어 붙이면 줄이 길어져요. 이럴 때 `all()`과 `any()`가 편해요.

`all()`은 "모두 참이어야" True예요. 하나라도 거짓이면 False가 돼요.

`any()`는 "하나라도 참이면" True예요. 전부 거짓일 때만 False가 돼요.

기본 모양은 이래요. `all(조건 for 항목 in 목록)` 처럼 목록을 하나씩 돌면서 조건을 검사해요.

```python
온도목록 = [72, 88, 95, 60]

# 모든 값이 100 이하인가? (센서가 모두 정상 범위인지 확인)
정상 = all(v <= 100 for v in 온도목록)
print(정상)
# 출력: True

# 하나라도 90을 넘는 값이 있나? (주의가 필요한 센서가 있는지)
주의 = any(v > 90 for v in 온도목록)
print(주의)
# 출력: True
```

이게 어떻게 동작하는지 이해하려고, 같은 일을 반복문으로도 써 볼게요. `all()`은 사실 아래 코드와 똑같은 일을 해요.

```python
온도목록 = [72, 88, 95, 60]

정상 = True
for v in 온도목록:
    if v > 100:      # 조건을 어기는 값을 하나라도 만나면
        정상 = False
        break        # 더 볼 필요 없이 멈춤
print(정상)
# 출력: True
```

두 코드는 결과가 같아요. `all()`은 이 반복문을 한 줄로 줄여 준 것뿐이에요. 그래서 `all()`이 짧고 읽기 좋아요.

## 3. 긴 if/elif 대신 표로 판별하기 (핵심)

단계가 여러 개인 판별을 할 때, 보통 if/elif를 길게 늘어놓게 돼요. 예를 들어 배터리 잔량을 상태로 바꾸는 경우예요.

```python
def 배터리상태(잔량):
    if 잔량 >= 80:
        return "충분"
    elif 잔량 >= 50:
        return "보통"
    elif 잔량 >= 20:
        return "부족"
    else:
        return "위험"

print(배터리상태(65))
# 출력: 보통
```

동작은 하지만, 기준이 바뀌면 함수 안의 if 줄들을 하나하나 고쳐야 해요. 기준이 열 개, 스무 개로 늘면 정말 지저분해져요.

이럴 때 "표"를 따로 만들어요. 기준과 이름을 쌍(튜플)으로 묶어 리스트에 담는 거예요. 큰 기준부터 순서대로 넣는 게 중요해요.

```python
battery_table = [(80, "충분"), (50, "보통"), (20, "부족"), (0, "위험")]

def 배터리상태(잔량):
    for 기준, 이름 in battery_table:
        if 잔량 >= 기준:     # 처음으로 만족하는 기준의 이름을 돌려줌
            return 이름
    return "알 수 없음"        # 표에 없는 경우 대비

print(배터리상태(65))
# 출력: 보통
print(배터리상태(30))
# 출력: 부족
```

표를 위에서부터 훑다가, 잔량이 기준 이상이 되는 첫 줄을 만나면 바로 그 이름을 돌려줘요. 큰 기준을 먼저 넣었기 때문에 순서대로 딱 맞아떨어져요.

이 방식이 왜 더 좋을까요? 기준이 바뀌어도 함수 코드는 그대로 두고, 표(데이터)만 고치면 되기 때문이에요.

예를 들어 "보통"의 기준을 50에서 55로 바꾸고 싶으면, `battery_table` 한 곳의 숫자만 바꾸면 끝이에요. 함수는 손댈 필요가 없어요.

```python
# 기준만 수정, 함수는 그대로
battery_table = [(80, "충분"), (55, "보통"), (20, "부족"), (0, "위험")]
```

이렇게 데이터(표)와 코드(함수)를 분리해 두면, 나중에 규칙이 바뀌어도 고칠 곳이 한군데로 모여 실수가 줄어요.

같은 아이디어는 택배 무게별 요금에도 똑같이 써요. 무게 기준과 요금을 표로 만들고, 위에서부터 만족하는 첫 줄을 고르면 돼요.

```python
요금표 = [(20, 8000), (10, 5000), (5, 3500), (0, 2500)]

def 배송비(무게):
    for 기준, 요금 in 요금표:
        if 무게 >= 기준:
            return 요금
    return 0

print(배송비(12))
# 출력: 5000
```

이제 심화 과제에서는 이 표 방식을 점수 등급표에 그대로 적용해 보세요. 배터리나 무게 자리에 점수를, 이름 자리에 등급을 넣으면 구조는 똑같아요.

## 4. all() 검사와 비교를 합친 판별 함수 만들기

조건 하나가 아니라 "여러 조건을 모두 만족해야" 통과시키고 싶을 때가 있어요. 이럴 때 True 또는 False를 돌려주는 작은 함수를 만들면 깔끔해요.

예를 들어 "모든 값이 기준 이상이면서, 평균도 기준 이상"인지 판별한다고 해 볼게요. 두 조건을 `and`로 묶어 한 번에 판단해요.

```python
def 모두통과(값목록, 최소기준, 평균기준):
    # 조건 1: 모든 값이 최소기준 이상인가
    모두이상 = all(v >= 최소기준 for v in 값목록)
    # 조건 2: 평균이 평균기준 이상인가
    평균 = sum(값목록) / len(값목록)
    평균이상 = 평균 >= 평균기준
    # 두 조건이 모두 참일 때만 True
    return 모두이상 and 평균이상

print(모두통과([70, 80, 90], 최소기준=60, 평균기준=75))
# 출력: True

print(모두통과([50, 80, 90], 최소기준=60, 평균기준=75))
# 출력: False (50이 최소기준 60보다 작아서)
```

여기서 배울 점은 두 가지예요. 하나는 `all()`로 "모든 값" 조건을 한 줄로 검사한 것이고, 다른 하나는 그 결과와 다른 비교를 `and`로 합쳐 최종 True/False를 만든 것이에요.

이 함수는 일부러 점수 과목이 아니라 그냥 숫자 목록으로 만들었어요. 심화 과제에서는 이 패턴을 여러분의 상황에 맞게 바꿔 쓰면 돼요.

## 스스로 확인하기

Q1. 온도 목록 `[30, 45, 50]`이 있어요. "모든 값이 50 이하인지"를 `all()`로 검사하려면 어떻게 쓸까요?

Q2. 아래 요금표에서 무게가 7일 때 어떤 요금이 나올까요? 그리고 왜 그런지 설명해 보세요.
`요금표 = [(20, 8000), (10, 5000), (5, 3500), (0, 2500)]`

Q3. `any()`를 써서, 점수 목록 `[88, 92, 70]` 중에 "90점을 넘는 값이 하나라도 있는지" 검사하는 코드를 써 보세요.

```python
# Q1: 모든 값이 50 이하인지
온도목록 = [30, 45, 50]
print(all(v <= 50 for v in 온도목록))
# 출력: True

# Q2: 무게 7일 때 요금
# 표를 위에서부터 훑으면 20 이상? 아니오, 10 이상? 아니오,
# 5 이상? 예 -> 3500 을 돌려줌
요금표 = [(20, 8000), (10, 5000), (5, 3500), (0, 2500)]
무게 = 7
for 기준, 요금 in 요금표:
    if 무게 >= 기준:
        print(요금)
        break
# 출력: 3500

# Q3: 90을 넘는 값이 하나라도 있는지
점수목록 = [88, 92, 70]
print(any(v > 90 for v in 점수목록))
# 출력: True
```

## 한 줄 정리

여러 조건은 and, or, all(), any()로 묶어 한 번에 다루고, 단계가 많은 판별은 긴 if/elif 대신 기준을 담은 표를 순회해 첫 번째로 맞는 값을 고르면 데이터와 코드가 깔끔하게 분리돼요.

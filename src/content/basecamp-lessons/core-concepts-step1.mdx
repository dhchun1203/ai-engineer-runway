## 먼저 알아두기: 문법, 함수, 메서드, 라이브러리 구분

코드를 읽다 보면 괄호가 있는 것도, 없는 것도, 점이 찍힌 것도 있어요. 이게 다 같은 종류처럼 보이면 코드가 어려워져요.

딱 네 가지로 나눠 보면 훨씬 잘 읽혀요. 엑셀로 치면 "엑셀 자체 규칙", "SUM 같은 함수", "특정 셀에만 쓰는 기능", "추가 기능(애드인)"이라고 생각하면 돼요.

| 구분 | 모양 | 뜻 | 예시 |
| --- | --- | --- | --- |
| 문법(키워드) | 단어 + 콜론(`:`), 또는 기호 | 파이썬이 원래 정해 둔 규칙이에요. 괄호 없이 써요 | `if`, `for`, `while`, `def`, `try`, `=` |
| 함수 | `이름(값)` | 값을 넣으면 일을 해 주는 도구예요. 혼자서 써요 | `print()`, `len()`, `int()`, `type()` |
| 메서드 | `값.이름()` | 리스트나 글자 같은 특정 값에 붙여 쓰는 함수예요 | `fruits.append()`, `text.strip()` |
| 라이브러리 | `import 이름` | 다른 사람이 만들어 둔 기능 묶음이에요. 불러와서 써요 | `numpy`, `pandas`, `openpyxl` |

```python
fruits = ["사과", "바나나", "포도"]

print(len(fruits))      # 3  (함수: 괄호 안에 값을 넣어요)
fruits.append("귤")     # 메서드: 값 뒤에 점(.)을 찍고 써요
if len(fruits) > 3:     # 문법: 괄호 없이 키워드 + 콜론
    print("많아요")      # 많아요
```

구별법은 하나만 기억하면 돼요. 점(.) 뒤에 붙어 있으면 메서드, 혼자서 괄호를 달고 있으면 함수예요.

그리고 메서드는 값의 종류마다 쓸 수 있는 게 달라요. 리스트에는 `append()`가 있지만, 글자에는 없어요.

```python
# 실행 안 함
"안녕".append("!")   # AttributeError: 글자(str)에는 append 메서드가 없어요
```

## 1. print와 주석

`print()`는 값을 화면에 보여 주는 함수예요. `#` 뒤에 쓴 글은 주석이라고 하는데, 파이썬이 읽지 않고 그냥 지나가는 메모예요.

엑셀로 치면 `print()`는 셀 값을 눈으로 확인하는 것이고, 주석은 셀에 붙이는 메모 같은 거예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `print(값1, 값2, ...)` | 화면에 출력해요. 쉼표로 여러 값을 주면 한 칸씩 띄워서 보여 줘요 |
| 문법 | `# 메모` | 실행되지 않는 설명이에요 |

```python
print("안녕하세요")          # 안녕하세요
print(10 + 5)               # 15  (계산한 결과를 보여 줘요)
print("합계:", 10 + 5)       # 합계: 15  (쉼표로 여러 값)
# 이 줄은 실행되지 않아요
# print("잠깐 꺼 둔 줄")      # 앞에 #을 붙이면 이 줄도 실행되지 않아요
```

**이럴 때 써요**

- 코드가 제대로 도는지 중간에 확인할 때: 엑셀에서 읽어 온 한 줄을 `print(row)`로 찍어 보기
- 나중에 이 코드를 볼 사람(미래의 나 포함)에게 의도를 남길 때: `# 부가세 10% 계산`
- 잠깐 실행하고 싶지 않은 줄이 있을 때: 줄 앞에 `#`을 붙여 임시로 끄기

**조심**

`print()`는 보여 주기만 해요. 값을 어딘가에 저장하지는 않아요. 이 차이는 STEP 2의 함수 파트(print와 return)에서 다시 나와요.

## 2. 변수

변수는 값에 이름표를 붙여 보관해 두는 거예요. 엑셀에서 셀에 "단가"라는 이름을 붙여 두고 수식에서 이름으로 부르는 것과 비슷해요.

여기서 `=`는 "같다"가 아니에요. "오른쪽 값을 왼쪽 이름에 넣어라"라는 뜻이에요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `이름 = 값` | 값을 저장해요 |
| 문법 | `이름 += 값` | 원래 값에 더해서 다시 저장해요(`이름 = 이름 + 값`과 같아요) |

```python
name = "김철수"
age = 25
age = age + 1          # 원래 값(25)에 1을 더해서 다시 저장
age += 1               # 위와 같은 뜻, 더 짧게
print(name, age)       # 김철수 27

a, b = 10, 20          # 한 줄에 여러 개를 저장
print(a, b)            # 10 20
```

변수 이름은 아무렇게나 지을 수 없어요. 아래 세 가지 규칙만 지키면 돼요.

| 써도 되는 이름 | 안 되는 이름 | 이유 |
| --- | --- | --- |
| `my_name` | `my name` | 이름에 띄어쓰기를 넣을 수 없어요 |
| `name1` | `1name` | 숫자로 시작할 수 없어요 |
| `total_price` | `if`, `for` | 파이썬 문법 단어는 이름으로 못 써요 |

```python
FILE = "sales_10월.xlsx"   # 파일 이름을 변수로 두기
TAX_RATE = 0.1             # 기준값 저장
MIN_AMOUNT = 1000

total = 0
for price in [1000, 2500, 800]:
    total += price         # 합계를 차곡차곡 쌓기
print(total)               # 4300

Name = "대문자 N"
name = "소문자 n"
print(Name, name)          # 대문자 N 소문자 n  (서로 다른 변수예요)
```

**이럴 때 써요**

- 파일 이름을 변수에 두기: `FILE = "sales_10월.xlsx"`처럼 써 두면, 다음 달에는 이 한 줄만 바꾸면 돼요
- 기준값을 한곳에 모아 두기: `TAX_RATE = 0.1`, `MIN_AMOUNT = 1000`
- 반복문 안에서 합계 쌓기: `total += price`

**조심**

파이썬은 대문자와 소문자를 다르게 봐요. `Name`과 `name`은 완전히 다른 변수예요.

## 3. 데이터 타입

값에는 종류(타입)가 있어요. 종류에 따라 할 수 있는 일이 달라요.

엑셀에서도 셀 서식이 "숫자"냐 "텍스트"냐에 따라 SUM이 되기도 하고 안 되기도 하죠. 파이썬도 똑같아요.

| 타입 | 뜻 | 예시 | 할 수 있는 일 |
| --- | --- | --- | --- |
| `int` | 정수 | `10`, `-3` | 계산 |
| `float` | 실수(소수) | `3.14`, `0.5` | 계산 |
| `str` | 글자(문자열) | `"안녕"`, `"10"` | 붙이기, 자르기, 바꾸기 |
| `bool` | 참 또는 거짓 | `True`, `False` | 조건 판단 |
| `None` | 값이 없음 | `None` | 빈 칸 표시(엑셀의 빈 칸을 읽으면 이게 나와요) |

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `type(값)` | 값이 어떤 종류인지 알려 줘요 |

```python
print(type(10))       # <class 'int'>
print(type(3.5))      # <class 'float'>
print(type("10"))     # <class 'str'>   따옴표가 있으면 숫자처럼 보여도 글자예요
print(type(True))     # <class 'bool'>
print(type(None))     # <class 'NoneType'>

print("10" + "20")    # 1020  (글자끼리는 이어 붙여요)
print(10 + 20)        # 30    (숫자끼리는 더해요)
```

**이럴 때 써요**

- 계산 결과가 이상할 때 원인 찾기: 30이 나와야 하는데 `"10" + "20"`처럼 `1020`이 나오면 `type()`으로 확인해 보세요
- 엑셀에서 읽은 금액이 숫자로 들어왔는지, 글자로 들어왔는지 확인할 때

**조심**

`"10"`(글자)과 `10`(숫자)은 겉모습만 비슷할 뿐 완전히 다른 값이에요.

**더 깊게**: [변수와 자료형](/lesson/1-3-python-variables-and-types)

## 4. 형변환

형변환은 값의 종류를 다른 종류로 바꾸는 거예요. 글자와 숫자는 서로 더할 수 없어서, 계산하기 전에 종류를 맞춰 줘야 해요.

엑셀에서 "텍스트 형식으로 저장된 숫자"를 숫자로 바꿔 주는 것과 같은 일이에요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `int(값)` | 정수로 바꿔요(소수점 아래는 버려요) |
| 함수 | `float(값)` | 실수로 바꿔요 |
| 함수 | `str(값)` | 글자로 바꿔요 |

```python
price = "1000"            # 글자
print(int(price) + 500)   # 1500     (글자를 숫자로)
print(str(500) + "원")    # 500원    (숫자를 글자로)
print(float("3.5"))       # 3.5
print(int(3.9))           # 3        (반올림이 아니라 버림이에요)
```

실무에서 자주 나오는 모양 두 가지도 같이 볼게요.

```python
money = "1,000"                          # 엑셀에서 쉼표가 낀 글자로 들어온 금액
print(int(money.replace(",", "")))       # 1000  (쉼표를 지운 뒤 숫자로)

total = 4300
print("총 " + str(total) + "원")          # 총 4300원  (숫자를 문장에 붙일 때)
```

`input()`으로 받은 값은 숫자를 입력해도 항상 글자예요. 그래서 계산하려면 `int()`로 감싸요.

```python
age = int(input("나이: "))   # 나이: 25   (25를 입력했다면)
print(age + 1)               # 26
```

숫자로 바꿀 수 없는 글자를 `int()`에 넣으면 에러가 나요.

```python
# 실행 안 함
int("abc")    # ValueError: 숫자로 읽을 수 없는 글자예요
int("")       # ValueError: 빈 글자도 숫자로 못 바꿔요
```

**이럴 때 써요**

- `input()`으로 받은 값 계산하기: `age = int(input("나이: "))`
- 엑셀에서 `"1,000"`처럼 글자로 들어온 금액: `int("1,000".replace(",", ""))`로 `1000` 만들기
- 숫자를 문장에 붙이기: `"총 " + str(total) + "원"`

**조심**

`int("abc")`, `int("")`처럼 숫자로 바꿀 수 없는 글자는 `ValueError`가 나요. 이런 값이 섞여 있어도 멈추지 않게 하는 법은 STEP 4, 5의 예외 처리에서 배워요.

**더 깊게**: [변수와 자료형](/lesson/1-3-python-variables-and-types), [엑셀 파일 읽고 쓰기, 멈추지 않는 코드](/basecamp/python-excel-files-exceptions)

## 5. 연산자

연산자는 계산할 때 쓰는 기호예요. 엑셀 수식에 쓰는 `+`, `-`, `*`, `/`와 거의 같아요.

다만 몫과 나머지, 거듭제곱은 파이썬만의 모양이 있어요.

| 구분 | 형태 | 하는 일 | 예시 → 결과 |
| --- | --- | --- | --- |
| 문법 | `+`, `-`, `*` | 더하기, 빼기, 곱하기 | `7 * 2` → `14` |
| 문법 | `/` | 나누기(결과는 항상 소수) | `7 / 2` → `3.5` |
| 문법 | `//` | 나눈 몫 | `7 // 2` → `3` |
| 문법 | `%` | 나눈 나머지 | `7 % 2` → `1` |
| 문법 | `**` | 거듭제곱 | `2 ** 3` → `8` |

```python
print(7 * 2)     # 14
print(7 / 2)     # 3.5
print(6 / 2)     # 3.0  (딱 나눠떨어져도 /는 소수로 줘요)
print(7 // 2)    # 3
print(7 % 2)     # 1
print(2 ** 3)    # 8
```

글자에도 몇몇 연산자를 쓸 수 있어요. `+`는 이어 붙이기, `*`는 반복이에요.

```python
print("AX" + "캠프")    # AX캠프
print("=" * 10)        # ==========
```

활용 예시를 코드로 확인해 볼게요.

```python
n = 8
print(n % 2 == 0)        # True  (2로 나눈 나머지가 0이면 짝수)

minutes = 130
print(minutes // 60)     # 2   (2시간)
print(minutes % 60)      # 10  (10분)

price = 1000
print(price * 1.1)         # 1100.0  (소수를 곱하면 결과도 소수예요)
print(round(price * 1.1))  # 1100

print("-" * 30)          # ------------------------------
```

**이럴 때 써요**

- 짝수, 홀수 가르기: `n % 2 == 0`이면 짝수
- 분을 시간으로: `130 // 60`은 2시간, `130 % 60`은 10분
- 부가세 포함 금액: `price * 1.1`
- 출력 구분선 긋기: `print("-" * 30)`

**조심**

`price * 1.1`처럼 소수를 곱하면 결과도 소수(float)라서 `1100.0`처럼 나와요. 금액을 정수로 깔끔하게 보여 주고 싶으면 `round()`로 반올림해 주세요.

**더 깊게**: [변수와 자료형](/lesson/1-3-python-variables-and-types)

## 6. 문자열 다루기

글자(문자열)를 다듬고, 바꾸고, 나누는 방법이에요. 대부분 `글자.이름()` 모양의 메서드로 써요.

엑셀의 TRIM, UPPER, SUBSTITUTE, "텍스트 나누기" 기능을 파이썬으로 하는 거라고 보면 돼요.

| 구분 | 형태 | 하는 일 | 예시 → 결과 |
| --- | --- | --- | --- |
| 메서드 | `.strip()` | 앞뒤 공백을 지워요 | `" 김철수 ".strip()` → `"김철수"` |
| 메서드 | `.upper()`, `.lower()` | 대문자로, 소문자로 | `"ax".upper()` → `"AX"` |
| 메서드 | `.replace(a, b)` | a를 b로 바꿔요 | `"1,000".replace(",", "")` → `"1000"` |
| 메서드 | `.split(기준)` | 기준으로 잘라 리스트로 만들어요 | `"a,b".split(",")` → `['a', 'b']` |
| 함수 | `len(글자)` | 글자 수를 세요 | `len("안녕")` → `2` |
| 문법 | `f"...{변수}..."` | 문장 안에 값을 끼워 넣어요(f-string) | `f"{name}님"` |
| 문법 | `글자[번호]` | 한 글자를 꺼내요 | `"Python"[0]` → `"P"` |

```python
text = "  Hello Python  "
print(text.strip())                    # Hello Python
print(text.strip().upper())            # HELLO PYTHON  (메서드를 이어서 쓸 수 있어요)
print("AX".lower())                    # ax
print("사과,바나나".split(","))          # ['사과', '바나나']
print("2026-10-20".replace("-", "/"))  # 2026/10/20
print(len("안녕"))                      # 2
print("Python"[0])                     # P

name, score = "김철수", 90
print(f"{name}님의 점수는 {score}점입니다")   # 김철수님의 점수는 90점입니다
print(f"합계: {12000:,}원")                 # 합계: 12,000원  (천 단위 쉼표)
```

활용 예시도 실행해 볼게요.

```python
raw_name = "  이영희 "
print(raw_name.strip())                 # 이영희

print("2026-10-20".split("-"))          # ['2026', '10', '20']
print("2026-10-20".split("-")[1])       # 10

date = "10월 24일"
print(f"{name}님, {date}까지 제출 부탁드립니다.")   # 김철수님, 10월 24일까지 제출 부탁드립니다.
```

**이럴 때 써요**

- 엑셀에서 읽은 이름 앞뒤에 공백이 섞여 있을 때: `.strip()`
- `"2026-10-20"` 같은 날짜에서 월만 뽑을 때: `"2026-10-20".split("-")[1]`이면 `"10"`
- 안내 문자를 자동으로 만들 때: `f"{name}님, {date}까지 제출 부탁드립니다."`

**조심**

문자열 메서드는 원래 글자를 바꾸지 않아요. 다듬은 새 글자를 돌려줄 뿐이에요.

그래서 `text.strip()`만 한 줄 써 두면 아무 일도 안 일어나요. `text = text.strip()`처럼 다시 담아야 바뀌어요.

```python
text = "  Hello Python  "
text.strip()             # 새 글자를 만들기만 하고 버려요
print(len(text))         # 16  (그대로예요)

text = text.strip()      # 다시 담아야 바뀌어요
print(len(text))         # 12
```

## 7. 리스트 `[ ]`

리스트는 여러 값을 순서대로 담는 상자예요. 넣고, 빼고, 바꿀 수 있어요.

엑셀로 치면 한 열에 값을 위에서부터 차례로 적어 둔 것과 같아요. 다른 점은 번호가 1이 아니라 0부터 시작한다는 거예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `[값1, 값2]` | 리스트를 만들어요 |
| 문법 | `리스트[번호]` | 하나를 꺼내요(0부터 세고, `-1`은 맨 끝) |
| 문법 | `리스트[시작:끝]` | 여러 개를 잘라 와요(슬라이싱). 끝 번호는 포함하지 않아요 |
| 메서드 | `.append(값)` | 맨 뒤에 추가해요 |
| 메서드 | `.insert(번호, 값)` | 원하는 자리에 끼워 넣어요 |
| 메서드 | `.remove(값)` | 값으로 찾아서 지워요 |
| 메서드 | `.pop()` | 맨 뒤 값을 꺼내면서 지워요 |
| 메서드 | `.sort()` | 정렬해요(`reverse=True`를 주면 큰 순서) |
| 함수 | `len()`, `sum()`, `max()`, `min()` | 개수, 합계, 최댓값, 최솟값 |
| 문법 | `값 in 리스트` | 들어 있는지 확인해요(`True` 또는 `False`) |

```python
fruits = ["사과", "바나나", "포도"]

print(fruits[0])       # 사과
print(fruits[-1])      # 포도
print(fruits[0:2])     # ['사과', '바나나']  (0번부터 2번 "앞"까지)

fruits.append("귤")
print(fruits)          # ['사과', '바나나', '포도', '귤']
fruits.remove("바나나")
print(fruits)          # ['사과', '포도', '귤']
fruits[0] = "배"
print(fruits)          # ['배', '포도', '귤']
print(len(fruits))     # 3
print("귤" in fruits)  # True
```

`insert()`와 `pop()`도 바로 이어서 해 볼게요.

```python
fruits.insert(1, "딸기")   # 1번 자리에 끼워 넣기
print(fruits)              # ['배', '딸기', '포도', '귤']

last = fruits.pop()        # 맨 뒤 값을 꺼내면서 지우기
print(last)                # 귤
print(fruits)              # ['배', '딸기', '포도']
```

숫자 리스트는 정렬하고 합계, 최댓값을 바로 구할 수 있어요.

```python
scores = [70, 95, 85]
scores.sort()
print(scores)                        # [70, 85, 95]
scores.sort(reverse=True)
print(scores)                        # [95, 85, 70]
print(sum(scores), max(scores), min(scores))   # 250 95 70
print(sum(scores) / len(scores))     # 83.33333333333333  (평균)
```

활용 예시를 코드로 옮기면 이래요.

```python
attendees = []
attendees.append("김철수")           # 참석자 명단 모으기
attendees.append("이영희")
print(attendees)                    # ['김철수', '이영희']

submitted = ["김철수"]
for person in attendees:
    if person not in submitted:      # 미제출자 확인
        print(person, "미제출")       # 이영희 미제출

points = [88, 72, 95, 60, 81]
points.sort(reverse=True)
print(points[:3])                   # [95, 88, 81]  (상위 3명)
```

**이럴 때 써요**

- 참석자 명단 모으기: `attendees.append(name)`
- 점수 목록에서 평균, 최고점 구하기: `sum()`, `len()`, `max()`
- 미제출자 찾기: `if name not in submitted:`
- 상위 3명만 뽑기: `scores.sort(reverse=True)` 다음에 `scores[:3]`

**조심**

번호는 0부터 시작해요. 항목이 3개면 마지막 번호는 2예요.

```python
# 실행 안 함
fruits = ["배", "포도", "귤"]
fruits[3]    # IndexError: 3번 자리는 없어요(0, 1, 2까지만 있어요)
```

## 8. 튜플 `( )`

튜플도 리스트처럼 순서대로 값을 담아요. 다른 점은 한 번 만들면 바꿀 수 없다는 거예요.

엑셀로 치면 "시트 보호"를 걸어 둔 칸이에요. 볼 수는 있지만 고칠 수는 없어요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `(값1, 값2)` | 튜플을 만들어요 |
| 문법 | `a, b = 튜플` | 한 번에 나눠 담아요(언패킹) |

```python
weekdays = ("월", "화", "수", "목", "금")
print(weekdays[0])     # 월

point = (3, 5)
x, y = point           # 언패킹: 첫 값은 x, 둘째 값은 y에
print(x, y)            # 3 5
```

튜플 안의 값을 바꾸려고 하면 에러가 나요.

```python
# 실행 안 함
weekdays[0] = "일"     # TypeError: 튜플은 고칠 수 없어요
```

리스트와 튜플, 언제 뭘 쓸지 표로 정리해 볼게요.

| 비교 | 리스트 `[ ]` | 튜플 `( )` |
| --- | --- | --- |
| 수정 | 할 수 있어요 | 할 수 없어요 |
| 용도 | 계속 바뀌는 목록 | 고정된 값 묶음 |
| 예시 | 참석자 명단, 주문 목록 | 요일, 좌표, 설정값 |

```python
row = ("김철수", "영업", 1000)      # 엑셀 한 행을 읽으면 이런 튜플로 나와요
name, dept, amount = row
print(name, dept, amount)          # 김철수 영업 1000

GRADE_CUT = (90, 80, 70)           # 바뀌면 안 되는 등급 기준
print(GRADE_CUT[0])                # 90
```

**이럴 때 써요**

- 엑셀을 한 행씩 읽으면 `('김철수', '영업', 1000)`처럼 튜플로 나와요(STEP 4, 5). `name, dept, amount = row`로 나눠 담으면 편해요
- 실수로 바뀌면 안 되는 값을 묶어 둘 때: 등급 기준 `(90, 80, 70)` 같은 것

**더 깊게**: [리스트, 튜플, 딕셔너리](/lesson/1-3-python-lists-tuples-dicts), [엑셀 파일 읽고 쓰기, 멈추지 않는 코드](/basecamp/python-excel-files-exceptions)

## 확인 퀴즈

공식 확인 퀴즈와 같은 개념을 묻되, 값과 상황을 바꿔 새로 만들었어요. 먼저 머릿속으로 답을 고른 뒤 Colab에서 직접 실행해 확인해 보세요.

**Q1.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
nums = [5, 15, 25, 35]
nums.append(45)
print(nums[2:4], nums[-2], len(nums))
```

① `[25, 35] 35 5`
② `[15, 25, 35] 35 5`
③ `[25, 35] 45 5`
④ `[25, 35, 45] 45 4`

<details>
<summary>정답 확인</summary>

정답은 ①이에요.

`append(45)` 뒤에 리스트는 `[5, 15, 25, 35, 45]`로 5개가 돼요. `nums[2:4]`는 2번과 3번(4번 앞까지)이라 `[25, 35]`이고, `nums[-2]`는 끝에서 두 번째인 `35`예요.

</details>

**Q2.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
x = "7"
y = 3
print(x + str(y), int(x) * y)
```

① `10 21`
② `73 21`
③ `73 73`
④ 에러가 나요

<details>
<summary>정답 확인</summary>

정답은 ②예요.

`x + str(y)`는 글자 `"7"`과 글자 `"3"`을 이어 붙여서 `73`이 돼요. `int(x) * y`는 숫자 7과 3을 곱해서 `21`이에요. 둘 다 종류를 맞춰 줬기 때문에 에러는 나지 않아요.

</details>

**Q3.** 주문서에서 읽은 날짜 `"2026/11/05"`에서 월(`"11"`)만 꺼내는 코드는 무엇일까요?

```python
order_date = "2026/11/05"
```

① `order_date.split("/")[0]`
② `order_date.split("/")[2]`
③ `order_date.split("/")[1]`
④ `order_date.strip("/")`

<details>
<summary>정답 확인</summary>

정답은 ③이에요.

`split("/")`은 `['2026', '11', '05']`를 만들어요. 번호는 0부터 세니까 연도가 0번, 월이 1번, 일이 2번이에요. `strip("/")`은 앞뒤 끝의 `/`만 지울 뿐이라 날짜가 그대로 남아요.

</details>

**Q4.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
member = "  박민수  "
member.strip()
print(len(member))
```

① `3`
② `5`
③ `7`
④ 에러가 나요

<details>
<summary>정답 확인</summary>

정답은 ③이에요.

`member.strip()`은 공백을 지운 새 글자를 만들 뿐, `member`에 다시 담지 않았어요. 그래서 `member`는 여전히 앞 공백 2개, 이름 3글자, 뒤 공백 2개로 7글자예요. `member = member.strip()`이라고 써야 3이 나와요.

</details>

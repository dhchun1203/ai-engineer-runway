## 준비 칸: 예제 엑셀 만들기

이 레슨의 예제는 `sales.xlsx`라는 엑셀 파일을 읽어요. 직접 엑셀을 만들 필요 없이, 아래 칸을 한 번 실행하면 Colab 폴더에 파일이 생겨요.

시트는 두 개예요. 첫 시트 "9월"에는 공식 예시와 같은 다섯 행을 넣고, 시트 이름으로 골라 읽는 연습용으로 "10월" 시트도 하나 더 만들어요. 일부러 오타(`abc`)와 빈 칸을 섞어 뒀어요.

```python
import pandas as pd

sep = pd.DataFrame({
    "이름": ["김철수", "이영희", "박민수", "최지우", "정하늘"],
    "부서": ["영업", "개발", "영업", "개발", "영업"],
    "금액": [1000, "abc", None, 800, 2500],   # None은 엑셀에서 빈 칸이 돼요
})
oct_ = pd.DataFrame({
    "이름": ["김철수", "최지우"],
    "부서": ["영업", "개발"],
    "금액": [1500, 900],
})

# 시트 두 개짜리 파일 만들기 (ExcelWriter는 9절에서 다시 봐요)
with pd.ExcelWriter("sales.xlsx") as writer:
    sep.to_excel(writer, sheet_name="9월", index=False)
    oct_.to_excel(writer, sheet_name="10월", index=False)

print("sales.xlsx 준비 완료")
# 결과
# sales.xlsx 준비 완료
```

만들어진 `sales.xlsx`의 첫 시트는 이렇게 생겼어요.

| 이름 | 부서 | 금액 |
| --- | --- | --- |
| 김철수 | 영업 | 1000 |
| 이영희 | 개발 | abc |
| 박민수 | 영업 | (빈 칸) |
| 최지우 | 개발 | 800 |
| 정하늘 | 영업 | 2500 |

이 파일은 레슨 끝까지 고치지 않아요. 아래 예제들은 필요할 때마다 이 원본을 새로 읽어서 시작해요.

## 1. 엑셀 자동화 4단계

엑셀 자동화는 무엇을 하든 결국 네 단계예요. 읽고, 정리하고, 가공하고, 저장하기.

요리로 치면 장 보기, 손질하기, 조리하기, 그릇에 담기예요. 어떤 요리든 이 순서는 같듯이, 어떤 자동화든 이 네 칸에 나눠 담으면 설계가 쉬워져요.

| 단계 | 하는 일 | Pandas 도구 |
| --- | --- | --- |
| 1단계 읽기 | 엑셀 파일을 표(DataFrame)로 불러와요 | `pd.read_excel()` |
| 2단계 정리 | 열 이름을 정리하고, 오타와 빈 칸을 처리해요 | `rename()`, `to_numeric()`, `dropna()` |
| 3단계 가공 | 계산 열을 붙이고, 골라내고, 그룹별로 더해요 | 새 열, `apply()`, 필터, `groupby()` |
| 4단계 저장 | 결과를 새 엑셀 파일로 내보내요 | `to_excel()`, `ExcelWriter` |

네 단계가 실제 코드에서 어떻게 보이는지 먼저 한 번에 볼게요. 줄마다 무슨 뜻인지는 아래 절에서 하나씩 풀어요.

```python
import pandas as pd

# 1단계 읽기: 엑셀을 표로
df = pd.read_excel("sales.xlsx")

# 2단계 정리: 숫자가 아닌 금액은 빈 값으로, 빈 값 행은 지우기
df["금액"] = pd.to_numeric(df["금액"], errors="coerce")
df = df.dropna(subset=["금액"])

# 3단계 가공: 부가세 열 붙이기, 부서별 금액 합계
df["부가세"] = df["금액"] * 0.1
summary = df.groupby("부서")["금액"].sum().reset_index()

# 4단계 저장: 새 엑셀로
summary.to_excel("report.xlsx", index=False)

print(summary)
# 결과
#    부서      금액
# 0  개발   800.0
# 1  영업  3500.0
```

### 이럴 때 써요

"매주 받는 주문 엑셀에서 담당자별 합계 내기"라는 일을 네 칸에 나눠 보면 이래요.

1. 읽기: `orders.xlsx`를 불러와요.
2. 정리: 금액 칸의 오타와 빈 칸을 걸러요.
3. 가공: 담당자별로 금액을 더해요.
4. 저장: `report.xlsx`로 저장해요.

### 조심

코드부터 치지 말고, 단계마다 무엇을 할지 먼저 한 줄씩 적어 보세요. 순서가 정해져 있으면 코드가 훨씬 덜 꼬여요.

## 2. 엑셀 읽기: read_excel

`pd.read_excel()` 한 줄이면 엑셀 시트 하나가 통째로 DataFrame(표)이 돼요. 엑셀의 첫 줄(제목 행)은 알아서 열 이름이 돼요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `pd.read_excel("파일.xlsx")` | 첫 번째 시트를 읽어요 |
| 옵션 | `sheet_name="10월"` | 이름으로 고른 시트를 읽어요 |
| 옵션 | `sheet_name=None` | 모든 시트를 한 번에 읽어요(시트 이름을 키로, 표를 값으로 하는 딕셔너리) |
| 메서드 | `df.head()` / `df.info()` | 앞부분 미리보기 / 열, 자료형, 빈 값 요약(STEP 3) |

```python
df = pd.read_excel("sales.xlsx")
print(df.head())
# 결과
#     이름  부서    금액
# 0  김철수  영업  1000
# 1  이영희  개발   abc
# 2  박민수  영업   NaN
# 3  최지우  개발   800
# 4  정하늘  영업  2500
```

빈 칸은 `NaN`(값 없음)으로 읽혀요. 엑셀에서 비어 있던 박민수의 금액 칸이 그래요.

이번엔 특정 시트만, 그리고 모든 시트를 한꺼번에 읽어 볼게요.

```python
df_oct = pd.read_excel("sales.xlsx", sheet_name="10월")   # 10월 시트만
print(df_oct)
# 결과
#     이름  부서    금액
# 0  김철수  영업  1500
# 1  최지우  개발   900

all_sheets = pd.read_excel("sales.xlsx", sheet_name=None)  # 전부
print(list(all_sheets.keys()))
print(len(all_sheets["9월"]))
# 결과
# ['9월', '10월']
# 5
```

`sheet_name=None`의 결과는 딕셔너리라서, STEP 2에서 배운 대로 `all_sheets["9월"]`처럼 시트 이름(키)으로 표를 꺼내요.

파일을 받자마자 `info()`로 상태를 점검하는 습관도 들여 보세요.

```python
df.info()
# 결과 (앞부분)
# <class 'pandas.DataFrame'>
# RangeIndex: 5 entries, 0 to 4
# Data columns (total 3 columns):
#  #   Column  Non-Null Count  Dtype
# ---  ------  --------------  -----
#  0   이름      5 non-null      str
#  1   부서      5 non-null      str
#  2   금액      4 non-null      object
```

금액 열은 4개만 값이 있고(빈 칸 하나), 자료형이 숫자가 아니라 `object`예요. 숫자 사이에 `abc`라는 글자가 섞여서 그래요. 5절에서 이걸 정리해요.

### 이럴 때 써요

- 달마다 시트가 따로 있는 파일에서 원하는 달만 읽을 때: `sheet_name="10월"`
- 받은 파일을 열자마자 `head()`, `info()`로 상태부터 확인할 때

### 조심

- 이름만 적어서 열려면 파이썬 파일(또는 Colab 작업 폴더)과 엑셀 파일이 같은 폴더에 있어야 해요. 다른 폴더라면 경로까지 적어 주세요.

## 3. 딕셔너리 리스트와 DataFrame

STEP 2의 "딕셔너리들의 리스트"는 사실 Pandas 표와 생긴 게 같아요. 딕셔너리 하나가 한 행이고, 키가 열 이름이에요.

그래서 둘은 서로 쉽게 바뀌어요. 엑셀로 치면 메모장에 한 줄씩 적어 둔 기록을, 그대로 표에 붙여 넣는 것과 비슷해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `pd.DataFrame(딕셔너리_리스트)` | 딕셔너리 리스트를 표로 바꿔요 |
| 메서드 | `df.to_dict("records")` | 표를 딕셔너리 리스트로 되돌려요 |

```python
rows = [
    {"이름": "김철수", "부서": "영업", "금액": 1000},
    {"이름": "이영희", "부서": "개발", "금액": 1200},
]
df = pd.DataFrame(rows)
print(df)
# 결과
#     이름  부서    금액
# 0  김철수  영업  1000
# 1  이영희  개발  1200

print(df.to_dict("records"))
# 결과
# [{'이름': '김철수', '부서': '영업', '금액': 1000}, {'이름': '이영희', '부서': '개발', '금액': 1200}]
```

### 파이썬 문법(for)과 Pandas 비교

| 비교 | 딕셔너리 리스트 + for | Pandas DataFrame |
| --- | --- | --- |
| 일하는 단위 | 한 행씩 | 표 전체를 한 번에 |
| 코드 길이 | 길어요 | 짧아요 |
| 좋은 점 | 원리를 이해하기 좋아요 | 실무에서 주로 써요 |

### 이럴 때 써요

여러 곳에서 모은 데이터를 `append`로 딕셔너리 리스트에 하나씩 쌓아 두고, 마지막에 `pd.DataFrame()`으로 표로 바꿔 저장할 때 써요.

```python
collected = []
collected.append({"이름": "한별", "부서": "기획", "금액": 700})
collected.append({"이름": "윤슬", "부서": "기획", "금액": 300})

new_df = pd.DataFrame(collected)
new_df.to_excel("collected.xlsx", index=False)
print(new_df)
# 결과
#    이름  부서   금액
# 0  한별  기획  700
# 1  윤슬  기획  300
```

## 4. 열 정리: 이름 바꾸기, 고르기, 지우기, 공백 빼기

받은 엑셀은 대개 지저분해요. 열 이름이 달마다 다르거나, 쓸모없는 열이 끼어 있거나, 이름 앞뒤에 공백이 붙어 있어요.

계산을 시작하기 전에 이런 것부터 정돈해요. 책상을 치우고 나서 일을 시작하는 것과 같아요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.rename(columns={"옛이름": "새이름"})` | 열 이름을 바꿔요 |
| 문법 | `df[["열1", "열2"]]` | 필요한 열만, 원하는 순서로 골라요 |
| 메서드 | `df.drop(columns=["열"])` | 필요 없는 열을 지워요 |
| 메서드 | `df["열"].str.strip()` | 글자 열의 앞뒤 공백을 한꺼번에 빼요 |

연습용으로 일부러 지저분한 표를 하나 만들어 볼게요. 이름에 공백이 붙어 있고, 쓸모없는 "메모" 열도 있어요.

```python
messy = pd.DataFrame({
    "이름": [" 김철수 ", "김철수", "최지우 "],
    "부서": ["영업", "영업", "개발"],
    "금액": [1000, 500, 800],
    "메모": ["", "확인", ""],
})

messy = messy.rename(columns={"금액": "매출액"})   # 열 이름 바꾸기
messy = messy.drop(columns=["메모"])              # 필요 없는 열 지우기
messy = messy[["이름", "부서", "매출액"]]          # 필요한 열만, 이 순서로
print(messy.columns.tolist())
# 결과
# ['이름', '부서', '매출액']
```

이제 공백이 왜 문제인지 볼게요. 공백을 빼기 전과 후에 사람별 합계를 내 봐요.

```python
print(messy.groupby("이름")["매출액"].sum().to_dict())
# 결과
# {' 김철수 ': 1000, '김철수': 500, '최지우 ': 800}

messy["이름"] = messy["이름"].str.strip()        # " 김철수 " 를 "김철수" 로
print(messy.groupby("이름")["매출액"].sum().to_dict())
# 결과
# {'김철수': 1500, '최지우': 800}
```

공백 하나 때문에 같은 김철수가 두 사람으로 나뉘어 있었어요. `.str.strip()`으로 정리하니 한 사람으로 합쳐졌어요.

### .strip()과 .str.strip() 비교

| 비교 | `.strip()` (STEP 1) | `.str.strip()` (Pandas) |
| --- | --- | --- |
| 대상 | 글자 하나 | 글자 열 전체 |
| 예시 | `" 김철수 ".strip()` | `df["이름"].str.strip()` |

```python
print(" 김철수 ".strip())
# 결과
# 김철수
```

### 이럴 때 써요

- 매달 받는 엑셀마다 열 이름이 조금씩 다를 때 하나로 맞추기
- 보고서에 필요한 열만 남기기
- 이름 앞뒤 공백 때문에 같은 사람이 다른 사람으로 집계되는 일 막기

### 조심

Pandas 메서드는 대부분 원본을 고치지 않고, 고친 새 표를 돌려줘요. 그래서 `df = df.rename(...)`처럼 결과를 다시 담아야 해요.

```python
messy.rename(columns={"매출액": "금액"})          # 결과를 담지 않음
print(messy.columns.tolist())
# 결과
# ['이름', '부서', '매출액']

messy = messy.rename(columns={"매출액": "금액"})  # 다시 담기
print(messy.columns.tolist())
# 결과
# ['이름', '부서', '금액']
```

첫 번째 `rename`은 결과를 담지 않아서 열 이름이 그대로예요. 다시 담은 두 번째에서야 바뀌었어요.

## 5. 잘못된 값 정리: to_numeric, isna, dropna, fillna

실무 엑셀에는 빈 칸, 오타(`abc`), 이상한 형식이 꼭 섞여 있어요. 이런 값을 먼저 걸러야 합계와 평균이 맞게 나와요.

엑셀에서 필터를 걸어 이상한 행을 찾아 지우던 일을, 코드 몇 줄로 해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `pd.to_numeric(열, errors="coerce")` | 숫자로 바꾸고, 못 바꾸는 값은 빈 값(NaN)으로 둬요 |
| 메서드 | `df["열"].isna()` | 빈 값인지 True/False로 알려 줘요 |
| 메서드 | `df.dropna(subset=["열"])` | 그 열이 비어 있는 행을 지워요 |
| 메서드 | `df["열"].fillna(값)` | 빈 값을 다른 값으로 채워요 |

`sales.xlsx`를 새로 읽어서 정리해 볼게요.

```python
df = pd.read_excel("sales.xlsx")
df["금액"] = pd.to_numeric(df["금액"], errors="coerce")   # "abc"가 NaN으로
bad = df[df["금액"].isna()]                              # 문제 행은 따로 보관
df = df.dropna(subset=["금액"])                          # 문제 행 지우기

print(f"정상 {len(df)}건, 확인 필요 {len(bad)}건")
print(bad["이름"].tolist())
# 결과
# 정상 3건, 확인 필요 2건
# ['이영희', '박민수']
```

`abc`였던 이영희, 빈 칸이던 박민수가 함께 걸러졌어요. 둘 다 `to_numeric` 뒤에는 NaN이 됐기 때문이에요.

### errors= 옵션 비교

| 옵션 | `abc`를 만나면 |
| --- | --- |
| `errors="raise"` (기본값) | 에러를 내고 멈춰요 |
| `errors="coerce"` | NaN으로 바꾸고 계속 가요 |

```python
# 실행 안 함
raw = pd.read_excel("sales.xlsx")
pd.to_numeric(raw["금액"])     # errors를 안 쓰면 "raise"
# ValueError: "abc"는 숫자로 바꿀 수 없다며 멈춰요
```

### dropna와 fillna, 언제 뭘 쓸까

| 상황 | 고를 것 |
| --- | --- |
| 빈 칸이면 그 행을 쓸 수 없어요(금액이 빠짐) | `dropna()` |
| 빈 칸을 0으로 봐도 돼요(실적이 없음) | `fillna(0)` |
| 빈 칸을 특정 글자로 표시하고 싶어요(응답 안 함) | `fillna("미응답")` |

```python
visits = pd.DataFrame({"매장": ["A", "B", "C"], "방문": [12, None, 5]})
visits["방문"] = visits["방문"].fillna(0)       # 기록 없음 = 0명
print(visits["방문"].tolist())
# 결과
# [12.0, 0.0, 5.0]

survey = pd.DataFrame({"이름": ["가람", "나래"], "만족도": ["좋음", None]})
survey["만족도"] = survey["만족도"].fillna("미응답")
print(survey["만족도"].tolist())
# 결과
# ['좋음', '미응답']
```

### 이럴 때 써요

- 금액, 수량 같은 숫자 열은 무조건 `to_numeric(errors="coerce")`부터 해요. 오타가 섞여 있어도 멈추지 않아요.
- 걸러 둔 `bad` 표를 따로 저장해서 담당자에게 "이 행들 확인해 주세요" 하고 보내요.

```python
bad.to_excel("확인필요.xlsx", index=False)
print(pd.read_excel("확인필요.xlsx")["이름"].tolist())
# 결과
# ['이영희', '박민수']
```

### 조심

`dropna()`를 `subset` 없이 쓰면, 어느 열이든 빈 칸이 하나라도 있는 행은 전부 지워져요. 꼭 필요한 열만 지정하세요.

```python
memo = pd.DataFrame({
    "이름": ["김철수", "최지우", "정하늘"],
    "금액": [1000, 800, 2500],
    "비고": ["VIP", None, None],    # 비고는 비어 있어도 괜찮은 열
})
print(len(memo.dropna()))                  # 비고가 빈 행까지 사라져요
print(len(memo.dropna(subset=["금액"])))   # 금액만 보고 지워요
# 결과
# 1
# 3
```

## 6. 새 열 만들기: 계산식, apply

엑셀에서는 첫 칸에 수식을 넣고 아래로 쭉 끌어내렸죠. Pandas에서는 한 줄이면 열 전체에 한 번에 들어가요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `df["새열"] = 계산식` | 계산 결과로 새 열을 만들어요 |
| 문법 | `df["새열"] = df["열1"] * df["열2"]` | 같은 행끼리 열과 열을 계산해요 |
| 메서드 | `df["열"].apply(함수)` | 직접 만든 함수를 열의 모든 값에 하나씩 적용해요 |

5절에서 정리한 `df`(정상 3건)에 이어서 열을 붙여 볼게요.

```python
df["부가세"] = df["금액"] * 0.1              # 숫자와 계산
df["합계"] = df["금액"] + df["부가세"]        # 열끼리 계산

def get_grade(amount):                       # STEP 2에서 배운 함수
    if amount >= 2000:
        return "대형"
    elif amount >= 1000:
        return "중형"
    return "소형"

df["등급"] = df["금액"].apply(get_grade)     # 모든 행에 함수 적용
print(df)
# 결과
#     이름  부서      금액    부가세      합계  등급
# 0  김철수  영업  1000.0  100.0  1100.0  중형
# 3  최지우  개발   800.0   80.0   880.0  소형
# 4  정하늘  영업  2500.0  250.0  2750.0  대형
```

행 번호가 0, 3, 4인 건 5절에서 1번(이영희), 2번(박민수) 행을 지웠기 때문이에요.

### 계산식과 apply 비교

| 비교 | 계산식 | `apply(함수)` |
| --- | --- | --- |
| 언제 | 더하기, 곱하기 같은 사칙연산으로 끝날 때 | if처럼 조건을 따져야 할 때 |
| 예시 | 부가세, 합계, 단가 곱하기 수량 | 등급, 상태(지연/정상), 분류 |

### 이럴 때 써요

- 단가 곱하기 수량으로 금액 열 만들기
- 금액별 등급, 출석률별 위험군(P0/P1/안정) 같은 분류 열 만들기

```python
orders = pd.DataFrame({"단가": [3000, 4500], "수량": [2, 3]})
orders["금액"] = orders["단가"] * orders["수량"]
print(orders["금액"].tolist())
# 결과
# [6000, 13500]

def risk(rate):
    if rate < 0.5:
        return "P0"
    elif rate < 0.8:
        return "P1"
    return "안정"

attend = pd.DataFrame({"이름": ["가람", "나래", "다온"], "출석률": [0.4, 0.75, 0.95]})
attend["위험군"] = attend["출석률"].apply(risk)
print(attend["위험군"].tolist())
# 결과
# ['P0', 'P1', '안정']
```

### 조심

`apply`에는 함수 이름만 넣어요. `apply(get_grade())`처럼 괄호를 붙이면, 함수를 넘기는 게 아니라 그 자리에서 바로 실행해 버려서 에러가 나요.

```python
# 실행 안 함
df["등급"] = df["금액"].apply(get_grade())
# TypeError: get_grade()에 amount 값이 빠졌다며 멈춰요
```

## 7. 골라내기와 정렬

STEP 3에서 배운 필터와 정렬을 그대로 써요. 엑셀의 자동 필터와 "내림차순 정렬" 버튼이에요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `df[df["열"] >= 값]` | 조건에 맞는 행만 남겨요 |
| 문법 | `df[(조건1) & (조건2)]` | 두 조건을 다 만족하는 행만 남겨요 |
| 메서드 | `df["열"].isin([값들])` | 목록 안의 값 중 하나에 해당하는지 봐요 |
| 메서드 | `df.sort_values("열", ascending=False)` | 큰 값부터 정렬해요 |

계속 같은 `df`(정상 3건)로 해 볼게요.

```python
big = df[df["금액"] >= 1000]                                  # 1000 이상
sales_big = df[(df["부서"] == "영업") & (df["금액"] >= 1000)]  # 영업이면서 1000 이상
dev = df[df["부서"].isin(["개발", "기획"])]                    # 개발 또는 기획
top = df.sort_values("금액", ascending=False).head(3)         # 금액 큰 순 3건

print(big["이름"].tolist())
print(sales_big["이름"].tolist())
print(dev["이름"].tolist())
print(top["이름"].tolist())
# 결과
# ['김철수', '정하늘']
# ['김철수', '정하늘']
# ['최지우']
# ['정하늘', '김철수', '최지우']
```

### 파이썬 문법과 Pandas, 같은 일

1000 이상인 행만 모으는 일을 두 방식으로 써 보면 이래요. `to_dict("records")`로 표를 딕셔너리 리스트로 바꿔서 for문에 넣었어요.

```python
rows = df.to_dict("records")

# 파이썬 문법 (for + if)
result = []
for r in rows:
    if r["금액"] >= 1000:
        result.append(r)
print([r["이름"] for r in result])
# 결과
# ['김철수', '정하늘']

# Pandas (한 줄)
result = df[df["금액"] >= 1000]
print(result["이름"].tolist())
# 결과
# ['김철수', '정하늘']
```

| 비교 | 파이썬 for + if | Pandas 필터 |
| --- | --- | --- |
| 쓰는 법 | 빈 리스트를 만들고, 한 행씩 검사해서 `append` | `df[조건]` 한 줄 |
| 결과 | 딕셔너리 리스트 | DataFrame(표) |

### 이럴 때 써요

고액 거래만 따로 보기, 미납이나 지연 건만 추리기, 상위 N명 뽑기.

### 조심

조건 두 개를 묶을 때는 `and` 대신 `&`를 쓰고, 조건마다 괄호로 감싸야 해요. 괄호를 빼면 계산 순서가 꼬여서 에러가 나요.

## 8. 그룹별 집계: groupby

같은 값끼리 묶어서 합계, 평균, 개수를 구해요. 엑셀의 피벗 테이블과 같은 일이에요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.groupby("기준열")["계산열"].sum()` | 그룹별 합계 |
| 메서드 | `.mean()` / `.count()` / `.max()` | 평균 / 개수 / 최댓값 |
| 메서드 | `.agg(["sum", "mean", "count"])` | 여러 계산을 한 번에 |
| 메서드 | `.reset_index()` | 결과를 다시 평범한 표 모양으로(저장하기 좋게) |

```python
summary = (df.groupby("부서")["금액"].sum()
             .reset_index()
             .sort_values("금액", ascending=False))
print(summary)
# 결과
#    부서      금액
# 1  영업  3500.0
# 0  개발   800.0

print(df.groupby("부서")["금액"].agg(["sum", "mean", "count"]))
# 결과
#        sum    mean  count
# 부서
# 개발   800.0   800.0      1
# 영업  3500.0  1750.0      2
```

`.mean()`, `.count()`, `.max()`도 하나씩 써 볼게요.

```python
print(df.groupby("부서")["금액"].mean().to_dict())
print(df.groupby("부서")["금액"].count().to_dict())
print(df.groupby("부서")["금액"].max().to_dict())
# 결과
# {'개발': 800.0, '영업': 1750.0}
# {'개발': 1, '영업': 2}
# {'개발': 800.0, '영업': 2500.0}
```

### reset_index는 왜 쓸까

| 비교 | `reset_index()` 전 | `reset_index()` 후 |
| --- | --- | --- |
| 모양 | 부서가 행 이름(인덱스) 자리에 있어요 | 부서가 평범한 열로 내려와요 |
| 엑셀로 저장하면 | 열 이름이 어긋나기 쉬워요 | 깔끔한 표로 저장돼요 |

```python
before = df.groupby("부서")["금액"].sum()
after = before.reset_index()
print(before)
# 결과
# 부서
# 개발     800.0
# 영업    3500.0
# Name: 금액, dtype: float64

print(after)
# 결과
#    부서      금액
# 0  개발   800.0
# 1  영업  3500.0
```

전에는 부서가 왼쪽 행 이름 자리에 붙어 있고, 후에는 "부서"라는 이름을 단 진짜 열이 됐어요.

### 이럴 때 써요

부서별 매출, 담당자별 처리 건수, 월별 평균, 기수별 참여 인원.

## 9. 엑셀로 저장하기: to_excel, ExcelWriter

정리한 표를 엑셀 파일로 내보내요. 시트가 하나면 `to_excel`, 한 파일에 시트 여러 개를 담으려면 `ExcelWriter`를 써요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.to_excel("파일.xlsx", index=False)` | 표 하나를 엑셀로 저장해요 |
| 옵션 | `sheet_name="이름"` | 시트 이름을 정해요 |
| 문법 | `with pd.ExcelWriter("파일.xlsx") as writer:` | 한 파일에 시트 여러 개를 써요 |

```python
df.to_excel("result.xlsx", index=False)                 # 시트 하나

with pd.ExcelWriter("report.xlsx") as writer:            # 시트 여러 개
    df.to_excel(writer, sheet_name="정리 데이터", index=False)
    summary.to_excel(writer, sheet_name="부서별 합계", index=False)
    bad.to_excel(writer, sheet_name="확인 필요", index=False)

print(list(pd.read_excel("report.xlsx", sheet_name=None).keys()))
# 결과
# ['정리 데이터', '부서별 합계', '확인 필요']
```

저장한 파일을 다시 읽어서 시트 이름만 확인했어요. 세 시트가 한 파일에 들어갔어요.

### index=False를 빼면

| `index=True` (기본값) | `index=False` |
| --- | --- |
| 맨 앞에 0, 1, 2 같은 번호 열이 하나 더 생겨요 | 데이터 열만 깔끔하게 들어가요 |

```python
df.to_excel("with_index.xlsx")              # index를 안 적으면 True
print(pd.read_excel("with_index.xlsx").columns.tolist())
# 결과
# ['Unnamed: 0', '이름', '부서', '금액', '부가세', '합계', '등급']

df.to_excel("no_index.xlsx", index=False)
print(pd.read_excel("no_index.xlsx").columns.tolist())
# 결과
# ['이름', '부서', '금액', '부가세', '합계', '등급']
```

`Unnamed: 0`이 바로 쓸데없이 따라 들어간 번호 열이에요.

### 이럴 때 써요

정리본, 요약본, 확인 필요 목록을 한 파일의 세 시트에 담아 보고할 때 써요.

### 조심

- 저장하려는 파일이 엑셀에서 열려 있으면 저장이 안 돼요(`PermissionError`). 엑셀을 닫고 다시 실행하세요.

## 10. 예외 처리: 멈추지 않는 코드

`to_numeric(errors="coerce")`로 값 오류는 해결했어요. 그런데 파일이 없거나, 저장할 파일이 열려 있는 문제는 여전히 프로그램을 멈춰 세워요.

이런 에러는 `try` / `except`로 잡아서 친절한 안내 문구를 대신 띄워요. 엑셀의 IFERROR처럼 "에러가 나면 이걸 보여 줘"라고 미리 정해 두는 거예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `try:` | 에러가 날 수도 있는 코드를 넣어요 |
| 문법 | `except 에러종류:` | 그 에러가 나면 대신 실행해요 |
| 문법 | `except (에러1, 에러2):` | 여러 에러를 한 번에 잡아요 |

먼저 파일 이름을 틀리게 적어 볼게요. `sales.xlsx`를 `salse.xlsx`로 잘못 썼어요.

```python
try:
    df2 = pd.read_excel("salse.xlsx")      # 오타: 이런 파일은 없어요
    print("읽기 성공")
except FileNotFoundError:
    print("salse.xlsx 파일을 찾을 수 없습니다. 파일 이름과 위치를 확인하세요.")
# 결과
# salse.xlsx 파일을 찾을 수 없습니다. 파일 이름과 위치를 확인하세요.
```

빨간 에러 대신 안내 문구가 나왔고, 프로그램도 멈추지 않았어요. 이름을 바르게 고치면 except는 건너뛰어요.

```python
try:
    df2 = pd.read_excel("sales.xlsx")
    print("읽기 성공")
except FileNotFoundError:
    print("sales.xlsx 파일을 찾을 수 없습니다. 파일 이름과 위치를 확인하세요.")
# 결과
# 읽기 성공
```

저장할 때 생기는 `PermissionError`도 같은 방식으로 잡아요. 이 에러는 `report.xlsx`가 엑셀 프로그램에서 열려 있을 때 나요.

Colab에서는 파일을 엑셀로 열어 둔 상태를 만들 수 없어서 직접 재현은 어려워요. 아래 코드는 파일이 닫혀 있으니 except로 가지 않고 조용히 저장만 돼요. 내 컴퓨터에서 `report.xlsx`를 엑셀로 열어 둔 채 실행하면 안내 문구가 나와요.

```python
try:
    df.to_excel("report.xlsx", index=False)
    print("저장 완료")
except PermissionError:
    print("report.xlsx가 열려 있어요. 엑셀을 닫고 다시 실행하세요.")
# 결과
# 저장 완료
```

에러 여러 개를 한 번에 잡으려면 괄호로 묶어요. `as e`를 붙이면 어떤 에러였는지도 알 수 있어요.

```python
try:
    df2 = pd.read_excel("없는파일.xlsx")
    df2.to_excel("out.xlsx", index=False)
except (FileNotFoundError, PermissionError) as e:
    print("파일 문제:", type(e).__name__)
# 결과
# 파일 문제: FileNotFoundError
```

### try / except 동작 순서

| 순서 | 무슨 일이 일어나나요 |
| --- | --- |
| 1 | try 안의 코드를 위에서부터 실행해요 |
| 2 | 에러가 안 나면 except는 통째로 건너뛰어요 |
| 3 | 에러가 나면 그 줄에서 바로 try를 멈추고, 맞는 except로 넘어가요 |
| 4 | 맞는 except가 없으면 원래처럼 에러를 내고 멈춰요 |

3번이 중요해요. 에러가 난 줄 아래에 있는 try 안의 코드는 실행되지 않아요.

```python
try:
    print("1. 읽기 시작")
    df2 = pd.read_excel("없는파일.xlsx")
    print("2. 이 줄은 실행되지 않아요")
except FileNotFoundError:
    print("3. except로 왔어요")
print("4. 프로그램은 계속 가요")
# 결과
# 1. 읽기 시작
# 3. except로 왔어요
# 4. 프로그램은 계속 가요
```

### 자주 만나는 에러

| 에러 | 이럴 때 나요 | 이렇게 풀어요 |
| --- | --- | --- |
| `FileNotFoundError` | 파일 이름이나 위치가 틀렸을 때 | 파일 이름과 폴더를 확인해요 |
| `PermissionError` | 저장할 파일이 엑셀에서 열려 있을 때 | 엑셀을 닫아요 |
| `KeyError` | 없는 열 이름을 쓸 때(`df["금엑"]`) | `df.columns`로 열 이름을 확인해요 |
| `ValueError` | `errors="coerce"` 없이 숫자로 못 바꾸는 값을 바꿀 때 | `to_numeric(errors="coerce")`를 써요 |
| `ModuleNotFoundError` | 라이브러리가 설치되지 않았을 때 | `pip install pandas openpyxl` |

`KeyError`와 `ValueError`도 직접 잡아 볼게요.

```python
try:
    print(df["금엑"])                     # 오타 난 열 이름
except KeyError:
    print("없는 열이에요. 지금 있는 열:", df.columns.tolist())
# 결과
# 없는 열이에요. 지금 있는 열: ['이름', '부서', '금액', '부가세', '합계', '등급']

raw = pd.read_excel("sales.xlsx")
try:
    pd.to_numeric(raw["금액"])            # coerce 없이
except ValueError:
    print("숫자로 못 바꾸는 값이 있어요")
# 결과
# 숫자로 못 바꾸는 값이 있어요
```

### 조심

`except:`처럼 에러 종류를 적지 않으면 모든 에러를 다 숨겨 버려요. 그러면 정작 진짜 원인을 찾기가 어려워져요. 예상되는 에러 이름을 꼭 적어 주세요.

## 11. 최종 과제 흐름: 나만의 엑셀 자동 정리 툴

지금까지 본 걸 네 단계 함수로 나눠서 툴 하나로 완성해요. 단계마다 함수가 따로 있으면 읽기 쉽고, 한 단계만 고치기도 쉬워요.

공장 라인에 비유하면 읽는 사람, 고치는 사람, 계산하는 사람, 포장하는 사람이 따로 있는 거예요. 포장 방식이 바뀌면 포장 담당만 바꾸면 돼요.

| 함수 | 단계 | 하는 일 |
| --- | --- | --- |
| `load(path)` | 1단계 읽기 | 엑셀을 불러와요 |
| `clean(df)` | 2단계 정리 | 금액 오류를 걸러내고, 문제 행은 따로 보관해요 |
| `analyze(df)` | 3단계 가공 | 등급 열을 붙이고, 부서별 합계를 내요 |
| `save(...)` | 4단계 저장 | 세 시트로 저장해요 |

1절의 예제와 똑같이 원본 `sales.xlsx`를 읽어서 시작해요.

```python
import pandas as pd

def get_grade(amount):
    if amount >= 2000:
        return "대형"
    elif amount >= 1000:
        return "중형"
    return "소형"

def load(path):
    return pd.read_excel(path)

def clean(df):
    df["금액"] = pd.to_numeric(df["금액"], errors="coerce")
    bad = df[df["금액"].isna()]
    good = df.dropna(subset=["금액"]).copy()   # copy(): 뒤에서 열을 붙일 때 경고 막기
    return good, bad

def analyze(df):
    df["등급"] = df["금액"].apply(get_grade)
    summary = (df.groupby("부서")["금액"].sum()
                 .reset_index()
                 .sort_values("금액", ascending=False))
    return df, summary

def save(df, summary, bad, path):
    with pd.ExcelWriter(path) as writer:
        df.to_excel(writer, sheet_name="정리 데이터", index=False)
        summary.to_excel(writer, sheet_name="부서별 합계", index=False)
        bad.to_excel(writer, sheet_name="확인 필요", index=False)

# 실행
try:
    raw = load("sales.xlsx")
    good, bad = clean(raw)
    good, summary = analyze(good)
    save(good, summary, bad, "report.xlsx")
    print(f"완료! 정상 {len(good)}건, 확인 필요 {len(bad)}건")
except FileNotFoundError:
    print("sales.xlsx 파일을 찾을 수 없습니다.")
except PermissionError:
    print("report.xlsx가 열려 있어요. 닫고 다시 실행하세요.")
# 결과
# 완료! 정상 3건, 확인 필요 2건
```

만들어진 `report.xlsx`의 "부서별 합계" 시트를 열어 보면 이래요.

```python
print(pd.read_excel("report.xlsx", sheet_name="부서별 합계"))
# 결과
#    부서    금액
# 0  영업  3500
# 1  개발   800
```

엑셀에 저장했다가 다시 읽으면 3500.0 같은 값은 3500처럼 소수점 없이 읽혀요. 값 자체는 같아요.

### 이럴 때 써요

- 다음 달에는 파일 이름만 바꿔서 그대로 실행해요. 예를 들어 `load("sales_11월.xlsx")`.
- 규칙이 바뀌면(부서별 대신 담당자별, 등급 기준 변경) 그 일을 맡은 함수 하나만 고쳐요.

## 확인 퀴즈

공식 퀴즈와 같은 개념을 묻되, 값과 상황을 바꿨어요. 먼저 머릿속으로 답을 고른 다음 코드를 실행해서 확인해 보세요.

**Q1.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
import pandas as pd
q = pd.DataFrame({"수량": ["5", "x", None, "7", "8"]})
q["수량"] = pd.to_numeric(q["수량"], errors="coerce")
q = q.dropna()
print(len(q), q["수량"].sum())
```

① 5 20.0
② 3 20.0
③ 4 13.0
④ 에러가 나서 멈춰요

<details>
<summary>정답 확인</summary>

정답은 ②예요. 출력은 `3 20.0`이에요.

`errors="coerce"` 덕분에 `"x"`는 에러 대신 NaN이 되고, 원래 비어 있던 `None`도 NaN이에요. `dropna()`가 이 두 행을 지우니 5, 7, 8 세 행이 남고, 합은 20.0이에요(NaN이 섞였던 열이라 소수점 숫자로 나와요).

</details>

**Q2.** 다음 파이썬 문법 코드를 Pandas로 바르게 옮긴 것은 무엇일까요? (`df`는 `rows`와 같은 내용의 표예요)

```python
result = []
for r in rows:
    if r["부서"] == "영업":
        result.append(r)
```

① `result = df[df["부서"] == "영업"]`
② `result = df["부서"] == "영업"`
③ `result = df.groupby("부서").sum()`
④ `result = df.sort_values("부서")`

<details>
<summary>정답 확인</summary>

정답은 ①이에요. 조건을 `df[ ]` 안에 넣어야 조건에 맞는 행만 남은 표가 돼요.

②는 행을 고르지 않고, 행마다 True/False만 적힌 목록을 돌려줘요. ③은 그룹별로 묶어 더하는 일이고, ④는 순서만 바꿀 뿐 행을 걸러내지 않아요.

</details>

**Q3.** `summary.to_excel("부서별.xlsx")`로 저장한 뒤 다시 읽어 보니, 열 이름 맨 앞에 `Unnamed: 0`이라는 번호 열이 끼어 있었어요. 다음부터 이 열 없이 저장하려면 어떻게 써야 할까요?

① `summary.to_excel("부서별.xlsx", header=False)`
② `summary.to_excel("부서별.xlsx", index=False)`
③ `summary.to_excel("부서별.xlsx", sheet_name=None)`
④ `summary.to_excel("부서별.csv")`

<details>
<summary>정답 확인</summary>

정답은 ②예요. `to_excel`은 기본값이 `index=True`라서 행 번호(인덱스)를 맨 앞 열로 같이 저장해요. 그 열이 다시 읽을 때 `Unnamed: 0`으로 보여요.

①의 `header=False`는 오히려 열 이름 줄을 빼 버리고, ③은 시트 이름 옵션이라 번호 열과 상관없어요. ④처럼 확장자만 바꿔도 번호 열은 그대로 따라가요.

</details>

**Q4.** 다음 코드를 실행하면 무엇이 출력될까요? (`없는파일.xlsx`는 정말 없는 파일이에요)

```python
try:
    data = pd.read_excel("없는파일.xlsx")
    print("A")
except FileNotFoundError:
    print("B")
print("C")
```

① A, C
② B, C
③ A, B, C
④ 에러를 내고 멈춰요

<details>
<summary>정답 확인</summary>

정답은 ②예요. B와 C가 차례로 출력돼요.

파일이 없어서 `read_excel` 줄에서 바로 에러가 나요. 그 순간 try를 멈추니 `print("A")`는 실행되지 않고, 맞는 except로 가서 B를 찍은 뒤, try 바깥의 C까지 계속 실행돼요.

</details>

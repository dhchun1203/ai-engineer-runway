그런데 챗봇은 표를 통째로 보여 주는 게 아니에요. 사용자가 "액션 영화 보여 줘"라고 하면, 그중 액션 영화만 골라서 답해야 하죠.

시작하기 전에, 이번 편에서 계속 쓸 영화 표를 다시 만들어 둘게요. (진짜 과제에서는 1편에서 `read_csv`로 불러온 그 데이터를 쓰면 돼요.)

```python
import pandas as pd

movies = pd.DataFrame({
    "제목": ["인터스텔라", "기생충", "라라랜드", "매드맥스", "코코"],
    "연도": [2014, 2019, 2016, 2015, 2017],
    "장르": ["SF", "드라마", "뮤지컬", "액션", "애니메이션"],
    "평점": [8.6, 8.5, 8.0, 8.1, 8.4],
})
```

## 오늘 만들 조각

3. (3편) 검색 결과에 AI 답변을 붙여 챗봇 완성하기

오늘 목표는 "검색어를 받으면 맞는 영화를 찾아 보기 좋게 돌려주는 기능"을 만들고, 거기에 웹 화면을 씌우는 거예요.

## 글자로 검색하기

1편에서는 `평점 >= 9.0`처럼 숫자로 걸러 봤어요. 그런데 챗봇에서는 "코코" 같은 글자로 찾는 일이 더 많죠.

글자 검색에는 `.str.contains()`를 써요. "이 열의 글자 안에 이 단어가 들어 있니?"를 줄마다 물어봐요.

```python
# 제목에 "맥스"가 들어 있는 영화만 남겨요
print(movies[movies["제목"].str.contains("맥스", na=False)])
# 출력:
#      제목    연도  장르   평점
# 3  매드맥스  2015  액션  8.1
```

`na=False`는 값이 비어 있는 칸을 만나도 오류 없이 그냥 넘어가라는 뜻이에요. 진짜 데이터에는 빈 칸이 종종 있어서 붙여 두면 안전해요.

장르로도 똑같이 찾을 수 있어요. 열 이름만 바꾸면 돼요.

```python
# 장르가 "액션"인 영화 찾기
print(movies[movies["장르"].str.contains("액션", na=False)])
```

## 함수로 묶기

지금은 검색어를 바꿀 때마다 코드를 고쳐야 해요. 챗봇은 사용자가 아무 검색어나 넣을 수 있어야 하니, 이걸 함수로 묶어 둘게요.

함수는 STEP 2에서 배웠죠. 입력을 받아 정해진 일을 하고 결과를 돌려주는 작은 기계였어요. 검색어를 입력으로 받는 기계를 만드는 거예요.

```python
# keyword(검색어)를 받아, 제목에 그 글자가 든 영화들을 돌려주는 함수
def search_movies(keyword):
    result = movies[movies["제목"].str.contains(keyword, na=False)]
    return result

# 이제 검색어만 바꿔 부르면 돼요
print(search_movies("코코"))
# 출력:
#    제목    연도    장르   평점
# 4  코코  2017  애니메이션  8.4
```

`keyword` 자리에 무엇을 넣든, 함수가 알아서 그 글자로 검색해 줘요. 코드를 다시 고칠 필요가 없어졌죠. 이게 함수로 묶는 이유예요.

## 반복문으로 답을 보기 좋게 만들기

`search_movies`는 표를 돌려줘요. 그런데 챗봇의 답으로는 표보다 읽기 좋은 문장이 나아요. "인터스텔라 (2014, SF, 평점 8.6)"처럼요.

표의 줄을 하나씩 돌면서 문장으로 바꿔 볼게요. 줄을 하나씩 도는 데는 `.iterrows()`를 써요. 반복문으로 줄마다 꺼내 오는 도구예요.

```python
def search_as_text(keyword):
    result = movies[movies["제목"].str.contains(keyword, na=False)]

    # 찾은 게 없으면 그렇다고 말해 줘요
    if len(result) == 0:
        return "찾는 영화가 없어요."

    # 줄을 하나씩 돌며 문장으로 바꿔 모아요
    lines = []
    for _, row in result.iterrows():
        lines.append(f'{row["제목"]} ({row["연도"]}, {row["장르"]}, 평점 {row["평점"]})')

    # 문장들을 줄바꿈으로 이어 하나의 답으로
    return "\n".join(lines)

print(search_as_text("코코"))
# 출력: 코코 (2017, 애니메이션, 평점 8.4)
```

한 줄씩 뜯어볼게요.

- `if len(result) == 0:` 은 찾은 영화가 없을 때를 대비해요. 아무것도 없으면 빈 답 대신 "찾는 영화가 없어요"라고 알려 줘요.
- `for _, row in result.iterrows():` 는 표를 한 줄씩 돌아요. `row`에 그 줄의 내용이 담기고, 앞의 `_`는 행 번호인데 안 쓸 거라 밑줄로 버렸어요.
- `row["제목"]` 처럼 대괄호에 열 이름을 적어 그 줄의 값을 꺼내요.
- `"\n".join(lines)` 는 모아 둔 문장들을 줄바꿈(`\n`)으로 이어 붙여요.

이제 `search_as_text("액션")`이든 무엇이든, 검색어를 넣으면 읽기 좋은 답이 나와요. 챗봇의 심장이 만들어진 거예요.

## Gradio가 뭐예요?

함수는 만들었는데, 지금은 우리만 코드로 부를 수 있어요. 사용자가 입력창에 검색어를 치고 답을 받는 화면이 필요하죠.

그 화면을 자동으로 만들어 주는 도구가 Gradio예요. 우리가 만든 함수 하나를 건네주면, 입력창과 결과창이 달린 웹 페이지를 뚝딱 만들어 줘요. 화면을 직접 디자인할 필요가 없어요.

Colab에서는 먼저 설치부터 해요.

## Gradio로 화면 붙이기

이제 우리 함수에 화면을 씌워 볼게요.

```python
import gradio as gr

# fn: 화면이 부를 함수, inputs: 입력 방식, outputs: 결과 표시 방식
demo = gr.Interface(
    fn=search_as_text,
    inputs="text",
    outputs="text",
)

demo.launch()
```

`gr.Interface`에 세 가지만 알려 주면 돼요.

- `fn=search_as_text` 는 화면이 부를 함수예요. 사용자가 입력창에 친 글자가 이 함수의 `keyword`로 들어가요.
- `inputs="text"` 는 글자를 입력받는 칸을 만들라는 뜻이에요.
- `outputs="text"` 는 함수가 돌려준 글자를 결과창에 보여 주라는 뜻이에요.

`demo.launch()`를 실행하면 Colab 안에 작은 웹 페이지가 뜨고, 검색어를 넣으면 우리 함수가 찾은 답이 나와요. 방금 만든 검색 기능이 진짜 화면 위에서 움직이는 거예요.

1편에서 데이터를 파이썬 안으로 불러왔어요. 이제 표는 손안에 있죠.

그런데 챗봇은 표를 통째로 보여 주는 게 아니에요. 사용자가 "화산귀환 알려 줘"라고 하면, 그중 화산귀환만 골라서 답해야 하죠.

그래서 오늘(2편)은 두 조각을 만들어요. 하나는 원하는 것만 찾아 주는 검색 기능, 다른 하나는 사용자가 검색어를 입력할 수 있는 화면이에요.

> 이번 편도 Google Colab에 직접 쳐 보며 따라와 주세요. 1편에서 만든 웹툰 표를 계속 이어서 씁니다.

시작하기 전에, 이번 편에서 계속 쓸 웹툰 표를 다시 만들어 둘게요. (진짜 과제에서는 1편에서 `read_csv`로 불러온 그 데이터를 쓰면 돼요.)

```python
import pandas as pd

webtoons = pd.DataFrame({
    "title": ["신의 탑", "여신강림", "화산귀환", "전지적 독자 시점", "마루는 강쥐"],
    "author": ["SIU", "야옹이", "비가", "슬리피-C", "모죠"],
    "genre": ["판타지", "로맨스", "무협", "판타지", "일상"],
    "rating": [9.7, 9.2, 9.9, 9.9, 9.9],
})
```

## 오늘 만들 조각

1. (1편) 데이터를 파이썬 안으로 불러오기 (완료)
2. (오늘) 원하는 데이터만 골라내는 검색 기능 만들기, 화면 붙이기
3. (3편) 검색 결과에 AI 답변을 붙여 챗봇 완성하기

오늘 목표는 "검색어를 받으면 맞는 웹툰을 찾아 보기 좋게 돌려주는 기능"을 만들고, 거기에 웹 화면을 씌우는 거예요.

## 글자로 검색하기

1편에서는 `rating >= 9.5`처럼 숫자로 걸러 봤어요. 그런데 챗봇에서는 "화산귀환" 같은 글자로 찾는 일이 더 많죠.

글자 검색에는 `.str.contains()`를 써요. "이 열의 글자 안에 이 단어가 들어 있니?"를 줄마다 물어봐요.

```python
# 제목에 "화산"이 들어 있는 웹툰만 남겨요
print(webtoons[webtoons["title"].str.contains("화산", na=False)])
# 출력:
#    title author genre  rating
# 2   화산귀환     비가     무협     9.9
```

`na=False`는 값이 비어 있는 칸을 만나도 오류 없이 그냥 넘어가라는 뜻이에요. 진짜 데이터에는 빈 칸이 종종 있어서 붙여 두면 안전해요.

장르로도 똑같이 찾을 수 있어요. 열 이름만 바꾸면 돼요.

```python
# 장르가 "판타지"인 웹툰 찾기
print(webtoons[webtoons["genre"].str.contains("판타지", na=False)])
```

## 함수로 묶기

지금은 검색어를 바꿀 때마다 코드를 고쳐야 해요. 챗봇은 사용자가 아무 검색어나 넣을 수 있어야 하니, 이걸 함수로 묶어 둘게요.

함수는 STEP 2에서 배웠죠. 입력을 받아 정해진 일을 하고 결과를 돌려주는 작은 기계였어요. 검색어를 입력으로 받는 기계를 만드는 거예요.

```python
# keyword(검색어)를 받아, 제목에 그 글자가 든 웹툰들을 돌려주는 함수
def search_webtoons(keyword):
    result = webtoons[webtoons["title"].str.contains(keyword, na=False)]
    return result

# 이제 검색어만 바꿔 부르면 돼요
print(search_webtoons("여신"))
# 출력:
#    title author genre  rating
# 1   여신강림    야옹이    로맨스     9.2
```

`keyword` 자리에 무엇을 넣든, 함수가 알아서 그 글자로 검색해 줘요. 코드를 다시 고칠 필요가 없어졌죠. 이게 함수로 묶는 이유예요.

## 반복문으로 답을 보기 좋게 만들기

`search_webtoons`는 표를 돌려줘요. 그런데 챗봇의 답으로는 표보다 읽기 좋은 문장이 나아요. "신의 탑 (SIU, 판타지, 평점 9.7)"처럼요.

표의 줄을 하나씩 돌면서 문장으로 바꿔 볼게요. 줄을 하나씩 도는 데는 `.iterrows()`를 써요. 반복문으로 줄마다 꺼내 오는 도구예요.

```python
def search_as_text(keyword):
    result = webtoons[webtoons["title"].str.contains(keyword, na=False)]

    # 찾은 게 없으면 그렇다고 말해 줘요
    if len(result) == 0:
        return "찾는 웹툰이 없어요."

    # 줄을 하나씩 돌며 문장으로 바꿔 모아요
    lines = []
    for _, row in result.iterrows():
        lines.append(f'{row["title"]} ({row["author"]}, {row["genre"]}, 평점 {row["rating"]})')

    # 문장들을 줄바꿈으로 이어 하나의 답으로
    return "\n".join(lines)

print(search_as_text("여신"))
# 출력: 여신강림 (야옹이, 로맨스, 평점 9.2)
```

한 줄씩 뜯어볼게요.

- `if len(result) == 0:` 은 찾은 웹툰이 없을 때를 대비해요. 아무것도 없으면 빈 답 대신 "찾는 웹툰이 없어요"라고 알려 줘요.
- `for _, row in result.iterrows():` 는 표를 한 줄씩 돌아요. `row`에 그 줄의 내용이 담기고, 앞의 `_`는 행 번호인데 안 쓸 거라 밑줄로 버렸어요.
- `row["title"]` 처럼 대괄호에 열 이름을 적어 그 줄의 값을 꺼내요.
- `"\n".join(lines)` 는 모아 둔 문장들을 줄바꿈(`\n`)으로 이어 붙여요.

이제 `search_as_text("판타지")`든 무엇이든, 검색어를 넣으면 읽기 좋은 답이 나와요. 챗봇의 심장이 만들어진 거예요.

## Gradio가 뭐예요?

함수는 만들었는데, 지금은 우리만 코드로 부를 수 있어요. 사용자가 입력창에 검색어를 치고 답을 받는 화면이 필요하죠.

그 화면을 자동으로 만들어 주는 도구가 Gradio예요. 우리가 만든 함수 하나를 건네주면, 입력창과 결과창이 달린 웹 페이지를 뚝딱 만들어 줘요. 화면을 직접 디자인할 필요가 없어요.

Colab에서는 먼저 설치부터 해요.

```python

```

맨 앞의 `!`는 "이건 파이썬 코드가 아니라 설치 명령이야"라는 표시예요. Colab에서 도구를 설치할 때 써요.

## Gradio로 화면 붙이기

이제 우리 함수에 화면을 씌워 볼게요.

```python
import gradio as gr

# fn: 화면이 부를 함수, inputs: 입력 방식, outputs: 결과 표시 방식
demo = gr.Interface(
    fn=search_as_text,
    inputs="text",
    outputs="text",
)

demo.launch()
```

`gr.Interface`에 세 가지만 알려 주면 돼요.

- `fn=search_as_text` 는 화면이 부를 함수예요. 사용자가 입력창에 친 글자가 이 함수의 `keyword`로 들어가요.
- `inputs="text"` 는 글자를 입력받는 칸을 만들라는 뜻이에요.
- `outputs="text"` 는 함수가 돌려준 글자를 결과창에 보여 주라는 뜻이에요.

`demo.launch()`를 실행하면 Colab 안에 작은 웹 페이지가 뜨고, 검색어를 넣으면 우리 함수가 찾은 답이 나와요. 방금 만든 검색 기능이 진짜 화면 위에서 움직이는 거예요.

## 1. 딕셔너리

### 이름표로 꺼내는 묶음

딕셔너리는 "이름표(키): 값"을 한 쌍씩 모아 둔 묶음이에요. 중괄호 `{ }`로 만들어요.

리스트는 "몇 번째"라는 번호로 값을 꺼내요. 딕셔너리는 "이름", "부서" 같은 이름표로 꺼내요. 그래서 엑셀 표의 한 행을 담기에 딱 맞아요. 열 이름이 이름표, 그 칸의 값이 값이 되는 거예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `{"키": 값, ...}` | 딕셔너리 만들기 |
| 문법 | `d["키"]` | 값 꺼내기 (없는 키면 에러) |
| 메서드 | `d.get("키", 기본값)` | 값 꺼내기 (없으면 기본값을 주고 에러 없음) |
| 문법 | `d["키"] = 값` | 값 바꾸기, 또는 새 항목 넣기 |
| 문법 | `del d["키"]` | 항목 지우기 |
| 메서드 | `.keys()` / `.values()` / `.items()` | 키만 / 값만 / (키, 값) 쌍으로 꺼내기 |
| 문법 | `"키" in d` | 그 키가 있는지 확인 (True 또는 False) |
| 함수 | `len(d)` | 항목이 몇 개인지 세기 |

```python
person = {"이름": "김철수", "부서": "영업", "나이": 30}

print(person["부서"])
print(person.get("연락처", "없음"))   # 없는 키인데도 에러 없이 기본값

person["나이"] = 31                   # 이미 있는 키 → 값이 바뀜
person["직급"] = "대리"                # 없던 키 → 새로 들어감
del person["부서"]                    # 지우기
print(person)

# 결과
# 영업
# 없음
# {'이름': '김철수', '나이': 31, '직급': '대리'}
```

`d["키"] = 값`은 한 가지 모양으로 두 가지 일을 해요. 키가 이미 있으면 값을 바꾸고, 없으면 새로 넣어요.

이번에는 남은 내용 전체를 훑어보고, 키가 있는지와 개수도 확인해 볼게요.

```python
for key, value in person.items():
    print(key, ":", value)

print("이름" in person)    # 이름표가 있나?
print("부서" in person)    # 방금 지웠으니 없음
print(len(person))         # 항목 개수

# 결과
# 이름 : 김철수
# 나이 : 31
# 직급 : 대리
# True
# False
# 3
```

### `d["키"]` vs `d.get("키")`

둘 다 값을 꺼내지만, 키가 없을 때 반응이 달라요.

| | `d["키"]` | `d.get("키", 기본값)` |
| --- | --- | --- |
| 키가 있을 때 | 값 | 값 |
| 키가 없을 때 | 에러 (KeyError) | 기본값 (안 적으면 None) |
| 언제 쓰나 | 키가 반드시 있을 때 | 있을지 없을지 모를 때 |

```python
# 실행 안 함
person["연락처"]
# KeyError: '연락처'  (없는 키를 대괄호로 꺼내면 여기서 멈춰요)
```

```python
print(person.get("연락처"))   # 기본값을 안 적으면 None

# 결과
# None
```

### 리스트 vs 딕셔너리

| | 리스트 `[ ]` | 딕셔너리 `{ }` |
| --- | --- | --- |
| 꺼내는 방법 | 번호 `[0]` | 이름표 `["이름"]` |
| 순서 | 중요해요 | 이름표로 찾으니 덜 중요해요 |
| 어울리는 데이터 | 같은 종류 여러 개 (점수 목록) | 한 대상의 여러 정보 (이름, 부서, 나이) |

### 이럴 때 써요

- 직원 한 명의 정보를 하나로 묶을 때: `{"이름": "김철수", "부서": "영업"}`
- 코드표, 변환표를 만들 때: 부서 코드를 부서 이름으로 바꾸는 표 (아래 코드)
- 항목별로 개수를 셀 때: `count[부서] = count.get(부서, 0) + 1` (7절과 퀴즈 3번에서 다시 나와요)
- STEP 3 챗봇에서 질문과 답변 목록을 담을 때

```python
dept_code = {"S01": "영업", "D01": "개발"}
print(dept_code["S01"])

# 결과
# 영업
```

### 조심

같은 키를 두 번 넣으면 나중에 넣은 값이 앞의 값을 덮어써요. 딕셔너리 안에서 키는 딱 하나만 있을 수 있어요.

```python
d = {"이름": "김철수", "이름": "이영희"}
print(d)

# 결과
# {'이름': '이영희'}
```

## 2. 비교 연산자와 논리 연산자

### 참인지 거짓인지 묻는 기호

"이 값이 80 이상이야?", "부서가 영업이야?"처럼 물으면 파이썬은 `True`(참) 아니면 `False`(거짓)로 대답해요. 이렇게 묻는 기호가 비교 연산자와 논리 연산자예요.

이 대답이 다음 절의 조건문, 반복문, 그리고 나중에 배우는 필터의 재료가 돼요. 엑셀에서 `=A2>=80`이라고 쓰면 TRUE나 FALSE가 나오는 것과 같아요.

| 구분 | 형태 | 하는 일 | 예시와 결과 |
| --- | --- | --- | --- |
| 문법 | `==` | 같다 | `5 == 5` 는 True |
| 문법 | `!=` | 다르다 | `5 != 3` 은 True |
| 문법 | `>` `>=` | 크다 / 크거나 같다 (이상) | `80 >= 90` 은 False |
| 문법 | `<` `<=` | 작다 / 작거나 같다 (이하) | `3 < 5` 는 True |
| 문법 | `and` | 둘 다 참이어야 참 | `True and False` 는 False |
| 문법 | `or` | 하나만 참이어도 참 | `True or False` 는 True |
| 문법 | `not` | 참과 거짓을 뒤집기 | `not True` 는 False |
| 문법 | `in` / `not in` | 들어 있다 / 없다 | `"서울" in ["서울", "부산"]` 은 True |
| 문법 | `is None` | 값이 비어 있는지 | `None is None` 은 True |

표의 예시를 직접 돌려 보면 이래요.

```python
print(5 == 5, 5 != 3, 80 >= 90, 3 < 5)
print(True and False, True or False, not True)
print("서울" in ["서울", "부산"], None is None)

# 결과
# True True False True
# False True False
# True True
```

여러 조건을 묶어 볼게요.

```python
age, city = 25, "서울"
print(age >= 20 and city == "서울")   # 둘 다 참
print(age < 20 or city == "부산")     # 둘 다 거짓
print(not age >= 20)                 # True를 뒤집음

# 결과
# True
# False
# False
```

### and / or 결과표

`and`는 "둘 다 참일 때만 참", `or`는 "하나라도 참이면 참"이에요. 경우는 딱 네 가지뿐이라 표로 외워 두면 편해요.

| A | B | A and B | A or B |
| --- | --- | --- | --- |
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

### 이럴 때 써요

- "영업부이면서 매출 100 이상": `dept == "영업" and sales >= 100`
- "VIP이거나 신규 고객": `grade == "VIP" or is_new`
- "아직 안 낸 사람": `name not in submitted_list`
- "금액 칸이 비어 있는지": `amount is None`

```python
dept, sales = "영업", 150
grade, is_new = "일반", True
name, submitted_list = "박민수", ["김철수", "이영희"]
amount = None

print(dept == "영업" and sales >= 100)
print(grade == "VIP" or is_new)
print(name not in submitted_list)
print(amount is None)

# 결과
# True
# True
# True
# True
```

### 조심

`=` 하나는 "넣어라"(대입)이고, `==` 두 개는 "같니?"(비교)예요. 조건에 `=` 하나를 쓰면 에러가 나요.

```python
# 실행 안 함
age = 20
if age = 20:
    print("스무 살")
# SyntaxError  (조건 자리에 = 하나를 써서 문법 에러. if age == 20: 으로 고쳐야 해요)
```

## 3. 조건문 if / elif / else

### 조건에 따라 갈림길 만들기

조건문은 조건이 참인지 거짓인지에 따라 실행할 코드를 고르는 문법이에요. 엑셀의 IF 함수와 같은 역할이에요.

길을 가다 갈림길을 만난다고 생각해 보세요. 첫 번째 표지판부터 차례로 읽다가, 맞는 표지판을 만나면 그 길로 가고 나머지 표지판은 보지 않아요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `if 조건:` | 조건이 참이면 실행 |
| 문법 | `elif 조건:` | 위 조건이 거짓이고 이 조건이 참이면 실행 (여러 개 써도 돼요) |
| 문법 | `else:` | 위 조건이 모두 거짓이면 실행 |

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:     # 위 조건이 거짓일 때만 검사
    grade = "B"
elif score >= 70:
    grade = "C"
else:                 # 모든 조건이 거짓일 때
    grade = "F"
print(grade)

# 결과
# B
```

85는 90 이상이 아니라서 첫 줄을 지나치고, 80 이상에서 걸려 "B"가 돼요. 70 이상도 참이지만, 이미 하나가 걸렸으니 더는 검사하지 않아요.

`else`는 꼭 써야 하는 게 아니에요. `if` 하나만 써도 되고, 조건 안에 조건을 또 넣을 수도 있어요(중첩).

```python
# if 하나만 (else 생략)
amount = None
if amount is None:
    print("금액이 비어 있습니다")

# 조건 안에 조건 (중첩)
dept, sales = "영업", 150
if dept == "영업":
    if sales >= 100:
        print("영업부 목표 달성")

# 결과
# 금액이 비어 있습니다
# 영업부 목표 달성
```

### if 여러 개 vs if-elif

`if`를 여러 개 나란히 쓰는 것과 `if`, `elif`로 잇는 것은 결과가 달라요.

| | `if` / `if` / `if` | `if` / `elif` / `elif` |
| --- | --- | --- |
| 검사 방식 | 모든 조건을 하나하나 다 검사 | 처음 맞는 하나만 실행하고 끝 |
| 언제 쓰나 | 여러 조건에 동시에 해당될 수 있을 때 | 하나만 골라야 할 때 (등급, 분류) |

같은 85점으로 비교해 볼게요.

```python
score = 85

# if 여러 개: 맞는 건 전부 실행
if score >= 90:
    print("if: 90 이상")
if score >= 80:
    print("if: 80 이상")
if score >= 70:
    print("if: 70 이상")

# if-elif: 처음 맞는 하나만
if score >= 90:
    print("elif: 90 이상")
elif score >= 80:
    print("elif: 80 이상")
elif score >= 70:
    print("elif: 70 이상")

# 결과
# if: 80 이상
# if: 70 이상
# elif: 80 이상
```

### 이럴 때 써요

- 금액에 따라 등급 매기기 (대형 / 중형 / 소형)
- 빈 칸이면 건너뛰기, 마감일이 지났으면 "지연" 표시하기
- 위험군 나누기: 출석률이 50 미만이면 "P0", 70 미만이면 "P1", 나머지는 "안정"
- STEP 3 챗봇에서 "종료"를 입력하면 대화 끝내기

```python
attendance = 62
if attendance < 50:
    level = "P0"
elif attendance < 70:
    level = "P1"
else:
    level = "안정"
print(level)

# 결과
# P1
```

### 조심

- 조건 끝에는 콜론(`:`)을 붙이고, 실행할 코드는 들여쓰기(스페이스 4칸)를 해야 해요. 둘 중 하나라도 빠지면 에러예요.
- 위에서부터 차례로 검사하고, 처음 맞는 하나만 실행해요. 그래서 "90 이상", "80 이상"처럼 범위가 겹치는 기준은 큰 기준부터 써야 해요. 작은 기준을 먼저 쓰면 거기서 다 걸려 버려요(퀴즈 2번).

## 4. 반복문 for

### 정해진 묶음을 하나씩

for는 리스트, 딕셔너리, 숫자 범위 같은 묶음에서 값을 하나씩 꺼내 같은 코드를 되풀이해요. 반복할 대상이 미리 정해져 있을 때 써요.

엑셀에서 맨 위 칸에 수식을 하나 쓰고 아래로 쭉 끌어 채우는 것과 같아요. 수식은 하나인데, 행마다 한 번씩 적용되죠.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `for 변수 in 묶음:` | 하나씩 꺼내 반복 |
| 함수 | `range(끝)` / `range(시작, 끝)` | 숫자 범위 만들기 (끝 숫자는 안 들어가요) |
| 함수 | `enumerate(묶음, start=1)` | 번호와 값을 같이 꺼내기 |

```python
prices = [1000, 2500, 800]
total = 0
for p in prices:      # p에 1000, 2500, 800이 차례로 들어감
    total += p
print(total)

# 결과
# 4300
```

`range`와 `enumerate`도 써 볼게요.

```python
for i in range(3):              # 0, 1, 2
    print(i)

for i in range(1, 4):           # 1, 2, 3 (끝 숫자 4는 안 들어감)
    print(f"{i}번째 반복")

names = ["A", "B", "C"]
for idx, name in enumerate(names, start=1):
    print(idx, name)

# 결과
# 0
# 1
# 2
# 1번째 반복
# 2번째 반복
# 3번째 반복
# 1 A
# 2 B
# 3 C
```

for 안에 if를 넣으면 조건에 맞는 것만 골라 담을 수 있어요.

```python
scores = [55, 80, 92, 67]
passed = []
for s in scores:
    if s >= 70:
        passed.append(s)
print(passed)

# 결과
# [80, 92]
```

### for에서 자주 쓰는 패턴 3가지

for문은 거의 이 세 가지 모양 중 하나로 써요.

| 패턴 | 모양 | 하는 일 |
| --- | --- | --- |
| 누적 | `total += 값` | 합계 구하기 |
| 골라 담기 | `if 조건: 새리스트.append(값)` | 필터 |
| 세기 | `count += 1` 또는 `d[k] = d.get(k, 0) + 1` | 개수 세기 |

위에서 누적(4300)과 골라 담기(`[80, 92]`)는 해 봤어요. 세기도 해 볼게요.

```python
scores = [55, 80, 92, 67]
count = 0
for s in scores:
    if s >= 70:
        count += 1
print(count)

# 결과
# 2
```

### 이럴 때 써요

- 엑셀의 모든 행을 한 줄씩 처리할 때 (STEP 4의 핵심이에요)
- 명단 전체에 안내 문구를 만들 때
- 합계나 개수를 누적할 때, 조건에 맞는 것만 골라 담을 때

```python
names = ["김철수", "이영희"]
for n in names:
    print(f"{n}님 안녕하세요")

# 결과
# 김철수님 안녕하세요
# 이영희님 안녕하세요
```

### 조심

for 줄 끝의 콜론(`:`)과 들여쓰기를 잊지 마세요. 들여쓰기가 안 된 줄은 반복에 들어가지 않아요. 반복이 다 끝난 뒤에 딱 한 번만 실행돼요.

```python
for n in [1, 2, 3]:
    print("반복 안:", n)
print("반복 끝난 뒤 한 번")

# 결과
# 반복 안: 1
# 반복 안: 2
# 반복 안: 3
# 반복 끝난 뒤 한 번
```

## 5. 반복문 while과 break, continue

### 언제 끝날지 모를 때

while은 조건이 참인 동안 계속 반복해요. 몇 번 돌지 미리 모를 때 써요.

for가 "명단 끝까지 한 명씩"이라면, while은 "손님이 그만하자고 할 때까지 계속"이에요. 그리고 break와 continue는 반복 도중에 흐름을 바꾸는 장치예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `while 조건:` | 조건이 참인 동안 반복 |
| 문법 | `break` | 반복을 완전히 끝냄 |
| 문법 | `continue` | 이번 차례만 건너뛰고 다음 반복으로 |

```python
count = 3
while count > 0:
    print(count)
    count -= 1        # 이 줄을 빼먹으면 영원히 끝나지 않아요
print("발사!")

# 결과
# 3
# 2
# 1
# 발사!
```

break와 continue를 같이 써 볼게요. 음수는 건너뛰고, 0을 만나면 멈춰요.

```python
for n in [1, 2, -1, 4, 0, 5]:
    if n < 0:
        continue      # 음수는 건너뛰기
    if n == 0:
        break         # 0을 만나면 반복 끝
    print(n)

# 결과
# 1
# 2
# 4
```

-1은 건너뛰었고, 0에서 반복이 끝나서 뒤의 5는 아예 보지도 않았어요.

이번엔 챗봇처럼 "종료"를 입력할 때까지 계속 받아 볼게요. 아래 결과는 "운영 시간이 어떻게 되나요?", "환불 되나요?", "종료"를 차례로 입력했을 때예요.

```python
while True:
    msg = input("입력: ")
    if msg == "종료":
        break
    print(f"받은 내용: {msg}")

# 결과 (입력한 내용에 따라 달라요)
# 입력: 운영 시간이 어떻게 되나요?
# 받은 내용: 운영 시간이 어떻게 되나요?
# 입력: 환불 되나요?
# 받은 내용: 환불 되나요?
# 입력: 종료
```

`while True:`는 "조건이 늘 참", 즉 끝없이 돌라는 뜻이에요. 그래서 반드시 안에서 `break`로 빠져나갈 길을 만들어 둬야 해요.

### for vs while

| | for | while |
| --- | --- | --- |
| 언제 쓰나 | 반복할 대상이 정해져 있을 때 | 언제 끝날지 모를 때 |
| 끝나는 때 | 대상을 다 돌면 저절로 끝 | 조건이 거짓이 되거나 break를 만날 때 |
| 예시 | 엑셀 100행 처리 | "종료"를 입력할 때까지 챗봇 대화 |

### break vs continue

| | break | continue |
| --- | --- | --- |
| 하는 일 | 반복 전체를 끝냄 | 이번 것만 건너뜀 |
| 활용 | 원하는 값을 찾으면 멈추기 | 잘못된 행 건너뛰기 |

### 이럴 때 써요

- 챗봇: `while True:`로 질문을 계속 받다가 "종료"가 오면 break (STEP 3)
- 데이터 정리: 빈 칸이나 잘못된 행은 continue로 건너뛰기 (STEP 4와 5에서는 Pandas의 `dropna()`가 같은 일을 해요)
- 검색: 명단에서 찾는 이름을 만나면 break로 멈추기

```python
members = ["김철수", "이영희", "박민수", "최지우"]
for m in members:
    if m == "박민수":
        print("찾았다:", m)
        break
    print("확인 중:", m)

# 결과
# 확인 중: 김철수
# 확인 중: 이영희
# 찾았다: 박민수
```

### 조심

`while True:`는 break가 없으면 영원히 끝나지 않아요. 이렇게 멈추지 않을 때는 터미널에서 `Ctrl + C`를 누르면 강제로 멈출 수 있어요(Colab에서는 코드 칸 왼쪽의 정지 버튼).

## 6. 함수 def

### 자주 쓰는 코드에 이름 붙이기

함수는 자주 쓰는 코드를 한 덩어리로 묶고 이름을 붙인 거예요. 재료(매개변수)를 넣으면 정해진 일을 하고, 결과를 `return`으로 돌려줘요.

사실 지금까지 쓴 `print()`, `len()`도 누군가 미리 만들어 둔 함수예요. `def`를 쓰면 나만의 함수를 만들 수 있어요. 엑셀로 치면 자주 쓰는 긴 수식에 내가 이름을 붙여 두는 거예요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `def 이름(매개변수):` | 함수 만들기 (정의) |
| 문법 | `return 값` | 결과 돌려주기 (여기서 함수가 끝나요) |
| 문법 | `이름(값)` | 함수 쓰기 (호출) |
| 문법 | `def 이름(a, b=기본값):` | 값을 안 넣으면 기본값을 써요 |

```python
def add_tax(price, rate=0.1):      # price: 매개변수, rate: 기본값 0.1
    return price * (1 + rate)

print(add_tax(1000))         # rate를 생략해서 0.1
print(add_tax(1000, 0.05))   # rate = 0.05

total = add_tax(2000)        # return 값은 변수에 담을 수 있어요
print(total)

# 결과
# 1100.0
# 1050.0
# 2200.0
```

함수 안에 조건문을 넣고, 반복문으로 여러 번 불러 볼게요.

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    return "C"

for s in [95, 82, 60]:
    print(s, get_grade(s))

# 결과
# 95 A
# 82 B
# 60 C
```

### 함수의 구조

함수는 네 부분으로 이뤄져요. 정의하고, 할 일을 적고, 돌려줄 값을 정하고, 마지막에 불러서 써요.

```python
def 함수이름(재료1, 재료2):     # ① 정의: 이름과 재료 정하기
    결과 = 재료1 + 재료2        # ② 하는 일 (들여쓰기)
    return 결과                # ③ 돌려줄 값

값 = 함수이름(10, 20)          # ④ 호출: 재료를 넣어 사용
print(값)

# 결과
# 30
```

이름을 한글로 써도 파이썬은 잘 돌아가요. 여기서는 구조를 보이려고 한글로 썼고, 실제로는 `add_tax`처럼 영어로 짓는 게 보통이에요.

### print vs return

가장 많이 헷갈리는 부분이에요. `print`는 화면에 보여 주기만 하고 끝나요. `return`은 값을 함수 밖으로 건네줘요.

| | print | return |
| --- | --- | --- |
| 하는 일 | 화면에 보여 주기만 | 값을 돌려줌 |
| 변수에 담기 | 안 돼요 (None이 담겨요) | 돼요 |
| 다른 계산에 쓰기 | 안 돼요 | 돼요 |

```python
def show_double(n):
    print(n * 2)       # 보여 주기만

def give_double(n):
    return n * 2       # 돌려주기

a = show_double(5)     # 이 줄에서 10이 화면에 찍힘
b = give_double(5)
print(a, b)
print(b + 1)

# 결과
# 10
# None 10
# 11
```

`a`에는 아무것도 돌려받지 못해서 `None`이 담겼어요. `b`에는 10이 담겨서 `b + 1` 계산까지 할 수 있어요.

### 이럴 때 써요

- 부가세 계산, 등급 판정처럼 여러 곳에서 되풀이되는 규칙을 묶을 때. 규칙이 바뀌면 함수 하나만 고치면 돼요.
- STEP 5에서 `df["금액"].apply(get_grade)`처럼 표 전체에 함수를 적용할 때
- 긴 코드를 `read_data()`, `clean_data()`, `save_data()`처럼 단계별로 나눠 읽기 쉽게 만들 때

### 조심

- 함수는 만들기만 해서는 실행되지 않아요. `get_grade(85)`처럼 불러야 실행돼요.
- `return`을 만나면 그 자리에서 함수가 끝나요. `return` 아래에 적은 코드는 실행되지 않아요.

```python
def check(n):
    return n * 10
    print("이 줄은 실행되지 않아요")

print(check(3))

# 결과
# 30
```

## 7. 딕셔너리 리스트 = 표

### 행을 모으면 표가 돼요

딕셔너리 하나가 표의 한 행이었죠. 그 딕셔너리들을 리스트로 모으면 표 전체가 돼요.

파이썬으로 엑셀 표를 나타내는 가장 기본적인 방법이에요. STEP 4와 5에서는 이 모양을 `pd.DataFrame()`에 넣기만 하면 바로 Pandas 표가 돼요.

```python
employees = [
    {"이름": "김철수", "부서": "영업", "매출": 300},
    {"이름": "이영희", "부서": "개발", "매출": 150},
    {"이름": "박민수", "부서": "영업", "매출": 200},
]
```

위 코드는 아래 표와 똑같아요.

| 이름 | 부서 | 매출 |
| --- | --- | --- |
| 김철수 | 영업 | 300 |
| 이영희 | 개발 | 150 |
| 박민수 | 영업 | 200 |

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `employees[0]` | 첫 번째 행 꺼내기 |
| 문법 | `employees[0]["이름"]` | 첫 번째 행의 이름 꺼내기 (결과 "김철수") |
| 함수 | `len(employees)` | 행이 몇 개인지 세기 (결과 3) |

```python
print(employees[0])
print(employees[0]["이름"])
print(len(employees))

# 결과
# {'이름': '김철수', '부서': '영업', '매출': 300}
# 김철수
# 3
```

리스트 번호로 행을 고르고, 이름표로 칸을 고르는 거예요. 엑셀로 치면 "몇 번째 행의, 어느 열"이에요.

이제 지금까지 배운 걸 다 섞어 볼게요.

```python
# 영업부만 출력 (for + if)
for e in employees:
    if e["부서"] == "영업":
        print(e["이름"], e["매출"])

# 전체 매출 합계 (for + 누적)
total = 0
for e in employees:
    total += e["매출"]
print(total)

# 부서별 매출 합계 (for + 딕셔너리 누적)
dept_total = {}
for e in employees:
    dept_total[e["부서"]] = dept_total.get(e["부서"], 0) + e["매출"]
print(dept_total)

# 결과
# 김철수 300
# 박민수 200
# 650
# {'영업': 500, '개발': 150}
```

부서별 합계에서 `get(e["부서"], 0)`이 핵심이에요. 처음 보는 부서는 0에서 시작하고, 이미 있는 부서는 지금까지의 합에 더해 줘요.

### 이럴 때 써요

- 엑셀을 읽어서 담아 두는 그릇으로 (STEP 4와 5)
- `pd.DataFrame(employees)` 한 줄로 Pandas 표로 바꿀 때 (STEP 4와 5)

```python
import pandas as pd

df = pd.DataFrame(employees)
print(df)

# 결과
#     이름  부서   매출
# 0  김철수  영업  300
# 1  이영희  개발  150
# 2  박민수  영업  200
```

### 지금까지 배운 것의 연결

> 리스트(행 모음) + 딕셔너리(한 행) + for(행 돌기) + if(조건) + 함수(규칙 묶기) = 엑셀 자동화의 기본 뼈대

STEP 4의 엑셀 자동 정리 툴도, STEP 5의 Pandas도 결국 이 조합 위에 서 있어요.


① `{'사과': 3, '배': 2, '귤': 1}`

② `{'사과': 1, '배': 1, '귤': 1}`

③ `['사과', '배', '귤']`

④ 에러 발생 (KeyError)

<details>
<summary>정답 확인</summary>

**정답: ①**

`count.get(f, 0)`은 처음 나온 과일이면 0을, 이미 센 과일이면 지금까지의 개수를 줘요. 거기에 1을 더해 다시 넣으니, 과일마다 나온 횟수가 쌓여요.

`get`에 기본값 0을 줬기 때문에 처음 보는 키에서도 KeyError가 나지 않아요. 사과 3번, 배 2번, 귤 1번이에요.

</details>

**Q4.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
total = 0
for n in [4, -1, 6, 0, 9]:
    if n < 0:
        continue
    if n == 0:
        break
    total += n
print(total)
```

① 4

② 18

③ 10

④ 19

<details>
<summary>정답 확인</summary>

**정답: ③**

4는 더하고, -1은 continue로 건너뛰고, 6은 더해요. 0을 만나면 break로 반복이 끝나서 9는 더하지 않아요.

그래서 4 + 6 = 10이에요. continue는 "이번만 건너뛰기", break는 "여기서 끝"이라는 차이를 묻는 문제예요.

</details>

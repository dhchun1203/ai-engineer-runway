## 잠깐, pandas가 뭐예요?

우리가 다룰 데이터는 대부분 CSV라는 형식이에요. 엑셀 표를 그대로 옮겨 놓은 것처럼 생겼어요. 가로줄(행)마다 웹툰 한 편, 세로줄(열)마다 제목이나 작가 같은 항목이 들어 있죠.

이런 표를 파이썬에서 다루게 해 주는 도구가 pandas예요. 파이썬 안에 엑셀을 하나 들여놓는다고 생각하면 편해요. 그리고 pandas가 다루는 표 한 장을 DataFrame이라고 불러요.

말로만 들으면 감이 안 오니, 작은 표를 직접 하나 만들어 볼게요. (진짜 데이터는 곧 불러올 거예요.) 열 이름은 실제 웹툰 데이터와 똑같이 영어로 두고, 값만 한글로 채워요.

```python
import pandas as pd  # 관례상 pd라는 짧은 별명으로 불러와요

# 웹툰 세 편을 표로 만들어 봐요
webtoons = pd.DataFrame({
    "title": ["신의 탑", "여신강림", "화산귀환"],
    "author": ["SIU", "야옹이", "비가"],
    "genre": ["판타지", "로맨스", "무협"],
    "rating": [9.7, 9.2, 9.9],
})

print(webtoons)
# 출력:
#    title author genre  rating
# 0   신의 탑    SIU    판타지     9.7
# 1   여신강림    야옹이    로맨스     9.2
# 2   화산귀환     비가     무협     9.9
```

맨 왼쪽의 0, 1, 2가 보이나요? 우리가 넣지 않았는데 생긴 이 숫자는 pandas가 자동으로 붙인 행 번호예요. 표의 몇 번째 줄인지 가리키는 이름표죠. 나중에 "3번 웹툰"처럼 특정 줄을 가리킬 때 이 번호를 써요.

열 이름은 영어(title, author, genre, rating)인데 값은 한글이죠. 진짜 데이터도 이렇게 열 이름은 영어, 내용은 한글인 경우가 많아요. 그래서 코드에서는 항상 영어 열 이름으로 값을 꺼내게 돼요.

## read_csv로 표 열기

파일은 올라왔지만, 아직 파이썬은 그 안을 들여다보지 않았어요. `pd.read_csv`로 파일을 열어 DataFrame으로 받아 와야 해요.

```python
import pandas as pd

# 따옴표 안에는 방금 올린 파일 이름을 정확히 적어요
df = pd.read_csv("naver.csv")

# head()는 위에서 다섯 줄만 미리 보여 줘요. 데이터가 잘 들어왔는지 확인하는 용도예요
print(df.head())
```

`df`는 DataFrame을 담는 흔한 이름이에요. 꼭 이 이름일 필요는 없지만, 다들 이렇게 쓰니 따라 두면 남의 코드도 읽기 편해요.

여기서부터는 진짜 데이터라, 출력 모양은 여러분이 고른 파일에 따라 달라져요. 그러니 다음 단계에서 이 파일에 어떤 열들이 있는지부터 확인하는 게 중요해요.

## 데이터 훑어보기 세 가지

데이터를 받았으면, 곧바로 검색에 뛰어들지 말고 먼저 어떤 데이터인지 파악해요. 세 가지만 보면 충분해요.

```python
# 표가 얼마나 큰지: (행 개수, 열 개수)
print(df.shape)

# 행이 몇 개인지 = 웹툰이 몇 편 들어 있는지
print(len(df))

# 어떤 항목(열)들이 있는지, 보기 편한 리스트로
print(df.columns.tolist())
```

이 중에서 열 목록을 특히 눈여겨보세요. 앞으로 코드에서 열 이름을 정확히 적어야 하는데, 그 이름을 여기서 확인하는 거예요. 서랍을 열기 전에 서랍마다 붙은 라벨을 먼저 읽어 두는 셈이죠. `.tolist()`를 붙이면 `['title', 'author', ...]`처럼 깔끔한 리스트로 보여 줘요.

네이버 웹툰 데이터라면 `title`, `author`, `genre`, `description`, `rating`, `age` 같은 열이 나와요. 여기서 확인한 그대로 적어야 파이썬이 알아들어요.

3. 답에 같이 보여 주면 좋을 정보 열은? (웹툰이라면 `rating`)

## 빈 칸(결측치)을 챗봇답게 다루기

진짜 데이터에는 빈 칸이 꼭 있어요. 줄거리가 비어 있거나, 장르가 안 적혀 있거나요. 이 빈 칸을 결측치라고 불러요.

먼저 열마다 빈 칸이 몇 개인지 세어 봐요.

```python
# 열마다 빈 칸(결측치)이 몇 개인지
print(df.isnull().sum())
```

데이터 분석에서는 빈 칸을 평균값으로 채우거나 그 줄을 지우기도 해요. 하지만 우리 챗봇은 더 간단하게 가요. 빈 칸을 만나면 "이 항목은 정보가 없어요"라고 솔직하게 말하면 되거든요. 그게 사람과 대화하는 챗봇다운 말투예요.

그래서 설계도에서 고른 특징 열의 빈 칸을 "정보없음"이라는 글자로 채워 둘게요. 그러면 검색할 때도 오류 없이 자연스럽게 넘어가요.

```python
# 설계도 2, 3번에서 고른 열들 (여러분 데이터에 맞게 바꾸세요)
search_columns = ["author", "genre", "rating", "description"]

# 빈 칸을 "정보없음"으로 채워요
for col in search_columns:
    df[col] = df[col].fillna("정보없음")

print("결측치 처리 완료!")
print(df[search_columns].isnull().sum())   # 모두 0이 나오면 성공
```

`fillna("정보없음")`은 그 열의 빈 칸(NaN)만 골라 "정보없음"으로 채운 새 열을 돌려줘요. 그걸 같은 열 이름에 다시 담아 바꿔 끼우는 거예요. 반복문으로 고른 열마다 한 번씩 해 줬어요.

## 원하는 칸 꺼내 보기 (맛보기)

데이터가 잘 들어왔는지 마지막으로 두 가지만 해 볼게요. 본격적인 검색은 2편에서 다루니, 오늘은 맛만 봅니다.

먼저 열 하나만 쏙 꺼내 보기예요.

```python
# 제목 열만 꺼내요
print(df["title"])
```

대괄호 안에 열 이름을 적으면 그 열만 골라서 보여 줘요. 표에서 세로줄 하나를 통째로 뽑아내는 거죠.

다음은 조건으로 걸러 보기예요.

```python
# 평점이 9.5 이상인 웹툰만 남겨요
print(df[df["rating"] >= 9.5])
```

`df["rating"] >= 9.5`는 각 줄마다 "이 웹툰 평점이 9.5 이상이야?"를 묻고 예/아니오로 답한 목록이에요. 그 목록을 다시 `df[...]`로 감싸면, 예라고 답한 줄만 남아요.

이 "원하는 것만 골라내기"를 제대로 다루는 게 바로 2편의 핵심이에요. 오늘은 데이터가 잘 들어왔다는 걸 확인하는 정도로 충분해요.

## 오늘 만들 조각

전체 챗봇을 세 조각으로 나눠 만들 거예요.

1. (오늘) 데이터를 파이썬 안으로 불러오기
2. (2편) 원하는 데이터만 골라내는 검색 기능 만들기
3. (3편) 검색 결과에 AI 답변을 붙여 챗봇 완성하기

오늘의 목표는 딱 하나예요. 데이터를 파이썬이 다룰 수 있는 형태로 불러와서, 몇 줄짜리인지, 어떤 항목이 들어 있는지 눈으로 확인하는 것. 검색이나 AI는 아직 신경 쓰지 않아도 돼요.

## 잠깐, pandas가 뭐예요?

우리가 다룰 데이터는 대부분 CSV라는 형식이에요. 엑셀 표를 그대로 옮겨 놓은 것처럼 생겼어요. 가로줄(행)마다 영화 한 편, 세로줄(열)마다 제목이나 연도 같은 항목이 들어 있죠.

이런 표를 파이썬에서 다루게 해 주는 도구가 pandas예요. 파이썬 안에 엑셀을 하나 들여놓는다고 생각하면 편해요. 그리고 pandas가 다루는 표 한 장을 DataFrame이라고 불러요.

말로만 들으면 감이 안 오니, 작은 표를 직접 하나 만들어 볼게요. (진짜 데이터는 곧 불러올 거예요.)

```python
import pandas as pd  # 관례상 pd라는 짧은 별명으로 불러와요

# 영화 세 편을 표로 만들어 봐요
movies = pd.DataFrame({
    "제목": ["인터스텔라", "기생충", "라라랜드"],
    "연도": [2014, 2019, 2016],
    "장르": ["SF", "드라마", "뮤지컬"],
    "평점": [8.6, 8.5, 8.0],
})

print(movies)
# 출력:
#       제목    연도   장르   평점
# 0  인터스텔라  2014   SF  8.6
# 1     기생충  2019  드라마  8.5
# 2    라라랜드  2016  뮤지컬  8.0
```

맨 왼쪽의 0, 1, 2가 보이나요? 우리가 넣지 않았는데 생긴 이 숫자는 pandas가 자동으로 붙인 행 번호예요. 표의 몇 번째 줄인지 가리키는 이름표죠. 나중에 "3번 영화"처럼 특정 줄을 가리킬 때 이 번호를 써요.

## 진짜 데이터 구하기: Kaggle에서 내려받기

이제 직접 만든 표 말고, 진짜 데이터를 구해 볼 차례예요. 그 데이터가 있는 곳이 Kaggle이에요. 전 세계 사람들이 온갖 데이터를 올려 두고 나눠 쓰는 창고 같은 곳이죠.

데이터를 고를 때 세 가지만 확인하면 돼요.

1. 내가 관심 있는 주제인가 (영화, 음악, 스포츠, 요리, 무엇이든 좋아요)
2. CSV 파일로 받을 수 있는가
3. 열이 여러 개인가 (제목만 있으면 심심해요. 연도, 평점, 장르처럼 여러 항목이 있어야 나중에 검색할 거리가 생겨요)

마음에 드는 데이터셋 페이지에서 Download 버튼을 누르면 파일이 내려와요. 압축 파일(zip)이면 풀어서 안에 든 CSV 하나를 꺼내 두세요.

우리는 이 레슨에서 영화 데이터를 골랐다고 치고 이어 갈게요. 파일 이름은 `movies.csv`라고 해 둘게요.

## read_csv로 표 열기

파일은 올라왔지만, 아직 파이썬은 그 안을 들여다보지 않았어요. `pd.read_csv`로 파일을 열어 DataFrame으로 받아 와야 해요.

```python
import pandas as pd

# 따옴표 안에는 방금 올린 파일 이름을 정확히 적어요
df = pd.read_csv("movies.csv")

# head()는 위에서 다섯 줄만 미리 보여 줘요. 데이터가 잘 들어왔는지 확인하는 용도예요
print(df.head())
```

`df`는 DataFrame을 담는 흔한 이름이에요. 꼭 이 이름일 필요는 없지만, 다들 이렇게 쓰니 따라 두면 남의 코드도 읽기 편해요.

여기서부터는 진짜 데이터라, 출력 모양은 여러분이 고른 파일에 따라 달라져요. 열 이름도 우리 예제처럼 한글이 아니라 `title`, `release_year`, `vote_average`처럼 영어인 경우가 많아요. 그러니 다음 단계에서 열 이름부터 확인하는 게 중요해요.

## 데이터 훑어보기 세 가지

데이터를 받았으면, 곧바로 검색에 뛰어들지 말고 먼저 어떤 데이터인지 파악해요. 세 가지만 보면 충분해요.

```python
# 표가 얼마나 큰지: (행 개수, 열 개수)
print(df.shape)

# 행이 몇 개인지 = 영화가 몇 편 들어 있는지
print(len(df))

# 어떤 항목(열)들이 있는지
print(df.columns)
```

이 중에서 `df.columns`를 특히 눈여겨보세요. 앞으로 코드에서 열 이름을 정확히 적어야 하는데, 그 이름을 여기서 확인하는 거예요. 서랍을 열기 전에 서랍마다 붙은 라벨을 먼저 읽어 두는 셈이죠. `평점`인지 `rating`인지 `vote_average`인지, 여기서 확인한 그대로 써야 파이썬이 알아들어요.

## 원하는 칸 꺼내 보기 (맛보기)

데이터가 잘 들어왔는지 마지막으로 두 가지만 해 볼게요. 본격적인 검색은 2편에서 다루니, 오늘은 맛만 봅니다.

먼저 열 하나만 쏙 꺼내 보기예요.

```python
# 제목 열만 꺼내요 (진짜 데이터라면 실제 열 이름으로, 예: df["title"])
print(df["제목"])
```

대괄호 안에 열 이름을 적으면 그 열만 골라서 보여 줘요. 표에서 세로줄 하나를 통째로 뽑아내는 거죠.

다음은 조건으로 걸러 보기예요.

```python
# 평점이 9.0 이상인 영화만 남겨요
print(df[df["평점"] >= 9.0])
```

`df["평점"] >= 9.0`은 각 줄마다 "이 영화 평점이 9.0 이상이야?"를 묻고 예/아니오로 답한 목록이에요. 그 목록을 다시 `df[...]`로 감싸면, 예라고 답한 줄만 남아요.

이 "원하는 것만 골라내기"를 제대로 다루는 게 바로 2편의 핵심이에요. 오늘은 데이터가 잘 들어왔다는 걸 확인하는 정도로 충분해요.

## 한 줄 정리

## 1. 라이브러리와 import

라이브러리는 다른 사람이 미리 만들어 둔 기능 묶음이에요. 파이썬 기본 기능만으로 표를 계산하거나 엑셀을 다루려면 코드가 한참 길어져요.

그래서 잘 만들어진 라이브러리를 `import`로 불러와 써요. 엑셀에 애드인을 설치하면 없던 메뉴가 생기는 것과 비슷해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `import 이름` | 라이브러리를 통째로 불러오기 |
| 문법 | `import 이름 as 별명` | 불러오면서 짧은 별명 붙이기 |
| 문법 | `from 이름 import 기능` | 필요한 기능 하나만 골라 불러오기 |

```python
import numpy as np        # 이제부터 numpy를 np라고 불러요
import pandas as pd       # 이제부터 pandas를 pd라고 불러요

print(np.array([1, 2, 3]))   # 별명.기능 모양으로 써요
# 결과: [1 2 3]
```

`from` 모양도 한번 볼게요. 파이썬에 기본으로 들어 있는 `math` 라이브러리에서 제곱근 기능 하나만 꺼내 와요.

```python
from math import sqrt     # math에서 sqrt만 가져오기

print(sqrt(16))           # 앞에 math. 을 안 붙여도 돼요
# 결과: 4.0
```

자주 쓰는 라이브러리 세 개와 관례 별명은 이래요.

| 라이브러리 | 관례 별명 | 무엇에 쓰나 | 주로 나오는 STEP |
| --- | --- | --- | --- |
| NumPy | `np` | 숫자 배열 계산 | 3 |
| Pandas | `pd` | 표(DataFrame) 다루기, 엑셀 읽고 쓰기 | 3, 5 |
| openpyxl | 별명 없음 | 엑셀 파일을 칸 단위로 다루기 | 4 |

**이럴 때 써요**

- 코드 맨 위에 필요한 import를 모아 두면, 이 코드가 어떤 도구를 쓰는지 첫눈에 보여요.
- `np`, `pd`는 전 세계가 똑같이 쓰는 별명이에요. 검색할 때도 그대로 쓰면 예제를 찾기 쉬워요.

**조심**

```python

# 설치하지 않았다면 ModuleNotFoundError: No module named 'openpyxl'
```

## 2. NumPy 배열

NumPy는 숫자 묶음(배열)을 반복문 없이 한 번에 계산하게 해 주는 도구예요. 리스트였다면 for문을 돌려야 하는 계산이 한 줄로 끝나요.

엑셀에서 맨 위 칸에 수식을 넣고 아래로 쭉 끌어 채우는 것과 같아요. 배열에 계산을 하나 걸면 모든 칸에 동시에 적용돼요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `np.array(리스트)` | 리스트로 배열 만들기 |
| 문법 | `배열 + 숫자`, `배열 * 숫자` 등 | 모든 값에 한꺼번에 계산 |
| 문법 | `배열1 + 배열2` | 같은 자리끼리 계산 |
| 메서드 | `.sum()` `.mean()` `.max()` `.min()` | 합계, 평균, 최댓값, 최솟값 |
| 문법 | `배열[배열 > 값]` | 조건에 맞는 값만 골라내기 |

```python
import numpy as np

prices = np.array([1000, 2000, 3000])

print(prices * 1.1)      # 모두 10% 올리기
# 결과: [1100. 2200. 3300.]

print(prices + 500)      # 모두 500원씩 올리기
# 결과: [1500 2500 3500]

print(prices.sum(), prices.mean(), prices.max())
# 결과: 6000 2000.0 3000

print(prices.min())
# 결과: 1000

qty = np.array([2, 1, 3])
print(prices * qty)      # 같은 자리끼리 곱하기(단가 × 수량)
# 결과: [2000 2000 9000]

print(prices[prices >= 2000])   # 2000 이상만 골라내기
# 결과: [2000 3000]
```

`prices * 1.1`처럼 소수를 곱하면 결과에 점(`1100.`)이 붙어요. 값이 실수(소수)로 바뀌었다는 표시예요.

### 리스트와 NumPy 배열, 같은 기호 다른 결과

모양은 비슷해 보여도 리스트와 배열은 계산 기호를 다르게 받아들여요. 리스트에게 `* 2`는 "두 번 이어 붙여"이고, 배열에게 `* 2`는 "칸마다 2를 곱해"예요.

| 계산 | 리스트 `[1, 2]` | NumPy `np.array([1, 2])` |
| --- | --- | --- |
| `* 2` | `[1, 2, 1, 2]` (리스트를 반복) | `[2 4]` (값마다 곱하기) |
| `+ 1` | 에러 | `[2 3]` |
| 전체 10% 할인 | for문이 필요 | `prices * 0.9` 한 줄 |
| 평균 | `sum(a) / len(a)` | `a.mean()` |

```python
a = [1, 2]
b = np.array([1, 2])

print(a * 2)
# 결과: [1, 2, 1, 2]

print(b * 2)
# 결과: [2 4]

print(b + 1)
# 결과: [2 3]

print(sum(a) / len(a), b.mean())
# 결과: 1.5 1.5
```

리스트에 `+ 1`을 하면 에러가 나요. 리스트는 리스트끼리만 이어 붙일 수 있거든요.

```python
# 실행 안 함
a = [1, 2]
print(a + 1)
# TypeError: can only concatenate list (not "int") to list
```

10% 할인을 리스트로 하면 이렇게 for문이 필요하고, 배열로 하면 한 줄이에요.

```python
price_list = [1000, 2000, 3000]
sale = []
for p in price_list:
    sale.append(p * 0.9)
print(sale)
# 결과: [900.0, 1800.0, 2700.0]

print(prices * 0.9)
# 결과: [ 900. 1800. 2700.]
```

**이럴 때 써요**

- 가격 목록 전체에 할인율이나 세율을 한 번에 적용할 때
- 단가 배열 × 수량 배열로 금액을 한꺼번에 구할 때
- 점수 목록의 평균과 최고점을 한 줄로 구할 때

**조심**

리스트와 NumPy 배열은 같은 기호를 써도 결과가 달라요. `[1, 2] * 2`와 `np.array([1, 2]) * 2`를 헷갈리지 마세요(아래 퀴즈 Q2에서 다시 나와요).

## 3. Pandas DataFrame

DataFrame은 파이썬 안에 들어 있는 엑셀 표예요. 가로줄(행, row)과 세로줄(열, column)이 있고, 열 하나만 떼어 낸 것은 Series라고 불러요.

실무에서 하는 데이터 분석은 대부분 Pandas로 해요. 용어부터 엑셀과 짝지어 볼게요.

| 용어 | 뜻 | 엑셀에서는 |
| --- | --- | --- |
| DataFrame | 표 전체 | 시트 한 장 |
| Series | 열 하나 | A열 같은 열 하나 |
| index | 행 번호(0, 1, 2부터 시작) | 왼쪽 행 번호(1, 2, 3부터 시작) |
| columns | 열 이름 | 첫 줄의 제목들 |

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 함수 | `pd.DataFrame(딕셔너리)` | 표 만들기(키는 열 이름, 값은 그 열의 데이터) |
| 메서드 | `df.head(n)` / `df.tail(n)` | 앞 n행 / 뒤 n행 미리 보기 |
| 속성 | `df.shape` | (행 수, 열 수). 괄호 없이 써요 |
| 속성 | `df.columns` | 열 이름 목록 |
| 메서드 | `df.info()` | 열마다 자료형과 빈 값 개수 요약 |
| 메서드 | `df.describe()` | 숫자 열의 개수, 평균, 최솟값, 최댓값 등 요약 |

이번 레슨 내내 쓸 작은 표를 하나 만들어요. 네 사람의 이름, 부서, 점수예요.

```python
import pandas as pd

df = pd.DataFrame({
    "이름": ["A", "B", "C", "D"],
    "부서": ["영업", "개발", "영업", "개발"],
    "점수": [70, 90, 85, 60],
})

print(df.head())
# 결과:
#   이름  부서  점수
# 0  A  영업  70
# 1  B  개발  90
# 2  C  영업  85
# 3  D  개발  60

print(df.head(2))
# 결과:
#   이름  부서  점수
# 0  A  영업  70
# 1  B  개발  90

print(df.tail(1))
# 결과:
#   이름  부서  점수
# 3  D  개발  60

print(df.shape)
# 결과: (4, 3)

print(df.columns)
# 결과: Index(['이름', '부서', '점수'], dtype='str')
```

`df.columns` 끝의 `dtype='str'`은 "열 이름이 글자"라는 뜻이에요. Pandas 버전에 따라 `dtype='object'`로 보일 수도 있는데, 같은 뜻이에요.

`info()`와 `describe()`는 표를 처음 받았을 때 건강검진처럼 돌려 보는 메서드예요.

```python
df.info()
# 결과:
# <class 'pandas.DataFrame'>
# RangeIndex: 4 entries, 0 to 3
# Data columns (total 3 columns):
#  #   Column  Non-Null Count  Dtype
# ---  ------  --------------  -----
#  0   이름      4 non-null      str
#  1   부서      4 non-null      str
#  2   점수      4 non-null      int64
# dtypes: int64(1), str(2)
# memory usage: 228.0 bytes

print(df.describe())
# 결과:
#               점수
# count   4.000000
# mean   76.250000
# std    13.768926
# min    60.000000
# 25%    67.500000
# 50%    77.500000
# 75%    86.250000
# max    90.000000
```

`info()`의 `4 non-null`은 "빈 값이 아닌 칸이 4개"라는 뜻이에요. 행이 4개니까 빈 칸이 하나도 없다는 얘기죠.

`describe()`는 숫자 열(점수)만 요약해 줘요. 평균(mean)은 76.25, 가장 낮은 점수(min)는 60, 가장 높은 점수(max)는 90이에요.

### 속성과 메서드, 괄호 하나 차이

`df.shape`에는 괄호가 없고 `df.head()`에는 괄호가 있죠. 둘 다 점(`.`) 뒤에 붙지만 성격이 달라요.

속성은 표가 이미 가지고 있는 정보를 꺼내 보는 것이고, 메서드는 표에게 무언가를 해 달라고 시키는 거예요. 엑셀로 치면 속성은 "시트 이름 보기", 메서드는 "정렬 버튼 누르기"예요.

| | 속성 | 메서드 |
| --- | --- | --- |
| 모양 | 괄호 없음 | 괄호 있음 |
| 뜻 | 정보를 꺼내 보기 | 동작을 실행하기 |
| 예시 | `df.shape`, `df.columns` | `df.head()`, `df.info()` |

**이럴 때 써요**

- 데이터를 처음 받으면 `head()`, `shape`, `info()` 순서로 어떻게 생긴 표인지부터 확인해요.
- `describe()`로 이상한 값(음수 금액, 말도 안 되게 큰 값)이 섞여 있지 않은지 빠르게 점검해요.

**조심**

속성에 괄호를 붙이면 에러가 나요. `shape`는 이미 계산된 값(튜플)이라 "실행"할 수 없거든요.

```python
# 실행 안 함
print(df.shape())
# TypeError: 'tuple' object is not callable
```

## 4. 열 고르기

표에서 필요한 열만 꺼내는 방법이에요. 엑셀에서 보고서에 쓸 열만 복사해 오는 것과 같아요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `df["열"]` | 열 하나 꺼내기(결과는 Series) |
| 문법 | `df[["열1", "열2"]]` | 여러 열 꺼내기(결과는 DataFrame). 대괄호 두 겹 |

```python
print(df["이름"])                # 이름 열 하나만
# 결과:
# 0    A
# 1    B
# 2    C
# 3    D
# Name: 이름, dtype: str

print(df[["이름", "점수"]])       # 이름, 점수 두 열로 새 표
# 결과:
#   이름  점수
# 0  A  70
# 1  B  90
# 2  C  85
# 3  D  60

print(df["점수"].mean())          # 점수 열의 평균
# 결과: 76.25

print(df["점수"].max())           # 점수 열의 최댓값
# 결과: 90
```

열 하나를 꺼내면 아래에 `Name: 이름`이 붙어 나와요. 표가 아니라 이름표 달린 열 하나(Series)라는 표시예요.

**이럴 때 써요**

- 보고서에 필요한 열만 뽑아 새 표를 만들 때
- 특정 열의 합계, 평균, 최댓값을 구할 때

**조심**

여러 열을 고를 때는 대괄호가 두 겹(`[[ ]]`)이에요. 바깥 대괄호는 "골라 줘", 안쪽 대괄호는 "열 이름 리스트"예요.

한 겹만 쓰면 Pandas는 `"이름", "점수"`를 열 이름 하나로 착각해요.

```python
# 실행 안 함
print(df["이름", "점수"])
# KeyError: ('이름', '점수')
```

## 5. 골라내기(필터)

조건에 맞는 행만 골라내요. 엑셀의 필터 버튼과 같은 일이에요.

조건을 쓸 때는 STEP 2에서 배운 비교 연산자(`==`, `>=` 등)가 그대로 쓰여요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 문법 | `df[조건]` | 조건이 참인 행만 남기기 |
| 문법 | `df[(조건1) & (조건2)]` | 둘 다 맞는 행(그리고, AND) |
| 문법 | `df[(조건1) \| (조건2)]` | 하나라도 맞는 행(또는, OR). 가운데는 세로선 기호 |
| 메서드 | `df["열"].isin([값들])` | 목록 안의 값 중 하나에 해당하는 행 |

```python
print(df[df["점수"] >= 80])                              # 점수 80 이상
# 결과:
#   이름  부서  점수
# 1  B  개발  90
# 2  C  영업  85

print(df[(df["부서"] == "영업") & (df["점수"] >= 80)])    # 영업 그리고 80 이상
# 결과:
#   이름  부서  점수
# 2  C  영업  85

print(df[(df["부서"] == "개발") | (df["점수"] >= 85)])    # 개발 또는 85 이상
# 결과:
#   이름  부서  점수
# 1  B  개발  90
# 2  C  영업  85
# 3  D  개발  60

print(df[df["이름"].isin(["A", "C"])])                    # 이름이 A 또는 C
# 결과:
#   이름  부서  점수
# 0  A  영업  70
# 2  C  영업  85
```

### 필터는 이렇게 움직여요

조건만 따로 출력해 보면 비밀이 보여요. 행마다 참(True)인지 거짓(False)인지 적힌 열이 하나 나와요.

```python
print(df["점수"] >= 80)
# 결과:
# 0    False
# 1     True
# 2     True
# 3    False
# Name: 점수, dtype: bool
```

이 True/False 열을 `df[ ]` 안에 넣으면, True인 행(1번과 2번)만 남아요. 엑셀 필터에서 체크 표시한 행만 보이는 것과 같아요.

### 파이썬 문법과 Pandas 필터는 여기가 달라요

| | 파이썬(STEP 2) | Pandas 필터 |
| --- | --- | --- |
| 그리고 | `and` | `&` |
| 또는 | `or` | `\|` (세로선 기호) |
| 괄호 | 써도 되고 안 써도 됨 | 조건마다 반드시 |

```python
# 실행 안 함
print(df[df["부서"] == "영업" and df["점수"] >= 80])
# ValueError: The truth value of a Series is ambiguous. ...
# (and는 값 하나끼리만 비교할 수 있어서, 열 전체를 받으면 헷갈려 해요)
```

**이럴 때 써요**

- 미납자만 뽑기: `df[df["납부여부"] == "N"]`
- 특정 달 데이터만 보기: `df[df["월"] == 10]`
- 위험 등급 명단 만들기: `df[df["분류"].isin(["P0", "P1"])]`

**조심**

Pandas 필터에서는 `and`, `or` 대신 `&`와 세로선 기호를 쓰고, 조건 하나하나를 괄호로 감싸야 해요(아래 퀴즈 Q3에서 다시 나와요).

## 6. 정렬과 개수 세기

순위표를 만들거나 "무엇이 몇 개인지" 셀 때 쓰는 메서드예요. 엑셀의 정렬 버튼, COUNTIF와 비슷해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.sort_values("열")` | 작은 값부터 정렬(오름차순) |
| 메서드 | `df.sort_values("열", ascending=False)` | 큰 값부터 정렬(내림차순) |
| 메서드 | `df["열"].value_counts()` | 값마다 몇 개인지 세기(많은 순) |

`ascending=False`는 메서드에 주는 옵션이에요. "오름차순(ascending)으로 하지 마"라는 뜻이라 큰 값이 위로 와요.

```python
print(df.sort_values("점수"))                    # 점수 낮은 순
# 결과:
#   이름  부서  점수
# 3  D  개발  60
# 0  A  영업  70
# 2  C  영업  85
# 1  B  개발  90

print(df.sort_values("점수", ascending=False))   # 점수 높은 순
# 결과:
#   이름  부서  점수
# 1  B  개발  90
# 2  C  영업  85
# 0  A  영업  70
# 3  D  개발  60

print(df.sort_values("점수", ascending=False).head(2))   # 상위 2명
# 결과:
#   이름  부서  점수
# 1  B  개발  90
# 2  C  영업  85

print(df["부서"].value_counts())
# 결과:
# 부서
# 영업    2
# 개발    2
# Name: count, dtype: int64
```

정렬해도 왼쪽 행 번호(index)는 원래 번호를 그대로 들고 다녀요. 그래서 B가 맨 위에 와도 번호는 1이에요.

**이럴 때 써요**

- 매출 순위표 만들기
- 상위 N명 뽑기: `sort_values(...)` 뒤에 `.head(N)` 붙이기
- 설문 응답별 인원 세기: `df["응답"].value_counts()`

**조심**

`sort_values()`는 정렬된 새 표를 돌려줄 뿐, 원본 `df`는 그대로예요. 정렬된 표를 계속 쓰려면 `df = df.sort_values(...)`처럼 다시 담아야 해요.

```python
df.sort_values("점수")    # 정렬한 결과를 아무 데도 안 담았어요
print(df)                 # 원본은 그대로
# 결과:
#   이름  부서  점수
# 0  A  영업  70
# 1  B  개발  90
# 2  C  영업  85
# 3  D  개발  60
```

## 7. 묶어서 계산하기(groupby)

같은 값끼리 한 묶음으로 모은 다음, 묶음마다 계산해요. 엑셀의 피벗 테이블과 비슷해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.groupby("기준열")["계산열"].sum()` | 그룹마다 합계 |
| 메서드 | `.mean()` / `.count()` / `.max()` / `.min()` (sum 자리에) | 그룹마다 평균 / 개수 / 최댓값 / 최솟값 |

읽는 요령이 있어요. `df.groupby("부서")["점수"].mean()`은 앞에서부터 "부서별로 묶어서, 점수 열의, 평균"이라고 읽으면 돼요.

```python
print(df.groupby("부서")["점수"].mean())
# 결과:
# 부서
# 개발    75.0
# 영업    77.5
# Name: 점수, dtype: float64

print(df.groupby("부서")["점수"].sum())
# 결과:
# 부서
# 개발    150
# 영업    155
# Name: 점수, dtype: int64

print(df.groupby("부서")["점수"].max())
# 결과:
# 부서
# 개발    90
# 영업    85
# Name: 점수, dtype: int64
```

결과는 그룹 이름의 가나다순(개발, 영업)으로 나와요.

### groupby가 일하는 순서

| 단계 | 하는 일 | 예시 |
| --- | --- | --- |
| ① 나누기 | 기준 열의 값으로 그룹을 나눠요 | 영업 그룹(A, C), 개발 그룹(B, D) |
| ② 계산하기 | 그룹마다 따로 계산해요 | 영업 70 + 85, 개발 90 + 60 |
| ③ 합치기 | 결과를 한 표로 모아요 | 영업 155, 개발 150 |

### value_counts와 groupby는 무엇이 다를까

둘 다 "부서별"로 뭔가를 보여 주지만 묻는 질문이 달라요. value_counts는 "몇 개야?"만 묻고, groupby는 "다른 열 값을 계산해 줘"라고 물어요.

| | `value_counts()` | `groupby().sum()` 등 |
| --- | --- | --- |
| 하는 일 | 몇 개인지만 셈 | 다른 열의 값을 계산 |
| 예시 | 부서별 인원 수 | 부서별 매출 합계 |

**이럴 때 써요**

- 부서별 매출 합계, 담당자별 처리 건수
- 월별 평균 점수, 기수별 참여 인원
- STEP 4와 5에서 엑셀 데이터를 부서별, 담당자별로 요약할 때

## 8. 빈 값(결측치) 처리

엑셀의 빈 칸은 Pandas로 읽으면 `NaN`(빈 값)이 돼요. 그대로 두면 합계와 평균이 엉뚱하게 나오거나 에러가 날 수 있어요.

그래서 빈 칸이 어디 몇 개 있는지 먼저 확인하고, 채울지 지울지 정해야 해요.

| 구분 | 형태 | 하는 일 |
| --- | --- | --- |
| 메서드 | `df.isnull().sum()` | 열마다 빈 값이 몇 개인지 세기 |
| 메서드 | `df.fillna(값)` | 빈 값을 정한 값으로 채우기 |
| 메서드 | `df.dropna()` | 빈 값이 하나라도 있는 행 지우기 |
| 메서드(옵션) | `df.dropna(subset=["열"])` | 특정 열이 비어 있는 행만 지우기 |

```python
df2 = pd.DataFrame({"이름": ["A", "B", "C"], "매출": [100, None, 300]})

print(df2.isnull().sum())
# 결과:
# 이름    0
# 매출    1
# dtype: int64
# (매출 열에 빈 값 1개)

print(df2.fillna(0))       # B의 매출을 0으로 채우기
# 결과:
#   이름     매출
# 0  A  100.0
# 1  B    0.0
# 2  C  300.0

print(df2.dropna())        # B 행 지우기
# 결과:
#   이름     매출
# 0  A  100.0
# 2  C  300.0
```

`None`으로 비워 둔 칸이 있으면 매출 열 전체가 실수(`100.0`)로 바뀌어요. NaN이 실수 자리에만 들어갈 수 있어서 그래요.

"평균이 틀어진다"는 게 무슨 뜻인지도 볼게요. Pandas는 빈 칸을 아예 빼고 계산해서, 0으로 채운 뒤의 평균과 값이 달라져요.

```python
print(df2["매출"].mean())             # 빈 칸을 빼고 A, C 둘의 평균
# 결과: 200.0

print(df2.fillna(0)["매출"].mean())   # B를 0으로 보고 셋의 평균
# 결과: 133.33333333333334
```

어느 쪽이 맞는지는 상황이 정해요. "B는 실적이 0"이 사실이면 아래 값이 맞고, "B는 아직 집계가 안 됐다"면 위 값이 맞아요.

### fillna와 dropna, 언제 무엇을 쓸까

| 상황 | 고를 것 |
| --- | --- |
| 빈 칸을 0으로 봐도 되는 경우(실적 없음, 미응답은 0점 처리) | `fillna(0)` |
| 빈 칸이 있으면 그 행을 쓸 수 없는 경우(이름이나 금액이 빠짐) | `dropna()` |

빈 칸이 여러 열에 흩어진 설문 표로 `fillna("미응답")`과 `subset` 옵션까지 해 볼게요.

```python
survey = pd.DataFrame({
    "이름": ["A", "B", "C", "D"],
    "응답": ["만족", None, "보통", None],
    "점수": [5, 4, None, 3],
})

print(survey.isnull().sum())
# 결과:
# 이름    0
# 응답    2
# 점수    1
# dtype: int64

print(survey["응답"].fillna("미응답"))   # 응답 열의 빈 칸만 글자로 채우기
# 결과:
# 0     만족
# 1    미응답
# 2     보통
# 3    미응답
# Name: 응답, dtype: str

print(survey.dropna())                    # 어디든 비면 지우기: A만 남아요
# 결과:
#   이름  응답   점수
# 0  A  만족  5.0

print(survey.dropna(subset=["응답"]))     # 응답이 빈 행만 지우기: A, C가 남아요
# 결과:
#   이름  응답   점수
# 0  A  만족  5.0
# 2  C  보통  NaN
```

`dropna()`는 점수만 빈 C까지 지워 버려요. 응답만 꼭 있어야 한다면 `subset=["응답"]`으로 기준 열을 콕 집어 주세요.

**이럴 때 써요**

- 데이터를 받으면 `isnull().sum()`으로 빈 칸부터 점검해요.
- 설문 미응답을 글자로 채우기: `df["응답"].fillna("미응답")`

**조심**

`fillna()`와 `dropna()`도 `sort_values()`처럼 새 표를 돌려줄 뿐 원본은 그대로예요. 결과를 계속 쓰려면 `df2 = df2.fillna(0)`처럼 다시 담아 주세요.

## 9. 미니 챗봇의 원리

미니 챗봇은 "질문 받기, 답 찾기, 답 보여 주기"를 사용자가 "종료"라고 할 때까지 되풀이하는 프로그램이에요. 새로운 문법은 하나도 없어요.

STEP 1과 2에서 배운 딕셔너리, while, if, in, input을 레고처럼 조립한 결과물이에요.

| 쓰인 개념 | 배운 곳 | 챗봇에서 맡은 일 |
| --- | --- | --- |
| 딕셔너리 | STEP 2 | 키워드와 답변을 짝지어 저장 |
| `input()` | STEP 1 | 사용자 질문 받기 |
| `while True` + `break` | STEP 2 | "종료" 전까지 대화를 계속 이어 가기 |
| `for` + `in` | STEP 2 | 질문 속에 키워드가 들어 있는지 찾기 |
| `if` | STEP 2 | 종료인지, 키워드가 맞는지 판단 |

```python
qa = {
    "시간": "평일 9시~18시입니다.",
    "위치": "서울 강남구입니다.",
    "주차": "건물 지하 주차장을 이용하세요.",
}

while True:
    q = input("질문 (종료하려면 '종료'): ")
    if q == "종료":
        print("이용해 주셔서 감사합니다.")
        break

    answer = "잘 모르겠어요. 다시 질문해 주세요."   # 기본 답변
    for keyword in qa:
        if keyword in q:            # 질문 속에 키워드가 들어 있으면
            answer = qa[keyword]
    print(answer)
```

질문을 세 번 넣어 본 실행 예시예요.

```text
질문 (종료하려면 '종료'): 운영 시간이 어떻게 되나요?
평일 9시~18시입니다.
질문 (종료하려면 '종료'): 환불 되나요?
잘 모르겠어요. 다시 질문해 주세요.
질문 (종료하려면 '종료'): 종료
이용해 주셔서 감사합니다.
```

첫 질문에는 "시간"이라는 키워드가 들어 있어서 답을 찾았어요. 두 번째 질문에는 어떤 키워드도 없어서 기본 답변이 그대로 나갔고요.

### 챗봇이 도는 순서

1. 질문을 입력받아요.
2. "종료"면 인사하고 끝내요(`break`).
3. 답변을 일단 "잘 모르겠어요"로 정해 둬요.
4. 키워드를 하나씩 확인해서, 질문 속에 있으면 그 답변으로 바꿔요.
5. 답변을 출력하고 1번으로 돌아가요.

**이럴 때 써요**

- 자주 받는 질문(FAQ)에 자동으로 답할 때
- 답변을 늘리고 싶으면 `qa`에 한 줄만 더하면 돼요. 데이터(답변 목록)와 로직(찾는 방법)을 따로 떼어 놓았기 때문이에요.
- 답변 목록을 엑셀로 관리하고 `pd.read_excel()`로 불러와 딕셔너리로 바꾸면, 코드는 손대지 않고 엑셀만 고쳐서 답변을 바꿀 수 있어요.

**조심**

`q == "시간"`처럼 `==`로 비교하면 질문이 딱 "시간" 두 글자일 때만 답해요. 질문 안에 들어 있는지를 보려면 `in`을 써야 해요.

## 확인 퀴즈

공식 퀴즈와 같은 개념을 숫자와 상황만 바꿔서 물어볼게요. 먼저 머릿속으로 답을 고르고, 그다음 정답을 열어 보세요.

**Q1.** 아래 표 `q`에서 지점별 판매량 합계를 구하는 코드는 무엇일까요?

| 지점 | 판매량 |
| --- | --- |
| 강남 | 30 |
| 홍대 | 20 |
| 강남 | 15 |

① `q["지점"].value_counts()`

② `q.groupby("지점")["판매량"].sum()`

③ `q.sort_values("지점")["판매량"].sum()`

④ `q[q["지점"] == "강남"]`

<details>
<summary>정답 확인</summary>

정답은 ② 예요. "지점별로 묶어서, 판매량 열의, 합계"를 그대로 코드로 옮긴 모양이에요. 결과는 강남 45, 홍대 20이에요.

①은 지점마다 몇 줄인지만 세서 강남 2, 홍대 1이 나와요. ③은 정렬만 하고 전체를 더해 65 하나가 나오고, ④는 강남 행만 골라낼 뿐 더하지 않아요.

```python
q = pd.DataFrame({"지점": ["강남", "홍대", "강남"], "판매량": [30, 20, 15]})
print(q.groupby("지점")["판매량"].sum())
# 결과:
# 지점
# 강남    45
# 홍대    20
# Name: 판매량, dtype: int64
```

</details>

**Q2.** 다음 코드를 실행하면 무엇이 출력될까요?

```python
import numpy as np

a = [5, 6]
b = np.array([5, 6])
print(a * 2)
print(b * 2)
```

① `[10, 12]` / `[10 12]`

② `[10, 12]` / `[5 6 5 6]`

③ 에러가 난다

④ `[5, 6, 5, 6]` / `[10 12]`

<details>
<summary>정답 확인</summary>

정답은 ④ 예요. 리스트에 `* 2`를 하면 리스트를 두 번 이어 붙여서 `[5, 6, 5, 6]`이 돼요.

NumPy 배열에 `* 2`를 하면 칸마다 2를 곱해서 `[10 12]`가 돼요. 배열은 쉼표 없이 출력된다는 것도 눈여겨보세요.

</details>

**Q3.** 회원 표 `m`에서 지역이 "서울"이면서 나이가 30 이상인 행만 골라내는 올바른 코드는 무엇일까요?

① `m[(m["지역"] == "서울") | (m["나이"] >= 30)]`

② `m[m["지역"] == "서울" and m["나이"] >= 30]`

③ `m[(m["지역"] == "서울") & (m["나이"] >= 30)]`

④ `m["지역" == "서울"]`

<details>
<summary>정답 확인</summary>

정답은 ③ 예요. "그리고"는 `&`로 쓰고, 조건마다 괄호로 감싸야 해요.

①은 세로선 기호(또는)라서 서울이 아니어도 30 이상이면 남아요. ②는 `and`를 써서 ValueError가 나고, ④는 열을 고르는 모양부터 잘못됐어요.

```python
m = pd.DataFrame({
    "이름": ["가", "나", "다"],
    "지역": ["서울", "부산", "서울"],
    "나이": [35, 40, 25],
})
print(m[(m["지역"] == "서울") & (m["나이"] >= 30)])
# 결과:
#   이름  지역  나이
# 0  가  서울  35
```

</details>

**Q4.** 앞에서 만든 `df`에 대해 아래 네 줄을 실행했을 때, 에러가 나는 것은 무엇일까요?

① `df.shape()`

② `df.shape`

③ `df.head()`

④ `df.columns`

<details>
<summary>정답 확인</summary>

정답은 ① 이에요. `shape`는 속성이라 괄호 없이 써야 해요. 괄호를 붙이면 TypeError가 나요.

`head()`는 메서드라 괄호가 필요하고, `columns`는 속성이라 괄호가 없어요. "정보 꺼내기는 괄호 없음, 동작 실행은 괄호 있음"으로 기억해 두세요.

</details>

## STEP 3 한 장 요약

| 개념 | 한 줄로 | 구분 |
| --- | --- | --- |
| `import 이름 as 별명` | 라이브러리를 짧은 이름으로 불러오기 | 문법 |
| `from 이름 import 기능` | 필요한 기능만 골라 불러오기 | 문법 |
| `np.array(리스트)` | 한 번에 계산되는 숫자 배열 만들기 | 함수 |
| `배열 * 숫자`, `배열1 * 배열2` | 모든 칸, 같은 자리끼리 한꺼번에 계산 | 문법 |
| `배열[배열 > 값]` | 조건에 맞는 값만 골라내기 | 문법 |
| `pd.DataFrame(딕셔너리)` | 파이썬 속 엑셀 표 만들기 | 함수 |
| `df.head()`, `df.info()`, `df.describe()` | 표 미리 보기와 건강검진 | 메서드 |
| `df.shape`, `df.columns` | 표 크기와 열 이름 꺼내 보기(괄호 없음) | 속성 |
| `df["열"]`, `df[["열1", "열2"]]` | 열 하나, 여러 열 꺼내기 | 문법 |
| `df[(조건1) & (조건2)]` | 조건에 맞는 행만 남기기 | 문법 |
| `df["열"].isin([값들])` | 목록 중 하나에 해당하는 행 | 메서드 |
| `df.sort_values("열", ascending=False)` | 큰 값부터 정렬 | 메서드(옵션) |
| `df["열"].value_counts()` | 값마다 몇 개인지 세기 | 메서드 |
| `df.groupby("기준")["계산"].sum()` | 묶어서 합계(피벗 테이블) | 메서드 |
| `df.isnull().sum()` | 열마다 빈 칸 개수 | 메서드 |
| `df.fillna(값)`, `df.dropna()` | 빈 칸 채우기, 빈 행 지우기 | 메서드 |
| 미니 챗봇 | 딕셔너리, while, if, in, input의 조립 | 문법 종합 |

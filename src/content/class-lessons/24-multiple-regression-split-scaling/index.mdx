## 2. 다중 선형회귀: 특징이 셋이면 가중치도 셋, 예측은 곱해서 더한 것

공부 시간, 수면 시간, 문제 풀이 개수 세 가지로 점수를 예측해요. 입력 X가 열 세 개짜리 표가 됐을 뿐, 학습 코드는 어제와 같아요.

```python
features = ["study_hours", "sleep_hours", "practice_count"]

# 입력 (10, 3), 정답 (10,)
X = df[features]
y = df["score"]

model = LinearRegression()
model.fit(X, y)

# 가중치 [5.80 2.68 0.63], 절편 17.66
print(model.coef_)
print(model.intercept_)
```

### 데이터와 입력, 정답

어제 7절과 같은 학생 10명이에요.

```python
df = pd.DataFrame({
    "study_hours":    [1, 2, 3, 4, 5, 2, 3, 5, 4, 1],
    "sleep_hours":    [6, 8, 5, 7, 8, 5, 8, 6, 6, 8],
    "practice_count": [10, 15, 20, 25, 30, 12, 28, 22, 32, 8],
    "score":          [47, 58, 60, 76, 87, 49, 73, 77, 79, 52]
})

# 복수개의 입력데이터
features = ["study_hours", "sleep_hours", "practice_count"]

# 입력데이터 (2차원)
X = df[features]
# 정답데이터 (1차원)
y = df["score"]

print(X.shape)
print(y.shape)
```

```text
(10, 3)
(10,)
```

열 이름 목록을 변수(`features`)에 담아 두면 `df[features]`로 고르고, 나중에 가중치 표와 표준화 표의 열 이름으로도 다시 써요.

### 학습하고 가중치 보기

```python
model = LinearRegression()

# 입력 데이터 3, 출력 데이터 1 사용해서 학습
model.fit(X, y)

print("가중치", model.coef_)
print("절편", model.intercept_)
```

```text

절편 17.660208080206644
```

어제는 특징이 하나라 `coef_`에 값이 하나였고, 오늘은 셋이에요. 순서는 `features`에 적은 순서 그대로예요. 절편 끝자리는 컴퓨터마다 조금 달라요(제 맥에서는 `17.660208080206615`).

### 가중치를 막대로

```python
coef_df = pd.DataFrame({
    "feature": features,
    "weight": model.coef_
})

plt.figure(figsize=(6, 2))

# 가로 막대: 세로축에 특징 이름
plt.barh(
    coef_df["feature"],
    coef_df["weight"],
    color="blue"

plt.show()
```

`study_hours` 막대가 가장 길고 `practice_count`가 가장 짧아요. 그렇다고 문제 풀이가 덜 중요한 것은 아니에요. 문제 수는 8\~32로 범위가 넓어서 1개당 0.63점이어도 다 합치면 크게 움직여요. 단위가 다른 가중치는 크기를 바로 비교할 수 없어요(5절에서 같은 자로 맞춰요).

### 새 학생 예측과 손 계산

공부 4시간, 수면 7시간, 문제 30개인 학생이에요.

```python
new_data = pd.DataFrame({
    "study_hours": [4],
    "sleep_hours": [7],
    "practice_count": [30]
})

prediction = model.predict(new_data)
print(f"예측 성적: {prediction[0]:.2f}점")
```

```text
예측 성적: 78.60점
```

```python
# 가중치 셋을 차례로 꺼낸다
w1, w2, w3 = model.coef_
b = model.intercept_

# 회귀식에 대입
result = w1 * 4 + w2 * 7 + w3 * 30 + b

print(f"직접 계산: {result:.4f}")
print(f"predict 계산: {prediction[0]:.4f}")
```

```text
직접 계산: 78.6021
predict 계산: 78.6021
```

`w1, w2, w3 = model.coef_`는 값이 셋인 배열을 변수 셋에 차례로 나눠 담아요. `predict`도 결국 `5.80 × 4 + 2.68 × 7 + 0.63 × 30 + 17.66`을 계산할 뿐이에요.

## 3. 학습한 데이터로 채점하면 MAE 1.17, R² 0.99로 후하게 나온다

10명 모두에게 예측값과 오차를 붙여 보면 가장 크게 틀린 학생도 2.2점 차이예요. 하지만 모델이 이미 본 데이터로 채점한 거라 실력보다 좋게 나와요.

```python
y_pred = model.predict(X)

# 원본을 건드리지 않게 복사본에
result_df = df.copy()

# 없는 열 이름에 넣으면 새 열이 생긴다
result_df["예측값"] = y_pred
result_df["예측오차"] = y - y_pred

# MAE 1.1739, MSE 1.8252, R2 0.9900
mae = mean_absolute_error(y, y_pred)
```

> **따라 하기:** 실습 노트북 3절을 실행해요. 0번 학생이 `47  45.87  1.13`으로 끝나는 10행 표와 `MAE: 1.1739`, `MSE: 1.8252`, `R2 : 0.9900`이 나오면 맞아요.

## 4. 데이터 나누기: 7명으로 배우고 처음 보는 3명으로 채점하면 MAE 3.09

시험 문제를 미리 보고 치면 실력을 알 수 없어요. `train_test_split`으로 30%(3명)를 떼어 두고, 남은 7명으로만 학습한 뒤 떼어 둔 3명으로 채점해요.

```python
from sklearn.model_selection import train_test_split

# 돌려받는 순서: X 학습, X 시험, y 학습, y 시험
X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)

test_model = LinearRegression()
test_model.fit(X_train, y_train)
test_pred = test_model.predict(X_test)

# MAE 3.0870, MSE 10.6380, R2 0.9327
```

### 나누기

```python
# 학습 데이터와 테스트 데이터 분리
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)

print("X_train", X_train.shape)
print("X_test", X_test.shape)
print("y_train", y_train.shape)
print("y_test", y_test.shape)
```

```text
X_train (7, 3)
X_test (3, 3)
y_train (7,)
y_test (3,)
```

| 설정 | 뜻 |
| --- | --- |
| `test_size=0.3` | 30%를 시험용으로 뗀다. 10명이면 3명 |
| `random_state=42` | 섞는 순서를 고정한다. 누가 돌려도 같은 3명이 뽑힌다 |

`train_test_split`은 섞은 뒤 나눠서, 시험용이 앞쪽 3명이 아니라 행 8, 1, 5(9번째, 2번째, 6번째 학생)예요. X와 y는 같은 학생끼리 짝이 맞게 나뉘어요.

### 학습용으로 배우고 시험용으로 채점

```python
test_model = LinearRegression()
# 70% 데이터로 학습
test_model.fit(X_train, y_train)
# 학습하지 않은 데이터로 결과 예측
test_pred = test_model.predict(X_test)

print(f"MAE: {mean_absolute_error(y_test, test_pred):.4f}")
print(f"MSE: {mean_squared_error(y_test, test_pred):.4f}")
print(f"R2: {r2_score(y_test, test_pred):.4f}")
```

```text
MAE: 3.0870
MSE: 10.6380
R2: 0.9327
```

## 5. 표준화: 단위가 다른 특징을 평균 0, 표준편차 1로 맞춘다

공부 시간은 1\~5, 수면 시간은 5\~8, 문제 풀이는 8\~32에 있어요. 크기가 이렇게 다르면 경사하강법이 한 걸음을 정하기 어려워요. **표준화**(`StandardScaler`)는 특징마다 `(값 - 평균) ÷ 표준편차`로 바꿔 모두 평균 0, 표준편차 1에 맞춰요.

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

# 학습용으로 평균, 표준편차를 재고(fit) 바로 바꾼다(transform)
X_train_scaled = scaler.fit_transform(X_train)

# 시험용은 학습용 기준으로 바꾸기만 한다
X_test_scaled = scaler.transform(X_test)
```

### 500 epoch 기록

```python
sgd = SGDRegressor(
    loss="squared_error",       # MSE 손실함수
    learning_rate="constant",   # 일정하게 학습
    eta0=0.01,                  # 초기 학습률
    random_state=42             # 난수 발생 seed
)

history = []

# 500 Epoch 학습
for epoch in range(500):
    # 1 Epoch 한번 학습
    sgd.partial_fit(X_train_scaled, y_train)
    pred = sgd.predict(X_train_scaled)

    history.append({
        "epoch": epoch + 1,
        "w1": sgd.coef_[0],
        "w2": sgd.coef_[1],
        "w3": sgd.coef_[2],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y_train, pred)
    })

history_df = pd.DataFrame(history)
history_df.tail(5).round(2)
```

## 오늘 꼭 기억할 주의점

- 특징이 여럿이면 `coef_`에 가중치가 특징 순서대로 하나씩 들어요. `predict`는 `w1 x1 + w2 x2 + w3 x3 + b`를 계산할 뿐이에요.
- 학습한 데이터로 채점하면 점수가 후해요. `train_test_split`으로 떼어 둔 처음 보는 데이터로 채점해요. 돌려받는 순서는 `X_train, X_test, y_train, y_test`예요.
- 시험용이 적으면 누가 뽑히느냐(`random_state`)에 따라 점수가 크게 흔들려요.
- 단위가 다른 가중치는 크기를 바로 비교할 수 없어요. 표준화하면 같은 자로 비교할 수 있어요.
- 표준화는 `(값 - 평균) ÷ 표준편차`예요. 학습용은 `fit_transform`, 시험용과 새 입력은 `transform`만 해요.
- 경사하강법(`SGDRegressor`)은 표준화한 데이터로 학습해요. 그대로 넣으면 가중치가 백억 단위로 튀어요.
- 흑백 사진은 칸마다 0\~1 밝기 숫자가 든 표예요. 64 × 64 사진 한 장은 숫자 4096개예요.

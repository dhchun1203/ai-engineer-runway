## 3. KNN: 가장 가까운 사진 K장에게 물어 다수결로 정한다

KNN(K-Nearest Neighbors)은 새 사진과 숫자 4096개가 가장 비슷한 사진 K장을 찾고, 그 사진들의 정답 중 가장 많은 사람으로 답해요. 229번 사진 한 장을 빼 두고, 나머지 399장으로 학습한 뒤 229번이 누구인지 물어봐요.

```python
new_index = 229
new_photo = X[new_index]

# 229번만 False, 나머지 399장은 True
known = np.arange(400) != new_index
X_known, y_known = X[known], y[known]

K = 3
model = KNeighborsClassifier(n_neighbors=K)
model.fit(X_known, y_known)

dist, idx = model.kneighbors([new_photo], n_neighbors=K)
print("가장 가까운 이웃:", y_known[idx[0]])  # [17 22 22]
print("이웃과의 거리:", dist[0].round(2))   # [6.07 6.26 6.44]
print("예측한 사람 :", model.predict([new_photo])[0])  # 22
print("실제 정답:", y[new_index])          # 22
```

> **따라 하기:** 실습 노트북 3절의 칸을 실행해요. `[17 22 22]`, `[6.07 6.26 6.44]`, 예측 `22`, 정답 `22`가 나오면 맞아요. 수업 노트북의 `K = 10`으로 바꿔 실행하면 예측이 `17`로 틀려요.

<details>
<summary>자세히 보기</summary>

### 입력과 정답

```python

# 섞이지 않은 원본(0번 10장, ..., 39번 10장)
faces = fetch_olivetti_faces(data_home="./datasets")

# 사진 한 장(64 × 64)을 한 줄로 편 데이터
X = faces.data
# 정답: 몇 번 사람인가
y = faces.target

print("X:", X.shape)
print("y:", y.shape)
```

```text
X: (400, 4096)
y: (400,)
```

KNN은 사진을 한 줄의 숫자로 받아요. 그래서 `faces.images`(400, 64, 64)가 아니라 `faces.data`(400, 4096)를 넣어요.

### 한 장 빼 두기

```python
known = np.arange(400) != new_index
print(known.sum())  # 399
```

`np.arange(400)`은 0\~399 번호, `!= 229`는 229번 자리만 False인 불리언 배열이에요. `X[known]`으로 229번을 뺀 399장이 남아요(수업 주석의 339장은 399장을 잘못 친 것이에요). 학습에 쓴 사진으로 물어보면 자기 자신이 거리 0으로 맨 앞에 나와 늘 맞히니, 처음 보는 사진처럼 한 장을 빼 두는 거예요.

### 거리는 숫자 4096개의 차이

두 사진의 거리는 같은 칸끼리 밝기 차이를 제곱해 4096칸 모두 더하고 제곱근을 씌운 값이에요(유클리드 거리). 직접 계산해도 `kneighbors`와 같아요.

```python
diff = X_known - new_photo
d = np.sqrt((diff ** 2).sum(axis=1))
print(np.sort(d)[:3].round(2))
```

```text
[6.07 6.26 6.44]
```

### kneighbors가 돌려주는 두 가지

`kneighbors`는 거리 배열 `dist`와 자리 번호 배열 `idx`를 돌려줘요. 사진을 `[new_photo]`처럼 대괄호로 감싸 "사진 한 장짜리 묶음"으로 넣어서, 결과도 한 겹 감싸여 나와요. 그래서 `dist[0]`, `idx[0]`으로 첫(유일한) 사진의 결과를 꺼내요.

`idx`는 `X_known` 안의 자리 번호예요. 229번을 뺐으니 229번 뒤의 사진은 원래 번호보다 하나씩 작아요. 그래서 정답은 `y`가 아니라 `y_known[idx[0]]`으로 찾아요.

### K에 따라 답이 바뀐다

수업 노트북은 `K = 10`인데 출력은 `[17 22 22]`였어요. 출력은 `K = 3`으로 실행한 결과이고, `K = 10`으로 다시 실행하면 이렇게 나와요.

```text
가장 가까운 이웃: [17 22 22 22 17 17  3 17 11  8]
이웃과의 거리: [6.07 6.26 6.44 6.63 6.68 6.93 7.02 7.07 7.23 7.27]
예측한 사람 : 17
실제 정답: 22
```

10장 중 17번이 4장, 22번이 3장이라 17번으로 틀려요. K를 1부터 10까지 바꿔 보면 3, 4, 5일 때만 맞혀요. 위 시뮬레이터에서 직접 눌러 볼 수 있어요.

</details>

## 5. KNN 채점: 처음 보는 100장으로 재면 정확도 87%

229번 한 장으로는 실력을 알 수 없어요. 어제 배운 `train_test_split`으로 300장을 학습용, 100장을 시험용으로 나눠 채점해요. `stratify`는 사람마다 시험용 사진이 고르게(2\~3장씩) 들어가게 해요.

```python
X_train, X_test, y_train, y_test = train_test_split(
    faces.data,
    faces.target,
    test_size=0.25,
    random_state=42,
    stratify=faces.target
)

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)

accuracy = model.score(X_test, y_test)
print(f"예측 정확도: {accuracy:.2%}")  # 87.00%
```

> **따라 하기:** 실습 노트북 5절의 칸을 실행해요. `예측 정확도: 87.00%`가 나오면 맞아요.

<details>
<summary>자세히 보기</summary>

### score는 맞힌 비율

`model.score(X_test, y_test)`는 시험용 100장을 예측해 정답과 같은 비율(정확도)을 돌려줘요. 100장 중 13장을 틀려서 0.87이에요. `:.2%`는 100을 곱해 소수 둘째 자리까지 `%`를 붙여요.

### stratify가 없으면

```python
# stratify 없이 나누면 사람마다 시험용 장수가 들쭉날쭉
X_train, X_test, y_train, y_test = train_test_split(
    faces.data,
    faces.target,
    test_size=0.25,
    random_state=42
)
```

이렇게 나누면 시험용에 7장이 들어간 사람도, 한 장도 없는 사람(16번)도 생겨요. 정확도는 83%로 나와요. 사진이 사람마다 10장뿐이라 고르게 나누는 게 중요해요.

### K를 바꿔 채점하면

같은 나눔에서 K만 바꿔 실행한 정확도예요.

| K | 정확도 |
| --- | --- |
| 1 | 95.00% |
| 3 | 92.00% |
| 5 | 87.00% |
| 7 | 79.00% |
| 10 | 74.00% |

사람마다 학습용 사진이 7\~8장뿐이라, K가 커지면 다른 사람 사진이 투표에 많이 섞여 정확도가 떨어져요. K는 정답이 정해진 값이 아니라 데이터를 보고 고르는 값이에요.

</details>

## 6. 로지스틱 회귀: 점수 대신 합격, 불합격을 맞힌다

어제의 학생 10명 데이터에서 정답을 점수가 아니라 "60점 이상인가"(True, False)로 바꿔요. 이렇게 답이 몇 가지 중 하나인 문제는 **분류**이고, 로지스틱 회귀는 이름에 회귀가 붙었지만 분류 모델이에요.

```python
X = df[["study_hours", "sleep_hours", "practice_count"]]
y = df["score"] >= 60

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42,
    stratify=y
)

scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

model = LogisticRegression(max_iter=1000)
model.fit(X_train_scaled, y_train)
print(model.coef_[0].round(3))  # [ 0.873 -0.37   0.877]
```

### 직선의 값을 확률로 바꾸는 시그모이드

## 7. 새 학생 합격 확률 92.58%, 시험용 3명은 모두 맞혔다

새 학생도 학습용으로 잰 자로 `transform`한 다음 넣어요. `predict`는 합격, 불합격을, `predict_proba`는 그 확률을 돌려줘요.

```python
new = pd.DataFrame([[4, 7, 30]], columns=X.columns)
new_scaled = scaler.transform(new)

predict = model.predict(new_scaled)[0]
# [0, 1]: 첫 학생의 True(합격) 확률
pass_proba = model.predict_proba(new_scaled)[0, 1]

print("예측 결과:", "합격" if predict else "불합격")
print(f"합격 확률: {pass_proba:.2%}")  # 92.58%
```

> **따라 하기:** 실습 노트북 7절의 칸을 실행해요. `합격`, `합격 확률: 92.58%`, `정확도: 100.0000%`, `[[1 0]`, ` [0 2]]`, 파란 히트맵이 나오면 맞아요. 다 됐으면 노트북 맨 아래 혼자 치기 5문제를 풀어요(정답은 그 아래에 있어요).

## 오늘 꼭 기억할 주의점

- KNN은 거리가 가장 가까운 K장의 정답으로 다수결해요. 동점이면 번호가 작은 사람을 골라요.
- K에 따라 답이 바뀌어요. 229번 사진은 K가 3\~5일 때만 맞히고, 얼굴 데이터의 정확도는 K = 1에서 95%, K = 10에서 74%예요.
- `kneighbors`의 `idx`는 학습에 넣은 배열(`X_known`) 안의 자리예요. 정답은 `y_known[idx[0]]`으로 찾아요.
- 사진을 그리려면 `reshape(64, 64)`로 다시 접어요. `plt.axis = "off"`는 함수를 덮어써요. `plt.axis("off")`로 불러요.
- `stratify`를 주면 시험용에 사람마다, 합격 불합격마다 비율이 고르게 들어가요.
- 로지스틱 회귀는 분류 모델이에요. `predict`는 답, `predict_proba`는 `classes_` 순서의 확률이고 0.5가 기준이에요.
- 혼동 행렬은 행이 실제, 열이 예측이에요. 시험용이 3명뿐이면 100%도 믿기 어려워요.

## 3. 숫자 빈칸: fillna(평균) 결과를 loc로 다시 넣는다

`fillna`는 채운 **사본**을 돌려줘요. 원본을 바꾸려면 결과를 다시 넣어야 해요.

```python
mean_age = df['age'].mean()                   # 29.699...
df.loc[:, 'age'] = df['age'].fillna(mean_age)
```

채운 뒤에 중앙값을 다시 구하면 28이 아니라 29.7이 나와요. 채운 값이 섞이기 때문이에요.

> **따라 하기:** 실습 노트북 3절의 칸을 실행해요. 채우기 전 `평균: 30`, `중앙값: 28`, 채운 뒤 5, 17, 19번 승객의 나이가 `29.699118`이면 맞아요.

<details>
<summary>자세히 보기</summary>

숫자 열은 평균(`mean()`)이나 중앙값(`median()`)으로 채워요. 먼저 두 값을 봤어요.

```python
print("평균:", round(df['age'].mean()))
print("중앙값:", round(df['age'].median()))
```

```text
평균: 30
중앙값: 28
```

`round()`가 정수로 반올림해서 평균 29.699가 30으로 찍혔어요. 수업에서는 평균 29.7로 채웠어요.

`fillna(값)`은 빈칸(NaN)만 주어진 값으로 바꾼 **새 Series**를 돌려줘요. 원본은 그대로라서, 결과를 `df.loc[:, '열'] = ...`으로 다시 넣어야 해요. 20회차에 배운 `loc` 대입이 여기서 쓰여요.

<Figure label="fillna는 채운 사본을 돌려준다">
  <Boxes

```python
# fillna : 빈칸(NaN)만 주어진 값을 새로운 값으로 채우는 메소드 df['열'] = df['열'].fillna(새로운값)
df.loc[:,'age'] = df['age'].fillna(mean_age)
df.loc[empty_age, ['sex', 'age', 'class']].head()
```

## 4. 글자 빈칸: 최빈값은 mode()[0], [0]을 빼면 조용히 안 채워진다

`mode()`는 값이 아니라 인덱스 0 하나뿐인 Series예요. 그대로 `fillna`에 넘기면 행 번호끼리 짝을 찾다가 실패해서, 오류 없이 빈칸 2개가 남아요.

<Figure label="fillna(Series)는 같은 행 번호끼리만 채운다">
  <Boxes
    row={[
      { title: "mode_town", tone: "amber", lines: ["인덱스 `0`: Southampton", "이것 하나뿐이에요"] },
      { arrow: "행 번호로 짝 찾기" },
      { title: "빈칸 있는 행", tone: "red", dashed: true, lines: ["61번: 짝 없음, `NaN` 그대로", "829번: 짝 없음, `NaN` 그대로"] },
    ]}
  />
</Figure>

```python
mode_town = df["embark_town"].mode()[0]       # 'Southampton'
df.loc[:, "embark_town"] = df['embark_town'].fillna(mode_town)
df.loc[:, 'embarked'] = df['embark_town'].str[0]   # 첫 글자 S, C, Q
```

`str[0]`은 원본이 `NaN`이면 결과도 `NaN`이라, `embark_town`을 먼저 채워야 해요.

> **따라 하기:** 실습 노트북 4절의 칸을 실행해요. 일부러 틀린 칸에서는 `NaN 2`가 그대로 남고, 고친 칸에서 `Southampton 646`, 마지막 칸에서 `embarked 0`, `embark_town 0`이면 맞아요.

### 글자 빈칸: 가장 많이 나온 값(최빈값)으로 채운다

글자에는 평균이 없어요. 그래서 가장 많이 나온 값, 최빈값(mode)으로 채워요. 먼저 `value_counts(dropna=False)`로 값마다 몇 번 나왔는지 세요. `dropna=False`를 주면 `NaN`도 따로 세어서 채우기 전후를 비교할 수 있어요.

```python

```

```text

Southampton    644
Cherbourg      168
Queenstown      77
NaN              2
Name: count, dtype: int64
```

Southampton이 644명으로 가장 많아요. `mode()`로 최빈값을 꺼내 채웠어요.

```python
mode_town = df["embark_town"].mode()
print('최빈값: ', mode_town)

```

```text

Name: embark_town, dtype: str
embark_town
Southampton    644
Cherbourg      168
Queenstown      77
NaN              2
```

오류 메시지는 없는데 `NaN`이 그대로 2개예요. Southampton도 644 그대로예요. 다음 절에서 이유를 봐요.

### 조용한 버그: mode()는 값이 아니라 Series라서 짝을 못 찾는다

`mode()`의 출력 맨 앞에 `0`이 붙어 있었어요. 최빈값이 여러 개일 수 있어서 `mode()`는 값 하나가 아니라 **인덱스 0 하나뿐인 Series**를 돌려줘요.

`fillna`에 Series를 넘기면 같은 인덱스(행 번호)끼리 짝지어 채워요. 그런데 `embark_town`이 빈 행은 61번과 829번이에요. 넘긴 Series에는 0번밖에 없으니 짝이 없어서 아무것도 안 채워져요.

값 하나를 꺼내려면 `mode()[0]`이라고 써요. 그러면 `'Southampton'`이라는 글자 하나가 모든 빈칸에 들어가요.

```python
# 고친 코드: [0]으로 값 하나를 꺼낸다
mode_town = df["embark_town"].mode()[0]          # 'Southampton'
df.loc[:, "embark_town"] = df['embark_town'].fillna(mode_town)
df['embark_town'].value_counts(dropna=False)
```

```text
embark_town
Southampton    646
Cherbourg      168
Queenstown      77
Name: count, dtype: int64
```

빈칸 2개가 Southampton이 되어 644가 646이 됐어요. `NaN` 줄이 사라졌어요.

### 다른 열에서 만들기: str[0]이 글자마다 첫 글자를 꺼낸다

`embarked`(탑승 항구 약자 S, C, Q)는 `embark_town`의 첫 글자예요. 그래서 따로 채우지 않고 `embark_town`에서 다시 만들었어요. `.str[0]`은 문자열마다 첫 글자를 꺼내요.

```python
# embarked town
df.loc[:, 'embarked'] = df['embark_town'].str[0]
df[['embarked', 'embark_town']].isnull().sum()
```

수업 노트북(`mode()` 그대로)에서는 이렇게 나왔어요.

```text

embark_town    2
dtype: int64
```

원본이 `NaN`이면 첫 글자도 `NaN`이에요. 4절의 버그로 `embark_town`이 안 채워져서 `embarked`도 2개가 남은 거예요. `mode()[0]`으로 고친 뒤에 실행하면 둘 다 0이 돼요.

## 6. 튀는 값: Q3 + 1.5 × IQR 위는 의심, 지우는 건 극단값만

<Figure label="fare의 IQR과 상한선">
  <Trail label="fare를 크기 순으로 세웠을 때" values={["Q1 7.91", "Q3 31.00", "IQR = 31.00 - 7.91 = 23.09", "상한선 = 31.00 + 1.5 × 23.09 = 65.63", "최댓값 512.33"]} />
</Figure>

```python
q1, q3 = df['fare'].quantile(0.25), df['fare'].quantile(0.75)
upper = q3 + 1.5 * (q3 - q1)            # 65.63, 넘는 승객 116명
df = df[df['fare'] < 512].copy()        # 극단값 3행만 지워 891 → 888
```

116명 중 104명이 1등석이라 다 지우지 않았어요. `df[조건]`은 새 표라서 `df =`로 다시 넣어야 지워져요.

> **따라 하기:** 실습 노트북 6절의 칸을 실행해요. `UPPER = 65.63`, `116 명`, 요금 512.3292인 3행, `891 => 888`이 나오면 맞아요.

<details>
<summary>자세히 보기</summary>

요금(`fare`)의 최댓값 512.33은 다른 값보다 너무 커요. 이런 튀는 값(이상치)을 찾는 대표 방법이 IQR이에요.

데이터를 크기 순으로 줄 세웠을 때 25% 지점이 Q1, 75% 지점이 Q3이에요. 그 사이 폭이 IQR(Q3 - Q1)이에요. Q3 + 1.5 × IQR을 넘으면 튀는 값으로 봐요.

`quantile(비율)`이 그 지점의 값을 구해요. `describe()`의 25%, 50%, 75%와 같은 값이에요.

```python
print(df['fare'].quantile([0.25,0.5,0.75]))
df['fare'].describe()[["25%", "50%", "75%"]]
```

```text
0.25     7.9104
0.50    14.4542
0.75    31.0000
Name: fare, dtype: float64
25%     7.9104
50%    14.4542
75%    31.0000
Name: fare, dtype: float64
```

```python
# IQR 계산 (Q3 - Q1)
# 이상수치 Q3 + 1.5 * IQR

q1 = df['fare'].quantile(0.25)
q3 = df['fare'].quantile(0.75)
iqr = q3 - q1
upper = q3 + 1.5 * iqr

print(f"Q1 = {q1:.2f}, Q3 = {q3:.2f} IQR = {iqr:.2f} UPPER = {upper:.2f}")
print("이상 승선요금: ",(df["fare"] > upper).sum(), "명")
```

```text
Q1 = 7.91, Q3 = 31.00 IQR = 23.09 UPPER = 65.63
이상 승선요금:  116 명
```

`(df["fare"] > upper)`는 True/False 줄이라 `.sum()`이 상한선을 넘는 승객 수가 돼요. f-string의 `:.2f`는 소수 둘째 자리까지 찍어요.

상한선을 넘는 116명을 다 지우지는 않았어요. 직접 세어 보니 116명 중 104명이 1등석이었어요. 1등석은 원래 요금이 비싸서, 다 지우면 1등석 승객 216명 중 절반 가까이가 사라져요. 그래서 최댓값 512.33만 따로 확인했어요.

## 오늘 꼭 기억할 주의점

- 처음 받은 데이터는 `shape`, `info()`, `describe()` 순서로 봐요. `info()`의 Non-Null Count가 행 수보다 작으면 빈칸이 있어요.
- `fillna`는 채운 사본을 돌려줘요. `df.loc[:, '열'] = df['열'].fillna(값)`처럼 다시 넣어야 표가 바뀌어요.
- `mode()`는 Series예요. `fillna(df['열'].mode())`는 오류 없이 빈칸을 그대로 둬요. 값 하나는 `mode()[0]`으로 꺼내요.
- category 열은 목록에 없는 값을 못 넣어요. `cat.add_categories('Unknown')`으로 목록부터 늘려요.
- `str[0]`은 원본이 `NaN`이면 결과도 `NaN`이에요. 바탕이 되는 열을 먼저 채워요.
- 채운 뒤에 평균, 중앙값 셀을 다시 실행하면 채운 값이 섞인 결과가 나와요.
- 채우기가 끝나면 `isnull().sum()`을 꼭 다시 세요. 조용한 버그는 다시 세어야 보여요.
- IQR 상한선을 넘는 값을 무조건 지우지 않아요. 극단값만 확인하고, 지운 결과는 `df = df[조건].copy()`로 다시 넣어요.
- 이름이나 승객 번호가 없는 표에서 `duplicated()`는 다른 사람도 중복으로 잡아요. 세어 보고 판단해요.
- 한글 그래프는 글꼴부터 정해요. 맥은 `AppleGothic`이에요.
- 한 값으로 빈칸을 채우면 히스토그램에 막대 하나가 솟아요. 평균 채우기는 분포를 가운데로 쏠리게 해요.

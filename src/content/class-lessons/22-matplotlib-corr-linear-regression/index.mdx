## 2. 그래프는 질문으로 고른다: 흐름은 선, 분포는 히스토그램, 관계는 산점도, 그룹은 박스플롯

캔버스(Figure)와 그래프 칸(Axes)을 만들고, `ax`에 그린 뒤 제목과 축 이름을 붙여요. `label`을 준 뒤 `legend()`를 불러야 범례가 나와요.

```python
plt.rcParams["font.family"] = "AppleGothic"   # 한글 글꼴(맥), 먼저 정한다
fig, ax = plt.subplots(figsize=(6, 3))
ax.plot(x, y, marker="o", label="매출")       # 선. scatter는 산점도, hist는 히스토그램
ax.set_title("제목"); ax.legend(); plt.show()
sns.boxplot(x="class", y="fare", data=df, ax=ax, hue="class", palette="Set2", legend=False)
```

> **따라 하기:** 실습 노트북 2절의 두 칸을 실행해요. 꺾은선 하나(6월 192가 가장 높고 범례 `매출`)와 상자 세 개(First가 가장 넓고 위로 튀는 점이 많다)가 나오면 맞아요.

### 선 그래프: My Mall 월 매출 (`02_ml.ipynb` 셀 1)

```python
import numpy as np
import pandas as pd
import seaborn as sns # 통계 그래프 라이브러리
import matplotlib.pyplot as plt

# 한글 폰트 설정
#plt.rcParams["font.family"] = "Malgun Gothic"   # Windows OS
plt.rcParams["font.family"] = "AppleGothic"     # 맥 OS

# Figure(캔버스), Axes(그래프)
fig, ax = plt.subplots(figsize=(6, 3))
# X축 데이터 (월)
months = ["1월", "2월", "3월", "4월", "5월", "6월"]
# Y축 데이터 (매출액, 만원)
sales = [120, 135, 120, 160, 170, 192]

# 선 그래프
ax.plot(months, sales, marker="o", label="매출")
ax.set_title("My Mall 월 매출")     # 그래프 제목
ax.set_xlabel("월")
ax.set_ylabel("매출(만원)")
ax.legend()                         # 범례 표시
plt.show()                          # 차트 그리기
```

`marker="o"`는 값마다 동그라미를 찍어요. `legend()`는 `label`을 준 것만 범례에 넣어요. 한글 글꼴을 정하지 않으면 제목과 축의 한글이 네모로 깨지니 첫 셀에서 정해요. 21회차에 본 것처럼 맥은 `AppleGothic`, 윈도우는 `Malgun Gothic`이에요.

## 3. 상관계수: 함께 움직이는 정도를 -1~1로, 골라낸 10채는 믿지 않는다

`corr`은 1에 가까울수록 한쪽이 커질 때 다른 쪽도 커진다는 뜻이에요. 미국 주택 300채는 면적과 가격이 0.08이었는데, 조건으로 골라낸 10채만 보면 0.89였어요. 표본이 작거나 골라낸 데이터만 보면 관계가 강해 보일 수 있어요.

```python
house["SquareFeet"].corr(house["Price"])   # 0.08 (300채)
small["SquareFeet"].corr(small["Price"])   # 0.89 (2015년 이후, 범죄율 40 미만 10채)
office["area"].corr(office["price"])       # 0.896 (오피스텔 200건, 면적으로 가격을 설명하기 좋다)
```

> **따라 하기:** 실습 노트북 3절의 세 칸을 실행해요. `datasets/usa_housing.csv`(수업 자료)가 있어야 해요. 마지막 칸에서 `0.08`과 `0.89`가 나오면 맞아요. 파일이 없으면 이 절만 건너뛰어요.

## 4. seed를 고정하면 누가 돌려도 같은 가짜 데이터가 나온다

`default_rng(40)`처럼 seed를 고정하면 난수가 항상 같아서 결과를 비교할 수 있어요. 직접 같은 코드를 돌려 보니 수업에서 저장한 `office.csv`와 값이 완전히 같았고, 특이매물 번호도 `[53 13 2 92 71]`로 같았어요.

```python
rng = np.random.default_rng(40)
area = rng.uniform(20, 85, 200)                                        # 20 이상 85 미만에서 고르게
price = (area * 450 + 5000 + rng.normal(0, 2500, 200)).round(-1)       # 평균 0 근처에 몰린 잡음, 10원 단위
special = rng.choice(200, 5, replace=False)                            # 0~199에서 중복 없이 5개
price[special] += rng.uniform(15000, 25000, 5).round(-1)               # 특이매물은 더 비싸게
```

> **따라 하기:** 실습 노트북 4절의 세 칸을 실행해요. `describe()`의 price 평균이 `29138.4`, 마지막 칸의 상관계수가 `0.896`이면 맞아요. `datasets` 폴더에 `office.csv`가 생겨요.

### 가상 오피스텔 데이터 만들기 (`02_ml.ipynb` 셀 5, 6)

```python
# [셀 5] 가상 오피스텔 데이터 만들기
# 시드(seed) : 난수 발생시 참고하는 데이터, 동일한 seed 값을 적용하는 
# 항상 동일한 난수가 발생
rng = np.random.default_rng(40)

n = 200
area = rng.uniform(20, 85, n) # 20 이상 85 미만에서 균등하게 n개 만큼 난수 발생

# 선형회귀
# y = wx + b
# w: 기울기 450
# b: 절편(편향) 5000
```

## 5. 선형회귀: 점들을 가장 잘 지나는 직선 y = wx + b를 찾는다

입력 `X`는 표(2차원)라서 `office[["area"]]`, 정답 `y`는 열 하나라서 `office["price"]`예요. 학습한 w는 439.46, b는 5926.68로 만들 때 쓴 450, 5000과 가깝지만 같지 않아요. 잡음과 특이매물 때문이에요.

```python
from sklearn.linear_model import LinearRegression

y = office["price"]                     # 대괄호 한 겹: Series (200,)
model = LinearRegression()
model.fit(X, y)                         # 학습
model.coef_[0], model.intercept_        # 439.46, 5926.68
model.predict(pd.DataFrame({"area": [33, 59]})).round(-1)   # [20430., 31850.]
```

## 6. 채점: MAE는 평균적으로 얼마나 틀리나, RMSE는 크게 틀린 것에 더 민감하다

넷 다 실제 가격 `y`와 예측 `y_pred`를 넣어요. 두 배열의 길이가 같아야 해요.

| 지표 | 뜻 | 오늘 값 (200건) |
| --- | --- | --- |
| MAE | 오차 절댓값의 평균. 평균적으로 얼마나 틀리나 | 2,493 |
| MSE | 오차 제곱의 평균. 단위도 제곱 | 16,240,971 |
| RMSE | MSE의 제곱근. 원래 단위로 돌아옴 | 4,030 |
| R² | 가격 차이를 모델이 얼마나 설명하나. 1에 가까울수록 좋다 | 0.803 |

R² 0.803은 가격 차이의 약 80%를 면적으로 설명한다는 뜻이에요.

> **따라 하기:** 실습 노트북 6절의 칸을 실행해요. `MAE = 2,493`, `MSE = 16,240,971`, `RMSE = 4,030`, `R_SCORE=0.803`이 나오면 맞아요.

### RMSE가 큰 오차에 더 민감한 이유

오차가 1,000짜리 하나와 20,000짜리 하나를 생각해 봐요. 절댓값으로는 20배 차이지만, 제곱하면 1,000,000과 400,000,000으로 400배 차이가 나요. 그래서 크게 틀린 몇 건이 RMSE를 확 끌어 올려요. 오늘 특이매물 5건의 오차는 16,164~22,045로 다른 매물보다 훨씬 커요.

<TwistBox title="R²가 0보다 작을 수도 있어요">

수업 주석에는 "0 ~ 1"이라고 적었지만, R²는 1이 최고이고 아래로는 끝이 없어요. 0은 "모든 매물을 평균 가격 하나로 찍은 것"만큼이라는 뜻이고, 그보다 못하면 음수가 나와요. 모든 예측을 50,000으로 찍으면 `r2_score`가 -5.268이에요. 학습한 모델에 학습한 데이터로 재면 보통 0~1 사이라서 주석처럼 생각해도 오늘은 맞아요.

</TwistBox>

<TwistBox title="진짜 규칙 450, 5000이 MAE는 더 작다">

위 그림에서 "만들 때 쓴 값"을 눌러 보면 200건의 MAE가 2,479로 학습한 직선(2,493)보다 작아요. 대신 RMSE는 4,052로 더 커요. `LinearRegression`은 오차 제곱의 합이 가장 작은 직선을 찾기 때문에 RMSE로는 이길 수 없지만, MAE로는 다른 직선이 더 작을 수 있어요. 모델이 무엇을 줄이도록 만들어졌는지에 따라 "가장 좋은 직선"이 달라져요.

## 7. 특이매물 5건을 빼고 다시 재면 RMSE가 더 많이 줄어든다

크게 틀린 5건이 빠지자 MAE는 2,493 → 2,075, RMSE는 4,030 → 2,732로 줄었어요. RMSE가 더 많이 줄었어요. 계산은 꼭 `for`문 안에 들여 쓰고, 골라낸 예측 `y_hat`을 넣어요.

```python
for name, mask in cases:
    y_true = y[mask]        # 실제가격
    y_hat = y_pred[mask]    # 예측가격

    mae = mean_absolute_error(y_true, y_hat)
    rmse = root_mean_squared_error(y_true, y_hat)
    print(f"{name} MAE {mae:,.0f} | RMSE {rmse:,.0f}")
# 전체 200건 MAE 2,493 | RMSE 4,030
# 특이매물 제외한 195 MAE 2,075 | RMSE 2,732
```

## 오늘 꼭 기억할 주의점

- 범례는 `label`을 주고 `legend()`를 불러야 나와요. 둘 중 하나만 있으면 범례가 없어요.
- 시간 흐름은 선, 한 값의 분포는 히스토그램, 두 값의 관계는 산점도, 그룹별 분포와 튀는 값은 박스플롯이에요.
- `palette`를 쓸 때는 `hue`도 같이 주고 `legend=False`로 꺼요.
- 상관계수는 -1~1이에요. 조건으로 골라낸 작은 표본은 관계가 강해 보일 수 있어요(300채 0.08, 10채 0.89).
- seed를 고정하면(`default_rng(40)`) 누가 돌려도 같은 난수가 나와요. `choice(..., replace=False)`는 중복 없이 뽑아요.
- 저장할 때는 `to_csv(경로, index=False)`로 행 번호를 빼요.
- X는 표(`office[["area"]]`), y는 열 하나(`office["price"]`)예요. 예측할 새 입력도 같은 열 이름의 표로 만들어요.
- 학습한 w, b는 데이터를 만든 값과 같지 않아요. 잡음과 튀는 값이 직선을 끌어당겨요.
- 직선을 그릴 때는 입력을 `sort_values`로 줄 세운 뒤 `plot`해요.
- MAE는 평균적으로 얼마나 틀리나, RMSE는 크게 틀린 것에 더 민감해요. R²는 1에 가까울수록 좋아요.
- 평가 함수에 넣는 두 배열은 길이가 같아야 해요. 반복마다 계산하려면 `for`문 안으로 들여 써요.

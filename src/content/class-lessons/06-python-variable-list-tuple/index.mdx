## 1. 변수 재할당

### 값을 다시 넣으면

10월 30일에 자료형을 볼 때 `age = 25`처럼 값을 넣어 봤어요. 그 변수에 값을 다시 넣으면 어떻게 될까요?

```python
age = 20  # 메모리에 20 객체를 생성, age는 메모리 주소를 기억
age = 25  # 메모리에 25 객체를 생성, age -> 25
print(age)
# 25
```

그림으로 보면 이래요.

```text
age = 20     age -> [ 20 ]

age = 25     age -> [ 25 ]
```

변수는 값을 품은 상자라기보다 **값을 가리키는 이름표**예요. 두 번째 줄 뒤에는 이름표 `age`가 25 객체로 옮겨 가요.

### 자기 자신을 이용한 재할당

```python
money = 5000
money = money + 2000
print(money)
# 7000
```

수학 시간의 등호처럼 읽으면 말이 안 되는 식이에요. 파이썬의 `=`는 "같다"가 아니라 **오른쪽을 계산해서 왼쪽에 넣어라**예요.

그래서 오른쪽 `money + 2000`을 먼저 계산해 7000을 만들고, 그 결과를 `money`에 넣어요. 줄여 쓰는 `+=`는 2장에서 나와요.

### type()과 id()

```python
x = 10
print(type(x))
print(id(x))

x = "hello"
print(type(x))
print(id(x))
```

```text
<class 'int'>
140731648920280
<class 'str'>
1981923006416
```

- `type(x)`: 지금 `x`가 가리키는 값의 자료형이에요. 같은 `x`에 문자열을 넣어도 에러 없이 `int`에서 `str`로 바뀌어요.
- `id(x)`: 그 객체의 고유 번호예요. 앞뒤 값이 서로 달라요. 이름표가 다른 객체로 옮겨 갔다는 뜻이에요.

`age`로 재할당 전후를 비교해도 마찬가지예요.

```python
age = 20
print(id(age))
age = 25
print(id(age))
```

두 번호가 서로 달라요. 번호 자체는 실행할 때마다 바뀌니 외울 필요가 없고, **같은지 다른지만** 보면 돼요.

### 가비지 컬렉터(Garbage Collector)

수업 노트에 이렇게 적혀 있어요. "메모리 할당 해제를 개발자가 신경 쓰지 않는다."

이름표가 옮겨 가면 예전 객체를 가리키는 이름표가 없어질 수 있어요. 아무도 안 쓰는 객체는 파이썬이 알아서 치워요. 이 청소를 맡는 것이 가비지 컬렉터예요. 덕분에 "이 메모리 다 썼어요"라고 직접 알리는 코드를 쓰지 않아요.

<TwistBox title="작은 정수는 미리 만들어 둬요">

"20 객체를 생성한다"는 설명은 그림으로 이해하기 좋은 말이에요. 실제 파이썬(CPython)은 20 같은 자주 쓰는 작은 정수를 미리 만들어 두고 함께 써요.

```python
a = 20
b = 20
print(id(a) == id(b))
# True
```

그래도 오늘 배운 내용은 그대로예요. 값을 다시 넣으면 이름표가 다른 객체로 옮겨 가요.

</TwistBox>

## 2. 연산자

### 산술 연산자

```python
1+1
print(10*2)
print(10/2)
print(10%3)
print(10//3)
print(10**2)
```

| 식 | 의미 | 결과 |
| --- | --- | --- |
| `10*2` | 곱셈 | `20` |
| `10/2` | 나눗셈 (결과는 소수) | `5.0` |
| `10%3` | 나머지 | `1` |
| `10//3` | 몫 | `3` |
| `10**2` | 거듭제곱 | `100` |

`10/2`가 `5`가 아니라 `5.0`인 게 눈에 띄어요. 나눗셈 `/`의 결과는 나누어떨어져도 **소수(float)** 예요. 정수 몫이 필요하면 `//`를 써요.

첫 줄 `1+1`의 `2`는 화면에 나오지 않아요. 노트북은 칸의 **마지막 줄**이 값일 때만 자동으로 보여 주는데, 이 칸의 마지막 줄은 `print(...)`이기 때문이에요.

### 복합 대입 연산자

```python
score = 100
score += 50  # score = score + 50
score %= 3   # score = score % 3
print(score)
# 0
```

`score`는 100에서 150으로, 다시 0으로 바뀌어요. 150은 3으로 나누어떨어져서 나머지가 0이에요.

1장의 `money = money + 2000`도 `money += 2000`으로 줄여 쓸 수 있어요.

### 비교 연산자

```python
a = 10
print(a == 10)  # True
print(a != 10)  # False
print(a > 10)   # False
print(a < 10)   # False
print(a >= 10)  # True
print(a <= 10)  # True
```

`==`는 같다, `!=`는 다르다예요. 값을 넣는 `=`와 헷갈리지 않게 조심해요.

문자열도 비교할 수 있어요.

```python
print("apple" > "banana")  # False
print(ord("a"))            # 97
print(ord("b"))            # 98
```

`ord()`는 글자의 번호를 알려 줘요. 문자열은 앞 글자부터 이 번호로 비교해요. `a`(97)가 `b`(98)보다 작으니 `"apple" > "banana"`는 `False`예요.

### 논리 연산자

```python
is_adult = True
has_ticket = False

print(is_adult and has_ticket)  # False
print(is_adult or has_ticket)   # True
print(not is_adult)             # False
```

- `and`: 둘 다 참이어야 참
- `or`: 하나라도 참이면 참
- `not`: 참과 거짓을 뒤집어요

## 3. 단락 평가와 우선순위

### 단락 평가

결과가 이미 정해지면 파이썬은 오른쪽을 **계산하지 않아요.**

```python
print(False and (10/0 > 1))
# False

print(False or (10/0 > 1))
# ZeroDivisionError: division by zero
```

- `and`는 왼쪽이 `False`면 답이 이미 `False`예요. 오른쪽을 안 봐서, 0으로 나누는 식이 있어도 에러가 안 나요.
- `or`는 왼쪽이 `False`면 오른쪽을 봐야 답이 나와요. 그래서 계산하다가 `ZeroDivisionError`가 나요.

반대로 `or`의 왼쪽이 `True`면 답이 정해졌으니 오른쪽을 건너뛰어요.

```python
print(True or (10/0 > 1))
# True
```

### 연산자 우선순위

수업 노트의 순서예요.

```text
**
*
/
//
%
+
-
```

```python
result = 10 + 2 * 5 > 25    # False
result = (10 + 2) * 5 > 25  # True
print(result)
# True
```

- 곱셈이 먼저라 첫 식은 `10 + 10 > 25`, 즉 `False`예요.
- 괄호가 가장 먼저라 둘째 식은 `60 > 25`, 즉 `True`예요. `result`에 마지막으로 들어간 값이 `True`라서 그게 출력돼요.

<TwistBox title="세로로 적었지만 같은 등급인 것들이 있어요">

목록을 세로로 적으면 `*`가 `/`보다 먼저인 것처럼 보여요. 실제로는 `*`, `/`, `//`, `%`가 **같은 등급**이고, 왼쪽부터 차례로 계산해요. `+`와 `-`도 같은 등급이에요.

```python
print(2*3//4)      # 1      (2*3 = 6, 6//4 = 1)
print(2*7%4)       # 2      (2*7 = 14, 14%4 = 2)
print(10 / 2 * 5)  # 25.0   (10/2 = 5.0, 5.0*5 = 25.0)
```

`*`가 먼저라서가 아니라 왼쪽에 있어서 먼저예요. 세 번째 줄은 `/`가 왼쪽이니 나눗셈을 먼저 해요.

비교(`>`)는 계산이 다 끝난 뒤에 해요. 헷갈리면 괄호를 쳐요. 읽는 사람도 편해요.

</TwistBox>

## 4. 문자열 포맷

값을 문자열에 넣는 방법이 세 가지 나왔어요.

### % 방식

```python
print("선발 출전: %s, %d" % ("손흥민", 20))
print("선발 출전: [%5d]" % (20))
print("소수점 표기 : %.2f" % (3.141592))
```

```text
선발 출전: 손흥민, 20
선발 출전: [   20]
소수점 표기 : 3.14
```

| 표시 | 뜻 |
| --- | --- |
| `%s` | 문자열 자리 |
| `%d` | 정수 자리 |
| `%5d` | 정수를 폭 5칸에 넣기(남는 칸은 왼쪽 공백) |
| `%.2f` | 소수점 아래 2자리 |

### format 방식과 f-string 방식

```python
name = "Cake"
price = 6500
qty = 2

# format 방식
format_str = "주문내역: {0} {1} -> 총 {2}원".format(name, qty, price)
print(format_str)

# f-string 방식(주로 사용)
format_str = f"주문내역: {name} {price} -> 총 {(price * qty):>10,}원"
print(format_str)
```

```text
주문내역: Cake 2 -> 총 6500원
주문내역: Cake 6500 -> 총     13,000원
```

- **format:** `{0}`, `{1}`, `{2}`는 `.format()`에 넣은 값의 순서예요.
- **f-string:** 문자열 앞에 `f`를 붙이고, `{}` 안에 변수나 식을 바로 써요. 값이 놓일 자리에 이름이 바로 보여서 읽기 쉬워요. 그래서 주로 이 방식을 써요.

두 줄의 총액이 다른 건 코드가 그렇게 쓰였기 때문이에요. format 줄의 `{2}`에는 `price`(단가 6500)를 넣었고, f-string 줄은 `price * qty`(13000)를 계산했어요. format 쪽도 `price * qty`를 넣으면 `총 13000원`이 나와요.

### 콜론 뒤의 모양 지정

`{값:>10,}`에서 콜론 뒤가 **어떻게 보여 줄지**예요.

| 표시 | 뜻 |
| --- | --- |
| `>` | 오른쪽 정렬 |
| `<` | 왼쪽 정렬 |
| `10` | 폭 10칸 |
| `,` | 천 단위 쉼표 |

출력의 `13,000`은 여섯 글자라서, 10칸 안에서 앞에 공백 네 칸이 붙고 오른쪽으로 붙어요. 값을 바로 쓴 문자열에도 똑같이 돼요.

```python
print(f"금액: {15000:>8,}원")
# 금액:   15,000원
```

## 5. 영수증 만들기

지금까지 배운 것을 합쳐요. 오늘 수업의 작은 완성품이에요.

```python
# 가상의 주문 데이터
orders = [
    ("Latte", 5000, 2),
    ("Americano", 3000, 1),
    ("Cake", 6000, 1)
]
print("=" * 34)
print(f"{'메뉴명':<10} {'단가':>8} {'금액':>9}")
print("-" * 34)

total_amount = 0

for menu, price, qty in orders:
    subtotal = price * qty
    total_amount += subtotal
    print(f"{menu:<10} {price:>12,} {subtotal:>10,}")

print("-" * 34)
print(f"{'합계금액':<10}{total_amount:>20,}원")
```

```text
==================================
메뉴명              단가        금액
----------------------------------
Latte             5,000     10,000
Americano         3,000      3,000
Cake              6,000      6,000
----------------------------------
합계금액                    19,000원
```

- `"=" * 34`: 문자열을 34번 반복해요. 구분선을 이렇게 그려요.
- `orders`: 값 세 개짜리 묶음(튜플)을 담은 리스트예요. 튜플은 6장에서 다뤄요.
- `for menu, price, qty in orders`: 묶음을 하나씩 꺼내 세 변수에 나눠 담아요. 반복문은 아직 자세히 안 배웠으니 "한 줄씩 꺼내는구나" 정도로 봐요.
- `total_amount += subtotal`: 소계를 더해 합계를 만들어요. 10,000 + 3,000 + 6,000 = 19,000이에요.

<TwistBox title="한글이 들어간 줄만 칸이 안 맞는 이유">

f-string의 폭은 **글자 수**로 세요. 그런데 글자 폭이 고정된 터미널에서 한글은 영문의 두 칸을 차지해요.

`{'메뉴명':<10}`은 세 글자에 공백 일곱 개를 붙여요. 눈에는 13칸으로 보여서, 위 출력의 머리글과 합계 줄은 구분선 34칸보다 2칸 길어요.

한글 글자 수만큼 폭을 줄이면 34칸에 맞아요. 합계 줄의 `원`은 칸 수를 맞추려고 뺐어요.

```python
print(f"{'메뉴명':<7} {'단가':>10} {'금액':>8}")
print(f"{'합계금액':<6}{total_amount:>24,}")
```

```text
메뉴명             단가       금액
합계금액                    19,000
```

이 페이지의 코드 칸은 한글 글꼴의 폭이 달라서 칸이 정확히 맞아 보이지 않아요. 터미널에서 직접 돌려 보면 맞는 걸 볼 수 있어요.

</TwistBox>

## 6. 리스트와 튜플

### 괄호로 구분해요

| 자료구조 | 괄호 | 특징 |
| --- | --- | --- |
| 리스트 | `[ ]` | 값을 바꿀 수 있어요 |
| 튜플 | `( )` | 만든 뒤에는 추가, 수정, 삭제를 할 수 없어요 |
| 딕셔너리 | `{ }` | 오늘은 제목과 괄호 설명만 나왔고, 코드는 아직이에요 |

### 리스트

```python
shopping_list = ["apple", "banana", "cherry"]

print(shopping_list)
print(shopping_list[0])

shopping_list[0] = "kiwi"
print(shopping_list[0])
print(shopping_list)
```

```text
['apple', 'banana', 'cherry']
apple
kiwi
['kiwi', 'banana', 'cherry']
```

인덱스로 요소를 바로 바꿀 수 있어요. 튜플에 같은 일을 하면 에러가 나요.

### 리스트 메서드

메서드는 값 뒤에 점을 찍고 부르는 그 값 전용 기능이에요.

```python
fruits = ["apple"]

fruits.append("banana")
print(fruits)
# ['apple', 'banana']

fruits.insert(0, "kiwi")
print(fruits)
# ['kiwi', 'apple', 'banana']

fruits.remove("apple")
print(fruits)
# ['kiwi', 'banana']

fruits.remove("grape")
# ValueError: list.remove(x): x not in list
```

| 메서드 | 하는 일 |
| --- | --- |
| `append(값)` | 맨 뒤에 추가 |
| `insert(자리, 값)` | 그 자리에 끼워 넣기 |
| `remove(값)` | 그 값을 찾아 지우기. 없으면 `ValueError` |

### 튜플

```python
axis = (38.123, 41.123)

axis[0] = 36.1234
# TypeError: 'tuple' object does not support item assignment

point = 1, 2, 3
print(point, type(point))
# (1, 2, 3) <class 'tuple'>
```

튜플은 요소를 바꾸면 에러가 나요. `point`처럼 **괄호 없이 쉼표만으로도** 튜플이 돼요. 튜플을 만드는 건 괄호보다 쉼표예요.

값이 하나인 튜플에서 이 차이가 드러나요.

```python
print(type((1)))   # <class 'int'>
print(type((1,)))  # <class 'tuple'>
```

### 리스트와 튜플의 크기 비교

```python
import sys
print(sys.getsizeof([1,2,3]))  # 리스트 : 데이터의 순서를 보장
print(sys.getsizeof((1,2,3)))  # 튜플 : 데이터 안정성
```

| 실행한 곳 | 리스트 | 튜플 |
| --- | --- | --- |
| 수업 노트북 | `88` | `72` |
| 파이썬 3.13.18 | `88` | `64` |
| 파이썬 3.12.10 | `88` | `64` |

숫자는 환경에 따라 달라요. 기억할 건 **같은 값이면 튜플이 더 작다**는 쪽이에요. 리스트는 늘었다 줄었다 해야 해서 관리할 정보가 더 많아요.

노트북 주석의 "순서를 보장"은 리스트만의 특징이 아니에요. 튜플도 인덱스로 꺼내니 순서가 있어요. 둘을 가르는 건 **바꿀 수 있는가**예요. 바뀌면 안 되는 값은 튜플에 담아 실수로 고치는 일을 막아요.

<TwistBox title="리스트를 고치는 것과 다시 넣는 것은 달라요">

1장에서 값을 다시 넣으면 `id`가 바뀌었어요. 리스트 안을 고칠 때는 어떨까요?

```python
a = [1, 2]
before = id(a)

a[0] = 9
print(id(a) == before)  # True
a.append(3)
print(id(a) == before)  # True
a = [9, 2, 3]
print(id(a) == before)  # False
```

요소를 바꾸거나 추가하면 **같은 리스트 객체의 속이 바뀌어요.** `=`로 새 리스트를 넣을 때만 이름표가 옮겨 가요.

그래서 이름표 두 개가 같은 리스트를 가리키면 한쪽을 고칠 때 다른 쪽도 바뀌어 보여요.

```python
b = [1, 2]
c = b
c.append(3)
print(b)  # [1, 2, 3]
```

`c = b`는 복사가 아니라 이름표를 하나 더 붙인 거예요. 나중에 "분명 안 건드렸는데 값이 바뀌었다"는 일을 만나면 이걸 떠올려요.

</TwistBox>

## 7. 꺼내기: 인덱스, 슬라이싱, 2차원 리스트

### 인덱스

```python
colors = ["red", "green", "blue"]
print(colors[0])   # red
print(colors[-1])  # blue
```

| 방향 | red | green | blue |
| --- | --- | --- | --- |
| 정방향 | 0 | 1 | 2 |
| 역방향 | -3 | -2 | -1 |

앞에서는 **0부터** 세고, 뒤에서는 **-1부터** 세요. 맨 뒤 값이 필요할 때 개수를 몰라도 `-1`로 꺼내요.

없는 자리를 꺼내면 에러가 나요.

```python
print([1, 2, 3][5])
# IndexError: list index out of range
```

### 슬라이싱

형식은 `[시작:끝:간격]`이고, 끝은 **포함하지 않아요.** 노트북 주석대로 "1번부터 4번 미만까지"예요.

```python
numbers = [0, 1, 2, 3, 4, 5]
```

| 식 | 뜻 | 결과 |
| --- | --- | --- |
| `numbers[1:4]` | 1번부터 4번 미만까지 | `[1, 2, 3]` |
| `numbers[::2]` | 2칸씩 간격으로 | `[0, 2, 4]` |
| `numbers[::-1]` | 역순으로 | `[5, 4, 3, 2, 1, 0]` |
| `numbers[:3]` | 앞에서 3개만 | `[0, 1, 2]` |
| `numbers[3:]` | 3번부터 끝까지 | `[3, 4, 5]` |

튜플도 슬라이싱돼요. `print((10, 20, 30, 40)[1:3])`의 출력은 `(20, 30)`이에요.

인덱스와 달리 슬라이싱은 범위를 넘어도 에러가 나지 않고, 있는 만큼만 줘요. `[1, 2, 3][1:9]`는 `[2, 3]`이에요.

수업 노트북에서 다섯 식을 한 칸에 쓰고 돌렸더니 출력은 `[3, 4, 5]` 하나뿐이었어요. 2장의 `1+1`과 같은 이유예요. 칸의 마지막 줄만 자동으로 보여 줘요. 다 보려면 `print`로 감싸요.

### 2차원 리스트

리스트 안에 리스트를 넣은 모양이에요. 표처럼 생각하고 `[행][열]` 순서로 꺼내요.

```python
matrix = [
    [1,2,3],
    [4,5,6]
]

print(matrix[1])
print(matrix[1][2])
print(len(matrix), len(matrix[0]))
```

```text
[4, 5, 6]
6
2 3
```

- `matrix[1]`: 두 번째 행 `[4, 5, 6]`이에요.
- `matrix[1][2]`: 그 행의 세 번째 값 `6`이에요. 인덱스는 0부터 세요.
- `len(matrix)`는 행 개수 `2`, `len(matrix[0])`은 첫 행의 값 개수 `3`이에요.

<PredictPrompt />

`matrix`에서 `5`를 꺼내려면 어떻게 쓸지 예측해 보세요.

정답은 `matrix[1][1]`이에요. 두 번째 행의 두 번째 값이에요.

## 8. 세기와 확인하기

```python
user_roles = ["admin", "member", "guest"]
print(len(user_roles))
print("admin" not in user_roles)
```

```text
3
False
```

- `len(user_roles)`: 요소 개수 `3`이에요.
- `"admin" not in user_roles`: `admin`이 목록에 있으니 `False`예요.
- `"admin" in user_roles`는 `True`, `"owner" not in user_roles`도 `True`예요.

`len()`은 리스트만의 기능이 아니에요. `len((10, 20, 30))`은 `3`, `len("hello")`는 `5`예요.

## 오늘 꼭 기억할 주의점

- `=`는 "같다"가 아니라 "오른쪽을 계산해서 왼쪽에 넣어라"예요. 같은지 비교는 `==`예요.
- 값을 다시 넣으면 이름표가 다른 객체로 옮겨 가요. `id()`가 달라져요. 메모리 정리는 가비지 컬렉터가 맡아요.
- `/`의 결과는 나누어떨어져도 소수예요. 몫은 `//`, 나머지는 `%`예요.
- `and`는 왼쪽이 `False`면, `or`는 왼쪽이 `True`면 오른쪽을 계산하지 않아요.
- `*`, `/`, `//`, `%`는 같은 등급이라 왼쪽부터 계산해요. 헷갈리면 괄호를 쳐요.
- 문자열 포맷은 f-string을 주로 써요. `{값:>10,}`은 오른쪽 정렬, 폭 10칸, 천 단위 쉼표예요.
- 리스트는 바꿀 수 있고, 튜플은 바꿀 수 없어요. 튜플을 만드는 건 괄호보다 쉼표예요.
- 인덱스는 0부터, 뒤에서는 -1부터 세요. 슬라이싱의 끝은 포함하지 않아요.
- 노트북은 칸의 마지막 줄만 자동으로 보여 줘요. 다 보려면 `print`로 감싸요.

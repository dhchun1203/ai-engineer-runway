## 2. 선형회귀 복습: 공부 시간 5개 케이스로 기울기 10, 절편 35를 찾는다

공부 시간(`hours`)으로 시험 점수(`scores`)를 예측해요. 어제처럼 입력 X는 표(대괄호 두 겹), 정답 y는 열 하나예요.

```python
data = {
    "hours": [1, 2, 3, 4, 5],
    "scores": [47, 53, 65, 73, 87]
}
df = pd.DataFrame(data)

# 입력(특징, Feature): 2차원, 정답(Target): 1차원
X = df[["hours"]]
y = df["scores"]

model = LinearRegression()
model.fit(X, y)

# 기울기 10.00, 절편 35.00
print(f"기울기: {model.coef_[0]:.2f}")
print(f"절편: {model.intercept_:.2f}")

# 6시간 공부하면 95.00점
new_data = pd.DataFrame({"hours": [6]})
print(model.predict(new_data)[0])
```

> **따라 하기:** 실습 노트북 2절의 칸들을 실행해요. `기울기: 10.00`, `절편: 35.00`, `6시간 학습한 학생의 예상 성적: 95.00점`이 나오면 맞아요.

## 4. 손실 함수: 틀린 정도를 MSE 하나로 만들고, 그 숫자를 줄이는 쪽으로 걷는다

모델이 얼마나 틀렸는지를 숫자 하나로 나타내는 것이 **손실 함수**(Loss Function)예요. 선형회귀는 보통 MSE를 써요.

**MSE = (1/n) × Σ (실제 yᵢ − 예측 ŷᵢ)²**

**경사하강법**(Gradient Descent)은 w, b를 아무 값에서 시작해, MSE가 줄어드는 방향으로 조금씩 고치기를 되풀이해요. 안개 낀 산에서 발밑의 기울기만 보고 한 걸음씩 내려가는 것과 같아요.

```python
import numpy as np

hours = np.array([1, 2, 3, 4, 5])
scores = np.array([47, 53, 65, 73, 87])

# 손실(MSE) 계산 함수
def mse(w, b):
    return ((scores - (w * hours + b)) ** 2).mean()

print(mse(0, 0))    # 4428.2: 시작점
print(mse(12, 30))  # 12.2: 가까워졌다
print(mse(10, 35))  # 3.2: 가장 낮은 곳
```

> **따라 하기:** 실습 노트북 4절의 칸을 실행해요. `4428.2`, `12.2`, `3.2`가 차례로 나오면 맞아요. 이 셋은 수업에 없던 칸으로, 손실이 무엇인지 숫자로 보려고 더했어요.

## 5. SGDRegressor: partial_fit 한 번이 데이터 전체를 한 바퀴(1 epoch) 도는 것이다

같은 데이터를 `SGDRegressor`로 학습해요. `partial_fit`을 부를 때마다 5개 케이스를 하나씩 보며 w, b를 고쳐요. 이렇게 데이터 전체를 한 바퀴 도는 것을 **epoch**라고 해요.

```python
sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=1000,
    shuffle=False,
    random_state=42
)

history = []
for epoch in range(1000):
    # 전체 데이터 1회 학습 (1 epoch)
    sgd.partial_fit(X, y)
    y_pred = sgd.predict(X)
    history.append({
        "epoch": epoch + 1,
        "weight": sgd.coef_[0],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y, y_pred)
    })
```

### 목표 먼저 재 두기

경사하강법이 도달하려는 답을 `LinearRegression`으로 먼저 구해 둬요.

```python
import pandas as pd

from sklearn.linear_model import LinearRegression
# 배치 경사하강법 (BGD) : 전체 데이터를 사용, 시간, 리소스 많이 사용
# 확률적 경사하강법 (SGD) : 확률적을 1개의 데이터를 추출해서 하강 방법
from sklearn.linear_model import SGDRegressor

df = pd.DataFrame({

X = df[["hours"]]
```

### 모델 만들기

```python
sgd = SGDRegressor(
    loss="squared_error",       # 제곱 오차 기반 손실함수
    learning_rate="constant",   # 학습률을 일정하게 유지
    eta0=0.01,                  # 초기 학습률
    max_iter=1000,              # 학습횟수 fit() 반복 회수
    shuffle=False,              # 학습 데이터 섞지 않음
    random_state=42             # 난수 시드 설정
)
```

| 설정 | 뜻 |
| --- | --- |
| `loss="squared_error"` | 손실을 제곱 오차(MSE)로 잰다 |
| `learning_rate="constant"` | 학습률을 끝까지 같게 둔다 |
| `eta0=0.01` | 학습률(한 걸음의 크기) |
| `max_iter=1000` | `fit()`이 데이터를 도는 최대 횟수 |
| `shuffle=False` | 한 바퀴마다 데이터 순서를 섞지 않는다 |
| `random_state=42` | 난수 seed, 누가 돌려도 같은 결과 |

### 1000 epoch 학습하고 기록하기

```python
# 전체 데이터를 기준으로 총 몇회 반복
epochs = 1000

# 학습과정 저장 리스트
history = []

for epoch in range(epochs):
    # 전체 데이터 1회 학습 (1 epoch)
    sgd.partial_fit(X, y)

    # 1회 학습 후 예측
    y_pred = sgd.predict(X)

    # 현재 모델의 MSE 계산

    history.append({
        "epoch": epoch + 1,
        "weight": sgd.coef_[0],
        "bias": sgd.intercept_[0],
        "mse": mse
    })
```

### 1 epoch를 손으로 따라가 보기

w, b를 0에서 시작해 케이스 5개를 차례로 보며 고치면 1 epoch의 결과 `8.455225`, `2.731163`이 똑같이 나와요.

```python
w = 0.0
b = 0.0
eta = 0.01     # 학습률 eta0
alpha = 0.0001 # SGDRegressor 기본 규제 세기

for xi, yi in zip([1, 2, 3, 4, 5], [47, 53, 65, 73, 87]):
    error = (w * xi + b) - yi
    w = w * (1 - eta * alpha) - eta * error * xi
    b = b - eta * error

print(w, b)
```

```text
8.455224781754193 2.731163490747725
```

오차가 음수(너무 낮게 예측)면 w, b가 올라가요. 첫 케이스(1시간, 47점)에서 오차는 `0 - 47 = -47`이라 b는 `0.47`, w도 `0.47`만큼 올라가요. 그다음 케이스는 고친 w, b로 다시 예측해요. 이렇게 하나씩 보고 바로 고치는 것이 SGD예요. `alpha`는 기울기가 너무 커지지 않게 살짝 줄이는 기본 설정(규제)으로, 이 데이터에서는 거의 차이가 없어요.

<TwistBox title="partial_fit은 max_iter를 보지 않아요">
수업 코드의 `max_iter=1000`은 `fit()`을 쓸 때 데이터를 최대 몇 바퀴 돌지 정하는 값이에요. `partial_fit`은 부를 때마다 딱 한 바퀴만 돌아서, 1000번을 돈 건 `for`문 덕분이에요. 같은 설정으로 `sgd.fit(X, y)`를 한 번 부르면 427바퀴째에 "더 나아지지 않는다"고 스스로 멈추고, 기울기 10.31, 절편 34.04가 나와요.
</TwistBox>

## 오늘 꼭 기억할 주의점

- 입력 X는 표(`df[["hours"]]`), 정답 y는 열 하나(`df["scores"]`)예요. 입력은 독립변수, 정답은 종속변수라고도 해요.
- `coef_`는 특징마다 기울기가 하나씩 든 배열이라 `[0]`으로 꺼내요. `intercept_`는 `LinearRegression`에서는 숫자, `SGDRegressor`에서는 배열이에요.
- 손실 함수는 틀린 정도를 숫자 하나로 만든 것이고, 선형회귀는 보통 MSE를 써요.
- 경사하강법은 손실이 줄어드는 방향으로 w, b를 조금씩 고치기를 되풀이해요. 한 걸음의 크기가 학습률이에요.
- `partial_fit` 한 번은 데이터 전체를 한 바퀴(1 epoch) 돌아요. `max_iter`는 `fit()`에만 쓰여요.
- 학습률이 너무 작으면 1000 epoch로도 바닥에 못 닿아요(0.001이면 MSE 33.13).
- 그래프에 `label`을 줬으면 `legend()`도 불러요. 축 이름은 실제 값과 맞게 써요(가로축은 Epoch).
- 히트맵의 마이너스 경고는 `plt.rcParams["axes.unicode_minus"] = False`로 없애요.

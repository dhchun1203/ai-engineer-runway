이번 미니 프로젝트는 터미널에서 도는 **쇼핑몰 장바구니**예요. 상품을 담고 빼고, 쿠폰을 골라 쓰고, 결제하면 재고가 줄어요.

처음 짠 코드는 5시간을 붙잡고도 숫자가 계속 어긋났어요. 문법 문제가 아니라 "이 값은 누가 갖고, 누가 바꾸나"의 문제였어요. 그 지점부터 짚고, **튜터님 답안**을 따라 빈 파일에서 완성까지 다시 쌓아요.

위에서부터 차례로 읽으면 전체 흐름이 잡혀요. 레슨 끝에 확인 퀴즈가 있고, 문항을 모두 풀면 [수업 복습](/class) 목록에 완료로 표시돼요.

## 1. 전체 그림: 누가 누구를 쓰나

튜터 답안은 클래스를 역할마다 **파일 하나**에 나눠 둬요. 일을 하는 건 장바구니예요. 장바구니가 상품의 가격과 재고를 읽고, 쿠폰에게 할인 금액을 물어요.

반대로 상품과 쿠폰은 장바구니를 전혀 몰라요. 그래서 `cart.py` 맨 위에만 `from product import Product`, `from coupon import Coupon`이 있어요.

## 2. 발제 읽기: 규칙이 곧 테스트 조건이다

코드를 쓰기 전에 발제를 항목별로 나눠 읽어요. 학습 목표 여섯 개가 프로젝트의 어디에 해당하는지부터 짝지어 봐요.

| 번호 | 목표 | 이 프로젝트에서 |
| --- | --- | --- |
| 1 | 역할이 다른 클래스 여러 개를 설계할 수 있다 | `Product`, `Cart`, `Coupon` 계열 |
| 2 | 한 객체가 다른 객체를 속성으로 가지는 구조(조합)를 만들 수 있다 | `Cart`가 상품 객체(딕셔너리 키)와 쿠폰 객체를 가져요 |
| 3 | 상속으로 공통 틀을 만들고, 자식 클래스에서 오버라이딩할 수 있다 | `Coupon`을 물려받는 쿠폰 두 종류 |
| 4 | 같은 메서드 호출이 객체에 따라 다르게 동작하는 다형성을 설명할 수 있다 | `discount_amount(total)` 한 줄 |
| 5 | 객체의 상태 변경을 메서드로만 하도록 캡슐화할 수 있다 | 재고는 결제 한 곳에서만 줄여요. 메서드로 묶는 연습은 9절 |
| 6 | 클래스 변수로 객체에 자동 번호를 붙일 수 있다 | `Product.next_id` |

판매 상품은 다섯 개예요(6절 그림). 상품 번호는 직접 쓰지 않고, **객체를 만들 때 자동으로 1, 2, 3...** 이 붙어야 해요.

메뉴는 한 줄이에요.

```text
1.상품목록 2.담기 3.빼기 4.장바구니 5.쿠폰 6.결제 q.종료
```

| 메뉴 | 동작 |
| --- | --- |
| 1. 상품목록 | 전체 상품을 번호, 가격, 재고(또는 품절)로 출력 |
| 2. 담기 | 상품 번호와 수량을 받아 장바구니에 추가. 이미 담긴 상품이면 수량을 더함 |
| 3. 빼기 | 상품 번호와 수량을 받아 장바구니에서 빼기 |
| 4. 장바구니 | 담긴 상품, 상품 합계, 할인, 배송비, 결제 금액 출력 |
| 5. 쿠폰 | 쿠폰 목록을 보여 주고 하나를 골라 적용(한 번에 1장) |
| 6. 결제 | 영수증 출력, 재고 감소, 장바구니 비우기, 쿠폰 초기화 |
| q | 프로그램 종료 |

쿠폰은 세 종류예요.

| 쿠폰 | 객체 | 할인 금액 계산 |
| --- | --- | --- |
| 쿠폰 없음 | `Coupon("쿠폰 없음")` | 항상 0원 |
| 10% 할인 (최대 5,000원) | `RateDiscount(rate=0.1, max_discount=5000)` | 상품 합계 x 10%, 단 5,000원을 넘지 않음. 원 단위 미만은 버림 |
| 3,000원 할인 (20,000원 이상 구매 시) | `FixedDiscount(amount=3000, min_total=20000)` | 상품 합계가 20,000원 이상이면 3,000원, 아니면 0원 |

금액은 네 칸이 이어달리기하듯 계산해요. 앞 칸의 결과를 다음 칸이 받아 써요. 아래 숫자는 발제 예시(무선이어폰 2개 + 텀블러 9개, 10% 쿠폰)예요.

      { fn: "② 할인", desc: "쿠폰에게 ①을 주고 물어봐요", ex: "31,300이지만 상한 5,000", value: "5,000원" },

발제의 실행 예시에서 꼭 볼 곳은 두 군데예요.

- 텀블러(재고 10)를 9개 담은 뒤 2개를 더 담으면 `재고가 부족합니다. (담을 수 있는 수량: 1개)`가 나와요. **담는 순간에는 재고가 줄지 않는다**는 뜻이에요.
- 결제한 뒤 상품목록을 다시 보면 텀블러가 `(재고 1개)`예요. 재고는 **결제할 때** 줄어요.

## 3. 처음 막힌 곳: 상자 하나에 이름표 둘

처음 짠 코드는 `Item`의 `qty` 하나를 재고로도, 장바구니에 담은 수량으로도 썼어요. 문제가 되는 부분만 줄여서 돌려 보면 이래요.

```python
class Item:
    def __init__(self, name, price, qty):
        self.name = name
        self.price = price
        self.qty = qty

class Cart:
    def __init__(self):
        self.carts = []

    def add_item(self, item, qty):
        self.carts.append(item)
        self.carts[-1].qty = qty   # 담은 수량을 item.qty에 저장

earphone = Item("무선이어폰", 89000, 3)
items = [earphone]
bucket = Cart()

bucket.add_item(items[0], 2)   # 2개 담기
items[0].qty -= 2              # 담자마자 재고에서 빼기

print("재고:", items[0].qty)
print("장바구니:", bucket.carts[0].qty)
print("같은 객체?", items[0] is bucket.carts[0])
```

```text
재고: 0
장바구니: 0
같은 객체? True
```

재고 3개에서 2개를 담았으니 재고 1, 장바구니 2가 나와야 해요. 그런데 둘 다 0이에요.

리스트에 객체를 넣는다고 **복사되지 않아요**. `items[0]`과 `bucket.carts[0]`은 이름표만 둘이고, 상자는 하나예요(`같은 객체? True`).

`self.carts[-1].qty = qty`가 재고 3을 담은 수량 2로 덮어쓰고, 바로 다음 줄 `items[0].qty -= 2`가 한 번 더 빼서 0이 됐어요. 이 상태에서는 어떤 `if`를 고쳐도 숫자가 계속 어긋나요. 담는 순간 재고를 빼는 것도 발제 규칙과 달랐어요.

원인이 하나 더 있었어요.

```python
menu_choice = input("선택: ").strip()
while not menu_choice in ("1", "2", "3", "4", "5", "6", "q"):
    print("메뉴 항목 중 하나를 선택해주세요.")
```

반복 안에서 `input()`을 다시 받지 않아서, 잘못된 메뉴를 한 번 넣으면 같은 줄을 영원히 찍어요.

<TwistBox title="그럼 재고와 담은 수량은 어디에 둬야 할까요?">

재고 10과 담은 수량 9는 서로 다른 값이라 저장할 곳도 달라야 해요.

- **재고**는 상품 객체가 가져요(`product.stock`). 결제 전까지 바뀌지 않아요.
- **담은 수량**은 장바구니가 따로 가져요. 튜터 답안은 딕셔너리 `{상품: 수량}` 하나로 해결해요.

그러면 담을 수 있는 수량은 `상품의 재고 - 이미 담은 수량`이고, 결제할 때만 담은 수량만큼 재고를 줄여요. 이 구조가 학습 목표 2번의 조합이에요.

</TwistBox>

## 4. 장바구니의 속: 딕셔너리 하나

## 6. product.py: 클래스는 붕어빵 틀, next_id는 공용 번호표

```python
class Product:
    next_id = 1 # 클래스 변수

    # 새 상품의 초기 정보 저장
    def __init__(self, name, price, stock):
        self.id = Product.next_id
        Product.next_id += 1 # 다음 상품을 위해 Index 값 + 1
        self.name = name
        self.price = price
        self.stock = stock

    def is_sold_out(self):
        return self.stock == 0

    def __str__(self):
        stock_text = "품절" if self.is_sold_out() else f"재고 {self.stock}개"
        return f"{self.id}: {self.name:<10} {self.price:>8,} {self.stock} ({stock_text})"
```

`Product` 클래스는 "상품이라면 이름, 가격, 재고를 가진다"는 **틀**이에요. `Product("텀블러", 15_000, 10)`처럼 부를 때마다 실제 상품(인스턴스) 하나가 찍혀 나와요.

재미있는 부분은 `next_id`예요. `def` 밖, 클래스 바로 아래에 있죠. 이런 변수를 **클래스 변수**라고 해요. 상품마다 따로 있는 게 아니라 **클래스에 딱 하나만 있는 공용 번호표 발급기**예요.

`self.id = Product.next_id`로 지금 번호를 내 번호표로 받아 두고, 그다음 `Product.next_id += 1`로 발급기를 올려요. 상품 다섯 개를 만들면 번호는 1부터 5, 발급기는 다음 상품을 위해 6이 돼요.

<TwistBox title="번호가 3 3 3으로 나오는 코드는 뭐가 빠졌을까요?">

처음에 이렇게 써서 `3 3 3`이 나왔어요.

```python
class Product:
    number = 0

    def __init__(self, name):
        Product.number = self.number + 1
```

발급기 숫자만 올리고 번호표는 아무도 받지 않았어요. `a`에는 `number`가 없으니 `a.number`는 클래스의 `Product.number`를 읽고, 그 값은 마지막에 3이에요. 튜터 답안처럼 `self.id = ...`로 객체에 저장하는 줄이 있어야 해요.

두 줄의 순서를 바꿔 올리기를 먼저 하면 첫 상품이 2번이 돼요. 저장이 먼저, 올리기가 나중이에요.

</TwistBox>

클래스 변수는 **클래스 이름으로** 바꿔요(`Product.next_id += 1`). 객체 이름으로 대입하면(`a.next_id = 99`) 클래스 변수는 그대로고, 그 객체에만 같은 이름의 속성이 새로 생겨 클래스 변수를 가려요.

`__str__`은 `print(상품)`을 했을 때 찍힐 글자를 돌려주는 메서드예요. 상품을 어떻게 보여 줄지는 상품이 제일 잘 아니까 상품 클래스에 둬요.

| 서식 | 뜻 | 예 |
| --- | --- | --- |

## 7. 담기: 문지기 두 명을 통과해야 들어간다

```python
from product import Product

class Cart:
    def __init__(self):
        # 빈 장바구니 생성
        self.items = {} # {상품: 수량}

    # 장바구니에 상품 담기
    def add(self, product, qty):
        # 품절 상품은 담을 수 없다.
        if product.is_sold_out():
            print("품절된 상품입니다.")
            return

        # 이미 장바구니에 담겨있는 수량
        in_cart_qty = self.items.get(product, 0)
        # 더 담을 수 있는 수량
        extra_qty = product.stock - in_cart_qty
        if qty > extra_qty: # 재고 수량 범위를 벗어난 경우
            print(f"재고가 부족합니다. (담을 수 있는 수량: {extra_qty}개)")
            return

        self.items[product] = self.items.get(product, 0) + qty
        print(f"{product.name} {qty}개를 담았습니다.")
```

`add()`는 문지기 두 명을 통과해야 바구니에 넣어 줘요. 하나라도 걸리면 안내를 찍고 `return`으로 바로 끝내요.

## 8. 빼기와 합계: 세 함수가 이어달리기한다

```python
    # 장바구니에서 상품 제거(빼기)
    def remove(self,product, qty):

        if product not in self.items:
            print("장바구니에 해당 상품이 없습니다.")
            return

        # 담은 수량 이상 빼면 상품을 통째로 삭제
        if qty >= self.items[product]:
            del self.items[product]
            print(f"{product.name}을 장바구니에서 모두 뺐습니다.")
        else:
            self.items[product] -= qty
            print(f"{product.name} {qty}개를 뺐습니다.")

    # 장바구니 비었는지 확인
    def is_empty(self):
        return len(self.items) == 0

    # 상품 합계 계산
    def subtotal(self):
        return sum(p.price * q for p, q in self.items.items())

    # 배송비
    def shipping(self):
        if self.is_empty(): return 0
        return 0 if self.subtotal() >= 30_000 else 3_000

    # 결제 금액 계산
    def total(self):
        return self.subtotal() + self.shipping()
```

`remove()`는 담기보다 단순해요. 바구니에 없으면 안내하고 끝, 담은 개수 이상을 빼면 **칸째로 삭제**, 그보다 적으면 개수만 줄여요.

```python
import unicodedata

def pad(text, width):
```

## 10. coupon.py: 부모가 틀을 정하고, 자식이 계산을 채운다

튜터님이 올린 `coupon.py`는 틀까지 만들어져 있어요. 부모 `Coupon`이 이름을 받고, 자식 둘이 `super().__init__(이름)`으로 부모에게 이름을 넘겨요. 할인 계산은 아직 `pass`로 비어 있어요.

```python
class FixedDiscount(Coupon):
    def __init__(self, amount, min_total):
        super().__init__(f"쿠폰이름- {min_total}만원이상 {amount}원 할인쿠폰 ")

    def discount_amount(self, total):
        pass
        # 상품 합계가 20,000원 이상이면 3,000원, 아니면 0원
```

이대로 장바구니에 연결하면 세 군데서 걸려요. 직접 돌려 확인했어요.

| 증상 | 이유 |
| --- | --- |
| `discount_amount()`가 `None`을 돌려줘요. `313000 - None`에서 `TypeError` | 몸통이 `pass`뿐이라 아무것도 `return`하지 않아요 |
| `f.amount`에서 `AttributeError` | `__init__`이 `amount`, `min_total`을 받기만 하고 `self`에 저장하지 않았어요 |
| 이름이 `쿠폰이름- 20000만원이상 3000원 할인쿠폰` | `min_total`이 이미 20000원인데 뒤에 "만원"을 붙였어요 |

세 군데를 채우고 이름을 발제 표기에 맞춘 `coupon.py`예요.

```python
class Coupon:
    def __init__(self, name):
        self.name = name

    # 할인 금액 반환
    def discount_amount(self, total):
        return 0

# 10% 할인 쿠폰
class RateDiscount(Coupon):
    # 할인율과 최대 할인 금액 적용
    def __init__(self, rate, max_discount):
        super().__init__(f"{int(rate * 100)}% 할인 (최대 {max_discount:,}원)")
        self.rate = rate
        self.max_discount = max_discount

    def discount_amount(self, total):
        # 상품합계 X 10%, 단 5,000원을 넘지 않는다. 원단위 미만은 버림
        amount = int(total * self.rate)
        return min(amount, self.max_discount)

# 정액 할인 쿠폰
class FixedDiscount(Coupon):
    def __init__(self, amount, min_total):
        super().__init__(f"{amount:,}원 할인 ({min_total:,}원 이상 구매 시)")
        self.amount = amount
        self.min_total = min_total

    def discount_amount(self, total):
        # 상품 합계가 20,000원 이상이면 3,000원, 아니면 0원
        return self.amount if total >= self.min_total else 0
```

부모 `Coupon`은 "모든 쿠폰은 `name`과 `discount_amount(total)`을 가진다"는 공통 틀이에요. 할인이 없어서 항상 0원이라, `Coupon("쿠폰 없음")`이 곧 "쿠폰 없음" 쿠폰이에요.

- 자식이 `discount_amount`를 같은 이름으로 다시 정의하는 것이 **오버라이딩**이에요.
- `int(total * self.rate)`가 원 단위 미만을 버리고, `min(..., self.max_discount)`가 5,000원을 넘지 않게 잘라요.

## 11. 장바구니에 쿠폰 연결: 배송비는 할인 뒤 금액으로

`cart.py`에 쿠폰을 붙이는 곳은 다섯 군데예요.

```python
from coupon import Coupon

class Cart:
    def __init__(self):
        # 빈 장바구니 생성
        self.items = {} # {상품: 수량}
        self.coupon = Coupon("쿠폰 없음") # 처음엔 쿠폰 없음

    # 쿠폰 적용 (한 번에 1장)
    def apply_coupon(self, coupon):
        self.coupon = coupon
        print(f"[{coupon.name}] 쿠폰을 적용했습니다.")

    # 할인 금액 (쿠폰 종류는 묻지 않는다)
    def discount(self):
        return self.coupon.discount_amount(self.subtotal())

    # 배송비 (할인을 뺀 금액으로 정한다)
    def shipping(self):
        if self.is_empty(): return 0
        return 0 if self.subtotal() - self.discount() >= 30_000 else 3_000

    # 결제 금액 계산
    def total(self):
```

```python
class Coupon:
    def __init__(self, name):
        self.name = name

    # 할인 금액 반환
    def discount_amount(self, total):
        return 0

# 10% 할인 쿠폰
class RateDiscount(Coupon):
    # 할인율과 최대 할인 금액 적용
    def __init__(self, rate, max_discount):
        super().__init__(f"{int(rate * 100)}% 할인 (최대 {max_discount:,}원)")
        self.rate = rate
        self.max_discount = max_discount

    def discount_amount(self, total):
        # 상품합계 X 10%, 단 5,000원을 넘지 않는다. 원단위 미만은 버림
        amount = int(total * self.rate)
        return min(amount, self.max_discount)

# 정액 할인 쿠폰
class FixedDiscount(Coupon):
    def __init__(self, amount, min_total):
        super().__init__(f"{amount:,}원 할인 ({min_total:,}원 이상 구매 시)")
        self.amount = amount
        self.min_total = min_total

    def discount_amount(self, total):
        # 상품 합계가 20,000원 이상이면 3,000원, 아니면 0원
        return self.amount if total >= self.min_total else 0
```

### cart.py

```python
from product import Product
from coupon import Coupon, RateDiscount

class Cart:
    def __init__(self):
        # 빈 장바구니 생성
        self.items = {} # {상품: 수량}
        self.coupon = Coupon("쿠폰 없음") # 처음엔 쿠폰 없음

    # 장바구니에 상품 담기
    def add(self, product, qty):
        # 1개 이상만 담을 수 있다.
        if qty <= 0:
            print("1개 이상 담아 주세요.")
            return

        # 품절 상품은 담을 수 없다.
        if product.is_sold_out():
            print("품절된 상품입니다.")
            return

        # 이미 장바구니에 담겨있는 수량
        in_cart_qty = self.items.get(product, 0)
        # 더 담을 수 있는 수량
        extra_qty = product.stock - in_cart_qty
        if qty > extra_qty: # 재고 수량 범위를 벗어난 경우
            print(f"재고가 부족합니다. (담을 수 있는 수량: {extra_qty}개)")
            return

        self.items[product] = self.items.get(product, 0) + qty
        print(f"{product.name} {qty}개를 담았습니다.")

    # 장바구니에서 상품 제거(빼기)
    def remove(self,product, qty):

        if product not in self.items:
            print("장바구니에 해당 상품이 없습니다.")
            return

        # 담은 수량 이상 빼면 상품을 통째로 삭제
        if qty >= self.items[product]:
            del self.items[product]
            print(f"{product.name}을 장바구니에서 모두 뺐습니다.")
        else:
            self.items[product] -= qty
            print(f"{product.name} {qty}개를 뺐습니다.")

    # 장바구니 비었는지 확인
    def is_empty(self):
        return len(self.items) == 0

    # 상품 합계 계산
    def subtotal(self):
        return sum(p.price * q for p, q in self.items.items())

    # 쿠폰 적용 (한 번에 1장)
    def apply_coupon(self, coupon):
        self.coupon = coupon
        print(f"[{coupon.name}] 쿠폰을 적용했습니다.")

    # 할인 금액 (쿠폰 종류는 묻지 않는다)
    def discount(self):
        return self.coupon.discount_amount(self.subtotal())

    # 배송비 (할인을 뺀 금액으로 정한다)
    def shipping(self):
        if self.is_empty(): return 0
        return 0 if self.subtotal() - self.discount() >= 30_000 else 3_000

    # 결제 금액 계산
    def total(self):
        return self.subtotal() - self.discount() + self.shipping()

    # 장바구니 내용 출력
    def show(self):
        line = "-" * 40
        print(line)

        if self.is_empty():
            print("장바구니가 비어있습니다.")

        for p, q in self.items.items():
            # 제품명 가격 x 수량 = 총합계
            print(f"{p.name:<10} x {q} = {p.price * q:>12,}원")

        print(line)
        print(f"{'상품 합계':<10} {self.subtotal():>15,}원")
        print(f"{'할인':<10} {-self.discount():>15,}원  [{self.coupon.name}]")
        print(f"{'배송비':<10} {self.shipping():>15,}원")
        print(f"{'결제 금액':<10} {self.total():>15,}원")
        print(line)

    # 결제
    def checkout(self):
        if self.is_empty():
            print("장바구니가 비어있습니다.")
            return

        print("[영수증]")
        self.show()
        # 재고 감소 처리
        for p, q in self.items.items():
            p.stock -= q

        # 장바구니 비우기
        self.items.clear()
        # 쿠폰 초기화
        self.coupon = Coupon("쿠폰 없음")

        # 결제 성공여부
        print("결제가 완료되었습니다. 감사합니다!")

#테스트 코드=========================================
if __name__ == "__main__":
    # 제품 인스턴스 생성
    tumbler = Product("텀블러", 15_000, 10)
```

## 오늘 꼭 기억할 주의점

- 한 값에는 한 가지 뜻만 담아요. 재고와 담은 수량을 같은 변수에 두면 서로 덮어써요.
- 리스트나 딕셔너리에 객체를 넣어도 복사되지 않아요. 두 곳이 같은 객체를 가리키면 한쪽에서 바꾼 값이 다른 쪽에도 보여요.
- 장바구니는 딕셔너리 `{상품: 수량}` 하나로 충분해요. 키가 상품 객체라 `p.price`, `p.stock`을 바로 꺼내요.
- `dict.get(키, 0)`은 처음 담는 상품도 `KeyError` 없이 0부터 세게 해 줘요.
- 담을 수 있는 수량은 `재고 - 이미 담은 수량`이고, 재고는 결제할 때만 줄여요.
- 모든 객체가 같이 보는 값은 클래스 변수, 객체마다 다른 값은 인스턴스 변수예요. 자동 번호는 저장 먼저, 올리기 나중이에요.
- 클래스 변수는 `클래스이름.변수`로 바꿔요. `객체.변수 = 값`은 새 속성을 만들어 가려요.
- 수량 같은 입력은 받는 쪽(메서드)에서도 0과 음수를 막아요.
- 파일마다 테스트는 `if __name__ == "__main__":` 아래에 둬요. 안 그러면 `import`만 해도 돌아요.
- 부모 클래스로 공통 틀을 정하고 자식이 오버라이딩하면, 부르는 쪽은 종류를 몰라도 돼요(다형성). 자식의 `__init__`은 `super().__init__()`으로 부모 몫을 맡겨요.
- 자식 `__init__`에서 받은 값은 `self`에 저장해야 다른 메서드에서 쓸 수 있어요. 메서드 몸통이 `pass`뿐이면 `None`을 돌려줘요.
- "없음"도 객체로 두면(`Coupon("쿠폰 없음")`) `None` 검사가 사라져요.
- 배송비는 할인 뒤 금액으로 정해요. 발제 예시의 숫자(313,000원, 5,000원, 0원, 308,000원)로 직접 확인해요.
- 입력 검사 `while` 안에서는 반드시 `input()`을 다시 받아요.

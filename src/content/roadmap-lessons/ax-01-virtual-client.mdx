## 왜 화장품 D2C인가

가상 고객사가 있어야 세팅에 이유가 생깁니다. "이 회사는 왜 이 문의가 많고, 무엇을 자동으로 넘기면 상담원이 덜 지치나"를 물을 수 있으니까요.

업종은 공개 데이터로 골랐습니다.

| 후보 | 쓸 수 있는 공개 데이터 | 판단 |
| --- | --- | --- |
| 화장품 D2C | Kaggle REES46 화장품 쇼핑몰 이벤트 로그(조회, 장바구니, 장바구니 빼기, 구매) | 장바구니 이탈이 있어 CRM 연습에 맞다 |
| 의류 | H&M 구매 데이터 3,100만 건 | 구매 기록만 있고 비상업 조건, 너무 크다 |

화장품은 문의 내용도 좋습니다. 배송과 환불 같은 쇼핑몰 공통 문의에, "이거 써도 되나요" 같은 제품 문의와 피부 트러블이 섞여요. ALF가 답해도 되는 것과 사람이 받아야 하는 것의 경계가 분명하게 생깁니다.

한국어 상담 문의 데이터는 업종과 상관없이 공개된 것이 없어서 직접 만듭니다. 영어 Bitext 고객 지원 데이터(2.7만 건, 의도 27개)는 문의 분류 체계를 잡는 참고로만 씁니다.

## 회사 한 장

아래 숫자는 모두 **가상**입니다. 세팅과 리포트에서 계산이 되도록 그럴듯하게 정했어요.

| 항목 | 값 |
| --- | --- |
| 이름 | 늘결 (가상 브랜드) |
| 무엇을 파나 | 민감 피부용 기초 화장품, 자사몰에서만 판매 |
| 시작 | 2021년 |
| 직원 | 18명, 그중 CS 3명(팀장 1, 상담원 2) |
| 월 주문 | 약 9,000건 |
| 월 문의 | 약 2,400건 |
| 문의 채널 | 자사몰 채팅(채널톡), 카카오 상담톡, 전화(평일 오전만) |
| 상담 시간 | 평일 10:00~17:00, 점심 12:30~13:30 |
| 브랜드 말투 | 차분하고 짧게, 존댓말, 과장 없음 |

상담원 두 명이 하루 약 110건을 나눠 받는 셈입니다(2,400건, 한 달 22일 근무). 이 숫자가 2단계에서 "어디를 줄여야 하나"의 출발점이 돼요.

## 운영 정책

ALF 지식의 원재료가 되는 칸입니다. 실제 쇼핑몰 FAQ는 **구조만** 참고했고, 문장과 값은 새로 정했습니다.

### 주문과 배송

- 평일 오후 2시 전 결제는 당일 출고, 이후는 다음 영업일 출고.
- 택배는 한 곳(가상 택배사), 출고 후 보통 1~2일 안에 도착.
- 3만 원 이상 무료 배송, 미만은 배송비 3,000원.
- 제주와 도서산간은 3,000원 추가.
- 주문 취소는 출고 전까지 마이페이지에서 직접. 출고 뒤에는 반품으로 처리.
- 주소 변경은 출고 전까지 상담으로만.

### 교환, 반품, 환불

- 단순 변심: 받은 날부터 7일 안, **개봉하지 않은 상품만**. 왕복 배송비 6,000원은 고객 부담.
- 상품 불량, 오배송, 상세 페이지와 다른 상품: 받은 날부터 3개월 안, 그 사실을 안 날부터 30일 안. 배송비는 늘결 부담.
- 개봉한 상품의 단순 변심은 반품 불가.
- 환불 시점: 반품 상품이 창고에 도착해 확인된 뒤. 카드는 취소 후 3~5영업일, 적립금은 바로.

위 기간은 전자상거래법의 청약철회 기준에 맞춘 것입니다. 실제 세팅 전에 국가법령정보센터에서 조문을 한 번 더 확인합니다.

### 피부 트러블 (늘결 자체 정책)

- 사용 후 30일 안, 트러블 부위 사진을 보내면 사용량과 상관없이 1회 환불.
- 피부과 소견서는 선택. 있으면 같은 상품 재구매 시 상담원이 성분 확인을 돕는다.
- 붓기가 심하거나 숨쉬기 불편하다는 말이 있으면 **환불 안내보다 병원 안내가 먼저**, 바로 사람이 받는다.

법보다 넓게 받아 주는 정책이라 "민감 피부 브랜드"라는 성격과 맞습니다. 대신 이 문의는 ALF가 끝까지 처리하지 않고 접수까지만 합니다.

### 정기배송

- 진정 토너와 수분 장벽 크림, 4주 또는 8주 주기, 10% 할인.
- 다음 결제 3일 전까지 건너뛰기, 주기 변경, 해지 가능. 해지 위약금 없음.

### 적립금과 쿠폰

- 구매 금액의 2% 적립, 유효기간 1년.
- 쿠폰은 한 주문에 하나, 적립금과 함께 쓸 수 있음.

## 사람이 받아야 하는 문의

ALF가 답을 알더라도 사람에게 넘기는 기준입니다. 3단계 규칙으로 옮깁니다.

| 신호 | 왜 사람인가 | 넘길 곳 |
| --- | --- | --- |
| 붓기, 호흡 곤란, 심한 통증 | 안전이 먼저 | 팀장, 즉시 |
| 같은 주문이 두 번 결제됨 | 돈이 걸린 확인 작업 | 상담원 |
| 소비자원, 신고, 고소 같은 말 | 말 한마디가 분쟁이 된다 | 팀장 |
| 욕설, 같은 불만 세 번째 | 감정 대응은 사람이 낫다 | 상담원 |
| 대량 구매, 입점, 제휴 | 영업 기회 | 팀장 |

## 문의는 어떻게 나뉘나

월 2,400건을 이렇게 나눴다고 정합니다. Bitext 의도 분류와 일반적인 화장품 쇼핑몰 FAQ 메뉴 구조를 보고 비율은 직접 정했어요.

| 유형 | 비율 | 월 건수 | ALF로 끝낼 수 있나 |
| --- | --- | --- | --- |
| 배송 조회, 출고일 | 30% | 720 | 대부분 가능 |
| 교환, 반품, 환불 | 22% | 528 | 안내는 가능, 접수는 사람 |
| 제품 사용법, 성분 | 18% | 432 | 지식이 있으면 가능 |
| 주문 변경, 취소 | 10% | 240 | 출고 전이면 안내 가능 |
| 피부 트러블 | 8% | 192 | 접수까지만 |
| 정기배송 | 6% | 144 | 안내는 가능 |
| 결제, 적립금, 쿠폰 | 4% | 96 | 일부 가능 |
| 기타(제휴, 불만 등) | 2% | 48 | 사람 |

이 표의 비율은 가정입니다. 4단계에서 시험 문의를 직접 만들 때 이 비율로 뽑고, 리포트에서도 "가정한 분포"라고 밝힙니다.

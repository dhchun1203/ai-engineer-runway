## 왜 따로 갈래를 만드나

채널톡 AX팀이 **AX Consultant**를 뽑고 있습니다. 정규직이고 주니어부터 시니어까지 열려 있어요.

이 로드맵의 나머지는 Applied AI Engineer 기준입니다. 모델, RAG, 평가를 코드로 다루는 사람이죠. AX Consultant는 고객사 안으로 들어가 채널톡 제품으로 상담과 마케팅을 바꿔 주는 사람입니다.

겹치는 부분은 있지만 하루의 모양이 다릅니다. 그래서 교육과정과 별개로, 이 갈래를 따로 채워 나갑니다.

## 공고 문장을 할 일로

공고 문장 하나마다 "내가 무엇을 보여 줄 수 있나"를 붙였습니다. 오른쪽 칸이 이 트랙에서 만들 증거입니다.

| 공고 문장 | 무게 | 이 트랙에서 만들 것 |
| --- | --- | --- |
| CS/CX 도메인 이해 | 필수 | 상담 지표와 흐름 정리(2단계) |
| 챗봇, 자동화 시나리오 구축 운영 | 필수 | ALF 지식, 규칙, 워크플로우 세팅(1, 3단계) |
| 마케팅 실무 하나 이상 | 필수 | 내 서비스 구독자로 CRM 캠페인(6단계) |
| 생성형 AI를 업무에 적용 | 필수 | 고치기 전후 숫자가 있는 ALF 채점표 |
| 데이터로 문제 정의, 리포트 | 필수 | 상담 데이터 진단 리포트(4단계) |
| 비전문가와 소통 | 필수 | 고객사 담당자용 한 장 요약 |
| ALF, 워크플로우, 태스크 직접 세팅 | 최고 우대 | 트라이얼 14일 동안 직접 세팅한 화면 |
| API, 웹훅, DB, n8n 같은 도구 | 우대 | 웹훅에서 시트까지 가는 흐름(5단계) |
| 콜센터 지표(IVR) | 우대 | 용어만 익히기(7단계) |

절차는 서류, 1차 AX팀 리드의 직무 기술 면접, 2차 사업 총괄의 컬처핏입니다. 1차에서 "직접 세팅해 봤나"를 물을 가능성이 가장 큽니다.

## 정직하게 비어 있는 칸

CS팀을 실제로 운영해 본 경력은 없습니다. 마케팅 실무 경력도 없습니다.

이 둘은 가상 고객사로 채워지지 않아요. 가상 고객사로 보여 줄 수 있는 것은 "세팅하고, 재고, 고치는 힘"까지입니다. 면접에서도 그렇게 말합니다.

현장 경력의 빈칸을 메울 가장 큰 기회는 교육과정 후반의 기업연계 프로젝트입니다. 그때 CS나 CX 조직이 있는 회사를 고르는 것이 이 트랙의 숨은 목표예요.

## 일곱 순서

1. **채널톡 직접 세팅.** 가상 고객사 하나를 정해 놓고 채널을 만든다.
2. **CS/CX 지표와 흐름.** 첫 응답 시간, 해결률, 재문의율 같은 숫자와 상담이 흘러가는 길.
3. **ALF 지식과 시나리오.** 교육과정의 RAG와 같은 원리다. 지식을 넣고, 시험지로 재고, 고친다.
4. **상담 데이터 진단 리포트.** 문의를 유형으로 나누고, 어디서 사람이 낭비되는지 숫자로 보인다.
5. **API, 웹훅, n8n.** 상담에서 생긴 사건을 다른 도구로 흘려보낸다.
6. **CRM 마케팅.** 구독자가 있는 내 서비스로 진짜 캠페인을 한 번 돌린다.
7. **콜센터와 Voice.** 용어만. 깊이 갈 시간은 없다.

결과물은 하나로 묶습니다. **"가상 고객사 AX 도입 케이스"**, 문제 정의부터 세팅, 숫자, 다음 제안까지 이어진 한 묶음이에요.

## 언제 트라이얼을 켜나

채널톡 요금 안내(2026-11-17 확인)로 보면 두 가지 길이 있습니다.

| | 무료+ | 트라이얼 14일 |
| --- | --- | --- |
| ALF | 월 100세션 | 가능 |
| 지식 | 액티브 3개 | 가능 |
| 워크플로우, 마케팅 캠페인 | 각 3개 | 가능 |
| 태스크, 프로시저 | 불가 | 10개 |
| 웹훅 | 불가 | 가능 |
| Open API | 불가 | 불가 |

태스크와 웹훅은 공고의 최고 우대 항목인데, 트라이얼에서만 열립니다. 14일은 한 번뿐이라 아껴야 해요.

그래서 순서는 이렇습니다. 무료+로 지식과 시험지를 먼저 돌리고, 태스크와 웹훅 설계도를 다 그린 다음 트라이얼을 켭니다. 14일은 만들기만 하는 기간으로 씁니다.

계정을 만들고 결제 수단을 넣는 일은 내가 직접 합니다.

## 지금 어디까지 왔나

- 가상 고객사: **화장품 D2C 브랜드** "늘결"로 정했다. 설정서는 01편.
- ALF 지식 3개, 규칙 1개, 문의 30개 시험지: 원고는 02편에 있다. 무료+로 1회차 채점이 다음 할 일이다.
- 3단계(ALF)를 2단계보다 먼저 손댄 이유: 무료+로 지금 바로 해 볼 수 있고, 채점 숫자가 2단계 지표 공부의 재료가 된다.
- 트라이얼: 아직 켜지 않았다.

## 1. 학습 목표

이 레슨을 마치면 다음을 알아듣습니다.

- 파인튜닝(fine-tuning, 모델을 특정 목적에 맞게 다시 학습시키는 것)이 무엇을 하는 작업인지 한 문장으로 말할 수 있다
- PEFT·LoRA·QLoRA가 각각 무엇이고 왜 등장했는지 말할 수 있다
- 언제 프롬프트·RAG 대신 튜닝을 고려하는지 말할 수 있다
- 튜닝이 전체 파이프라인에서 어느 자리에 놓이는지 안다

## 2. 왜 배우나

프롬프트와 RAG로 대부분의 문제가 풀리지만, 조직 특유의 말투나 형식을 모델이 전혀 모르는 경우처럼 남는 문제가 있습니다.

튜닝은 이럴 때 쓰는 마지막 카드이며, 비용과 시간이 많이 듭니다. 그래서 먼저 알아야 할 것은 언제 튜닝을 쓰지 않아야 하는가입니다.

## 3. 개념 설명

### 🏗️ 전체 파인튜닝 — 건물을 통째로 다시 짓기

전체 파인튜닝(full fine-tuning)은 모델의 모든 가중치를 다시 학습시키는 방법입니다. 건물을 통째로 허물고 다시 짓는 것과 비슷해서, 시간과 비용이 크게 듭니다.

### 🎯 PEFT — 인테리어만 바꾸기

PEFT(Parameter-Efficient Fine-Tuning, 모델의 일부만 손대는 효율적인 튜닝 방식)는 건물은 그대로 두고 인테리어만 바꾸는 것과 비슷합니다. 모델 전체가 아니라 아주 일부만 학습시킵니다.

### 🧥 LoRA — 옷 위에 덧입는 조끼

LoRA(Low-Rank Adaptation)는 PEFT의 대표 기법입니다. 원본 가중치는 그대로 얼려두고(freeze), 그 위에 작은 어댑터(adapter, 원본 위에 덧붙여 학습하는 작은 층) 층만 새로 학습합니다. 옷을 갈아입지 않고 조끼 하나만 덧입는 것과 같습니다.

### 📦 QLoRA — 짐을 진공 압축해 작은 가방에 넣기

QLoRA(Quantized LoRA)는 모델을 양자화(quantization, 숫자 표현을 더 작은 크기로 압축하는 것)로 먼저 압축한 뒤 LoRA를 적용하는 방식입니다. 짐을 진공 압축해 더 작은 가방에 담는 것과 비슷해서, 더 적은 자원으로도 튜닝할 수 있습니다.

### 🧭 언제 튜닝 대신 프롬프트·RAG로 푸는가

| 상황 | 권장 접근 |
|------|---------|
| 모델이 이미 아는 지식이고 지시만 명확히 하면 되는 경우 | 프롬프트 |
| 모델이 모르는 최신·사내 정보를 찾아 붙여줘야 하는 경우 | RAG |
| 프롬프트·RAG로도 조직 특유의 말투·형식을 못 맞추는 경우 | PEFT 튜닝 |

파이프라인에서의 자리는 다음과 같습니다.

`문제 정의 → 프롬프트로 해결 시도 → RAG로 지식 보강 → 그래도 안 되면 PEFT 튜닝 → 평가`

## 4. 실무 예제

### 실무에서 이게 어떻게 쓰이나

한 조직은 고객 상담 답변의 말투와 금지 표현을 사내 기준에 맞추려고 소규모 모델에 LoRA 어댑터를 얹었습니다. 프롬프트만으로는 매번 같은 규칙을 다 지키게 만들기 어려웠기 때문입니다.

또 다른 사례는 특정 산업 용어가 많은 문서 요약입니다. 일반 모델은 업계 용어를 어색하게 풀어 쓰는데, 그 업계 문서로 튜닝한 모델은 용어를 자연스럽게 그대로 씁니다.

> 아래 코드는 개념을 눈으로 보기 위한 예시입니다 — 지금 실행할 필요는 없습니다.
> 개강 후 본 과정에서 실제로 다뤄보게 됩니다.

```python
# 개념 예시 — LoRA 어댑터를 선언하는 설정 조각입니다.
from peft import LoraConfig

config = LoraConfig(
    r=8,                                   # 어댑터 층의 크기를 나타내는 값
    lora_alpha=16,                         # 어댑터가 결과에 반영되는 정도를 나타내는 값
    target_modules=["q_proj", "v_proj"],   # 어댑터를 붙일 원본 모델의 부분
    lora_dropout=0.05,                     # 학습 중 일부를 무작위로 끄는 비율
    bias="none",                           # 편향(bias) 값은 그대로 둔다는 표시
    task_type="CAUSAL_LM",                 # 이 모델이 어떤 작업에 쓰이는지
)
# 원본 가중치는 얼려두고, 위 설정으로 만든 작은 어댑터 층만 학습합니다.
```

## 5. 실무 팁

- 튜닝 전에 평가셋부터 만들어 둡니다. 무엇이 좋아졌는지 판단할 기준이 없으면 튜닝 여부를 결정할 수 없습니다(다음 편에서 다룹니다).
- 기법 선택보다 데이터 품질이 결과를 더 크게 좌우합니다.
- 어댑터는 크기가 작아서 용도별로 여러 개를 만들어 갈아 끼울 수 있습니다.
- 학습 데이터에 개인정보가 섞이면 모델이 그것을 그대로 기억할 수 있습니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 전체 파인튜닝은 모델 전체를 다시 학습시키는 것이고, PEFT는 일부만 손대는 방식이다
- LoRA는 원본 가중치를 얼리고 작은 어댑터 층만 학습하는 PEFT 기법이다
- QLoRA는 모델을 압축한 뒤 LoRA를 적용해 더 적은 자원으로 튜닝하는 방식이다
- 튜닝은 프롬프트·RAG로 안 되는 경우에 쓰는 마지막 카드다
- 이 레슨의 코드는 읽기용이며, 실제로 다뤄보는 것은 개강 후 본 과정에서다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 파인튜닝 | 모델을 특정 목적에 맞게 다시 학습시키는 것 |
| PEFT | 모델 전체가 아니라 일부만 학습하는 효율적인 튜닝 방식 |
| LoRA | 원본 가중치는 얼려두고 작은 어댑터 층만 학습하는 PEFT 기법 |
| QLoRA | 모델을 압축한 뒤 LoRA를 적용하는 방식 |
| 어댑터 | 원본 모델 위에 덧붙여 학습하는 작은 층 |
| 양자화 | 모델의 숫자 표현을 더 작은 크기로 압축하는 것 |
| 베이스 모델 | 튜닝하기 전 원본 모델 |

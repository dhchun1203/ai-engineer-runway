## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- 전체 커리큘럼이 Step 1 → Step 2 → Step 3 순서로 어떻게 이어지는지 설명할 수 있다
- 이 사이트에서 오늘 배정된 레슨을 찾아 완료 표시를 남길 수 있다
- `/schedule`에서 자신의 학습이 일정보다 앞서는지 뒤처지는지 확인할 수 있다
- 하루 학습 루틴(읽기·실습 시간 배분)을 자기 하루 일정에 맞춰 계획할 수 있다

## 2. 왜 배우나

이 사전학습 사이트의 목적은 커리큘럼을 통달하는 것이 아니라 개강 전에 기초를 다지는 것입니다. 지도를 먼저 보면 뒤에 만날 각 레슨이 전체 여정에서 어디쯤 있는지 알 수 있고, 낯선 용어가 나와도 당황하지 않습니다.

사이트 사용법과 하루 루틴을 먼저 익혀두면 첫 실습부터 헤매지 않고 바로 시작할 수 있습니다. 지도를 손에 쥐고 출발하는 것과 무작정 걷는 것은 완주 확률이 다릅니다.

### 🎒 실습 프로젝트 5종이 지도에서 하는 일

## 4. 실무 예제

아래는 하루 학습을 마칠 때마다 채우는 학습 기록 템플릿입니다. 코드는 아니지만 그대로 복사해서 씁니다.

```text
오늘 배운 것: (예: Python 변수와 자료형, if/for 기본 문법)
막힌 것: (예: f-string과 문자열 덧셈의 차이가 헷갈렸다)
내일 할 일: (예: 오늘 헷갈린 부분 다시 읽고 다음 레슨 시작)
```

이 템플릿을 둘 곳은 메모 앱, 노션, 아니면 저장소 안 `.md` 파일 어디든 상관없습니다. 중요한 것은 매일 같은 자리에 3줄을 남겨서, 나중에 막혔던 부분을 빠르게 다시 찾아볼 수 있게 하는 것입니다.

## 5. 실무 팁

- **완료 체크는 미루지 마세요.** 진행률과 페이스 상태는 오직 완료 버튼을 누른 기록으로만 계산됩니다.
- **밀려도 일정은 자동으로 밀리지 않습니다.** 일정표의 날짜는 고정이고, 밀린 레슨 목록만 홈 화면이 따로 보여줍니다.
- **이해가 안 되는 절은 표시만 하고 넘어가세요.** 완벽히 이해하지 못해도 다음 레슨으로 넘어가고, 나중에 다시 돌아와 확인하면 됩니다.
- **읽기는 아이패드, 실습은 PC로 나눠 쓰면 편합니다.** 이동 중에는 아이패드로 읽고, 코드를 직접 치고 실행할 때는 PC 앞에 앉는 식으로 기기를 나눠 쓰세요.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 커리큘럼은 Step 1 → 2 → 3 순서로 이어지며 총 19개 모듈·35편의 레슨·5종의 실습 프로젝트로 구성된다
- 실습 프로젝트 5종은 이 사이트에서 개요·사전 준비 가이드로만 제공된다
- 홈 화면에서 오늘 배정된 레슨을 확인하고, 본문 끝 완료 버튼으로 진행률에 반영한다
- 날짜별 레슨 배정은 `/schedule`이 유일한 기준이다
- 하루 1레슨, 읽기 30분 + 실습 120분 배분으로 진행하고 밀리면 사이트가 계산해 알려준다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| Step | 커리큘럼을 이루는 3개의 큰 단계 |
| 모듈 | Step 안에서 주제로 묶인 학습 단위 |
| 레슨 | 모듈 안의 개별 학습 콘텐츠 한 편 |
| 심화 | 코드를 직접 실습하며 깊게 다루는 레슨 깊이 |
| 개요 | 개념과 흐름 위주로 훑어보는 레슨 깊이 |
| D-day | 개강일까지 남은 날짜 수 |
| 진행률 | 완료한 레슨이 전체에서 차지하는 비율 |
| 페이스 | 오늘 기준 학습이 일정보다 앞서는지 뒤처지는지 나타내는 상태 |

## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- VS Code·Python·Git·GitHub 계정·Supabase 계정 다섯 가지를 설치·가입할 수 있다
- 각 도구가 정상적으로 설치됐는지 확인 명령으로 검증할 수 있다
- Windows에서 `python` 명령이 먹통일 때 무엇을 의심해야 하는지 안다
- 앞으로 이어질 실습 8편이 이 다섯 도구를 어떤 순서로 쓰는지 설명할 수 있다

## 2. 왜 배우나

이 다섯 가지는 뒤따르는 8편의 실습이 딛고 서는 바닥입니다. 편집기가 없으면 코드를 칠 곳이 없고, Python이 없으면 실행할 곳이 없고, Git·GitHub 계정이 없으면 1-2의 협업 실습을 할 수 없고, Supabase 계정이 없으면 1-4의 SQL 실습을 할 수 없습니다.

지금 한 번에 갖춰두면 뒤 레슨에서 "설치부터 해야 하나" 하고 흐름이 끊기는 일이 없습니다.

## 4. 실무 예제

VS Code·Python·Git이 정상 설치됐는지 아래 세 명령으로 한 번에 확인합니다.

<PredictPrompt />

```powershell
code --version
py --version
git --version
```

`code --version`은 버전 번호·커밋 해시·아키텍처 세 줄을 출력하면 정상입니다. `py --version`은 `Python 3.12.x` 형태(예: `Python 3.12.10`)로 나오면 정상입니다.

`git --version`은 `git version 2.x.x.windows.1` 형태(예: `git version 2.52.0.windows.1`)로 나오면 정상입니다.

macOS는 `python3 --version`으로 Python 버전을 확인합니다.

GitHub·Supabase는 실행 확인 명령이 없습니다 — 가입 후 각 사이트에 로그인된 화면이 보이면 설치·가입이 끝난 것입니다.

## 5. 실무 팁

- **`python`을 쳤는데 Microsoft Store가 열리거나 아무 반응이 없다면 `py`를 대신 쓰세요.** Windows 11은 기본으로 `python`/`python3` 앱 실행 별칭을 켜 두는데, 실제 설치된 Python을 두고 이 별칭이 먼저 걸리는 경우가 흔합니다. 이럴 때 `python --version`을 아무리 실행해도 반응이 없거나 스토어가 열립니다. Windows 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 `python.exe`/`python3.exe`를 꺼도 해결됩니다.
- **설치 중 "Add to PATH" 옵션은 항상 체크합니다.** Python 설치 화면에서 이 옵션을 놓치면 `py` 런처조차 인식되지 않을 수 있습니다.
- **VS Code에는 Python 확장을 설치해 둡니다.** 문법 강조와 자동완성이 실습 속도를 크게 올려줍니다.
- **GitHub·Supabase 비밀번호는 비밀번호 관리자에 저장해 둡니다.** 1-2, 1-4 실습에서 계속 로그인해야 하므로 매번 새로 찾지 않도록 미리 관리해 두면 편합니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 다섯 공구(VS Code·Python·Git·GitHub 계정·Supabase 계정)는 뒤 8편 실습의 전제다
- `code --version`·`py --version`·`git --version` 세 명령으로 설치 상태를 확인한다
- Windows는 `python` 대신 `py`가 1차 안내다 — 앱 실행 별칭 때문에 `python`이 먹통일 수 있다
- GitHub·Supabase는 로그인된 화면이 보이면 준비가 끝난 것이다
- macOS는 `python3` 명령으로 확인한다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 편집기 | 코드를 작성하는 프로그램 |
| 런타임 | 코드를 실제로 돌리는 실행 환경 |
| 버전 관리 | 코드가 바뀐 과정을 기록하는 도구 |
| 저장소 | 코드를 모아 관리하는 보관 공간 |
| 터미널 | 명령을 글자로 입력해 실행하는 화면 |
| PATH | 명령 실행 시 프로그램을 찾는 폴더 목록 |
| 앱 실행 별칭 | Windows가 특정 명령을 자동으로 다른 프로그램(예: 스토어)으로 연결하는 설정 |

<details>
<summary>정답 보기</summary>

"찾을 수 없는 명령입니다" 같은 오류가 나며 실행되지 않습니다. `git clone`·`git commit` 같은 명령은 내 PC에 설치된 Git 프로그램이 실행하기 때문입니다.

GitHub 계정은 원격 저장소 로그인·저장소 생성만 가능하게 해줄 뿐 명령 실행과는 무관합니다. `git --version`으로 설치를 먼저 확인해야 합니다.

</details>

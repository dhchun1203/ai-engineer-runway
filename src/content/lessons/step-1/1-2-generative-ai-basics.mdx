## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- 생성형 AI가 무엇을 하는 도구인지 비유로 설명할 수 있다
- 공식 SDK로 최소 호출 코드를 작성해 실행할 수 있다
- API 키를 코드에 넣지 않고 환경변수로 다룰 수 있다
- AI에 맡길 일과 사람이 검증해야 할 일을 구분해 판단할 수 있다

## 2. 왜 배우나

이 커리큘럼 전체의 주제가 바로 생성형 AI를 활용한 서비스를 만드는 것입니다. 지금 여기서 배우는 API 호출 한 번이 Step 2 전체에서 반복해서 쓰일 기본 동작입니다.

특히 API 키를 다루는 습관은 이 레슨에서 처음 만들어지고, 이후 모든 레슨이 그 습관을 그대로 물려받습니다. 그래서 개념보다 "키를 어떻게 안전하게 다루는가"가 이 레슨에서 가장 중요합니다.

## 3. 개념 설명

### 🔮 아주 똑똑해진 자동완성

생성형 AI(generative AI, 새로운 텍스트·이미지 등을 만들어내는 AI)는 스마트폰 자판의 "다음 단어 추천" 기능이 아주 똑똑해진 것이라고 생각하면 이해하기 쉽습니다. 모델(model, 학습된 AI 프로그램 자체)은 지금까지 나온 글을 보고 "다음에 올 확률이 가장 높은 말"을 계속 골라 이어 붙입니다.

확률로 고르기 때문에 문법도 맞고 그럴듯하게 들리지만 사실은 틀린 답이 나올 수 있습니다 — 이를 할루시네이션(hallucination, AI가 사실이 아닌 내용을 그럴듯하게 지어내는 현상)이라고 부릅니다. "말이 되는 것"과 "사실인 것"은 다른 문제라는 걸 항상 기억해야 합니다.

### ⚖️ 맡길 일과 검증할 일

생성형 AI 윤리는 "무엇을 하면 안 된다"는 원칙 목록보다, "무엇을 맡겨도 되고 무엇을 사람이 다시 확인해야 하는가"라는 판단 기준으로 이해하는 것이 실무에서 훨씬 유용합니다.

| 맡겨도 되는 일 | 반드시 사람이 확인할 일 |
|----------------|--------------------------|
| 초안 작성, 문장 다듬기 | 사실 확인, 수치·통계 |
| 요약, 번역 | 법적·의료적 판단 |
| 코드 뼈대(보일러플레이트) 생성 | 저작권이 걸린 원문 그대로 복제 여부 |
| 아이디어 브레인스토밍 | 개인정보가 섞여 나오는지 여부 |

AI는 그럴듯한 근거나 출처를 실제로 존재하지 않는데도 만들어낼 수 있습니다(할루시네이션). 그래서 AI가 제시한 사실·수치·출처는 항상 사람이 별도로 확인해야 하는 항목으로 분류해야 합니다.

## 4. 실무 예제

아래는 공식 `anthropic` SDK로 Claude API를 한 번 호출하는 최소 예제입니다. API 키가 없다면 코드를 건너뛰고 아래 대체 경로로 바로 넘어가도 됩니다.

<PredictPrompt />

```python
# claude_hello.py
# 환경변수 ANTHROPIC_API_KEY에 API 키가 설정되어 있어야 합니다.
# 키가 없다면 아래 "키 없이 실습하기"로 바로 넘어가세요.

import os
from anthropic import Anthropic

client = Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))

response = client.messages.create(
    model="claude-opus-5",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "생성형 AI를 한 문장으로 설명해줘."}
    ],
)

for block in response.content:
    if block.type == "text":
        print(block.text)
```

**실행 방법:**

```powershell
pip install anthropic
$env:ANTHROPIC_API_KEY = "여기에_발급받은_키"
py claude_hello.py
```

macOS는 환경변수를 `export ANTHROPIC_API_KEY="여기에_발급받은_키"`로 설정하고 `python3 claude_hello.py`로 실행합니다.

실행하면 터미널에 Claude가 생성형 AI를 한 문장으로 설명한 답변 텍스트가 출력됩니다. 답변 내용은 매번 조금씩 달라질 수 있습니다 — 같은 질문이라도 확률로 다음 말을 고르기 때문입니다.

**키 없이 실습하기.** API 키가 없어도 이 레슨의 해보기를 끝낼 수 있습니다.

위 코드의 프롬프트("생성형 AI를 한 문장으로 설명해줘.")를 그대로 복사해 [claude.ai](https://claude.ai) 같은 채팅 화면에 붙여 넣고 결과를 받아보세요. API와 채팅 UI가 같은 모델을 쓰는지 답변의 말투·길이를 비교해보는 것도 좋은 관찰 포인트입니다.

## 5. 실무 팁

- **키를 코드 파일이나 저장소에 넣지 않습니다.** 한 번이라도 커밋되면 이력에 남아 지우기 어렵습니다 — 항상 환경변수로만 다룹니다.
- **설치 패키지 이름과 import 이름이 다를 수 있습니다.** 이 예제는 `pip install anthropic`으로 설치하고 `from anthropic import Anthropic`으로 그대로 불러오지만, 다른 라이브러리는 설치명과 import명이 다른 경우가 흔합니다(예: `scikit-learn` 설치 후 `import sklearn`).
- **모델 ID는 시간이 지나며 바뀔 수 있습니다.** 이 레슨의 예제는 이 글을 쓴 시점 기준 모델 ID를 씁니다 — 최신 모델 ID는 항상 Anthropic 공식 문서에서 확인하세요.
- **답을 그대로 믿지 않습니다.** 특히 사실·수치·출처는 AI가 그럴듯하게 지어낼 수 있으므로(할루시네이션), 검증 대상을 미리 정해두고 확인하는 습관을 들입니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 생성형 AI는 다음에 올 확률이 가장 높은 말을 계속 골라 이어 붙이는 도구다
- 문법과 말투가 그럴듯해도 사실이 아닐 수 있다(할루시네이션)
- API 키는 오직 환경변수로만 다루고 코드나 저장소에 절대 적지 않는다
- 초안·요약·번역·코드 뼈대는 맡겨도 되지만, 사실·수치·법적/의료 판단은 사람이 검증한다
- 모델 ID는 공식 문서에서 최신 값을 확인해야 한다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 생성형 AI | 새로운 텍스트·이미지 등을 만들어내는 AI |
| 프롬프트 | AI에게 주는 질문이나 지시문 |
| 토큰 | 텍스트를 잘게 나눈 처리 단위 |
| 모델 | 학습된 AI 프로그램 자체 |
| API | 다른 프로그램이 AI 기능을 불러 쓸 수 있게 열어둔 통로 |
| 환경변수 | 코드 밖에서 값을 넣어두고 프로그램이 읽어가게 하는 설정 |
| 할루시네이션 | AI가 사실이 아닌 내용을 그럴듯하게 지어내는 현상 |

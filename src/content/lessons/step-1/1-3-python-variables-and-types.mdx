## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- Python 변수에 값을 저장하고, 이름을 짓는 규칙을 지켜 변수를 선언할 수 있다
- 정수(`int`)·실수(`float`)·문자열(`str`)·불리언(`bool`) 네 가지 기본 자료형을 구분하고 `type()`으로 직접 확인할 수 있다
- `if`/`elif`/`else`로 조건에 따라 다른 코드를 실행하는 조건문을 작성할 수 있다
- `for`로 리스트를 순서대로 순회하며 각 항목을 처리하는 반복문을 작성할 수 있다

## 2. 왜 배우나

변수·자료형·조건문·반복문은 이후 배울 함수·API 응답 처리·데이터 전처리 전부의 재료입니다. 값을 상자에 담고(변수), 상자 안 내용에 따라 갈림길을 타고(조건문), 여러 개를 한 번에 처리하는(반복문) 이 네 가지 없이는 어떤 실무 코드도 짜기 어렵습니다. 지금 확실히 다져두면 나중에 만나는 에러 메시지의 절반을 스스로 진단할 수 있습니다.

## 3. 개념 설명

### 📦 변수는 이름표 붙은 상자

변수(variable, 값을 담아두는 이름 붙은 공간)를 상자라고 생각하면 쉽습니다. 상자 안에 값을 넣고, 상자에 이름표를 붙이는 것이 변수 선언입니다.

Python은 상자를 만들기 전에 "이 상자엔 숫자만 담는다" 같은 선언을 하지 않습니다. 값을 넣는 순간 Python이 자동으로 자료형을 정합니다. 이를 동적 타이핑(dynamic typing, 값을 넣는 순간 자료형이 자동으로 정해지는 방식)이라고 부릅니다.

```python
age = 25          # 정수 상자
name = "지현"       # 문자열 상자
```

### 🎨 자료형 4종 — 상자마다 다른 내용물

| 자료형 | 이름 | 예시 | 일상 비유 |
|--------|------|------|-----------|
| `int` | 정수 | `25`, `-3`, `0` | 사람 수를 셀 때 — "3.5명"은 없다 |
| `float` | 실수(소수) | `175.5`, `3.14` | 체중계 숫자 — 소수점이 자연스럽다 |
| `str` | 문자열 | `"지현"`, `"안녕"` | 이름표에 적힌 글자 |
| `bool` | 불리언(참/거짓) | `True`, `False` | 스위치의 켜짐/꺼짐 상태 |

문자열은 반드시 따옴표로 감싸야 합니다 — `name = 지현`은 에러가 나지만 `name = "지현"`은 정상 동작합니다. 숫자와 문자열은 자동으로 섞이지 않으므로(`"나이: " + 25`는 에러), f-string(`f"나이: {25}"`)으로 조합해야 합니다.

<TwistBox>

`==`는 겉보기엔 "값이 같은가"만 묻는 것 같지만, Python은 자료형이 달라도 값만 같으면 `True`를 돌려줍니다. 아래 세 줄을 실행하기 전에 결과를 먼저 예측해보세요.

```python
print(True == 1)      # 예상?
print(1 == 1.0)       # 예상?
print("1" == 1)       # 예상?
```

`True == 1`과 `1 == 1.0`은 모두 `True`입니다 — `bool`은 내부적으로 `int`의 특별한 경우(`True`는 `1`, `False`는 `0`)이고, `int`와 `float`은 값만 같으면 자료형이 달라도 같다고 봅니다.

하지만 `"1" == 1`은 `False`입니다 — 문자열과 숫자는 값이 "같아 보여도" 서로 다른 세계라 자동으로 비교되지 않습니다.

</TwistBox>

### 🎢 반복문은 컨베이어벨트

공장 컨베이어벨트 위로 상자가 하나씩 흘러오고, 작업자는 상자마다 똑같은 작업을 반복합니다. 반복문(loop statement, 여러 값을 순서대로 처리하는 문법)이 이 역할을 합니다.

`for 항목 in 리스트:`는 리스트의 값을 하나씩 꺼내 같은 코드를 반복 실행합니다. 몇 번 반복할지 미리 정해져 있지 않고 "조건이 참인 동안" 계속 반복하고 싶을 땐 `while 조건:`을 씁니다.

## 5. 실무 팁

- **변수 이름은 의미를 담아서 짓습니다.** `a`, `temp1` 대신 `membership_status`처럼 무엇을 담고 있는지 알 수 있게 짓습니다.
- **숫자를 문자열에 직접 이어 붙이지 않습니다.** `"나이: " + str(25)`보다 `f"나이: {25}"`(f-string)가 더 짧고 안전합니다.
- **`type()`을 디버깅 도구로 활용합니다.** `TypeError`가 뜨면 관련 변수에 `print(type(변수명))`을 추가해 실제 자료형부터 확인합니다.
- **Windows에서는 `python` 대신 `py`를 씁니다.** `python`을 치면 Microsoft Store 화면이 열리거나 아무 반응이 없을 수 있습니다 — 실제 설치된 Python은 `py` 런처로 찾습니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- Python은 동적 타이핑이라 값을 넣는 순간 자료형이 자동으로 정해진다
- 기본 자료형 네 가지: `int`(정수), `float`(실수), `str`(문자열), `bool`(불리언)
- 조건문(`if`/`elif`/`else`)은 조건에 따라 다른 코드를 실행하는 갈림길이다
- 반복문(`for`)은 리스트의 값을 하나씩 꺼내 같은 코드를 반복하는 컨베이어벨트다
- 숫자와 문자열은 자동으로 섞이지 않으며 f-string으로 안전하게 합쳐야 한다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 변수 | 값을 담아두는 이름 붙은 공간 |
| 동적 타이핑 | 값을 넣는 순간 자료형이 자동으로 정해지는 방식 |
| 자료형 | 값의 종류(정수·실수·문자열·불리언 등) |
| 조건문 | 조건에 따라 다른 코드를 실행하는 문법 |
| 반복문 | 여러 값을 순서대로 처리하는 문법 |
| f-string | 문자열 안에 변수 값을 바로 넣어 조합하는 문법 |
| 불리언 | 참/거짓 두 값만 갖는 자료형 |

## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- Python에서 변수에 값을 저장하고, 이름을 짓는 규칙을 지켜 변수를 선언할 수 있다
- 정수(`int`), 실수(`float`), 문자열(`str`), 불리언(`bool`) 네 가지 기본 자료형을 구분하고 각각 언제 쓰는지 설명할 수 있다
- `type()` 함수로 값의 자료형을 직접 확인하고, 자료형이 다른 값끼리 연산할 때 무슨 일이 벌어지는지 예측할 수 있다
- 실제로 동작하는 Python 스크립트를 작성해 실행하고, 출력 결과를 해석할 수 있다

## 2. 왜 배우나

AI Engineer 교육과정의 모든 실습 — 데이터 전처리 스크립트, LLM API 호출 코드, 백엔드 서버 로직 — 은 결국 변수에 값을 담고 그 값의 자료형에 맞는 연산을 하는 것에서 시작합니다. 변수와 자료형을 정확히 이해하지 못하면 이후에 나올 함수·클래스·API 응답 처리 단계에서 "왜 숫자인데 더하기가 안 되지?", "왜 리스트에 저장한 값이 예상과 다르지?" 같은 문제를 스스로 해결하기 어렵습니다. 지금 이 기초를 확실히 다져두면, 개강 후 실무 프로젝트에서 마주치는 에러 메시지의 절반 이상을 빠르게 스스로 진단할 수 있게 됩니다.

## 3. 개념 설명

### 변수는 이름표가 붙은 상자

변수를 "값을 담는 상자"라고 생각하면 이해하기 쉽습니다. 상자 안에 어떤 값을 넣고, 그 상자에 이름표를 붙이는 것이 변수 선언입니다. Python은 다른 언어(Java, TypeScript 등)와 달리 상자를 만들기 전에 "이 상자에는 숫자만 담을 것이다" 같은 타입 선언을 미리 하지 않습니다. 값을 넣는 순간 Python이 자동으로 자료형을 판단합니다. 이를 **동적 타이핑(dynamic typing)** 이라고 부릅니다.

```python
age = 25          # 정수 상자
height = 175.5     # 실수 상자
name = "지현"       # 문자열 상자
is_student = True  # 불리언 상자
```

### 네 가지 기본 자료형

| 자료형 | 이름 | 예시 | 일상 비유 |
|--------|------|------|-----------|
| `int` | 정수 | `25`, `-3`, `0` | 사람 수를 셀 때 — "3.5명"은 없다 |
| `float` | 실수(소수) | `175.5`, `3.14` | 체중계 숫자 — 소수점이 자연스럽다 |
| `str` | 문자열 | `"지현"`, `"안녕"` | 이름표에 적힌 글자 |
| `bool` | 불리언(참/거짓) | `True`, `False` | 스위치의 켜짐/꺼짐 상태 |

문자열은 반드시 따옴표(`"..."` 또는 `'...'`)로 감싸야 합니다. 따옴표가 없으면 Python은 그것을 변수 이름이나 명령어로 착각합니다 — 즉 `name = 지현`은 에러가 나지만 `name = "지현"`은 정상 동작합니다.

### 자료형이 섞이면 생기는 일

정수와 실수는 함께 연산하면 자동으로 실수로 승격됩니다(`1 + 2.0`은 `3.0`). 하지만 숫자와 문자열은 자동으로 섞이지 않습니다 — `"나이: " + 25`는 에러를 냅니다. 문자열과 숫자를 함께 출력하려면 숫자를 `str()`로 문자열로 바꿔주거나, f-string(`f"나이: {25}"`)을 사용해야 합니다. 이 규칙을 모르면 실무에서 가장 자주 만나는 `TypeError`의 원인을 못 찾고 헤매게 됩니다.

## 4. 실무 예제

아래 스크립트는 회원 정보를 변수에 저장하고, 자료형을 확인한 뒤, 자료형에 맞는 방식으로 값을 조합해 출력하는 완결된 예제입니다. 그대로 복사해서 실행할 수 있습니다.

```python
# variables.py
# 회원 정보를 변수로 관리하고 자료형별로 다르게 다루는 예제

name = "김지현"
age = 27
height = 168.3
is_premium_member = True

# 1) 각 변수의 자료형을 직접 확인한다
print(f"{name}의 자료형: {type(name)}")
print(f"{age}의 자료형: {type(age)}")
print(f"{height}의 자료형: {type(height)}")
print(f"{is_premium_member}의 자료형: {type(is_premium_member)}")

print("---")

# 2) 숫자와 문자열을 함께 출력할 때는 f-string을 사용한다
print(f"회원명: {name}, 나이: {age}세, 키: {height}cm")

# 3) 정수와 실수를 연산하면 실수로 자동 승격된다
average = (age + height) / 2
print(f"나이와 키의 평균값(의미는 없지만 자료형 확인용): {average}")

# 4) 불리언 값으로 조건을 분기한다
if is_premium_member:
    discount_rate = 0.2
    print(f"프리미엄 회원 할인율: {discount_rate * 100}%")
else:
    print("일반 회원입니다.")
```

**실행 방법:** 위 코드를 `variables.py` 파일로 저장한 뒤, 터미널에서 아래 명령을 실행합니다.

```bash
python variables.py
```

실행하면 각 변수의 자료형(`<class 'str'>`, `<class 'int'>` 등)과 조합된 회원 정보, 평균값, 할인율이 순서대로 출력됩니다. `type()` 함수의 출력 형태를 직접 눈으로 확인하는 것이 이 예제의 핵심입니다.

## 5. 실무 팁

- **변수 이름은 의미를 담아서 짓습니다.** `a`, `b`, `temp1` 같은 이름 대신 `user_age`, `total_price`처럼 무엇을 담고 있는지 알 수 있게 짓습니다. 실무에서는 몇 주 뒤의 나 자신도 코드를 처음 보는 사람과 다르지 않습니다.
- **숫자를 문자열에 직접 이어 붙이지 않습니다.** `"나이: " + str(25)`보다 `f"나이: {25}"` (f-string)를 사용하는 것이 더 짧고 읽기 쉽고, 실무 코드베이스에서도 표준으로 자리 잡았습니다.
- **`type()`을 디버깅 도구로 활용합니다.** 에러 메시지에 `TypeError`가 뜨면 가장 먼저 관련 변수에 `print(type(변수명))`을 추가해 실제 자료형을 확인하는 습관을 들이면 문제 해결 속도가 크게 빨라집니다.
- **불리언 값은 `True`/`False`(대문자 시작)입니다.** 다른 언어의 `true`/`false`(소문자)와 헷갈리기 쉬우니 주의합니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- Python 변수는 선언 시점에 값에 따라 자료형이 자동으로 결정된다(동적 타이핑)
- 기본 자료형 네 가지: `int`(정수), `float`(실수), `str`(문자열), `bool`(불리언)
- 숫자와 문자열은 자동으로 섞이지 않으며, f-string이나 `str()`로 명시적으로 변환해야 한다
- `type()` 함수는 값의 자료형을 확인하는 가장 기본적이고 강력한 디버깅 도구다

**스스로 점검**

1. `age = "27"`처럼 나이를 문자열로 저장했다면, `age + 3`을 실행했을 때 어떤 일이 일어날까요? 왜 그럴까요?
2. `price = 15000`, `discount = 0.1`일 때, 할인된 가격을 계산해 `f"할인가: {가격}원"` 형태로 출력하는 코드를 직접 작성해보세요.
3. 위 실무 예제의 `is_premium_member` 값을 `False`로 바꾸고 다시 실행하면 출력이 어떻게 달라지는지 예측한 뒤 직접 실행해서 확인해보세요.

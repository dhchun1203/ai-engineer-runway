### 📋 리스트는 순서 있는 목록

리스트(list, 순서 있는 값들의 목록)는 값을 여러 개 순서대로 담는 그릇입니다. 대괄호로 만들고, 값마다 0부터 시작하는 번호(인덱스)가 붙습니다.

```python
scores = [78, 92, 85]
print(scores[0])     # 78 (첫 번째)
print(scores[-1])    # 85 (마지막, 음수 인덱스)
```

리스트는 만든 뒤에도 바꿀 수 있습니다. 값을 더하거나(`append`), 특정 자리를 새 값으로 고칠 수 있습니다.

```python
scores.append(95)    # 맨 뒤에 추가
scores[0] = 80       # 첫 자리 수정
```

### ✂️ 슬라이싱과 정렬

슬라이싱(slicing, 리스트의 일부 구간을 잘라 오기)은 콜론으로 범위를 지정해 일부만 잘라 옵니다. 끝 번호는 포함하지 않습니다.

```python
nums = [10, 20, 30, 40, 50]
print(nums[:3])      # [10, 20, 30] — 앞 3개
print(nums[2:])      # [30, 40, 50] — 3번째부터 끝
print(nums[::-1])    # [50, 40, 30, 20, 10] — 거꾸로
```

`sort()`는 리스트를 정렬합니다. `reverse=True`를 주면 큰 값부터 내림차순으로 정렬합니다.

### 🔒 튜플은 못 바꾸는 목록

튜플(tuple, 한 번 만들면 바꿀 수 없는 목록)은 리스트와 거의 같지만, 만든 뒤에는 값을 바꿀 수 없습니다. 소괄호로 만듭니다.

한 번 정하면 변하면 안 되는 정보에 씁니다. 예를 들어 학번, 생년월일, 좌표처럼요. 이렇게 못 바꾸게 막는 성질을 불변성(immutability)이라고 합니다.

```python
student = ("2026001", "김민준", 2010)
print(student[1])            # 김민준
# student[1] = "이서연"      # 여기서 에러가 난다 (튜플은 못 바꿈)
```

### 🔧 튜플 메서드와 자료형 변환

튜플에도 값을 세거나 위치를 찾는 메서드가 있습니다. `count()`는 어떤 값이 몇 번 나오는지, `index()`는 그 값이 처음 나온 자리를 알려 줍니다.

```python
nums = (1, 3, 5, 3, 7, 3)
print(nums.count(3))    # 3 (세 번 등장)
print(nums.index(3))    # 1 (처음 나온 자리)
```

리스트와 튜플은 서로 바꿀 수 있습니다. `list()`로 튜플을 리스트로, `tuple()`로 리스트를 튜플로 바꿉니다.

바꿔야 할 값이 생기면 튜플을 리스트로 풀어 고치고, 다시 고정하고 싶으면 튜플로 되돌리는 식으로 씁니다.

```python
student = ("2026001", "김민준", 2010)
edited = list(student)       # 리스트로 (바꿀 수 있게)
edited[1] = "이서연"
student = tuple(edited)      # 다시 튜플로 (고정)
```

### 🗂️ 딕셔너리는 이름표로 찾는 서랍

딕셔너리(dictionary, 키로 값을 찾는 그릇)는 번호가 아니라 이름표(키)로 값을 찾습니다. 서랍마다 이름을 붙여 두고 그 이름으로 꺼내는 셈입니다.

```python
profile = {"name": "김민준", "score": 92}
print(profile["score"])      # 92 (키로 값 꺼내기)
profile["grade"] = "A"       # 새 키와 값 추가
```

없는 키를 대괄호로 꺼내면 에러가 납니다. 안전하게 꺼내려면 `profile.get("age")`처럼 `get`을 쓰면 없을 때 `None`이 나옵니다.

### 🪆 리스트 안에 튜플, 그리고 실무 연결

리스트와 튜플, 딕셔너리는 서로 겹쳐 담을 수 있습니다. 이렇게 겹친 것을 중첩 자료형이라고 합니다.

실무에서 아주 흔한 모양이 리스트 안에 튜플입니다. 예를 들어 학생 명부를 (이름, 점수) 튜플들의 리스트로 담습니다.

데이터와 AI에서도 그대로 쓰입니다. 표 한 줄을 딕셔너리로, 여러 줄을 리스트로 담고, 모델에 넣을 특징 묶음도 딕셔너리로 표현합니다.

## 4. 실무 예제

아래 스크립트는 학생 명부를 리스트, 튜플, 딕셔너리로 함께 다루는 완결된 예제입니다. 위 "실행" 버튼을 누르면 브라우저 안에서 바로 돌아갑니다.

<RunPython>

```python
# roster.py
# 학생 명부를 리스트·튜플·딕셔너리로 다루는 예제

scores = [78, 92, 85, 60, 88]        # 리스트: 순서 있는 목록
print("앞 3명:", scores[:3])           # 슬라이싱
scores.append(95)                     # 추가
scores.sort(reverse=True)             # 내림차순 정렬
print("정렬 후:", scores)

average = sum(scores) / len(scores)   # 합계와 개수로 평균
print(f"평균: {average:.1f}점")

student = ("2026001", "김민준", 2010)  # 튜플: 못 바꾸는 정보
print("이름:", student[1])

profile = {"name": "김민준", "score": 92}   # 딕셔너리: 키로 값 찾기
profile["grade"] = "A"
print("등급:", profile["grade"])

class_list = [("김민준", 85), ("이서연", 92)]  # 리스트 안에 튜플
for name, score in class_list:
    print(f"{name}: {score}점")
```

</RunPython>

실행하면 슬라이싱 결과, 정렬된 점수, 평균, 튜플에서 꺼낸 이름, 딕셔너리 등급, 그리고 명부 두 줄이 순서대로 출력됩니다.

## 5. 실무 팁

- **바뀌면 안 되는 정보는 튜플로 담습니다.** 학번, 좌표처럼 고정된 값을 튜플에 두면 실수로 바꾸는 사고를 막습니다.
- **딕셔너리는 `get`으로 안전하게 꺼냅니다.** 없을 수도 있는 키는 대괄호 대신 `.get(키)`로 꺼내 `KeyError`를 피합니다.
- **표 데이터는 리스트 안 딕셔너리로 떠올립니다.** 한 줄이 딕셔너리, 여러 줄이 리스트라는 그림이 pandas 같은 도구로 자연스럽게 이어집니다.
- **정렬 결과를 다시 담을지 확인합니다.** `sort()`는 리스트 자체를 바꾸고, `sorted()`는 새 리스트를 돌려줍니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 리스트는 순서 있는 목록이고, 인덱싱과 슬라이싱, 정렬과 추가로 자유롭게 다룬다
- 튜플은 리스트와 비슷하지만 만든 뒤 바꿀 수 없다(불변성)
- 딕셔너리는 번호가 아니라 키(이름표)로 값을 찾는다
- 리스트 안에 튜플이나 딕셔너리를 담는 중첩 자료형이 실무에서 흔하다
- 없는 키는 `get`으로 안전하게 꺼내 `KeyError`를 피한다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 리스트 | 순서 있는 값들의 목록. 대괄호로 만들고 바꿀 수 있다 |
| 튜플 | 한 번 만들면 바꿀 수 없는 목록. 소괄호로 만든다 |
| 딕셔너리 | 키(이름표)로 값을 찾는 그릇 |
| 인덱싱 | 번호로 특정 값을 꺼내기 |
| 슬라이싱 | 콜론으로 일부 구간을 잘라 오기 |
| 불변성 | 만든 뒤에는 값을 바꿀 수 없는 성질 |
| 중첩 자료형 | 리스트 안에 튜플처럼 그릇을 겹쳐 담은 구조 |

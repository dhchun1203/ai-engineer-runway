## 1. 학습 목표

이 레슨을 마치면 다음을 할 수 있습니다.

- 분류·회귀·군집이 각각 어떤 문제를 푸는지 구분해 설명할 수 있다
- 정답 데이터가 있는 학습과 없는 학습의 차이를 말할 수 있다
- 내장 데이터셋으로 분류 모델을 학습시키고 예측을 뽑을 수 있다
- 군집 결과가 정답과 어떻게 다른지 관찰할 수 있다

## 2. 왜 배우나

앞으로 만나게 될 대부분의 AI 서비스는 결국 분류·회귀·군집 셋 중 하나에 얹혀 있습니다. 스팸 메일 걸러내기는 분류, 집값 예측은 회귀, 고객을 몇 개 그룹으로 나누는 마케팅은 군집입니다.

어떤 문제를 받았을 때 이 셋 중 무엇에 해당하는지 판단하는 것이 실무의 첫 단추이고, 이 판단이 틀리면 그다음에 고르는 도구도 전부 어긋납니다. 오늘은 세 유형을 직접 한 번씩 돌려보며 이 판단력을 몸에 익힙니다.

## 3. 개념 설명

### 🎯 정답이 있느냐 없느냐

머신러닝(machine learning, 데이터에서 규칙을 스스로 찾아내는 프로그램)을 배우는 방식은 크게 둘로 나뉩니다. 지도 학습(supervised learning, 정답이 붙어 있는 데이터로 배우는 방식)은 선생님이 문제와 정답을 같이 주는 것과 같습니다 — "이 사진은 고양이다"처럼 정답표가 붙어 있는 데이터로 배웁니다.

비지도 학습(unsupervised learning, 정답 없이 데이터 안의 패턴만으로 배우는 방식)은 정답표 없이 "비슷하게 생긴 것끼리 알아서 모아봐"라고 시키는 것과 같습니다. 분류와 회귀는 지도 학습, 군집은 비지도 학습입니다.

### 🗂️ 세 유형 한눈에

| 유형 | 무엇을 맞히나 | 일상 비유 | 이 레슨의 예 |
|------|--------------|-----------|--------------|
| 분류(classification) | 이름표(카테고리) | 우편함을 종류별로 나누기 | 꽃잎 크기로 품종 맞히기 |
| 회귀(regression) | 숫자(연속값) | 점들 사이에 선을 긋고 다음 값 맞히기 | 건강 수치로 병의 진행도 맞히기 |

### 🧠 학습과 예측

scikit-learn에서는 두 단어만 기억하면 됩니다 — `fit`으로 배우고 `predict`로 맞힙니다. `fit(X, y)`에 특징(X)과 정답(y)을 같이 넣으면 모델이 데이터를 통째로 외우는 게 아니라 "꽃잎이 길수록 어떤 품종일 확률이 높다" 같은 패턴을 요약해서 저장합니다.

그다음 `predict(새로운_데이터)`를 호출하면 그 요약된 패턴에 새 데이터를 대입해 답을 냅니다. 군집처럼 정답이 없을 때는 `fit_predict`로 배우기와 맞히기를 한 번에 합니다.

## 4. 실무 예제

<PredictPrompt />

```python
# ml_types.py
# 붓꽃(iris) 데이터로 분류·군집·회귀를 각각 한 번씩 돌려보는 예제

from sklearn.datasets import load_iris, load_diabetes
from sklearn.linear_model import LogisticRegression, LinearRegression
from sklearn.cluster import KMeans

# 1) 내장 데이터 불러오기와 모양 확인
iris = load_iris()
X, y = iris.data, iris.target
print(f"샘플 수: {X.shape[0]}, 특징 수: {X.shape[1]}")
print(f"품종 이름: {[str(name) for name in iris.target_names]}")

print("---")

# 2) 분류 — 정답(품종)을 이미 알고 있을 때
clf = LogisticRegression(max_iter=200)
clf.fit(X, y)
print("분류기 예측(첫 5개):", clf.predict(X[:5]))
print("실제 정답(첫 5개):  ", y[:5])

print("---")

# 3) 군집 — 정답 없이 비슷한 것끼리 묶기
# 군집 번호(0/1/2)는 그저 묶음 이름일 뿐, 품종 번호(0/1/2)와 같은 순서로
# 매겨진다는 보장이 없다. "1번 군집 = 1번 품종"이라고 넘겨짚으면 안 된다.
kmeans = KMeans(n_clusters=3, n_init=10, random_state=0)
cluster_labels = kmeans.fit_predict(X)
print("군집 결과(첫 5개):  ", cluster_labels[:5])

print("---")

# 4) 회귀 — 다른 내장 데이터로, 이름이 아니라 숫자를 예측한다
diabetes = load_diabetes()
X_d, y_d = diabetes.data, diabetes.target
reg = LinearRegression()
reg.fit(X_d, y_d)
print("회귀 예측(첫 3개):", [round(float(v), 1) for v in reg.predict(X_d[:3])])
print("실제 값(첫 3개):  ", [round(float(v), 1) for v in y_d[:3]])
```

`import` 문과 `clf = LogisticRegression(max_iter=200)` 줄만 위 코드로 바꾸면 됩니다. 붓꽃 데이터는 품종 구분이 비교적 뚜렷해서 두 모델 다 첫 5개 샘플은 똑같이 맞히는 경우가 많습니다 — 모델을 바꿔도 데이터가 쉬우면 차이가 잘 안 드러난다는 것도 함께 관찰할 수 있습니다.

</details>

## 5. 실무 팁

- **설치할 때 쓰는 이름과 코드에서 부르는 이름이 다릅니다.** 설치는 `pip install scikit-learn`이지만 코드 안에서는 `import sklearn`으로 부릅니다. import 이름을 그대로 설치 명령에 써서 `sklearn`이라는 패키지를 찾으려 하면 원하는 패키지가 아닐 수 있으니 주의합니다.
- **군집 번호는 정답 라벨과 일치할 이유가 없습니다.** 군집은 이름표 없이 묶기만 하므로, 0번 군집이 어떤 품종인지는 실행할 때마다 달라질 수 있습니다.
- **작은 내장 데이터로 잘 나온 결과가 실제 데이터에서 그대로 나오지 않습니다.** 붓꽃 데이터는 150개뿐이고 품종 구분이 뚜렷해서 성능이 좋게 보이지만, 실무 데이터는 훨씬 크고 지저분합니다.
- **난수가 개입하는 곳은 반드시 `random_state`를 고정합니다.** 그래야 같은 코드를 다시 실행했을 때, 또는 동료와 결과를 비교할 때 값이 흔들리지 않습니다.

## 6. 핵심 정리 및 스스로 점검

**핵심 정리**

- 정답이 있으면 지도 학습(분류·회귀), 없으면 비지도 학습(군집)이다
- 분류는 이름표를, 회귀는 숫자를, 군집은 정답 없는 그룹을 맞힌다
- scikit-learn에서는 `fit`으로 배우고 `predict`(또는 `fit_predict`)로 맞힌다
- 군집 번호는 정답 라벨과 순서가 일치한다는 보장이 없다
- 난수가 개입하는 모델은 `random_state`를 고정해야 재현 가능하다

**이 레슨의 단어**

| 단어 | 뜻 |
|------|-----|
| 지도 학습 | 정답이 붙어 있는 데이터로 배우는 방식 |
| 비지도 학습 | 정답 없이 데이터 안의 패턴만으로 배우는 방식 |
| 분류 | 데이터를 정해진 이름표 중 하나로 맞히는 문제 |
| 회귀 | 데이터를 보고 연속된 숫자값을 맞히는 문제 |
| 군집 | 정답 없이 비슷한 데이터끼리 묶는 문제 |
| 특징 | 모델이 보고 판단하는 데이터의 속성 |
| 라벨 | 정답으로 붙어 있는 값 |

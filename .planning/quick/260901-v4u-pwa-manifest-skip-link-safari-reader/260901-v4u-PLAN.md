## 사용자 UAT(실기기 전용 — 자동화 불가)
- 아이패드 Safari에서 사이트를 "홈 화면에 추가" → 홈 화면 아이콘이 스크린샷이 아닌 앱 아이콘("AI")으로 뜨고, 열면 주소창 없는 앱 형태(standalone)로 실행되는지.
- 레슨 페이지에서 Safari 주소창의 Reader(읽기 도구)가 뜨는지 — 뜨면 "듣기" 오디오 복습이 무료로 따라온다(리서치 2단).
- (선택) 홈 화면 웹앱으로 며칠 사용 후에도 진도(localStorage)가 유지되는지 — manifest 도입의 목적.
</verification>

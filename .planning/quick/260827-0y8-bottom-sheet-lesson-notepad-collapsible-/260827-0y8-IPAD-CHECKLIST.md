# 아이패드 실기기 점검표 — 레슨 메모장

2분 안에 끝나는 점검입니다. 헤드리스 브라우저로는 증명할 수 없는 항목만 담았습니다 —
나머지(정렬·자동 저장·접근성·가로 스크롤 없음 등)는 자동 게이트 20건이 이미 통과했습니다.

아이패드 Safari에서 `https://ai-engineer-runway.vercel.app/lesson/1-1-course-orientation`
을 엽니다. (아직 잠금 해제 전이면 소유자용 잠금 해제 링크로 먼저 들어가 주세요.)

## 점검 항목

- [ ] **화면 맨 아래 `메모` 띠를 탭한다.** 메모장이 아래에서 올라옵니다.
      키보드가 필요 없는 상태입니다 — 잘 보이나요?
      → 안 되면 이렇게 알려주세요: 어떤 화면(레슨 제목)에서, 탭했을 때 무슨 일이
      일어났는지(안 열림 / 다른 자리에서 열림 / 화면이 깨짐).

- [ ] **메모칸을 탭해 키보드를 띄운다.** 세로 모드에서 메모칸이 키보드 **위에**
      바로 보이나요, 아니면 뒤로 숨거나 한 번 튀나요? 가로 모드로 돌려서도
      똑같이 확인해 주세요.
      → 안 되면 이렇게 알려주세요: 세로/가로 중 어느 쪽이 문제인지, "숨음"과
      "튐" 중 어느 쪽에 더 가까운지.

- [ ] **키보드를 내린다(완료 또는 화면 다른 곳 탭).** 메모장이 원래 자리로
      정확히 돌아오나요?
      → 안 되면 이렇게 알려주세요: 얼마나 어긋나 보이는지(살짝 / 많이).

- [ ] **한글을 타이핑한다.** "아니오"처럼 받침이 자음/모음 사이를 옮겨 다니는
      단어로 조합 중에 글자가 깨지거나 지워지지 않는지 확인해 주세요. 천천히
      쳐도 되고 빠르게 쳐도 됩니다.
      → 안 되면 이렇게 알려주세요: 어떤 단어를 쳤을 때, 화면에 뭐가 남았는지.

- [ ] **두 손가락으로 화면을 확대(핀치 줌)한 상태에서 메모장을 열어본다.**
      시트 위치가 살짝 어긋나 보일 수 있습니다 — **이건 이미 알고 있는 v1
      한계**입니다. 위치가 어긋나는 것 자체는 문제 삼지 않습니다. 다만 쓰는 데
      실제로 거슬릴 정도인지만 한 줄로 알려주세요.

- [ ] **종이색·괘선이 눈에 편한지 확인한다.** 라이트 모드와 다크 모드(우측
      상단 달/해 아이콘) 양쪽에서 열어 보고, 괘선이 글씨와 싸우지 않고 옅게
      보이는지 확인해 주세요.
      → 안 되면 이렇게 알려주세요: 라이트/다크 중 어느 쪽이 불편한지, 괘선이
      너무 진한지 아니면 다른 문제인지.

- [ ] **다른 기기(PC)에서 같은 레슨을 열어 방금 쓴 메모가 그대로 있는지
      확인한다.** PC 브라우저에서 같은 URL(`/lesson/1-1-course-orientation`)을
      열고 메모칸을 펼쳐 보세요.
      → 안 되면 이렇게 알려주세요: 무엇이 보였는지(비어 있음 / 다른 내용 /
      에러).

## v1에서 일부러 빼둔 것

- 드래그로 시트 높이 조절 — 항상 보이는 뷰포트의 약 40% 고정.
- 서식(굵게/기울임/목록 등) — 줄글만 씁니다.
- 메모 검색.
- 메모 전체 보기 페이지(레슨 밖에서 모아보기).
- 메모 내보내기(복사/다운로드).
- 핀치 줌 상태에서의 시트 위치 보정 — 알려진 한계, 점검표 항목 5에서 확인만 합니다.
- 오프라인 큐잉 — 네트워크가 끊기면 저장이 "저장하지 못했어요"로 표시되고,
  재시도는 자동으로 일어나지 않습니다(다음 타이핑 멈춤에 다시 시도됩니다).

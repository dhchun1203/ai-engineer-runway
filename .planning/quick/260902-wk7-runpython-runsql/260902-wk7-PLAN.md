run-python·run-sql 양쪽이 import할 단일 `'use client'` 컴포넌트를 만든다. 파일 상단 주석은 이 저장소의 한국어 상세 주석 문체를 따르고, 왜 별도 컴포넌트로 뽑는지(양쪽 복붙 금지)와 IME 안전성 근거를 적는다.

시그니처: `export function TraceEditor({ guide, value, onChange, ariaLabel }: { guide: string; value: string; onChange: (next: string) => void; ariaLabel: string })`. 상태는 부모가 소유하고(controlled) 이 컴포넌트는 렌더·정렬·일치 계산만 담당한다.

마크업(패널 포함): `.panel mt-2 p-3` 래퍼 안에 (1) 안내 문구 라벨(예: "흐리게 보이는 원본 위에 그대로 따라 쳐 보세요. 눈이 아니라 손으로 익히는 연습입니다.", 기존 편집 라벨과 같은 `text-label ... text-muted dark:text-muted-dark` 클래스), (2) `<div className="trace-overlay">` 안에 `<pre className="trace-guide" ref={guideRef} aria-hidden="true">{guide}</pre>`와 `<textarea className="trace-input" ref={inputRef} value={value} onChange={(e) => onChange(e.target.value)} onScroll={syncScroll} wrap="off" spellCheck={false} autoCapitalize="off" autoCorrect="off" autoComplete="off" aria-label={ariaLabel} />`, (3) 일치 상태 줄.

IME 안전(HARD): textarea는 표준 controlled `value`/`onChange`만 쓴다. `onKeyDown`으로 값을 다시 쓰거나 키 입력을 가로채지 않는다 — 한국어 조합이 깨진다. `wrap="off"` + CSS `white-space: pre`로 줄바꿈을 막아 열이 안내와 정확히 맞도록 한다.

스크롤 미러링: `guideRef`(HTMLPreElement)·`inputRef`(HTMLTextAreaElement) ref 두 개. `syncScroll`는 inputRef의 scrollTop·scrollLeft를 guideRef에 그대로 대입한다. onScroll에서 호출하고, `onChange` 경로에서도(입력으로 캐럿이 자동 스크롤될 때) 다음 프레임에 한 번 더 맞춰 초기·리셋 시 어긋남을 없앤다.

줄 일치 계산: 모듈 스코프 순수 함수 `countMatchingLines(guide, typed)`를 둔다 — guide·typed를 각각 '\n'으로 나눠 같은 인덱스끼리 `line.replace(/\s+$/, '')` 비교(줄 끝 공백만 무시), guide 줄 수를 total로 삼아 일치 개수를 센다. 컴포넌트에서 `const total = guide.split('\n').length; const matched = countMatchingLines(guide, value); const complete = total > 0 && matched === total;`.

상태 표시: `role="status" aria-live="polite"`인 보이는 한 줄. 미완이면 `` `${matched}/${total}줄 일치` ``(기존 `text-label ... text-muted dark:text-muted-dark`), 완성이면 "완성! 모든 줄이 원본과 일치해요"를 muted 없이 전강도 foreground로. 강조는 새 토큰을 만들지 말고 기존 클래스(예: muted 제거 + 굵기 올리기)만으로 처리한다.

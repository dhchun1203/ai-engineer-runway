- 인박스 추가 폼 textarea는 `.note-paper`(옥스포드 괘선, `height:100%` 전제 — note-sheet-panel 컨테이너 없이는 collapse)를 재사용하지 않고, `border-line`/`bg-surface-2` 등 기존 `@theme` 토큰만 조합한 평범한 textarea로 새로 스타일링했다. design-tokens 규칙 c(임의값 대괄호 금지)를 지키면서 note-paper의 고정 높이 전제와 충돌하지 않는 선택이었다.

## Issues Encountered
- **워크트리에 `node_modules`가 없었다.** 이 실행자 워크트리는 git 워크트리라 `node_modules`(gitignored)가 비어 있어 `next build`(Turbopack)가 "Could not find the Next.js package" 오류로 실패했다. `npm ci`로 워크트리에 직접 설치해 해결했다(535 packages, ~28초). `npx tsc` 자체는 상위 디렉터리의 `node_modules`를 걸어 올라가 찾아 동작했지만(순수 Node 모듈 해석), Turbopack의 워크스페이스 루트 해석은 그렇게 동작하지 않았다.
- **워크트리에 `.env.local`이 없었다.** `SUPABASE_URL`/`SUPABASE_SERVICE_ROLE_KEY`/`UNLOCK_SECRET`가 없으면 `src/lib/supabase/admin.ts`가 즉시 throw해 빌드·개발 서버가 죽는다. 메인 체크아웃의 `.env.local`을 워크트리로 복사해 해결했다(`.gitignore`의 `.env*` 패턴에 걸려 커밋되지 않음을 확인).
- **`src/app/layout.tsx`(RootLayout)에서 간헐적 hydration mismatch 관찰됨(사전 존재, 이번 변경과 무관).** `<html className>`(pretendard/newsreader 폰트 변수) 서버/클라이언트 불일치가 `/inbox`·`/notes` 전체 페이지 로드 중 약 30~40% 빈도로 나타났다 — 재현 불가능하게 간헐적이고, diff가 항상 RootLayout의 폰트 클래스 문자열이라 신규 라우트/컴포넌트와 무관한 사전 존재 결함으로 판단했다. Scope Boundary 원칙에 따라 고치지 않고 `deferred-items.md`에 기록했다.

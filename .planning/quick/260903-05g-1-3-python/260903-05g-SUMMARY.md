# Summary — 따라 치기 블록 설명 가이드 + 오답 표시

따라 치기(고스트 오버레이) 모드를 두 갈래로 키웠다. 둘 다 아이패드 크기 내장
브라우저로 실측 검증했다.

## 1. 블록 단위 설명 가이드 (파일럿 1-3 Python)
- 코드의 한 논리 블록(빈 줄로 나뉘는 비어있지 않은 줄 묶음)을 다 정확히 치면 그
  블록이 뭘 하는지 eli5 설명이 편집기 아래에 순서대로 누적된다.
- `TraceEditor`에 `blockGuides?: readonly string[]` 추가. `splitBlocks(guide)`로 블록
  경계를 잡아 위치를 줄 인덱스가 아니라 블록에 묶는다(코드 내부 한두 줄 수정에 안 밀림).
  빈 문자열 = 그 블록 설명 없음. `RunPython`·`RunSQL`은 prop만 전달, 미지정 시 기존과 동일.
- 파일럿: `1-3-python-variables-and-types.mdx` 실무 예제 RunPython에 8블록 설명(구분선
  1블록은 빈 문자열). 완성 시 7개 노트 누적 + "완성!" 확인, blockGuides 없는 SQL 블록은
  노트 0(옵트인).
- **롤아웃 대기**: 사용자 승인 후 나머지 실행 블록(1-3 함수·IO, 1-4 SQL 2편, 2-1 등)에
  블록 설명 작성 확장.

## 2. 오답 글자 빨간색 표시 (컴포넌트 전역, 콘텐츠 불필요)
- 고스트와 다르게 친 글자를 즉시 빨갛게 표시. 입력층 위에 진단층(`.trace-diff`, z 2)을
  겹쳐, 친 값을 원본과 같은 줄·같은 열끼리 글자 단위 비교해 다른 글자만 `.miss`
  (destructive)로 그린다. 맞는 글자는 transparent(아래 입력층 글자가 그대로 보임).
- 친 글자를 그대로 렌더 → 한글 2배폭 정렬 유지. `pointer-events: none` → 캐럿·선택·
  한글 IME 무간섭(입력층 자체 무변경). guide보다 길게 친 글자도 오답 처리. 스크롤 미러링.
- 실측: 영문 오타 1글자만 빨강, 한글 오타 음절만 빨강, 전체 정답 시 빨강 0개.

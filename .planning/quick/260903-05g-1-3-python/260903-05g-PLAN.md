<objective>
따라 치기(고스트 오버레이) 모드에 **블록 단위 설명 가이드**를 얹는다. 학습자가 코드의 한
논리 블록(빈 줄로 나뉘는, 비어있지 않은 줄 묶음)을 다 정확히 치면 그 블록이 뭘 하는지
eli5 설명이 편집기 아래에 누적으로 뜬다. 파일럿으로 1-3 Python 실무 예제의 RunPython
블록 하나에만 적용하고, 아이패드 확인·사용자 승인 후 다른 실행 블록으로 확장한다
(lessons-eli5-pilot-first 원칙).
</objective>

<design>
- 설명 단위: **블록**(사용자 선택). 블록 = 가이드 코드에서 빈 줄로 구분되는, 비어있지
  않은 줄들의 연속 묶음. `# N)` 주석 구획과 자연히 일치한다. 위치가 줄이 아니라 블록에
  묶여 코드 내부 줄을 조금 고쳐도 매핑이 안 밀린다(북마크 인덱스 취약성 회피).
- 콘텐츠 전달: 저자가 MDX에서 `<RunPython blockGuides={[...]}>` 로 블록 순서대로 설명
  문자열 배열을 넘긴다(코드와 같은 곳에 co-locate). 빈 문자열 = 그 블록은 설명 없음
  (구분선 print("---") 같은 자명한 블록).
- 노출: TraceEditor가 guide를 비어있지 않은 줄 묶음(블록)으로 쪼개고, 학습자가 친 값이
  블록 i의 모든 줄을 (줄 끝 공백 관대) 맞추고 그 블록 끝 줄까지 도달하면 blockGuides[i]를
  아래 누적 리스트에 순서대로 보여준다. 기존 'N/M줄 일치'→'완성!' 상태는 유지.
- 기존 계약 보존: blockGuides 미지정 시 지금과 완전히 동일(설명 없음). edit 모드·실행·
  원래대로·IME·오버레이 정렬·스크롤 동기 무변경.
</design>

- **④ 실무 예제** — **실행: PC 로컬 VS Code**를 한 줄로 명시한다(D-73). 절차를 `powershell` 펜스 여러 개로 나눠 순서대로 준다(D-75 — Windows 기준, 다른 부분만 macOS 병기):

  4. 설정 생성 — `npx tsc --init`.
  5. 첫 파일 실행 — `npx tsx hello.ts`.
  `package.json`과 `tsconfig.json`은 `json` 펜스로 **필요한 부분만 발췌**해 보여 주고 각 키가 무슨 뜻인지 산문으로 설명한다(`scripts`, `devDependencies`, `strict`, `target`, `module` 정도). `hello.ts`는 `typescript` 펜스 하나에 완결 코드로 넣는다 — 첫 줄은 파일명 주석, 내용은 타입이 붙은 함수 하나(예: 상품 객체 배열을 받아 총액을 계산해 문자열로 반환)와 호출·출력. 타입 오류를 일부러 내 보는 경우 어떤 메시지가 뜨는지 산문 2~3줄로 설명한다.

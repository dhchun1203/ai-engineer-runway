절별 목표:
- ① 학습 목표 — "반복되는 처리를 함수로 묶어 이름을 붙일 수 있다", "함수에 값을 넘기고 결과를 돌려받는 흐름을 설명할 수 있다", "예상 가능한 실패를 `try`/`except`로 감싸 프로그램이 멈추지 않게 할 수 있다", "결과를 파일에 저장하고 다시 읽어 확인할 수 있다" 계열 4개.
- ② 왜 배우나 — 코드가 길어지면 왜 조각으로 나눠야 하는지, 그리고 바깥 세계(사용자 입력·파일·네트워크)는 늘 실패한다는 것. 4문장 이내.
- ③ 개념 설명 — 이모지 `###` 소제목 3~4개.
  - "함수는 자판기" — `def`로 정의하고 괄호 안 매개변수로 입력을 받고 `return`으로 결과를 돌려준다. 매개변수(parameter)와 인자(argument)의 차이를 한 줄로 구분해 준다. 3열 표(자판기 · 함수 · 예시)로 대응시킨다.
  - "예외는 안전망" — 실패하는 코드가 프로그램 전체를 멈추는 것과, `try`/`except`로 잡아 다음으로 넘어가는 것의 차이. 잡을 예외를 이름으로 지정하는 형태(`except ValueError:`)를 기본으로 가르치고, 모든 예외를 이름 없이 삼키는 형태는 왜 위험한지 한 줄 경고한다.
  - "파일은 편지" — 쓰기 모드와 읽기 모드, `with` 블록이 파일을 자동으로 닫아 준다는 것. 인코딩을 `utf-8`로 지정해야 한글이 깨지지 않는다는 것(Windows 기본 인코딩 때문에 실제로 자주 겪는 문제)을 여기서 짚는다.
- ④ 실무 예제 — 완결된 단일 `python` 펜스 하나. 파일명은 `members_io.py`, 첫 줄은 파일명 주석. 구성:
  - 회원 한 명의 정보를 받아 요약 문자열을 돌려주는 함수 하나(`def` + 매개변수 2~3개 + `return`).
  - 나이 값이 숫자가 아닐 때를 `try`/`except ValueError`로 감싸 "잘못된 값입니다" 계열 메시지를 남기고 계속 진행하는 부분. 잘못된 값이 섞인 리스트를 순회하며 함수를 호출해 예외가 실제로 한 번 발생하도록 데이터를 구성한다 — 학습자가 안전망이 작동하는 것을 출력으로 봐야 한다.
  - 정상 처리된 요약들을 `with open(...) as f:` 블록으로 `members.txt`(또는 `.csv`)에 쓰고, 이어서 다시 열어 읽은 뒤 출력하는 부분. 파일 경로는 스크립트와 같은 디렉터리의 상대 경로만 쓰고 절대 경로를 쓰지 않는다. 인코딩은 `utf-8`로 명시한다.
  - 실행 방법을 `powershell` 펜스로 준다: `py members_io.py` 한 줄. 아래에 macOS 병기 한 줄(`python3 members_io.py`)과 예상 출력 설명 산문 2~3줄, 그리고 "실행 후 같은 폴더에 생긴 파일을 직접 열어 보라"는 안내 한 줄.
  - `### 해보기` 2~3개: ① 함수에 매개변수를 하나 더해(예: 등급) 출력이 어떻게 달라지는지 확인한다(정답 블록에 수정된 함수 시그니처와 예상 출력), ② 리스트에 잘못된 값을 하나 더 섞어 예외가 몇 번 잡히는지 확인한다(정답 블록에 예상 출력과 왜 프로그램이 안 멈추는지), ③(선택) 저장 파일명을 바꾸고 읽기 부분도 같이 고쳐 두 파일이 생기게 해 본다.

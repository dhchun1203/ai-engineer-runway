**(a) `src/app/api/progress/route.ts` 신설.**
`export async function GET(request: Request)` 하나만 export한다. `src/app/unlock/route.ts`의 헤더 주석
규율을 복제한다 — 응답·로그 어디에도 쿠키 원문 값이나 시크릿을 남기지 않는다.

본문 순서 자체가 보안 계약이다. `hasUnlockCookie()`를 무조건, 그리고 어떤 조회보다도 먼저 부른다
(`src/app/page.tsx` 23~25행의 주석 취지를 이 파일에 옮겨 적는다). 잠금 해제 전이면
`{ unlocked: false, ok: false, overall: null, steps: null, modules: null, completedSlugs: null, nextLessonSlug: null, lesson: null }`
을 status 200으로 돌려준다 — 완료 데이터를 담은 필드는 절대 채우지 않는다.

잠금 해제 상태면 `readCompletedLessonIds()`를 부른다. 실패면 `{ unlocked: true, ok: false, ... 나머지
전부 null }`을 status 502로 돌려준다. 성공이면 `overall`(`overallProgress`), `steps`(stepId 1·2·3
각각의 `stepProgress`), `modules`(`getModulesByStep`으로 모든 모듈 id를 얻어 각각 `moduleProgress`),
`completedSlugs`(정렬된 배열), `nextLessonSlug`(`nextIncompleteLesson`의 slug 또는 null)를 채워
status 200으로 돌려준다.

`request.url`의 `lesson` 검색 파라미터가 있으면 `getLessonBySlug()`로 매니페스트 존재 여부를 먼저
검증한다(`actions.ts` 23~27행과 같은 방어). 매니페스트에 없으면 `lesson`을 null로 둔다 — 오류를
내지 않는다(존재 여부를 되묻는 탐침이 되지 않게). 존재하면 `lesson: { slug, done }`을 채운다.
메모(`note`) 필드는 08-03이 이 자리에 덧붙인다 — 지금은 만들지 않는다.

모든 응답에 `Cache-Control: private, no-store` 헤더를 명시적으로 설정한다. 이 핸들러에
`export const dynamic` 선언을 붙이지 않는다 — `cookies()`를 호출하므로 기본적으로 동적이고,
정적 캐싱을 강제하면 한 사용자의 진도가 다른 요청자에게 응답되는 캐시 오염이 생긴다.

**(b) `src/components/progress-provider.tsx` 신설 (`'use client'`).**
`ProgressProvider({ lessonId, children })`가 마운트 후 `fetch('/api/progress' + (lessonId ? '?lesson=' + encodeURIComponent(lessonId) : ''))`
를 한 번 부른다. `useEffect` + `AbortController`로 언마운트 시 취소한다. `complete-button.tsx`가 쓰는
`useOptimistic`/`useTransition`은 사용자 액션 트랜지션용이라 이 시나리오에 맞지 않는다 —
`useState`로 `{ status: 'loading' | 'ready' | 'error', data }` 3상태를 관리한다.

React Context로 `{ status, data, refresh }`를 노출하고 `useProgress()` 훅을 함께 export한다.
`refresh()`는 같은 fetch를 다시 실행한다 — 08-03의 완료 토글이 이 표면을 쓴다. 지금 만들어 둔다.

Provider 자신은 `<div data-progress-island data-progress-state={상태}>`로 children을 감싼다. 상태값은
`loading` / `ready` / `error` / `locked` 넷이다(`unlocked === false`면 `locked`, `ok === false`면 `error`).
이 훅이 `e2e-progress.mjs`가 수화 완료를 기다리는 신호가 된다.

`lib/supabase/admin`이나 `lib/progress-store`를 절대 import하지 않는다 — G2가 검사한다.

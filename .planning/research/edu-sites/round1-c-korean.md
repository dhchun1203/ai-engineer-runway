# Round 1-C: 한국 코딩 교육 (조사 원문, 2026-09-01)

조사 대상: 생활코딩, 인프런, 코드잇, 엘리스, 노마드코더, 프로그래머스, 백준/solved.ac

### 연속 학습 스트릭 + "프리즈"(용서 장치)
- 출처: solved.ac — 오전 6시 리셋 스트릭(잔디) + 재화로 사는 "스트릭 프리즈"
  (본체 403 — help.solved.ac + 나무위키/velog 교차, 프리즈 세부는 2차 출처).
- 왜 효과: 습관 연속성 + 손실 회피. 핵심은 프리즈 — 한 번 끊기면 전부 포기하는
  "what-the-hell 효과"를 용서 장치가 막는다. 제품 관행.
- 적용: 홈에 연속 학습일 표시(완료 타임스탬프로 계산). 프리즈는 "주 1회 휴식은 유지"
  규칙으로 단순화(재화 불필요).
- 규모: 반나절~1일 / 충돌: 없음

### 개념 제시 전 "질문입니다" 예측 프롬프트
- 출처: 생활코딩 WEB1 원시웹 레슨(https://opentutorials.org/course/3084/18889, 본문 확인) —
  "질문입니다. 인터넷과 웹은 같을까요? 다를까요?", "웹의 고향은 어디일까요? 맞혀 보세요"
  를 설명 전에 던지고 답 공개. 본문 중간 여러 번 반복.
- 왜 효과: 사전 시험 효과(pretesting) — 틀리더라도 먼저 예측하면 이어지는 설명의 정착이
  좋아진다. 호기심 갭. 우리 점검 문제는 사후, 이건 사전이라 역할이 다름.
- 적용: 3장 도입부에 접기 질문 1개 — "답을 먼저 찍어보세요". 파일럿 2~3편 먼저.
- 규모: 반나절(파일럿) / 전체 2~3일 / 충돌: 없음

### "이 수업이 끝나면 할 수 있는 것" — 선후행 지식지도
- 출처: 생활코딩/seomal — WEB1 페이지의 "수업이 끝나고 할 수 있는 것" + seomal.com
  지식지도 선후행 그래프 (본문 확인).
- 왜 효과: 선행 조직자 — 전체 지도의 어디에 있고 무엇을 열어주는지. "지도 없이 공부하는
  막막함"(생활코딩 표현) 감소.
- 적용: 6장 끝 "이 레슨이 열어주는 것" 한 줄 (frontmatter `unlocks`). 그래프 UI 불필요 —
  35편 관계 정의는 한 번이면 끝.
- 규모: 1일 / 충돌: 없음

### 완료 체크 시 "오늘 배운 것 한 줄" — TIL 회고 프롬프트
- 출처: 한국 TIL 문화 — "기억은 기록을 이길 수 없다"(github.com/namjunemy/TIL),
  "기록보다 돌아보는 행위가 핵심"(dal-lab.com/2019/09/18/today-i-learned).
- 왜 효과: 자유 회상 테스트 + 자기 설명 효과. 한국 학습자 관습으로 검증된 형식.
- 적용: 완료 체크 순간 "오늘 배운 것 한 줄?" 입력란(건너뛰기 가능) → 메모장 상단 TIL로
  저장(기존 테이블 재사용). 기존 메모장의 "명백히 더 잘하는 변형".
- 규모: 반나절~1일 / 충돌: 없음

### 코드를 보여주기 전 "먼저 스스로 설계" 단계
- 출처: 프로그래머스 — "Step 1: 강의 도움 없이 스스로 시도(통과 여부 중요치 않음) →
  Step 2: 해설" 명문화 (school.programmers.co.kr).
- 왜 효과: 생성 효과·생산적 실패. "통과 여부는 중요하지 않다"로 실패 부담 제거.
- 적용: 4장 코드 앞 한 문장 — "코드 보기 전 30초: 어떤 순서로 짜야 할지 머릿속으로.
  못 그려도 됩니다." 사고 실험이라 실행 제외 결정과 무충돌.
- 규모: 반나절 / 충돌: 없음

### 레슨 중간의 "여정 재정향" 내러티브
- 출처: 생활코딩 WEB1 중반 — "우리 수업은 두 개의 산으로… 방금 이 산을 멋지게 넘었습니다"
  (본문 확인). 숫자가 아니라 서사로 위치를 알림.
- 왜 효과: 서사적 이정표는 성취 회고 + 남은 구간의 구조 예고(목표 구배 + 인지 지도).
- 적용: 모듈 경계 레슨 ~10곳의 2장 첫 문단에 여정 문구 한두 문장.
- 규모: 반나절 / 충돌: 없음

### 용어 병기: 첫 등장 1회 "한글(원어)" 이후 한글 단독
- 출처: 생활코딩 — "월드 와이드 웹(world wide web)" 첫 등장만 병기, 이후 한글 (본문 확인).
- 왜 효과: 인지부하 관리 — 매번 병기는 무겁고, 무병기는 실무 문서(영어) 연결이 끊긴다.
- 적용: 컨벤션 명문화 — 본문 첫 등장 1회만 병기, 전량은 6장 용어 표 담당. 위반 레슨만 손봄.
- 규모: 반나절 / 충돌: 없음

## 사이트 한 줄 평
- 생활코딩: 최대 수확 — 사전 예측 질문·지식지도·여정 내러티브, "혼자 읽는 한국어 학습
  콘텐츠"의 원형 / solved.ac: 스트릭+프리즈, 자기 기록 게임화의 교과서 / 백준: 단계별
  풀기의 위계 배치 — 우리 커리큘럼 트리와 중복, 새 발견 없음 / 프로그래머스: "스스로
  먼저 → 해설" 명문화 / 노마드코더: cohort 압박이 핵심 — 1인용 변형이 기존 일정표+페이스와
  동일, 새 발견 없음 / 코드잇: 5분 마이크로 사이클 — 섹션 완료 체크는 효용 대비 과함,
  제외 / 인프런: 로드맵 큐레이션 — 학습 화면 자체의 배울 점 적음 / 엘리스: 이론→실습
  즉시 연결 + 자동 채점 — 둘 다 Out of Scope 충돌, 재제안 안 함

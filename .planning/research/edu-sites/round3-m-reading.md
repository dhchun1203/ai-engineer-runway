# Round 3-M: 읽기 경험·오프라인·인쇄 — 아이패드 관점 (2026-09-01)

코드베이스 사전 확인: 테마 토글 2단(light/dark, localStorage), manifest·apple-touch-icon
없음, skip link 없음, 메모는 Supabase(유실 위험 없음).

### 발견

1. **레슨 내부 "이어서 읽기"** (반나절) — VitalSource·Khan Resume. 우리 "오늘의 학습"은
   레슨 단위 재개만 — 레슨 **내부** 위치가 빠진 반쪽. 스크롤 위치(또는 마지막 지나친
   섹션)를 localStorage → 재방문 시 "○○ 섹션부터 이어서 읽기" 배너(자동 점프보다 안전).
2. **홈 화면 웹앱 등록** (반나절) — WebKit 공식: Safari는 7일 미방문 시 localStorage
   삭제하지만 **홈 화면 웹앱은 면제**. `app/manifest.ts` + 180px 아이콘 + standalone.
   매일 여는 습관 앵커 + 저장소 보호.
3. **오프라인 캐시** (2~3일) — 기술적으로 쉬우나(완전 정적) 시나리오가 집·학원
   와이파이면 체감 0. Supabase 부분 저하 처리가 숨은 비용. **후순위 판정.**
4. **다크 모드 3단(라이트/다크/자동)** (반나절) — Wikipedia Vector 2022 Appearance.
   **현행 2단의 실제 결함 발견: 한 번 토글하면 localStorage에 박혀 시스템 일몰 자동
   전환을 영구히 안 따라간다.** 자동 = 키 삭제로 구현. 글자 크기 조절은 iPad Safari
   "Aa"가 이미 하므로 만들지 않는 게 맞다고 판정.
5. **필기 여백 PDF** (반나절~1일) — GoodNotes 공식 블로그: 학생 표준 워크플로가 "PDF
   임포트 후 필기", 여백 부족이 실제 불편(피드백 포럼 확인). Cornell 템플릿 유통이 방증.
   기존 PDF 내보내기에 "필기 여백" 옵션 — print CSS 본문 폭 60~65% + 오른쪽 괘선 칼럼.
   생성 효과 + 큐 작성(회상 단서). **이 군집의 가장 독창적 발견.**
6. **접기 상태의 이중 규칙** (반나절) — GOV.UK 아코디언은 상태 기억이 표준이지만,
   **정답 접기는 반대다** — 펼침 복원되면 회상 연습이 죽는다. 정답 접기: 저장 금지 유지
   + "정답 모두 접기" 리셋 버튼. 탐색용 접기(있다면)만 상태 기억.
7. **Skip link + Safari Reader 호환** (반나절) — skip link 현재 없음. article+h1 시맨틱
   확인만 하면 Reader의 "듣기(오디오 복습)"·자체 글꼴 설정이 공짜로 열림.
8. 읽기 진행 바 — 조사했고 **낮게 판정** (효과 논쟁, 예상 시간 표시가 이미 있음).

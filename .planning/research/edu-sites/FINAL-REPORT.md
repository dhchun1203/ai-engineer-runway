# 최종 보고 — 코딩·개념 교육 사이트 전수 리서치 (2026-09-01)

**조사 규모**: 6라운드 · 조사원/판정관 17명 · 사이트·자료 약 90곳 · 후보 51건 + Round 6
세부 8건 · 반대 심문 3렌즈 전수 통과. 원문 18편이 이 디렉터리에 있다.

**종료 사유**: 포화 — Round 6에서 새 "능력" 차원 발견 0 (전부 기존 후보의 세부).
예산 소모 목표(잔여 50%) 대비 약 45% 시점.

**핵심 진단** (학습 효과 판정관): 이 사이트는 읽기·설명(레슨 35편+그림 115점)은 이미
상위권인데 **"기억" 장치가 0**이다. 그리고 후보 목록의 문제는 오답이 아니라 과밀 —
회상 연습 하나의 원리가 11개 껍데기로 흩어져 있어, 대표 구현(A2+A3)을 못 박는 것이
다른 무엇보다 중요하다.

## 2단 — 고려할 것 (개강 전, 조건·시기 명시)

- **/review 세션** (1.5일, **9/6 이후 적기** — 완료 레슨 12편+): 판정단 이견 지점.
  학습 효과 2위 vs 유지보수 반대(두 번째 마크다운 렌더러 부채). **권장 절충: 정답을
  세션 안에서 렌더하지 말고 질문만 표시 + 레슨 점검 섹션 앵커로 이동** — 렌더러 부채
  소멸. R6 세부: "안 남"은 내일 재예약(고스트), 전범위 랜덤 옵션, 2연속 실패 시 클로드
  과외 링크.
- **O/△/X 3단 판정 + 오답 모아보기** (1.5일): "맞았지만 불안" 중간 단계가 회독 문화의
  핵심. 조건: 문항 인덱스 키잉은 콘텐츠 편집마다 조용히 오염(게이트 불가) — 안정 키
  재설계 또는 부패 수용 명시. △ 기준 문구("한 군데라도 머뭇거렸으면 △") 상주.
- **/glossary 용어집** (0.5일): 3회 독립 수렴. L5 게이트 덕에 파싱 공짜(247용어 실측).
  다의어(회귀·상태)는 병합 금지 — 그룹 표시.
- **힌트 사다리** (0.5~1일, ① 뒤): 70문항 2단 접기. "방향만 한 줄" 규칙 필수(힌트가
  정답이면 인출 0).
- **빈칸 버전 예제 파일럿 3편** (0.5일): backward fading — C계열 근거 최강, 마크업 신규 0.
- **예측 프롬프트** (파일럿 0.5일): 사전 단계에 작동하는 유일 장치. 조건: 전량 승격
  계획 전제(의례 장치의 부분 적용은 유해 — 유지보수 판정).
- **반전(轉) 박스 + 안테피스 예고** (신규 R6, 미독 레슨부터): 저비용 콘텐츠 슬롯 2종.
  예고는 질문형만 — 답 언급 금지(스포일러 경고).
- **그림 규칙 편입** (진행 중 그림 개선 작업의 저작 규칙으로): 텍스트 밀도(위계 2단),
  색·모양 전역 의미 계약(+grep 게이트), 번호 읽기 경로 ①②③, 질문→도식 매핑(상태
  전이는 상태도). **은유 앵커 5~7점은 9/15 마감**(Step 3 읽기 전) — 한계 한 줄 필수.
- **완료 예측일** (0.5일): "지금 속도면 9/27 완주". 경고: 밀리면 낙담 신호로 반전 —
  ⑥과 짝, 문구 설계 주의.
- **TIL 한 줄 + 코넬 큐** (1일): 조건 — WR-01 미해결 컬럼에 문자열 결합 금지, **별도
  컬럼**으로. 문구는 "내 말로 한 문장으로 설명하면?".
- **홈 화면 manifest → 이어서 읽기** (각 0.5일, **이 순서로**): manifest가 없으면
  localStorage가 Safari 7일 정책에 증발.
- **내 노트 모아보기(단권화)** (0.5~1일, 9/20까지): 마지막 주 "모듈별 내 요약 만들기"
  슬롯과 세트. ★ 한 겹 압축.
- **궁금한 것 인박스** (1일): 곁가지 질문 전용 + 클로드 연결.
- **필기 여백 PDF** (0.5~1일): GoodNotes 임포트 습관이 실재하는지 사용자 확인 1개 선행.
- **skip link + Safari Reader 확인** (0.5일): Reader 열리면 "듣기" 오디오 복습 공짜.

**기회비용 판정관의 예산 지침**: 3일이면 1단의 ②③⑩ 중심, 5일이면 +/review, 7일이면
+판정 3단화·용어집·은유 앵커. **8일째부터는 어떤 후보도 "그 시간에 레슨 읽기"를 못
이긴다.** 2단 항목은 학습이 밀리지 않는 주에 틈새 편성.

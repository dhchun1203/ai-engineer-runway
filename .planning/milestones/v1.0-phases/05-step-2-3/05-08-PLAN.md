- **③ 개념 설명** — `### 무엇을 만드나 — 전체 구조` 소제목 아래 `문서 수집 → 청크 나누기 → 임베딩 → 벡터 저장소 → 질문 검색 → LLM 답변 + 근거 표시` 형태의 한 줄 도식(일반 텍스트, 화살표 문자만)과 표 하나. 표는 3열(`단계` / `하는 일` / `어느 레슨에서 나왔나`)로 여섯 행. 다이어그램 플러그인·이미지를 쓰지 않는다(D-48).

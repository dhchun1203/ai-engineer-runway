저장소 루트에 Next.js 16 App Router 프로젝트를 스캐폴드하고, Velite → rehype-pretty-code → MDXContent → `/lesson/[lessonId]` 한 줄기를 끝까지 연결한다. 계층별로 나누지 말고 이 한 줄기를 완성한 뒤 커밋한다.

**(1) 스캐폴드.** `npx create-next-app@latest`를 TypeScript / App Router / Tailwind / ESLint / `src/` 디렉터리 / import alias `@/*` 설정으로 실행한다. 저장소 루트에는 이미 `.planning/`, `.claude/`, `docs/`, `.git/`가 있어 create-next-app이 비어있지 않은 디렉터리를 거부하므로, 임시 하위 디렉터리(예: `.gsd-scaffold`)에 생성한 뒤 그 내용물을 점파일 포함해 루트로 옮기고 임시 디렉터리와 그 안의 `.git`을 제거한다. 플래그 이름이 다르면 `npx create-next-app@latest --help`로 확인해 대응한다. 결과 버전은 major가 일치하면 된다: next 16, react 19, tailwindcss 4.

**(2) 의존성 추가.** `velite`, `rehype-pretty-code`, `shiki`, `@rehype-pretty/transformers`, `lucide-react`를 dependencies로, `@tailwindcss/typography`를 devDependencies로 설치한다. Supabase 관련 패키지(`@supabase/ssr`, `@supabase/supabase-js`)는 이 Phase에서 설치하지 않는다 — 진도 저장은 Phase 2 범위다.

**(3) `next.config.ts`.** PATTERNS.md의 `next.config.ts` 발췌를 그대로 적용한다 — `process.argv`로 dev/build를 감지하고 `VELITE_STARTED` 환경변수 가드 뒤에서 `import('velite').then(m => m.build({ watch: isDev, clean: !isDev }))`를 top-level에서 호출한다. `VeliteWebpackPlugin`은 사용하지 않는다: Next 16의 기본 dev 번들러인 Turbopack에서 조용히 동작하지 않는다(RESEARCH Pitfall 1).

**(4) `velite.config.ts`.** `root: '.'`, `output.data: '.velite'`로 설정하고 `lessons` 컬렉션을 `pattern: 'src/content/lessons/**/*.mdx'`로 정의한다. 스키마 필드는 이 PLAN의 `<interfaces>` 블록과 정확히 일치시킨다(`title`, `stepId`, `moduleId`, `order`, `depth`는 `s.enum(['심화','개요'])`, `estimatedMinutes`는 `s.number().min(1)`, `slug`는 `s.slug('lessons')`, `hasContent`는 `s.boolean().default(true)`, `code`는 `s.mdx()`). MDX 옵션에 `rehypePrettyCode`를 rehype 플러그인으로 등록하고, 테마는 `{ dark: 'github-dark-dimmed', light: 'github-light' }`, transformers에는 `transformerCopyButton({ visibility: 'always', feedbackDuration: 3000 })`을 넣는다. `visibility`는 반드시 `always`다 — `hover`로 두면 hover 상태가 없는 주 사용 기기에서 복사 버튼에 도달할 수 없다(CONT-06, RESEARCH Pitfall 3).

**(5) `tsconfig.json`.** `compilerOptions.paths`에 `"#site/content": ["./.velite"]`를 추가한다.

**(6) `src/lib/fonts.ts` + 폰트 자산.** orioncactus/pretendard 릴리스에서 가변 폰트 `PretendardVariable.woff2`를 내려받아 `public/fonts/`에 둔다. `next/font/local`로 `variable: '--font-pretendard'`, `weight: '45 920'`, `display: 'swap'`으로 로드한다. 릴리스 자산 URL이 더 이상 해석되지 않으면 중단하고 사람에게 보고한다(RESEARCH Assumption A4).

**(7) `src/app/globals.css`.** `@import "tailwindcss";`, `@plugin "@tailwindcss/typography";`, `@custom-variant dark (&:where(.dark, .dark *));`를 선언한다. `@theme`에 UI-SPEC의 정확한 색값을 토큰으로 등록한다 — 배경 light `#F8FAFC` / dark `#0B1220`, 표면 light `#E7ECF3` / dark `#131B2E`, 전역 accent light `#0D9488` / dark `#2DD4BF`, destructive light `#DC2626` / dark `#F87171`, Step 1 `#3B82F6`/`#60A5FA`, Step 2 `#8B5CF6`/`#A78BFA`, Step 3 `#F59E0B`/`#FBBF24`, 개요 배지 중성색 light 텍스트 `#64748B`·배경 `#F1F5F9` / dark 텍스트 `#94A3B8`·배경 `#1E293B`. 타이포 토큰은 14/16/20/28px 4단계와 400/600 2웨이트만 등록한다(UI-SPEC Typography). `body`에 `word-break: keep-all; overflow-wrap: break-word;`를, `code, pre`에는 `font-family: ui-monospace, monospace;`를 지정해 코드가 한국어 본문 폰트를 상속하지 않게 한다(D-06). PATTERNS.md의 rehype-pretty-code 동반 CSS(`pre { overflow-x: auto; padding: 1rem 0; }`와 `code[data-theme*=" "]` 이중 테마 규칙)를 그대로 넣는다.

**(8) `src/app/layout.tsx`.** 이 Plan에서는 루트 레이아웃만 만든다 — `<html lang="ko">`에 Pretendard 폰트 변수 클래스, `globals.css` import, 그리고 하이드레이션 이전에 실행되는 인라인 테마 스크립트(`localStorage.theme`과 `matchMedia('(prefers-color-scheme: dark)')`를 읽어 `document.documentElement`에 `dark` 클래스를 토글)를 넣는다. ## Reversibility note — one-way 등급에 checkpoint:decision을 넣지 않은 이유

`verify plan-structure`는 one-way 등급이 붙은 태스크 앞에 `checkpoint:decision`이 없으면 경고를 낸다. Task 3에 대해 이 경고는 **의도된 상태**다.

`gsd-core/references/planner-reversibility.md`의 안티패턴 조항: *"Gating a decision already made — 위상 CONTEXT.md가 인간이 바로 그 선택지를 고른 것을 기록하고 있다면 문은 이미 통과한 것이다. 기록을 위해 등급은 유지하되, 다시 묻는 체크포인트를 넣지 말 것."*

이 Phase의 CONTEXT.md는 해당 선택을 세 곳에서 이미 확정했다 — D-14(저장소 공개), D-15(슬러그 `ai-engineer-runway`), D-02(공개 노출은 one-way). 따라서 등급은 기록용으로 유지하고, 되돌릴 수 없는 노출 자체는 체크포인트가 아니라 **푸시 직전 자동 스캔 게이트**(Task 3 verify의 브랜드 문자열·추적 파일 검사)로 통제한다. 같은 참조 문서의 권고 — *"문을 게이팅하기보다 되돌릴 수 있게 만들라"* — 를 여기서 적용할 수는 없으므로(공개 배포는 본질적으로 불가역), 차선책인 기계적 사전 차단을 택했다.

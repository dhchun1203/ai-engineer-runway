## 확정 설계 방향 (구현 대기)

### D-R4K-1 · 시그니처: 구간 테이프 (Section Tape)

상단 고정(sticky) 6칸 테이프. **칸 폭이 각 구간의 실제 렌더 높이에 비례** — 테이프가 스크롤
퍼센트가 아니라 그 레슨의 구조 지도가 된다. 현재 구간만 번호+제목 표시, 나머지는 무표시.
탭하면 해당 구간으로 이동.

근거:
- Step 1 레슨 10/10이 `1.학습 목표 / 2.왜 배우나 / 3.개념 설명 / 4.실무 예제 / 5.실무 팁 /
  6.핵심 정리 및 스스로 점검` 6단 척추를 예외 없이 따른다 (`grep '^## '` 측정).
- 번호 마커는 "내용이 실제로 순서일 때만" 정당한데 여기선 순서다.
- 사이트명이 이미 "Runway"인데 활주로 거리표식을 아무도 안 그렸다.

구현 메모:
- 구간 목록은 콘텐츠 파이프라인 변경 없이 마운트 후 DOM(`article h2`)에서 추출 → 35편 전체에
  자동 적용되고 Velite 스키마를 안 건드린다.
- 폭 = 다음 h2 `offsetTop` − 이 h2 `offsetTop`. `ResizeObserver`로 `<details>` 펼침 시 재계산.
- 높이 44px(터치 타깃)에 시각적 막대는 3px — 얇은 컨트롤로 44px를 확보하는 방법.
- 하이드레이션: 초기엔 균등 폭으로 렌더하고 effect에서 채운다.
- `hasContent: false` 레슨(h2 2개 미만)은 렌더하지 않는다.
- `.prose h2 { scroll-margin-top }` 필요 — 고정 테이프 아래로 숨지 않도록.
- 대안 기각: **좌측 세로 레일** — 768px에서 본문 measure를 28px 잡아먹고 가로 모드에서 무너진다.

### D-R4K-2 · 색: 새 색 0개, Step 색을 레슨 화면까지 확장

기존 18토큰은 양쪽 테마 AAA로 측정됐다(04-UI-REVIEW Pillar 3 = 4/4). **교체하지 않는다.**
테이프는 Step 색(1 `#3b82f6` / 2 `#8b5cf6` / 3 `#f59e0b`)을 입어 레슨이 어느 Step 소속인지
화면이 말하게 한다 — 이미 `/curriculum` 카드 레일이 쓰는 토큰이다.
청록 accent(`#0d9488`)는 상호작용·상태 전용으로 남긴다: 테이프에 accent를 쓰면 Step 1
파랑과 인접해 "청록 = 상호작용"이라는 기존 의미가 흐려진다.

### D-R4K-3 · 서체: 새 폰트 0개, mono를 계기판 목소리로 승격

Pretendard는 `weight: "45 920"` 가변인데 현재 400/600만 소비한다 → **700을 디스플레이로 사용**.
`ui-monospace`(이미 스택에 있음)를 구간 번호·소요시간·브레드크럼까지 확장 →
"본문 Pretendard / 계기 mono" 페어링.
한국어 디스플레이 서체를 새로 받지 않는다 — 가변 폰트 ~1MB에 얹는 추가 부담이
아이패드 읽기 사이트에서 정당화되지 않는다.

### D-R4K-4 · 타입 계약 재선언: 4종/2굵기 → 5종/3굵기

`01-UI-SPEC.md`의 "정확히 4종 / 2굵기"를 **의도적으로 개정**한다.
04-UI-REVIEW Pillar 4가 2/4인 실제 원인은 종수가 아니라 `@tailwindcss/typography`가 조용히
덮어써서 h2가 24/700로, 표 안 인라인 코드가 12.25px로 렌더된 것 — *선언되지 않은* 이탈이다.
측정값: 크기 `{28,24,20,16,14,12.25}px`, 굵기 `{400,600,700}`.

| 역할 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| display | 30px | 700 | 레슨 제목 (tracking -0.02em) |
| heading | 22px | 700 | h2 구간 제목 |
| subhead | 17px | 700 | h3 (크기 대신 굵기·여백·색으로 구분) |
| body | 16px | 400 | 본문 |
| label | 14px | 400/600 | 계기·표 셀·배지 |
| inline code | 15px (`0.9375rem` **절대값**) | 400 | rem이라 중첩해도 축소 불가 |

`prose` h1–h4를 위 값에 못 박아 플러그인 기본값이 새지 않게 한다.
→ **`01-UI-SPEC.md` Typography 표도 함께 갱신해야 한다.**

### D-R4K-5 · 인라인 코드: 리터럴 백틱 글리프 제거

`prose code::before/after { content: "`" }`가 `@tailwindcss/typography` 기본값 그대로다.
한 레슨에 58곳. 인라인 코드 배경이 완전 투명이라 백틱이 유일한 구분자인데, 한국어 본문에서
한글을 밀어낸다: `조건문(`if`/`elif`/`else`)은 …`
→ `::before/::after` 제거 + `--color-surface` / `--color-surface-dark` 배경 칩 + 좌우 padding.
(새 색 없음)

### D-R4K-6 · 표 가로 스크롤 래퍼

현재 모든 표가 우연히 들어맞지만(`scrollWidth === clientWidth`) 래퍼가 `overflow-x: visible`이라
Phase 5에서 넓은 표 하나가 페이지 전체를 가로로 민다.
→ MDX `table` 컴포넌트를 `overflow-x: auto` 래퍼로 오버라이드. `display: block`으로 때우지 말 것 —
열 너비 계산이 깨진다.

### D-R4K-7 · 페이저 이중 글리프 제거

`lesson-nav.tsx`가 Lucide chevron **과** 리터럴 `←`/`→`를 둘 다 렌더 → `‹ ← 이전 레슨`.
→ 라벨 문자열에서 리터럴 화살표만 삭제, chevron 유지.

### D-R4K-8 · `<main>` 랜드마크 + 잠금 상태 문구

- `/lesson/*`에 `<main>`이 없다(`/step/1`엔 있다) → VoiceOver "본문으로 건너뛰기" 불가.
- 잠금 해제 쿠키가 없으면 완료/진행률에 대한 **문구가 화면에 하나도 없다**
  (`완료|잠금|해제|unlock` 무매치). 이 프로젝트의 핵심 루프가 안 보인다.
  → 조용한 한 줄 추가. **링크는 걸지 않는다** — `/unlock`은 `?key=` 시크릿이 필요한
  `route.ts`라 링크가 동작하지 않는다.

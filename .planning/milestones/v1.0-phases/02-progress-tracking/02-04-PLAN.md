**`src/components/progress-summary.tsx`** — 서버 렌더 가능한 순수 표현 컴포넌트 `ProgressSummary`를 named export한다. 클라이언트 지시자를 붙이지 않는다. props는 `{ counts: ProgressCounts; nextLessonSlug: string | null }`. 데이터 조회를 이 컴포넌트 안에서 하지 않는다 — 값은 전부 홈 페이지가 계산해 넘긴다(Task 2).

세 가지 상태를 `counts`만 보고 판정한다.
  - `completed === 0` — UI-SPEC Copywriting Contract의 empty state 제목·본문을 쓴다. 큰 퍼센트 숫자를 강조하지 않는다: 0%를 28px accent로 크게 띄우는 것은 시작하려는 사람에게 줄 첫인상이 아니다. 진행률 바는 빈 트랙으로 렌더한다.
  - `0 < completed < total` — populated 제목과 `{완료}/{전체} 레슨 완료 · {percent}%` 본문을 쓴다. 큰 퍼센트 숫자를 Display 28px/600 accent 색으로 렌더한다.
  - `completed === total && total > 0` — all-complete 제목·본문을 쓴다.

공통 요소:
  - 진행률 바는 `step-card.tsx`의 마크업을 그대로 복제한다 — 같은 높이·라운드·트랙 색, `role="progressbar"`와 `aria-valuenow`/`aria-valuemin`/`aria-valuemax` 세 속성을 반드시 포함한다. 채움색은 전역 accent다(Step 카드와 달리 전체 진행률이므로 Step 상징 색을 쓰지 않는다 — UI-SPEC Color).

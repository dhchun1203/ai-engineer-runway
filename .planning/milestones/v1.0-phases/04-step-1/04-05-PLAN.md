<sql_safety_contract>
## 이 Plan의 SQL 안전 계약 (두 Task 공통, 어길 수 없음)

- 모든 예제는 `CREATE SCHEMA IF NOT EXISTS practice;` 로 시작하는 연습 스키마 안에서만 동작한다.
- 모든 테이블 이름은 `practice.` 접두사를 갖는다. 접두사 없는 벌거벗은 테이블 이름을 쓰지 않는다 — 접두사가 없으면 기본 스키마에 만들어지고, 그곳이 바로 이 사이트의 진도 데이터가 사는 곳이다.
- 사이트 진도가 저장된 테이블을 `FROM`·`JOIN`·`INSERT INTO`·`UPDATE`·`DELETE FROM`·`DROP TABLE`의 대상으로 삼지 않는다. 그 테이블은 "건드리면 안 되는 것"의 예로 산문에서 이름을 언급할 수는 있지만, 어떤 SQL 문의 대상도 되지 않는다.
- 각 레슨 마지막에 실습을 되돌리는 정리 SQL(연습 스키마를 통째로 지우는 문장)을 준다. 그 문장의 대상도 반드시 `practice`다.
- `DROP DATABASE`·`TRUNCATE`·`ALTER ROLE`·`GRANT` 계열은 쓰지 않는다.
</sql_safety_contract>
